[Mac OS X 版 Valgrind](http://sealiesoftware.com/valgrind/index.html)。

[Valgrind](http://valgrind.org/) 是一个开源的内存调试器。它能发现 Guard Malloc、MallocDebug 和 Instruments 都发现不了的问题。这个移植版不受官方支持，有 bug，也不完整，但它已经能在一些实际程序里找出一些实际的 bug 了。
