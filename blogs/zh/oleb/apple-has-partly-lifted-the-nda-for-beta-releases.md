# Apple 已（部分）解除 Beta 版本的 NDA

随着昨天在 WWDC 2014 上发布 iOS 8 和 OS X Yosemite 的 beta 版本，Apple 也更新了面向注册 iOS 和 Mac 开发者的法律协议。除其他变更外，Apple 在 [iOS Developer Program License Agreement](https://developer.apple.com/programs/terms/ios/standard/ios_program_standard_agreement_20140602.pdf) 的“10.1 被视为 Apple 保密信息的信息”一节中添加了以下句子：

> 此外，Apple 同意，对于 Apple 在 WWDC（Apple 全球开发者大会）上披露的关于预发布 Apple 软件与服务的技术信息，你将不受上述保密条款约束，但你不能发布屏幕截图、撰写公开评论或重新分发任何预发布 Apple 软件或服务。

我不是律师，但如果我的理解正确，这意味着操作系统和 SDK 的 beta 版本仍受 NDA 约束，但 Apple 允许开发者在公开场合讨论已在 WWDC 上介绍的新 API 和功能。这应该涵盖 iOS 8、Yosemite 和开发者工具中几乎所有的新内容。

我们仍然不能发布屏幕截图（传闻网站无论如何都会这样做），而且我不确定什么样才算“公开评论”。是我不能发表对新 API 的看法，还是这仅仅是为了防止在公开发布前对整个操作系统进行完整的评论？无论如何，这肯定比以前好。
