# Playground: What’s new in Swift 4.2

I made an Xcode playground to showcase many of the new features coming in Swift 4.2, like I did [last year for Swift 4.0](https://oleb.net/blog/2017/05/whats-new-in-swift-4-playground/). You can [download it on GitHub](https://github.com/ole/whats-new-in-swift-4-2).

The easiest way to run the playground is to [install the most recent beta version of Xcode 10](https://developer.apple.com/download/) (which ships with Swift 4.2). You can also run it in Xcode 9.4, but that requires installing a recent [Swift 4.2 snapshot](https://swift.org/download/#snapshots).
