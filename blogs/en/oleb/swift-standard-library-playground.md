# Swift Standard Library.playground

Apple has already posted the [sample code for WWDC 2015](https://developer.apple.com/sample-code/wwdc/2015/), and one of the sample projects is a [playground about the Swift Standard Library](https://developer.apple.com/sample-code/swift/downloads/Standard-Library.zip).

![](https://oleb.net/media/swift-standard-library-playground.png)

The playground covers two of the most important topics in the standard library:

- strings are different in Swift

  )
- Sequences and collections (including a very helpful implementation of a custom collection type)

It’s a great addition to [Apple’s Swift book](https://developer.apple.com/library/prerelease/ios/documentation/Swift/Conceptual/Swift_Programming_Language/index.html) because you can play around with the code and the explanations in the playground are more extensive than in the book. It “only” covers the standard library, however, so language features like the new `try/catch` error handling syntax are not included.

The playground requires Xcode 7. To see the page structure, make sure to show the Project Navigator. And if you’re seeing the raw documentation comments, choose `Editor > Show Rendered Markup` to switch to the formatted view.
