# iOS Development Highlights: July 2010

Unlike myself, the iOS developer community has been quite active posting great content this month. Here are some of the things I found most interesting from across the blogosphere:

- possiblity of Apple replacing Objective-C with a new platform

  based on an abstracted memory model. In a series of posts (

  Surpass

  ,

  Not Replaced

  ,

  Objective Dash

  ) Jesper explored a similar path, and finally Matt Gallagher chimed in:

  Is a virtual machine for Cocoa programming inevitable?

  All of these posts are very interesting reads. I certainly hope that Apple is working on leaving Objective-C’s C legacy behind.
