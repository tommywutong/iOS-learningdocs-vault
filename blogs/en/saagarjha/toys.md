# Toys

Random expriments that may or may not work.

## Nvidia SASS Tools  [GitHub](https://github.com/saagarjha/nvidia-sass-tools)

Tools for working with Nvidia's SASS code, largely generated by pointing an LLM at the internal architecture specification that ships in the SDK.

## Compiler Explorer  [Website](https://saagarjha.com/toys/godbolt)

Extrememly simple frontend for the [Compiler Explorer](https://godbolt.org) [API](https://github.com/compiler-explorer/compiler-explorer/blob/main/docs/API.md).

## Address Finder  [Website](https://saagarjha.com/toys/address-finder)

Quickly locate an address in a list of memory regions.

## Crank Player  [GitHub](https://github.com/saagarjha/CrankPlayer)

Plays videos on your [Panic](https://panic.com) [Playdate](https://play.date) if you turn the crank.

## TSOEnabler  [GitHub](https://github.com/saagarjha/TSOEnabler)

A kernel extension that enables total store ordering (TSO) on Apple silicon through a userspace-accessible sysctl. This internally sets the same flag that [Rosetta 2](https://en.wikipedia.org/wiki/Rosetta_(software)#Rosetta_2) uses.

## dummy_thicc  [GitHub](https://github.com/saagarjha/dummy_thicc)

An attempt at the fattest verified Mach-O in existence.

## Complicated  [GitHub](https://github.com/saagarjha/Complicated)

watchOS widgets for stocks and weather using (some) reverse-engineered Apple APIs.

## expresscall  [Blog Post](https://saagarjha.com/blog/2019/12/15/bypassing-objc-msgsend/) [GitHub](https://github.com/saagarjha/expresscall)

LLVM fork that patches Clang to speculatively inline [objc_msgSend](https://developer.apple.com/documentation/objectivec/1456712-objc_msgsend) calls, making them at least two times faster in most cases. Requires zero source code modifications and is fully compatible with Objective-C's dynamic features.

## DerivedDataDeleter  [GitHub](https://github.com/saagarjha/DerivedDataDeleter)

Xcode Source Editor Extension to delete the DerivedData folder.

## Apple Open Source Mirror  [GitHub](https://github.com/apple-open-source-mirror)

Python scripts that scrape the [Apple Open Source website](https://opensource.apple.com) for project tarballs and convert them into Git repositories, with best-effort correlation of project build numbers with OS releases and dates.

## DarkNight  [GitHub](https://github.com/saagarjha/DarkNight)

Launch agent that synchronizes dark mode on macOS with the activation of Night Shift, using reverse-engineered APIs from the CoreBrightness and SkyLight frameworks. Also allows for running a script to "complete" the transition for apps that don't use the system appearance API or have not linked with the macOS Mojave SDK.

## elevate  [GitHub](https://github.com/saagarjha/elevate)

Small but generic header-only C++11 library that provides useful extensions to the C++ Standard Library, providing templated implementations of common constructs such as comparison operators, primality and parity checking, pretty printing, additional functional algorithms, and polyfills for newer API such as ranges and type traits.

## vers  [GitHub](https://github.com/saagarjha/vers)

Prints software version and hardware configuration information in a particular format, taken from a variety of private data sources, for easy pasting into Apple's Bug Reporter.

## GenerateAppIcons  [GitHub](https://github.com/saagarjha/GenerateAppIcons)

A command line tool to generate app icon sets for the App Store. Supports pretty much any combination of iPhone, iPad, macOS, and Apple Watch icons, including image sizes from older versions of iOS.

## Details Viewer  [GitHub](https://github.com/saagarjha/DetailsViewer)

Originally a macOS Mail plugin (~~written in Swift, so beware!~~ just run-of-the-mill swizzling concerns now that ABI stability is here) to show extra details, but is now approaching a state where it's a dumping ground of random things I wish Mail did. Currently auto-expands the "Details" button in messages (hence the name), and adds tooltips to messages in the list view.
