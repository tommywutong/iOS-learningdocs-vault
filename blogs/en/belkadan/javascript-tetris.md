## [JavaScript Tetris](#)

Introducing an under-ten-hours project for the Flash-deprived: [JavaScript Tetris](http://belkadan.com/tetris)!

Trigger: suggesting turning off a friend’s Flash to make her more productive, then relenting a little. Heh.

Now, this isn’t the best-written piece of JavaScript, not by a long shot. (For starters, the rotation code should be a lot more data-directed.) But it’s definitely working code, a working copy of Tetris. And really, I wrote a Tetris now. Isn’t that one of those activities every hacker should try at some point?

Maybe.

Separately, I need to post here more, but I haven’t gotten to work on anything Cocoa recently at all. I apologize to anyone waiting for Dockyard, which has no real release date right now.

[Mike Ash](http://www.mikeash.com/?page=pyblog/) had a good idea: post something every week. I don’t know if I can maintain that frequency, but maybe I’ll try for biweekly?

If another post appears here within two weeks, the answer is “yes”.
