# SDWebImage 首页

本页包含 SDWebImage 及其相关项目的文档。

## [概述](https://sdwebimage.github.io/documentation/home/#Overview)

SDWebImage 包含可组合且可扩展的框架，专注于为 Apple 的 UI Framework（AppKit/UIKit/SwiftUI）集成提供易于使用且全栈式的图片加载解决方案（包括下载、缓存、编解码、动画等）。
