# HomeKit Changes for Objective-C

### HomeKit

#### HMAccessoryCategoryTypes.h

Added [HMAccessoryCategoryTypeRangeExtender](https://developer.apple.com/documentation/homekit/hmaccessorycategorytyperangeextender)

#### HMCharacteristicMetadata.h

Added [HMCharacteristicMetadataUnitsLux](https://developer.apple.com/documentation/homekit/hmcharacteristicmetadataunitslux)

#### HMCharacteristicTypes.h

Added [HMCharacteristicPropertyHidden](https://developer.apple.com/documentation/homekit/hmcharacteristicpropertyhidden)

#### HMError.h

Added [HMErrorCodeReferToUserManual](https://developer.apple.com/documentation/homekit/hmerrorcode/hmerrorcoderefertousermanual)
