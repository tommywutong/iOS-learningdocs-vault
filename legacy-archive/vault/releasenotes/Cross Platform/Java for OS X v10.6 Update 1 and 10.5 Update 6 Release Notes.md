# Introduction

These release notes provide information concerning known and resolved issues that may affect developers creating Java applications for OS X with Java for OS X v10.6 Update 1 and Java for OS X v10.5 Update 6.

Java for OS X v10.6 Update 1 delivers improved reliability, security, and compatibility for Java SE 6. Java for OS X v10.6 Update 1 supersedes the previous Java for OS X v10.6.

This release updates Java SE 6 to version 1.6.0_17.

This release is only for OS X v10.6.2 or later versions of OS X v10.6.

This release of Java SE 6 is available on Intel-based Macs only.

Java for OS X v10.5 Update 6 delivers improved reliability, security, and compatibility for J2SE 5.0 and Java SE 6. Java for OS X v10.5 Update 6 supersedes all previous updates of Java for OS X v10.5.

This release updates J2SE 5.0 to 1.5.0_22, and updates Java SE 6 to 1.6.0_17.

J2SE 1.4.2 is no longer being updated to fix bugs or security issues and is therefore disabled by default in this update.

This release is only for OS X v10.5.8 or later versions of OS X v10.5. This release of J2SE 5.0 supports all Intel and PowerPC-based Macs. Java SE 6 is available on 64-bit Intel-based Macs only.

Any developer who wants to develop Java applications on OS X v10.6 or OS X v10.5 should read this document as various issues and fixes found in this release may affect your application.

This document contains the following chapters:

- [New and Noteworthy](https://developer.apple.com/library/archive/releasenotes/CrossPlatform/JavaSnowLeopardUpdate1LeopardUpdate6RN/NewandNoteworthy/NewandNoteworthy.html#//apple_ref/doc/uid/TP40009400-CH4-SW1) lists high-profile features in these releases.
- [Known and Resolved Issues](https://developer.apple.com/library/archive/releasenotes/CrossPlatform/JavaSnowLeopardUpdate1LeopardUpdate6RN/ResolvedIssues/ResolvedIssues.html#//apple_ref/doc/uid/TP40009400-CH3-SW1) highlights a selection of high-visibility bugs that have been addressed in these releases. This chapter is broken down by the category where the bug occurs and provides a brief description of what the issue was and how it was resolved.

This document also contains a revision history.
