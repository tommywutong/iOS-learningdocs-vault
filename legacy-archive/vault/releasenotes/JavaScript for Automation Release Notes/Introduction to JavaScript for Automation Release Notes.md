# Introduction to JavaScript for Automation Release Notes

JavaScript for Automation provides the ability to use JavaScript for interapplication communication between apps in OS X.

This document describes significant changes to JavaScript for Automation (JXA) and related tools in OS X.

This document includes the following articles:

- [OS X 10.11 Release Notes](OS%20X%2010.11%20Release%20Notes.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2dkmbyfvbuqmjrgawvgvzr) describes the JavaScript for Automation changes that were introduced in OS X v10.11.
- [OS X 10.10 Release Notes](OS%20X%2010.10%20Release%20Notes.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2dkmbyfvbuqmjqhewvgvzr) describes the JavaScript for Automation changes that were introduced in OS X v10.10.
