# Introduction

These release notes provide information concerning known and resolved issues that may affect developers creating Java applications for Java for OS X 2012-006 and Java for OS X v10.6 Update 11.

Java for OS X 2012-006 delivers improved security, reliability, and compatibility by updating Java SE 6 to 1.6.0_37.

This update uninstalls the Apple-provided Java applet plug-in from all web browsers. To use applets on a web page, click on the region labeled “Missing Plug-in” to go download the latest version of the Java applet plug-in from Oracle.

The update also contains additional changes to Java application and command-line behavior which may be relevant to your application or development environment.

Java for OS X v10.6 Update 11 delivers improved security, reliability, and compatibility by updating Java SE 6 to 1.6.0_37.

On systems that have not already installed Java for OS X v10.6 update 9 or later, this update configures web browsers not to automatically run Java applets. Java applets may be re-enabled by clicking the region labeled “Inactive Plug-in” on a web page. If no applets have been run for an extended period of time, the Java web plug-in deactivates.

Any developer who develops or deploys Java applications on OS X v10.8, v10.7, or v10.6 should read this document as various behavior changes and fixes found in this release may affect your application.
