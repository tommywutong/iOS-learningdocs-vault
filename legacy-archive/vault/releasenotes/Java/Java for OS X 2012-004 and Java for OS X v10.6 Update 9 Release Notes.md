# Introduction

These release notes provide information concerning known and resolved issues that may affect developers creating Java applications for Java for OS X 2012-004 and Java for OS X v10.6 Update 9.

Java for OS X 2012-004 delivers improved security, reliability, and compatibility by updating Java SE 6 to 1.6.0_33.

Java for OS X v10.6 Update 9 delivers improved security, reliability, and compatibility by updating Java SE 6 to 1.6.0_33.

Any developer who wants to develop Java applications on OS X 10.7 or OS X v10.6 should read this document as various issues and fixes found in this release may affect your application.

This document contains the following chapters:

- [New and Noteworthy](https://developer.apple.com/library/archive/releasenotes/Java/Java_OSX2012001Java_MacOSX10.6Update7RN/NewandNoteworthy/NewandNoteworthy.html#//apple_ref/doc/uid/TP40012146-CH2-SW1) lists high-profile features in these releases.
- [Known and Resolved Issues](https://developer.apple.com/library/archive/releasenotes/Java/Java_OSX2012001Java_MacOSX10.6Update7RN/KnownAndResolvedIssues/KnownAndResolvedIssues.html#//apple_ref/doc/uid/TP40012146-CH3-SW1) highlights a selection of high-visibility bugs that have been addressed in these releases. This chapter is broken down by the category where the bug occurs and provides a brief description of what the issue was and how it was resolved.

This document also contains a revision history.
