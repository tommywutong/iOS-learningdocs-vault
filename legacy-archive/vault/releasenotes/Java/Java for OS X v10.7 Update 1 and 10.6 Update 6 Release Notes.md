# Introduction

These release notes provide information concerning known and resolved issues that may affect developers creating Java applications for OS X with Java for OS X v10.7 Update 1 and Java for OS X v10.6 Update 6.

Java for OS X v10.7 Update 1 delivers improved compatibility, security, and reliability by updating Java SE 6 to 1.6.0_29.

Java for OS X v10.6 Update 6 delivers improved compatibility, security, and reliability by updating Java SE 6 to 1.6.0_29.

Any developer who wants to develop Java applications on OS X v10.7 or OS X v10.6 should read this document as various issues and fixes found in this release may affect your application.

This document contains the following chapters:

- [New and Noteworthy](https://developer.apple.com/library/archive/releasenotes/Java/JavaLionUpdate1SnowLeopardUpdate6RN/NewandNoteworthy/NewandNoteworthy.html#//apple_ref/doc/uid/TP40011337-CH4-SW1) lists high-profile features in these releases.
- [Known and Resolved Issues](https://developer.apple.com/library/archive/releasenotes/Java/JavaLionUpdate1SnowLeopardUpdate6RN/ResolvedIssues/ResolvedIssues.html#//apple_ref/doc/uid/TP40011337-CH3-SW1) highlights a selection of high-visibility bugs that have been addressed in these releases. This chapter is broken down by the category where the bug occurs and provides a brief description of what the issue was and how it was resolved.

This document also contains a revision history.
