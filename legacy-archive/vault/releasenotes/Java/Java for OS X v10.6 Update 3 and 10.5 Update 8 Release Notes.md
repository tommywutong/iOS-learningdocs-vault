# Introduction

These release notes provide information concerning known and resolved issues that may affect developers creating Java applications for OS X with Java for OS X v10.6 Update 3 and Java for OS X v10.5 Update 8.

Java for OS X v10.6 Update 3 delivers improved compatibility, security, and reliability by updating Java SE 6 to 1.6.0_22.

Java for OS X v10.5 Update 8 delivers improved compatibility, security, and reliability by updating J2SE 5.0 to 1.5.0_26, and updating Java SE 6 to 1.6.0_22 for 64-bit capable Intel-based Macs. J2SE 1.4.2 is no longer being updated to fix bugs or security issues and remains disabled by default in this update.

Any developer who wants to develop Java applications on OS X v10.6 or OS X v10.5 should read this document as various issues and fixes found in this release may affect your application.

This document contains the following chapters:

- [New and Noteworthy](https://developer.apple.com/library/archive/releasenotes/Java/JavaSnowLeopardUpdate3LeopardUpdate8RN/NewandNoteworthy/NewandNoteworthy.html#//apple_ref/doc/uid/TP40010380-CH4-SW1) lists high-profile features in these releases.
- [Known and Resolved Issues](https://developer.apple.com/library/archive/releasenotes/Java/JavaSnowLeopardUpdate3LeopardUpdate8RN/ResolvedIssues/ResolvedIssues.html#//apple_ref/doc/uid/TP40010380-CH3-SW1) highlights a selection of high-visibility bugs that have been addressed in these releases. This chapter is broken down by the category where the bug occurs and provides a brief description of what the issue was and how it was resolved.

This document also contains a revision history.
