# Introduction

These release notes provide information concerning known and resolved issues that may affect developers creating Java applications for Java for OS X 2013-001 and Java for OS X v10.6 Update 13.

Java for OS X 2013-001 delivers improved security, reliability, and compatibility by updating Java SE 6 to 1.6.0_41.

Java for Mac OS X 10.6 Update 13 delivers improved security, reliability, and compatibility by updating Java SE 6 to 1.6.0_41.

Any developer who develops or deploys Java applications on OS X v10.8, v10.7, or v10.6 should read this document as various behavior changes and fixes found in this release may affect your application.

This document contains the following chapter:

- [Known and Resolved Issues](https://developer.apple.com/library/archive/releasenotes/Java/Java_OSX2013001Java_MacOSX10.6Update13RN/KnownAndResolvedIssues/KnownAndResolvedIssues.html#//apple_ref/doc/uid/TP40013110-CH2-SW1) highlights a selection of high-visibility bugs that have been addressed in these releases. This chapter is broken down by the category where the bug occurs and provides a brief description of what the issue was and how it was resolved.

This document also contains a revision history.
