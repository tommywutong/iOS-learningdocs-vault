# Introduction to Java for OS X v10.4, Release 7 Release Notes

These release notes provide information concerning known and resolved issues that may affect developers creating Java applications for OS X with Java for OS X v10.4, Release 7.

Java for OS X v10.4, Release 7 updates J2SE 5.0 and J2SE 1.4.2 to versions 1.5.0_16 and 1.4.2_18, respectively, on all Intel-based and PowerPC-based Macs. This release is only for OS X v10.4.11 and later, and should not be installed on earlier versions of OS X or OS X v10.5 Leopard.

Any developer who wants to develop Java applications on OS X v10.4 should read this document as various issues and fixes found in this release may affect your application.

This document contains the following chapter:

- [Known and Resolved Issues](https://developer.apple.com/library/archive/releasenotes/Java/JavaTigerUpdate7RN/ResolvedIssues/ResolvedIssues.html#//apple_ref/doc/uid/TP40008012-CH3-SW1) highlights a selection of high-visibility bugs that have been addressed in this release. This chapter is broken down by the category where the bug occurs and provides a brief description of what the issue was and how it was resolved.

This document also contains a revision history.
