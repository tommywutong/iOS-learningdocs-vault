# Switching Branches

Switch to another branch of a repository to work on a different line of code development or to prepare for a branch merge.

![bullet](../../_unindexed/Resources/1282/Images/task_2x.png)To switch branches

1. In the navigation pane of the repositories organizer, click the working copy folder for the repository.
2. Click the Switch Branch button at the bottom of the Organizer window.
3. In the Select a Branch dialog, choose the branch you want to use from the pop-up menu.
4. Click OK to confirm the switch.

   The video shows switching from the `Henchley_01` branch to the `Cardiff_02` branch of the `Sketch svn_M` repository.

When the working copy of a branch is selected in the navigation pane, the name and location of the current branch display at the top of the organizer pane. When the switching operation is successful, this designation updates to reflect the new current branch.
