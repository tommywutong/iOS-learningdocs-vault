| Q Why can't I create a Linked VR movie with links only (I don't want hot spots)?   A To create a Linked VR movie without the hot spots, set the composited hotspot directory in the Scene editor to the Link Hot Spot Picts directory, and set the file extension to .linkPict.   [Jun 01 1995] |
