| Q When I move an object around on the screen, it leaves trails, as if the screen is not being refreshed completely. Changing the type of QuickTime compression used on the source movie does not have any effect on the problem. What would cause this?   A The player is rewriting the new frame without erasing the old one, thus leaving a trail. To eliminate this problem, set key frames to every 1 frame.   [Jun 01 1995] |
