| ---   Q: How do I check if the OpenTransport IP protocol stack is loaded or not?  A: OpenTransport provides the option to delay the complete loading of the protocol stack. This reduces the use of system memory for the IP protocol stack until a TCP/IP application is launched. To check whether the stack is loaded, call `OTInetGetInterfaceInfo()`. If it returns an IP address, the stack is loaded. If the returned address is zero or the call fails, the stack is not yet loaded. The call to `OTInetGetInterfaceInfo()` does not force the load of the IP stack. |
