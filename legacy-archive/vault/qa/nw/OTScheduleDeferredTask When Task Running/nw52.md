| ---   Q: What happens when you use `OTScheduleDeferredTask` to schedule a task that is running?  A: The "Open Transport Client Note" mentions that `OTScheduleDeferredTask` returns false when you attempt to schedule a task that is already scheduled, but it doesn't say anything about what happens if the task is running. It turns out that a task that is running is not consider to be scheduled, so `OTScheduleDeferredTask` will successfully reschedule it. |
