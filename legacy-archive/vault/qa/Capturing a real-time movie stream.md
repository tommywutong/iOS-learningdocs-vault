# Capturing a real-time movie stream

## Q:  My QuickTime application can successfully play movies that are streamed real-time over RTP (Realtime Transport Protocol). However, I'd like to be able to save both the audio and video from these streams. Is this possible?

A: My QuickTime application can successfully play movies that are streamed real-time over RTP (Realtime Transport Protocol). However, I'd like to be able to save both the audio and video from these streams. Is this possible?

No. There is no QuickTime API support for capturing a real-time movie stream.
