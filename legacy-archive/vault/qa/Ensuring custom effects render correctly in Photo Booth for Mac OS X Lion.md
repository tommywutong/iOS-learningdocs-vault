# Ensuring custom effects render correctly in Photo Booth for Mac OS X Lion

## Q:  How can I ensure my custom effect will render correctly in Photo Booth on Mac OS X Lion?

A: To ensure that your custom effect will render correctly in Photo Booth on Mac OS X Lion the following requirements must be met:

- Do not make assumptions about the aspect ratio or dimensions of the input image. These values are not guaranteed to be constant.
- Do not make assumptions about the aspect ratio or dimensions of the preview input image. These values are not guaranteed to be constant.
