| Technical Q&A QD09Suppressing the LaserWriter 8.3 Manual Feed Alert |

|  |
| --- |
| ---   Q: What happened to the Preferences that you could set with earlier PrintMonitor implementations (prior to LaserWriter 8.3)? When I manually feed the LaserWriter sitting next to me, I know when it's ready to be fed, and I don't need the 8.3 Finder alert 3 to tell me this. Because of the Finder alert, I have to navigate back to the Finder, press OK, and then navigate back to my application.  A: There was a concern with suppressing the manual-feed alert in GX 1.0 printing. This was fixed in GX 1.1, and since the LaserWriter 8 Desktop Printer code is based on the GX code, we should be able to easily fix this in a future release. |
