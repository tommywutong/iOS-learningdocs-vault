| ---   Q: I've tried in vain to find a way to show white text on a black background. Is there a way to do this, and if so, how?  A: The trick is to use the `srcBic` pen mode:   |  | | --- | | ``` 	FillRect(theRect, black);  	PenMode(srcBic);  	DrawString(myString); ``` |   Note that this technique is for on-screen viewing, not for printing to a PostScript printer. |
