|  |
| --- |
| ---   Q: I just noticed that with LaserWriter 8.4.x, custom page sizes no longer seem to work with our PPDs. This worked fine with 8.3.4. Do we need to change something in our PPDs, or is this just broken in the driver?  A: With the release of LaserWriter 8.4, Apple temporarily removed support for custom page sizes. We have redesigned/rearchitected this support and will release it with LaserWriter 8.5.1 in late summer 1997. In the meantime, your users need to use the LaserWriter 8.3.4 driver to get custom page size support. Updated: 22-May-97 |
