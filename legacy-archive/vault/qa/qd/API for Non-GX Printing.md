| Technical Q&A QD29API for Non-GX Printing? |

|  |
| --- |
| ---   Q: We would like to incorporate non-GX printer technology in our line of print drivers. Is there, or will there be, an API we can follow to gain compatibility with Desktop Printing? If not, do you have any suggestions of how to obtain this functionality while minimally impacting the stability of the Mac OS?  A: Currently, there is no support for third party desktop printing in the Mac OS. In the past, Apple has maintained that it would not release the non-GX Desktop Printing APIs; however, we recently documented the specification [here](https://developer.apple.com/library/archive/technotes/tn/tn1097.html). We expect Finder support for third party desktop printing to be made available in a future release of the Mac OS (post Mac OS 8.1).  Please continue to watch our [Developer Web site](https://developer.apple.com/) for Technotes and further information on this topic. |
