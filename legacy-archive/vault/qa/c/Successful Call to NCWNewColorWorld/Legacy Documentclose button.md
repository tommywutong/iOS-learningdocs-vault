| ---   Q: Can I assume that the value of the ColorSync `CMWorldRef` parameter returned by the `NCWNewColorWorld` routine isn't null if the routine was successful? I'd like to determine whether a color world exists before trying to use it.  A: You can assume that if no error is returned, the `CMWorldRef` parameter will be valid. |
