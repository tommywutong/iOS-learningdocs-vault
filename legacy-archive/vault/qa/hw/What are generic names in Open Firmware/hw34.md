| ---   Q: What are generic names in Open Firmware?  A: Generic names are part of the Open Firmware Recommended Practices. For a list of these names see: [http://playground.sun.com/1275/practice/#gnames](http://playground.sun.com/1275/practice/#gnames). The Standard provides for these generic names to replace implementation specific names with human-readable names. For instance, the name of the PCI bridge controller on the 9500 is "bandit." The generic name for this type of controller is now "PCI." |
