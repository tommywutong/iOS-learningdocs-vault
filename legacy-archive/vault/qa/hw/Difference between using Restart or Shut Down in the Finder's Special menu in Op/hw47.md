| ---   Q: With respect to Open Firmware, is there any difference between using Restart or Shut Down in the Finder's Special menu?  A: No. Open Firmware behaves the same way, but POST (power on self test) is not completely retested. However, be aware that there is no requirement that states any different behavior between Restart and Shut Down. |
