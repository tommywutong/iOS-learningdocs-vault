| ---   Q: What are the Driver Services Library (`DriverServicesLib`) and the Multiprocessing Nanokernel (`MPLibrary`)? Which Apple Macintosh models do and do not support them?  A: These two libraries provide much of low-level services and functionality available to driver and application developers. Driver Services Library controls the support of functions enumerated in "DriverServices.h" and described in "[Designing PCI Cards and Drivers for Power Macintosh Computers](https://developer.apple.com/documentation/hardware/DeviceManagers/pci_srvcs/pci_cards_drivers/Designing_PCI_Cards_Drivers.pdf)." The MP Nanokernel provides low-level process control, timing services, and memory services as described in "[Adding Multitasking Capability to Applications Using Multiprocessing Services](https://developer.apple.com/documentation/macos8/OSSvcs/MultiPServices/MultiprocessingRef/index.html)."  The following chart indicates whether Driver Services Library (DSL) and the MP Nanokernel is present in a specified machine family. All listings refer to the entire machine family unless otherwise noted.   | Machine Family | DSL | MP Nanokernel | | --- | --- | --- | | 68K Machines  (including those with PowerPC upgrade cards) | No | No | | PowerMac 5200, 5300, 6100, 7100, 8100 Performa 5200, 5300, 6300, 6300 (excluding 6360) | No | After Mac OS 8.6 | | PowerBook 5300, 2300, 1400 | No | Mac OS 8.6 and later | | PowerMac 4400, 5400, 5500, 6400, 6500, later  7200, 7300, 7500, 7600, 8500, 8600, 9500, 9600, G3  Performa 5400, 6360, 6400  Twentieth Anniversary Macintosh  PowerBook 2400, 3400, G3 iMac Future Machines | Yes | Mac OS 8.6 and later | |
