|  __Q:__ What are the versions of Navigation Services, and with which versions of the OS are they compatible?  __A:__ The best way to answer these questions is with a table:   |  |  |  | | --- | --- | --- | | __Compatible  system__ | __Navigation Services  version__ | __Version of Appearance  API required__ | | System 7.5.5  and  Mac OS 7.6.1 | 1.0 | 1.0.1 or greater | | Mac OS 8.0 and 8.1 | 1.0 | 1.0.1 or greater | | Mac OS 8.5 | 1.1 | (n/a) |   Navigation Services 1.0 is available in SDK form and is a shared library installed into the Extensions folder.
