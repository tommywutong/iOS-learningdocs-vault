|  Q: Where can I find documentation on the QuickDraw 3D Meta File (3DMF) format?  A: You can find complete documentation in the following places:   - on the Mac OS SDK CD-ROM - on the Reference Library developer CD - on the CD that comes with the book _3D Graphics Programming with QuickDraw 3D_, Addison Wesley - on the [Technical Publications web site](https://developer.apple.com/documentation/quicktime/qtdevdocs/QD3D/qd3d_book.htm)   In addition to traditional documentation, Apple has also produced a FileMaker Pro database that details 3DMF format very specifically. You can also download the source code for a public domain 3DMF parser from the sources listed above. |
