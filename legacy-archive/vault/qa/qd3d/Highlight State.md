|  Q: What is the highlight state?  A: The highlight state determines whether to draw using the highlight color or the actual color of an object. The highlight state is stored as attribute of type `kQ3AttributeTypeHighlightState`, which is a `TQ3Boolean`.  If the hightlight state is equal to `kQ3True`, the object is drawn using the information stored in the current highlight style for the object. See Also:  - _3D Graphics Programming with QuickDraw 3D_, page 6-6. |
