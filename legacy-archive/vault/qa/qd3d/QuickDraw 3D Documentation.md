|  Q: How can I get some good pointers on the more intricate workings of QuickDraw 3D?  A: As an Apple Partner or Associate Plus member you are encouraged to send your questions to [feedback](https://developer.apple.com/contact/index.html).  Another good source for up-to-date information is our World Wide Web site at [http://product.info.apple.com/qd3d/QD3D.HTML](http://product.info.apple.com/qd3d/QD3D.HTML)  Apple's _develop_ magazine has several good articles with QD3D information:   - "QuickDraw 3D: A new Dimension for Macintosh Graphics", _develop_ 22, p. 6 - "The Basics of QuickDraw Graphics", _develop_ 23, p. 30 - "Graphical Truffles: Making the most of QuickDraw 3D", _develop_ 24, p. 42 - and more coming in future issues, including articles on custom attributes, debugging, and an introduction to NURB Curves.   _develop_ articles can be downloaded via the web from [http://developer.apple.com/dev/techsupport/develop/index.html](https://developer.apple.com/dev/techsupport/develop/index.html)  The monthly Developer CD Series also has QD3D information, especially the Tool Chest and Reference Library editions. Use the Find File command and search these CDs for filenames containing the string "3D".  All QuickDraw 3D programmers should have the manual  _3D Graphics Programming with QuickDraw 3D_ (Addison Wesley), available from the Apple Developer Catalog. This is essentially the _Inside Macintosh_ volume for QuickDraw 3D.  The CD-ROM that accompanies the book contains files with much more information than that in the printed pages. The Adobe Acrobat version of the manual, "3D Graphic Prog w/QD3D" is a 1,226 page superset of the printed manual. The Toolbox Assistant (QuickView) database file, "QuickDraw 3D.qv", provides quickly accessible, on-line documentation for all QuickDraw 3D data structures. |
