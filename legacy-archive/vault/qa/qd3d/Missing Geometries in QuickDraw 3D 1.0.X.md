|  Q: In QuickDraw 3D 1.0.X, I can't find several basic geometries that I was expecting to use. In particular: cones, cylinders, spheres, and tori, are missing.  A: The Geometry Sample code folder (see the Sample Code folder in the Samples folder in the QuickDraw 3D SDK) shows how to implement some of the missing geometries using the trigrid routines provided by the API. The GeometryTest sample application shows how to use the functionality provided in Geometry Sample code folder. |
