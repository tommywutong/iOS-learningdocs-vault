|  |
| --- |
| ---   Q: When you allocate memory for vertices & contours in general polygons (or any polygon, for that matter) is it necessary to free the memory when finished? Or does QuickDraw 3D do that for us?  A: After you create the geometry object (for example with `Q3Polygon_New()`), you can safely dispose of your buffers. QD3D will not do it for you. [Jul 11 1997] |
