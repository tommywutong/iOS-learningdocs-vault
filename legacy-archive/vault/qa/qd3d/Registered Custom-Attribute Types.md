|  Q: We found a document that contains the '`unts`', '`name`', '`frvt`', and '`upvt`' custom QuickDraw 3D attributes. Are there any additional registered custom-attribute types available?  A: Try Apple's [QuickDraw 3D home page](http://www.apple.com/quicktime/), which has an Attribute Registry sub page that allows online registration of custom attribute types. |
