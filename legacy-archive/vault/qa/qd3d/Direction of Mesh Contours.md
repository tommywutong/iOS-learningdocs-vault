|  Q: Do mesh contours run in the same or opposite direction as the face? For example, if the face runs clockwise, will the contour run counterclockwise?  A: The exterior face needs to be defined in an anti-clockwise direction, but the contours defining holes can run in either direction. The mesh code is able to identify holes in a face. |
