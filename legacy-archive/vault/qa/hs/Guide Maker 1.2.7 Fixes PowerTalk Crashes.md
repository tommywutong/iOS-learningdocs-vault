| Q After compiling my guide file with Guide Maker on my Macintosh with PowerTalk installed, my Macintosh seems to crash. Any idea why?   A You just need to upgrade to Guide Maker 1.2.7 or greater. Guide Maker 1.2.5 had a bug that caused a crash after compiling a guide when PowerTalk was installed. This has been fixed in Guide Maker 1.2.7. Guide Maker can now compile a guide file and properly manage the itl2 resource, so that other applications -- such as PowerTalk -- can have access to the resource. Updated: 14-May-96 |
