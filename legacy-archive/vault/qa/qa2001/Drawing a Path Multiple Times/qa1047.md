|  |
| --- |
| ---   Q: Why can't I stroke or fill a path multiple times in a row?  A: In Core Graphics, all of the functions that draw, stroke, or fill a path consume it. There is no way to preserve the path or reuse it. Even CGContextSaveGState doesn't preserve the current path. The only way to draw the path again is to recreate it from scratch.   ---  [Jul 02 2001] |
