| ---   Q: How much memory should I allocate for MPW?  A: In general, you should allocate as much memory as possible to MPW. However, don't use up all of your memory for MPW, or you won't have room to load some of the system resources that are required. Reserve approximately two to three megabytes, and allocate the rest to MPW. |
