[Oct 01 1990] |       ---      SCSI drive format for LaserWriter II NTX with Rev. 3 ROMs Date Written: 5/3/91  Last reviewed: 6/26/91  What could be causing intermittent PostScript errors from a LaserWriter II NTX with an SCSI hard disk mounted after installing the Rev 3 ROM upgrade?  The LaserWriter II NTX with Rev 3 ROMs does not work properly with a hard disk formatted with the LaserWriter Font Utility 1.x. You need to reformat the disk and copy the fonts back onto the hard disk using the LaserWriter Font Utility 2.0.2. Unfortunately, there is no way to make this procedure easier.  [Back to top](#) LaserWriter Font Utility copies Postscript file to printer Date Written: 9/23/91  Last reviewed: 10/8/91  Is there a utility that will send a PostScript file from disk to the LaserWriter?  The LaserWriter Font Utility handles this job and is part of the System 7 disk set. On the System 7 Golden Master CD, the path is System 7.0: System Software 7.0: Installer Version: Tidbits folder.
