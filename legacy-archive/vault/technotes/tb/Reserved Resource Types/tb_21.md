To avoid using type names which have been or will be used in the system, Apple has reserved all resource type names which consist entirely of spaces ($20), lower-case letters ($61 through $7A), and "international" characters (greater than $7F).  In addition Apple has reserved a number of resource types which contain upper-case letters and the "#" character. For a list of these resource types, see The Resource Manager Chapter of _Inside Macintosh_ (starting with _Volume V_).
