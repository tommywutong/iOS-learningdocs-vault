[Sep 01 1993] |       ---      Macintosh IIsi sound input documentation and samples Date Written: 4/30/91  Last reviewed: 3/18/92  Where can we learn how to access the recording capabilities of the Macintosh IIsi? We need to be able to acquire and process the samples in real time under program control (that is, no "push to record" button).  _Inside Macintosh_ Volume VI contains the comprehensive documentation on using sound with the Macintosh. It supersedes the information in the Sound Manager chapter of _Inside Macintosh_ Volume V. "Recording Sounds Directly From Sound Input Devices" is a section pertinent to your concerns. Also, check the SC.024.SoundApp folder in the DTS Sample Code folder and sound Q&As on AppleLink and on the latest developer CDs.
