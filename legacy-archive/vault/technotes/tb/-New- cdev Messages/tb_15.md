| |  |  |  |  |  |  | | --- | --- | --- | --- | --- | --- | | |  | | --- | | images/tnmenutop.gif | | 目录 | | [简介](#)   [参考资料](#)   [可下载资源](#) | | images/tnmenubottom.gif | | 本技术笔记描述了控制面板（Control Panel）可以发送给控制面板设备（cdev）的一些此前未曾记录的消息。  [1988 年 10 月 1 日] |       ---      简介 控制面板会在用户选择"编辑"菜单中的"撤销"、"剪切"、"拷贝"、"粘贴"和"清除"命令时，向控制面板设备（cdev）发送消息。如果 cdev 包含 `'CURS' = -4064` 资源，控制面板也会发送一条消息。下面是这些此前未曾记录的消息、说明及取值列表：  控制面板设备（cdev）消息  只有当应用程序调用 `SystemEdit`（`_SysEdit`）、桌面管理器（Desk Manager）随之向 cdev 发送编辑消息时，控制面板才会向 cdev 发送 `undoDev`、`cutDev`、`copyDev`、`pasteDev` 和 `clearDev` 消息。由于对 `SystemEdit`（`_SysEdit`）的调用是由菜单栏中的鼠标按下事件触发的，因此只有当用户用鼠标选择"编辑"菜单项时，才会向 cdev 发送这些消息，通过按下对应的 Command 键组合则不会触发。  通常，在收到 `cutDev`、`copyDev`、`pasteDev` 或 `clearDev` 消息时，你会调用 `_DlgCut`、`_DlgCopy`、`_DlgPaste` 或 `_DlgDelete`，并将传给 cdev 的 `DialogPtr` 传入该调用。  要响应"编辑"菜单命令对应的 Command 键组合，你必须自行检查具体的字符和修饰键，尽管这一点从不会被本地化。一旦确定某个字符是 Command 键组合，你就必须把传给 cdev 的事件记录的 `what` 字段改为 `nullEvent`，以防止对话框管理器（Dialog Manager）把该字符插入到 cdev 的 `editText` 项中。要修改事件记录，你应当把传给 cdev 的事件记录参数当作引用来处理。在 Pascal 中，这意味着要按如下方式声明 cdev 的接口：   |  | | --- | | ```     FUNCTION MyCdev(message, item, numItems, CPanelID: INTEGER         VAR theEvent: EventRecord; (* 'NEW' 方式 *)         cdevStorage: Handle;  ``` |   在 C 中，你需要这样做：   |  | | --- | | ```     Handle MyCdev(message, item, numItems, CPanelID         theEvent, cdevStorage, CPDialog)     short message, item, numItems, CPanelID;     EventRecord *theEvent;    /* 'NEW' 方式 */     Handle cdevStorage;  ``` |   在汇编语言中，这意味着你不会自己复制一份事件记录，因此你很可能已经具备了修改事件记录 `what` 字段值的条件。  如果 cdev 包含 `'CURS' = -4064` 资源，那么每当光标位于控制面板窗口中该 cdev 所在的区域时，控制面板就会向它发送一条 `cursorDev` 消息，而不是把光标设为十字光标（light cross）。这样 cdev 就可以设置并使用自己的光标。屏幕上其他区域的光标仍由控制面板负责处理。控制面板不会检查 `'CURS' = -4064` 资源的具体内容。  [返回顶部](#) 参考资料 Inside Macintosh 第五卷，控制面板  [返回顶部](#) 可下载资源  |  |  |  | | --- | --- | --- | | Acrobat gif | 本文档的 Acrobat 版本（68K）。 | [下载](https://developer.apple.com/library/archive/technotes/tb/pdf/tb_15.pdf) | |
