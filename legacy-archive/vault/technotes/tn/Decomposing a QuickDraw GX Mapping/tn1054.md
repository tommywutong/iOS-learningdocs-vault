It is easy enough to build up such a transformation from a sequence of _primitive transformations_, namely translations, scalings, rotations, skews and perspective distortions -- GX provides calls to construct nearly all of these components (the exception is perspective, for which there is library code in the GX SDK). Sometimes there is a need to go the other way: given an arbitrary linear transformation, can you break it into a sequence of pure translations, scalings, skews and perspective distortions? This Technote will show you how.  This Technote is aimed at those who already have some basic understanding of QuickDraw GX graphics, including how to make use of GX mappings. The exposition will take more of an intuitive, hand-waving approach, with little pretense at rigorous derivation.
