| |  |  |  |  |  |  | | --- | --- | --- | --- | --- | --- | | |  | | --- | | images/tnmenutop.gif | | CONTENTS | | [Introduction](#)   [References](#)   [Downloadables](#) | | images/tnmenubottom.gif | | [May 01 1987] |       ---      Introduction When you use the low-level printer driver to print, you don't get the benefits of the error checking that is done when you use the high-level Printing Manager. So, if the user prints to an AppleTalk ImageWriter (including an AppleTalk ImageWriter LQ) that is busy printing another job, the driver doesn't know whether the printer is busy, offline, or disconnected. Because of this, `PrError` will return (and `PrintErr` will contain) `abortErr`.  Since there is no way to tell when you are printing to an AppleTalk ImageWriter, the only workaround for this is to use high-level Printing Manager interface.
