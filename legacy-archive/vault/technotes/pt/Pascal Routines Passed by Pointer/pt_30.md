For example, filter procedures for modal dialogs are passed by pointer, as are controls' action procedures (when calling `TrackControl`), and I/O completion routines.  If you're using MPW Pascal, the syntax is usually  where MyProc is the procedure passed by pointer (using the @ symbol).  Because of the way that MPW Pascal (and some other compilers) construct stack frames, any procedure or function passed by pointer __must not__ have its declaration nested within another procedure or function. If its declaration is nested, the program will crash, probably with an illegal instruction error.
