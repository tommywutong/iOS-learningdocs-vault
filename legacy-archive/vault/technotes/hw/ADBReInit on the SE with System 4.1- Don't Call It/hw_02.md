| |  |  |  |  |  |  | | --- | --- | --- | --- | --- | --- | | |  | | --- | | images/tnmenutop.gif | | CONTENTS | | [References](#)   [Downloadables](#) | | images/tnmenubottom.gif | | Because of a bug (which causes auto-repeat) in the ROM version of the Macintosh SE keyboard driver, a patch was placed in System 4.1. If `ADBReInit` is called, the ROM version of the keyboard driver will be reloaded, and the RAM version of the driver with the patches will not be used. Therefore, it is recommended that `ADBReInit` not be called on the Macintosh SE until the problem is fixed. (There is no need to call `ADBReInit`.) This problem will not occur with the Macintosh II ROM version of the keyboard driver.
