# Administrative Tasks

Most directory paths specified in the following tasks are relative to the installation directory, _NEXT_ROOT_. The definition of _NEXT_ROOT_ depends on the platform you are using:

| Platform | Installation Directory |
| --- | --- |
| Mach | __/__ |
| HPUX | Defined at installation time. |
| Solaris | Defined at installation time. |
| Windows NT | Defined at installation time. |

Some tasks are special to WebObjects Enterprise and not WebObjects Pro. In addition, some tasks do not apply to WebObjects installed on Mach. These exceptions are noted in the task procedures.
