# Launch WebObjects Builder

On Windows NT, you can launch WebObjects Builder from the WebObjects program group in the Start menu. If you're using a different platform or if WebObjects Builder doesn't have a shortcut, you can find it in the directory <_NextRoot>___/NextDeveloper/Apps/WebObjectsBuilder.app__.
When you start up WebObjects Builder, an untitled document appears.
