## Printable PDF Documentation for WebObjects 3.0 and 3.1

PDF is a portable, printable format that is much richer than HTML, allowing us to provide you fully-formatted versions of the documentation. To use PDF, you need a PDF viewer.

- If you need a viewer for Mach, [download OmniPDF from OmniGroup](http://www.omnigroup.com/Software/OmniPDF/).
- If you need a viewer for Windows or other platforms, [download Acrobat from Adobe](http://www.adobe.com/prodindex/acrobat/main.html).
