# Package next.wo

## PACKAGE DESCRIPTION

The next.wo package contains Java classes and interfaces for the WebObjects Framework (installed in _NEXT_ROOT___/NextLibrary/Frameworks/WebObjects.framework__). The WebObjects Framework allows you to build dynamic server-side Web applications that can access standard relational databases.
