# Setting Page Attributes

Select any element in the page.

In the inspector window, click the leftmost icon. (Click the inspector button to display the inspector window.)

!

"[Setting Colors](SetColors.md#apple-kjcumnrvge4ta)" describes how to use the Colors panel that opens when you click a color well border.

You use the table on the page inspector only if you're creating a component that can be reused. See "[Creating Reusable Components](../Advanced/CreateReusableComponent.md)" for more information.
