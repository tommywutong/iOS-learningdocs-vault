The Custom Abstract Element

|  |  |
| --- | --- |
|  | ---   The Custom Abstract Element If the element you want to create isn't explicitly listed on the Abstract Elements palette, use the custom element. This creates an abstract dynamic element, but it leaves the type undefined. You enter the element's name in the [inspector window](../HTMLEdit/Inspectors.md). After you have done this, WebObjects Builder displays the binding attributes that element supports in the element's bindings inspector.   --- |
