Creating Images

# Creating Images

In the component window, place the cursor where you want the image to appear.

Locate the image in the file system.

Drag the image onto the page.

!

WebObjects Builder supports __.jpeg__, __.gif__, __.tiff__, __.eps__, and __.bmp__ images.

By default, WebObjects Builder copies the image into the component directory unless you are dragging from a shared directory. See "[Sharing Resources](../AppSetup/ShareResources.md)."

To set an image for the page background, use the page inspector. See "[Setting Page Attributes](SetPageAttributes.md#apple-kjcumnbwgq2te)."
