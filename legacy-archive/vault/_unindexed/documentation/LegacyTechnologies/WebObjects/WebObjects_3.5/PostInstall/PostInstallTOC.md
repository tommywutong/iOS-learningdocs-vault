# WebObjects Release 3.5 Post-Installation Instructions

---

This short guide describes steps you should follow immediately after you've installed WebObjects. By following the instructions in this guide, you'll be assured that the WebObjects package was installed properly.
Before reading this guide, be sure you have followed all of the instructions in the _WebObjects 3.5 Installation Guide_, which is included in the CD package and that you've checked the _WebObjects Release Notes_, available through [NeXTanswers #2455](http://enterprise.apple.com/NeXTanswers/HTMLFiles/2455.htmld/2455.html), for any late-breaking information.
