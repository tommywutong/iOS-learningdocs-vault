# The WebObjects Builder Toolbar

At the left of the toolbar are three buttons:

The ! pop-up list
allows you to switch editing modes. See ["Editing
Modes"](EdModes.md#apple-g42dcmy).

The ! button brings
up the Inspector window, which allows you to set various attributes of
the currently selected element. The sections describing each type of element
go into more detail on the Inspector.

The ! button brings
up the Palette window. See ["Palettes"](Pallette.md#apple-geytcnjv)
for more information on creating and using palettes.
