## Opening an Existing Project

To open an existing project from Project Builder:

- Choose Project !Open.
- In the Open Project panel, navigate to the project folder and click Open.
- Select the __PB.project__ file and click Open.

To open an existing project from the file system, double-click the __PB.project__ file in the project directory. Project Builder launches (if it is not already running) and opens the project.
