# Set Up

When you develop apps, you use Xcode, Apple’s integrated development environment (IDE). Xcode provides everything you need to create great Mac apps. It includes a source editor, a graphical user interface editor, and many other features. Xcode employs a single window, called the _workspace window_, that presents most of the tools you need to develop apps. Within the same window you smoothly transition from writing code, to debugging, to designing your user interface.

[（原归档配图获取待重试：`install_tools_2x.png`）](macappstore://itunes.apple.com/us/app/xcode/id497799835?mt=12)

__To get started:__

1. Download the latest version of Xcode.

   Open the Mac [App Store](macappstore://itunes.apple.com/us/app/xcode/id497799835?mt=12) app on your Mac, search for Xcode, and click Free to download Xcode. (The Mac App Store app is installed with Mac OS X version 10.7 and later. If you have an earlier version of Mac OS X, you need to upgrade.)
2. [Enroll in the Mac Developer Program](https://developer.apple.com/programs/mac/).

   After you enroll in the program, you have access to the tools and resources you need to distribute your app. You will learn more about these tools later in the road map.
