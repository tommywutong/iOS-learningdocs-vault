## Glossary

Here are terms you will encounter throughout this guide.

**__action__**
: A piece of code that’s linked to an event that can occur in your app.

**__activity viewer__**
: Part of the Xcode toolbar that displays messages about the build process and other information.

**__adaptive interface__**
: A [user interface (UI)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjy) that automatically adjusts so that it looks good in the context of the available screen space.

**__adopt__**
: To indicate that a [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy), [structure](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjt), or [enumeration](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooby) [conforms to](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomzs) a [protocol](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonjz).

**__application programming interface (API)__**
: A set of [functions](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoojt), [classes](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy), [protocols](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonjz), and other components that define how pieces of software should interact with each other.

**__app delegate__**
: An [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) in your app (specifically, an [instance](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvona) of the `AppDelegate` class) that creates the window where your app’s content is drawn and that provides a place to respond to state transitions within the app.

**__application object__**
: An [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) in your app that’s responsible for managing the life cycle of the app, communicating with its [delegate](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomzw), the [app delegate](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomrx), during state transitions within the app.

**__argument__**
: A value you pass in to a [function](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoojt), [method](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjs), or [initializer](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomq) to satisfy one of its [parameters](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomrq).

**__array__**
: A data type that stores multiple values of the same type in an ordered list.

**__Attributes inspector__**
: An inspector that you use to customize visual attributes of a [user interface (UI)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjy) element in a [storyboard](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooa).

**__asset catalog__**
: A tool to manage assets like images that are used by your app as part of its [user interface (UI)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjy).

**__assistant editor__**
: In Xcode, a secondary editor window that appears side-by-side with your primary editor.

**__Auto Layout__**
: A layout engine that helps lay out your [user interface (UI)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjy) based on the [constraints](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonzy) you specify.

**__base class__**
: A class that’s at the root of its [class hierarchy](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoobt), meaning that it has no [superclass](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjv).

**__canvas__**
: The background of a [storyboard](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooa) where you add and arrange [user interface (UI)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjy) elements.

**__class__**
: A piece of code that describes the behavior and [properties](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonjy) common to any particular type of [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq), essentially providing a blueprint for the object.

**__clean__**
: Removes all the product files, as well as any object files or other intermediate files created during the build process.

**__class hierarchy__**
: A hierarchical representation of a class’s relationships to its [superclass](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjv) and [subclasses](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomju).

**__closed range operator__**
: An operator (`...`) that lets you create a range of numbers that includes both the lower and upper values.

**__closure__**
: A self-contained block of functionality that can be passed around and used in your code. Closures in Swift are similar to blocks in C and Objective-C and to lambdas in other programming languages.

**__Cocoa Touch__**
: The set of Apple frameworks and technologies used to develop iOS apps.

**__code completion__**
: A feature of Xcode that infers what you’re trying to type from context and provides suggestions that you can select.

**__completion handler__**
: A [closure](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjtge) that’s passed as a [parameter](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomrq) to a [method](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjs) that calls the closure when it finishes executing.

**__comment__**
: A piece of text in a source code file that doesn’t get compiled as part of the program but provides context or other useful information about individual pieces of code.

**__conditional statement__**
: A control flow statement that checks whether a condition is true before executing a piece of code.

**__conform to__**
: For a [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy), [structure](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjt), or [enumeration](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooby) to satisfy the requirements of a [protocol](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonjz).

**__console__**
: A tool for debugging and for logging information for debugging purposes.

**__constant__**
: A value that’s [initialized](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomq) once and cannot change, indicated in Swift by the `let` keyword.

**__constraint__**
: In [Auto Layout](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonzx), a rule that explains where one element should be located relative to another, what size it should be, or which of two elements should shrink first when something reduces the space available for each of them.

**__content view__**
: A [view](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjw) [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) that’s located at the top of a [view hierarchy](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomrr), serving as a container for the [subviews](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomrs) in its hierarchy.

**__control__**
: A specialized type of [view](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjw) (specifically, an [instance](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvona) of the `UIControl` [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy) or one of its [subclasses](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomju)) that responds to user input.

**__convenience initializer__**
: A secondary [initializer](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomq), which adds additional behavior or customization, but must eventually call through to a designated initializer.

**__data model__**
: The representation or structure of data within an app.

**__data source__**
: An [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) that manages the app’s [data model](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomzv), providing a [view](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjw) object with the information it needs to display that data.

**__delegate__**
: An [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) that acts on behalf of, or in coordination with, another object.

**__designated initializer__**
: One of the primary initializers for a [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy); a [convenience initializer](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjrg4) within a class must ultimately call through to a designated initializer.

**__destination view controller__**
: The [view controller](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvony) whose contents are displayed at the end of a [segue](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonrv).

**__downcast__**
: To attempt to cast an [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) to one of its [subclass](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomju) types.

**__entry point__**
: Where control enters a program or piece of code.

**__enumeration__**
: A data type that defines a group of related values and enables you to work with those values in a type-safe way within your code.

**__event-driven programming__**
: A category of programming in which the flow of the app is determined by events: system events and user actions.

**__extension__**
: A capability to add functionality to an existing type.

**__failable initializer__**
: An [initializer](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomq) that could return [nil](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoni) after initialization.

**__first responder__**
: An [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) that is first to receive many kinds of app events, including key events, motion events, and action messages, among others.

**__fix-it__**
: A suggested fix for a compiler error in Xcode.

**__forced type cast operator__**
: An operator (`as!`) that attempts a [downcast](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoobx) and force-unwraps the result.

**__force-unwrap operator__**
: An operator (`!`) placed after an [optional](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjr) value to access its underlying value.

**__function__**
: A reusable, named piece of code that can be referred to from many places in a program.

**__Functions menu__**
: In Xcode, a jump menu that lets you navigate directly to a specific declaration or section in a source code file.

**__gesture recognizer__**
: An [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) that you attach to a [view](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjw) that allows the view to respond to actions the way a [control](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjx) does.

**__global__**
: A [constant](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomzt), [variable](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonzu), or [function](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoojt) defined at the top-level scope of a program.

**__guard__**
: A `guard` statement declares a condition that must be true in order for the code after the `guard` statement to be executed. Using a `guard` statement for requirements improves the readability of your code, compared to doing the same check with an `if` statement.

**__half-open range operator__**
: An operator (`..<`) that lets you create a range of numbers that includes the lower but not the upper value.

**__Identity inspector__**
: An inspector that you use to edit properties of an [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) in a [storyboard](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooa) related to that object’s identity, such as what [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy) the object belongs to.

**__identity operator__**
: An operator (`===`) that tests whether two [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) references both refer to the same object [instance](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvona).

**__immutable__**
: A value that cannot be changed (or mutated) after it’s [initialized](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomq), like a [constant](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomzt).

**__implement__**
: To define the behavior of something in code.

**__implicitly unwrapped optional__**
: An [optional](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjr) that can also be used like a nonoptional value, without the need to [unwrap](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjqhe) the optional value each time it is accessed, because it’s assumed to always have a value after that value is initially set.

**__inheritance__**
: When a [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy) is a [subclass](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomju) of another class, it gets all of its behavior (methods, properties, and other characteristics) from its [superclass](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjv).

**__initializer__**
: A [method](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjs) that handles the process of preparing an [instance](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvona) of a [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy), [structure](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjt), or [enumeration](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooby) for use, which involves setting an initial value for its properties and performing any other required setup.

**__inspector pane__**
: An area in Xcode that displays inspectors, such as the [Attributes inspector](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjz), [Identity inspector](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoobq), and [Size inspector](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoobs).

**__instance__**
: A specific occurrence of a [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy) (that is, an [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq)), [structure](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjt), or [enumeration](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooby).

**__integrated development environment (IDE)__**
: A software application that provides a set of tools for software development.

**__Interface Builder__**
: The graphical environment for building a [user interface (UI)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjy) in Xcode.

**__intrinsic content size__**
: The minimum size needed to display all the content in a view without clipping or distorting that content.

**__iterate__**
: To perform repeatedly.

**__library pane__**
: An area in Xcode that displays one of the ready-to-use libraries of resources for your project, like the [Object library](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonju).

**__local__**
: A [constant](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomzt) or [variable](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonzu) defined only within a particular, limited scope, like a [loop](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoojw), [conditional statement](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoobv), or [function](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoojt).

**__loop__**
: A control flow statement that executes the same piece of code multiple times.

**__method__**
: A reusable, named piece of code that’s associated with a particular [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy), [structure](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjt), or [enumeration](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooby).

**__modal segue__**
: A [segue](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonrv) in which one [view controller](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvony) presents another view controller as its child. The user must interact with the presented controller, and dismiss it before returning to the app’s main flow. Use modal segues to present tasks that the user must complete before continuing.

**__Model-View-Controller (MVC)__**
: A pattern of app design in which [view controllers](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvony) serve as the communication pipeline between [views](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjw) and the [data model](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomzv).

**__mutable__**
: A value that is able to be changed (or mutated) after it’s [initialized](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomq), like a [variable](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonzu).

**__navigation controller__**
: A specialized [view controller](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvony) [subclass](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomju) that manages transitions backward and forward through a series of view controllers.

**__navigation stack__**
: The set of [view controllers](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvony) managed by a particular [navigation controller](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoojx).

**__nil__**
: The absence of a value or no value.

**__nil coalescing operator__**
: An operator (`??`) placed between two values, `a ?? b`, that [unwraps](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjqhe) an [optional](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjr) `a` if it contains a value, or returns a default value `b` if `a` is [nil](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoni).

**__object__**
: An [instance](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvona) of a [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy).

**__Object library__**
: Part of the Xcode [workspace window](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooi) that shows a list of [objects](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) that can be added to a [storyboard](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooa), including each object’s name, description, and visual representation.

**__optional__**
: A value that contains either an underlying value or [nil](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoni) to indicate that the value is missing.

**__optional binding__**
: The process of attempting to assign an [optional](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjr) value to a constant in a conditional statement to see if the optional contains an underlying value.

**__optional type cast operator__**
: An operator (`as?`) that attempts a [downcast](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoobx) and returns the result as an [optional](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjr) value.

**__outlet__**
: A reference to an [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) in a [storyboard](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooa) from a source code file.

**__outline view__**
: A pane in a [storyboard](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooa) that lets you see a hierarchical representation of the objects in your storyboard.

**__override__**
: To replace an implementation of a [method](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjs) defined on a [superclass](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjv).

**__parameter__**
: An additional piece of information that must be passed into a [function](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoojt), [method](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjs), or [initializer](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomq) when it’s called.

**__playground__**
: A type of file in which you can change and play around with Swift code directly in Xcode and see the immediate results.

**__project navigator__**
: Part of the Xcode [workspace window](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooi) that displays all the files in your project.

**__property__**
: A piece of data encapsulated within a [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy), [structure](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjt), or [enumeration](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooby).

**__property observer__**
: A piece of code that’s called every time the value of a [property](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonjy) is set. Use property observers to observe and respond to changes in the property’s value.

**__protocol__**
: A blueprint of [methods](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjs), [properties](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonjy), and other requirements that suit a particular task or piece of functionality.

**__read-only__**
: A value that can only be viewed (read) but never changed (written).

**__read-write__**
: A value that can be both viewed (read) and changed (written).

**__resize handles__**
: Small white squares that appear on a [user interface (UI)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjy) element’s borders when it’s selected so you can change its size on the [canvas](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonq).

**__root view controller__**
: The first item added to a the [navigation stack](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonjt) of a [navigation controller](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoojx). The root view controller is never popped off (removed from) the stack.

**__run loop__**
: An event processing loop that you use to schedule work and coordinate the receipt of incoming events in your app.

**__runtime__**
: The period during which a program is executing.

**__scene__**
: A [storyboard](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooa) representation of a screen of content in your app.

**__scene dock__**
: A bar that contains information related to a [scene](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonrs) in a [storyboard](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooa).

**__segue__**
: A transition from one [scene](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonrs) to another in a [storyboard](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooa).

**__show segue__**
: A [segue](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonrv) that varies the way new content is displayed based on the target view controller. For navigation controllers, the show segue pushes new content on top of the current [view controller](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvony) stack. Use a navigation controller and show segues to navigate through hierarchical data.

**__Simulator__**
: An app in Xcode that simulates the behavior and appearance of running an app on a device.

**__Size inspector__**
: An inspector that you use to edit the size and position of a [user interface (UI)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjy) element in a [storyboard](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooa).

**__source view controller__**
: The [view controller](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvony) whose contents are displayed at the beginning of a [segue](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonrv).

**__storyboard__**
: A file that contains a visual representation of the app’s [UI (user interface)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjy), showing screens of content and the transitions between them, that you work on in [Interface Builder](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonbx).

**__storyboard entry point__**
: The first [scene](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonrs) that’s shown from a [storyboard](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvooa) when an app starts.

**__string interpolation__**
: The process of inserting string representations of [constants](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomzt), [variables](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonzu), literals, and expressions into longer strings.

**__structure__**
: A data type that’s similar to a class, but doesn’t support [inheritance](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonbv) and is passed by value instead of by reference.

**__subclass__**
: A [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy) that’s a child of another class (known as its [superclass](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjv)).

**__subview__**
: A [view](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjw) that is enclosed by another view (known as its [superview](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonrx)).

**__superclass__**
: A [class](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomy) that’s a parent of another class (known as its [subclass](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomju)).

**__superview__**
: A [view](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjw) that encloses another view (known as its [subview](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomrs)).

**__Swift standard library__**
: A set of data types and capabilities designed for Swift and baked into the language.

**__target__**
: The object that receives the [action](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomrt) message in the target-action pattern.

**__target-action__**
: A design pattern in which one [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) sends a message to another object when a specific event occurs.

**__tuple__**
: A grouping of values.

**__type casting__**
: A way to check the type of an [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq), and to treat that object as if it’s a different [superclass](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjv) or [subclass](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomju) from somewhere else in its own [class hierarchy](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvoobt).

**__type inference__**
: The ability of the Swift compiler to determine the type of a value from context, without an explicit type declaration.

**__UIKit__**
: A [Cocoa Touch](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjsgu) framework for working with the [user interface (UI)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjy) layer of an iOS app.

**__underscore__**
: A representation of a wildcard in Swift (`_`).

**__unit test__**
: A piece of code written specifically to test a small, self-contained piece of behavior in your app to make sure it behaves correctly.

**__unwrap__**
: To extract an underlying value from an [optional](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjr).

**__user interface (UI)__**
: The layer of visual elements that lets a user interact with a piece of software.

**__utility area__**
: An area in Xcode that displays the [inspector pane](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonbw) and .

**__unwind segue__**
: A type of [segue](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvonrv) used to implement backward navigation.

**__variable__**
: A value that can change after it’s been [initialized](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomq), indicated in Swift by the `var` keyword.

**__view__**
: An [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) that’s used to construct your [user interface (UI)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjy) and display content to the user.

**__view controller__**
: An [object](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjq) that manages a set of [views](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjw) and coordinates the flow of information between the app’s [data model](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomzv) and the views that display that data.

**__view hierarchy__**
: A hierarchical representation of [views](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2temjufvbuqmjsfvjvomjw) relative to other views.

**__workspace window__**
: The Xcode window, which you use to manage and navigate through the files and resources in your project.
