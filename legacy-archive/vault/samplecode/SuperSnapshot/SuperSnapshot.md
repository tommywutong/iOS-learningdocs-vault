# SuperSnapshot

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-10 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Color QuickDraw, CarbonLib |

A "buffed up" version of the Snapshot example, Super Snapshot goes above and beyond the call of carbonization. Includes such additions as multiple windows, saving snapshots to a PICT file, dynamic resizing of windows (perhaps the only example that does this using the "classic" or traditional event model), different menus for OS 9 and X, handling the Apple Event "Quit," and a special menu that will set the desktop on OS 9 and display full screen snapshots on OS X. Requirements: Color QuickDraw, CarbonLib Keywords: Snapshot, screen shot, pixmap, Carbon, PICT
