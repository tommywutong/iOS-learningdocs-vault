# LoopHealth: Using health documents and Activity rings in HealthKit and HealthKitUI

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2016-12-02 First release |
| __Build Requirements:__ | Xcode 8.0 or later; iOS 10.0 SDK or later; watchOS 3.0 SDK or later |
| __Runtime Requirements:__ | iOS 10.0 or later; watchOS 3.0 later |

This sample demonstrates how to use HKActivityRingView to display a user’s Apple Watch Activity rings in your own app. This sample also illustrates how apps from healthcare organizations can use the health documents APIs introduced in iOS 10 to share and retrieve a user’s health records.
