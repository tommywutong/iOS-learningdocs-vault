# HICustomLeftRightSwitch

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-02-06 Illustrates how to create a custom left/right switch using the HIView functions introduced in Mac OS X 10.2. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X 10.2 |

This simple sample code illustrates how to create a custom left right switch using the HIView APIs available in Mac OS X 10.2 and later. It's a more complex custom HIView than the more simple HICustomPushButton provides although it uses the same skeleton. Requirements: Mac OS X 10.2 Keywords: HIView Custom Left Right Switch HIObject Control
