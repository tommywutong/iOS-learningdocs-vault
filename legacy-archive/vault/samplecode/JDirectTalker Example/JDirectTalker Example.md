# JDirectTalker Example

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon MRJ 2.1 or later. |

JDirectTalker is a simple example of how to use Apple's JDirect technology to access APIs imported from code fragments, the Macintosh implemention of shared libraries. This example uses Apple's Speech Manager to provide text-to-speech capabilities inside a Java application. Requirements: MRJ 2.1 or later. Keywords: JDirect Speach Manager MRJ Java
