# DisplayVideo

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Color QuickDraw |

DisplayVideo is a sample that will display all info about all video modes supported by each installed video card with its attached monitor. This code provides a sample of how developers can discover the bit depths and timings of multisync displays. Requirements: Color QuickDraw Keywords: video device modes, bit depth, timings, multisync displays, DisplayVideo
