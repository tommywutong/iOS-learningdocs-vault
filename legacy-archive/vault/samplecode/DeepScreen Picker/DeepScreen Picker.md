# DeepScreen Picker

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Color QuickDraw |

This is a very simple sample program that demonstrates how to force the Color Picker dialog onto the deepest device available. It does nothing more than save the current GDevice, find the deepest GDevice, make it current and activate (and center) the Color Picker dialog. Requirements: Color QuickDraw Keywords: Color Picker, GDevice
