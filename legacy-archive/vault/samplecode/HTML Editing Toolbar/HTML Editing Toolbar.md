# HTML Editing Toolbar

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2007-06-11 Implements an HTML editing toolbar for Safari using JavaScript and CSS |
| __Build Requirements:__ | None, the sample is all HTML and JavaScript. |
| __Runtime Requirements:__ | Safari 3 or other WebKit browser on Mac OS X 10.5 |

Implements an HTML editing toolbar for Safari using JavaScript and CSS that fades in and out and has buttons to apply text formating and text alignment. Click in the text area to see the toolbar appear.
