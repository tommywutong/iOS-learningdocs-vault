# YASTControl

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-27 An application illustrating how to use a user pane control to define MLTE based text fields. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X |

An application illustrating how to use a user pane control to define your own MLTE based text fields that are like the unicode edit control, but include a scroll bar and allow access to the displayed TXNObject. Yet Another Scrolling Text (YAST) Control. Yast, it lets you edit Unicode text. Requirements: Mac OS X Keywords: MLTE Text Edit Control
