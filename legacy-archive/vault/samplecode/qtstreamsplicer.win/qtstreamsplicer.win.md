__Important__ This sample code may not represent best practices for current development. The project may use deprecated symbols and illustrate technologies and techniques that are no longer recommended.

This sample code has been updated for QuickTime 5.0 QTStreamSplicer is sample code that shows how to splice a still picture onto the front of a live streaming movie. Also allows you to splice a still picture over an audio-only streaming movie. The source code is extremely straightforward; it illustrates how to create a movie that contains a track from another movie. It also shows how to save the new movie as self-contained (without any references to the media in the source movie). 68k or PowerPC (or newer) machines running System 8.5 or later. PC with Intel Pentium or compatible processor. QuickTime 4.0 or later. CodeWarrior Pro 2 or later or Visual C++ 5.0 or later.
