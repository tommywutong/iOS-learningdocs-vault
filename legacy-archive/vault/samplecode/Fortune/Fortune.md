# Fortune

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-01 Demonstrates use of a widget plug-in |
| __Build Requirements:__ | Mac OS X 10.4 or later |
| __Runtime Requirements:__ | Mac OS X 10.4 or later |

This sample is deprecated in favor of newer projects. Please see the Birthdays sample to learn about writing widget plug-ins.

This sample widget uses a plug-in to communicate strings between Objective-C and JavaScript. It is identical to the widget found in /Developer/Examples/Dashboard/ on Mac OS X 10.4.
