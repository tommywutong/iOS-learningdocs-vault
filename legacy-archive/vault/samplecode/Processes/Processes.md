# Processes

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-07-28 This process management application uses most of AppleScript Studio's significant features. |
| __Build Requirements:__ | Xcode 2.x |
| __Runtime Requirements:__ | Tiger 10.4.x |

This sample project shows how to use most of AppleScript Studio's significant features. A complete outline containing all script source necessary is provided to enable developers to work their way through building the entire application, starting from the completed interface. Nine milestone projects are provided corresponding to the completion of that step in the outline.
