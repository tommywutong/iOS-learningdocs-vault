DrawSprocket Test This sample shows basic implementations of DrawSprocket Functions. It demonstrates: - Get Version - Display/context iteration - Context searching - Multiple-buffering/page flipping - CLUT operations - DSpUserSelectContext - Underlays - Single Buffering Requires: PowerPC, System 8.1 or later, and either Universal Interfaces 3.3 or DrawSprocket SDK Keywords: DrawSprocket, GetVersion, Context, blit, CLUT
