# ApplicationShortcuts: Using UIApplicationShortcutItems

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.3, 2017-12-14 Upgraded to Swift 4, iOS 11 SDK. [(Full Revision History)](https://developer.apple.com/library/archive/samplecode/ApplicationShortcuts/History/History.html#//apple_ref/doc/uid/TP40016545-RevisionHistory-DontLinkElementID_1) |
| __Build Requirements:__ | iOS 11.0 SDK, Xcode 9.0 |
| __Runtime Requirements:__ | iOS 10.0 or later |

Demonstrates how to use the UIApplicationShortcutItem class to provide quick access to parts of your application directly from the device's home screen. The sample shows two static shortcuts (defined in the app's Info.plist), and two dynamic shortcuts (defined in code with the UIMutableApplicationShortcutItem class). The dynamic shortcuts can be edited to change the title, subtitle and icon.
