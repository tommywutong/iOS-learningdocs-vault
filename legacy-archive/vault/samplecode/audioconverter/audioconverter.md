# audioconverter

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 SoundConverter routines to convert AIFF and AIFC files into AIFF/AIFC or QuickTime. Parse AIFF/AIFC files. |
| __Build Requirements:__ | Codewarrior |
| __Runtime Requirements:__ | Carbon |

AudioConverter is a sample application that illustrates how to use the Sound Manager's SoundConverter routines to convert AIFF and AIFC files (hereafter referred to as "AIFF/AIFC files") into either AIFF/AIFC files or QuickTime movies. It also illustrates how to parse AIFF/AIFC files. Requires: QuickTime 5 Keywords: QuickTime, SoundConverter, AIFF,AIFC
