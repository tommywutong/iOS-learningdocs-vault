GLUT for Mac OS X (supporting the GLUT 3.7 API) The OpenGL Utility Toolkit (GLUT) is a programming interface with ANSI C and FORTRAN bindings for writing window system independent OpenGL programs. This sample is the source and project for the GLUT-3.4.0 version of the GLUT framework. See the sample Read Me for specifics on what has changed and for build and installation instructions.
GLUT is available on Mac OS X through the GLUT framework. For details on how to use GLUT on Mac OS X, see the following Q&A:
Using GLUT and OpenGL on Mac OS X
http://developer.apple.com/mac/library/qa/qa2008/qa1613.html
