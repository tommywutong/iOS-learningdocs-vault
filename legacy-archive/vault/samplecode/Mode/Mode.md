# Mode

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Shows how to enumerate displays and list the available modes for each display. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X, Project Builder |

This is a CGDirectDisplay API demonstration command line tool. It shows how to identify the displays, iterate over them, and list the available modes for each display. The Mode sample does not actually change the display mode at all but instead writes out the available modes for each attached display to standard output. Requirements: Mac OS X, Project Builder Keywords: CGDirectDisplay, DrawSprocket, Display Manager, screen resolution, bit depth
