# RGB Image

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Demonstrates compositing to separate an NSimage into its RGB components, and how to recombine those components. |
| __Build Requirements:__ | N/A |
| __Runtime Requirements:__ | Mac OS X |

This sample demonstrates the use of compositing to separate an NSimage into its red, green, and blue components, and shows the results of recombining those components. Requirements: Mac OS X Version 10.2 (Jaguar)
