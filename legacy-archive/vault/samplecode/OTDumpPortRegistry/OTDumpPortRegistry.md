# OTDumpPortRegistry

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon You have to run the 68K version on a 68K Mac and the PPC version on a PPC Mac. |

This very simple sample dumps a text version of the OT port registry to stdout. The compiled executable also makes a handy debugging tool. Open Transport 1.1.1 or greater Requirements: You have to run the 68K version on a 68K Mac and the PPC version on a PPC Mac. Keywords: open transport, port registry, OTGetIndexedPort, dump, list, see, OTDumpPortRegistry
