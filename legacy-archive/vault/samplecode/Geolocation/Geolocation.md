# Geolocation

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2010-10-06 Demonstrates how to create location-aware iPhone web applications using the Geolocation API. |
| __Build Requirements:__ | Dashcode 3.0 or later, Mac OS X 10.6 or later |
| __Runtime Requirements:__ | iOS 3.0 or later |

This sample demonstrates how to create location-aware iPhone web applications using the Geolocation API. It displays a Google static map that shows the current location of a user. This sample describes how to register, update, and unregister for location change as well as how to handle location errors.
