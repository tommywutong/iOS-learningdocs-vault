# Print Clipped Offscreen

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-03-26 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

Print clipped offscreen: Takes a text string, turns it into a region and copies a clipped bitmap (just a pattern in this case, but it could be anything) to the printing grafPort. The effect is patterned text here, but any image could be showing through the text. This sample is a rewrite of the 'Offscreen region MaskRgn' sample. Keywords: clip, text, print
