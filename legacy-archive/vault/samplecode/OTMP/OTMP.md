# OTMP

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 A library for calling Open Transport synchronously from preemptively scheduled tasks (MP tasks). |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Open Transport, CarbonLib 1.2.5, Mac OS X, Mac OS 9 |

OTMP is a sample code library that lets you to call Open Transport synchronously from preemptively scheduled tasks (MP tasks). The library enables high performance network programming from a common source base on both Mac OS 9 and Mac OS X. This package contains the library itself, a number of supports modules, and a demo application. On traditional Mac OS, the OTMP library requires Mac OS 9.0 or above. Carbon applications should work with CarbonLib 1.0.4 and later, assuming the underlying Mac OS version is sufficient. On Mac OS X the OTMP library requires Mac OS X Public Beta or later. Requirements: Open Transport, CarbonLib 1.2.5, Mac OS X, Mac OS 9 Keywords: Open Transport, synchronous networking, sockets, Multiprocessor Threads, preemptive threads
