# QTKitThreadsExporter

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2007-10-08 Demonstrates QTKit threading APIs by performing concurrent exports on separate threads. |
| __Build Requirements:__ | Xcode 3.0 |
| __Runtime Requirements:__ | Mac OS X 10.5+, or Mac OS X 10.4.10+ w/QuickTime 7.3+. |

QTKitThreadsExporter is an example demonstrating the QTKit threading APIs added with Mac OS X 10.5 and QuickTime 7.3. It shows how to concurrently export up to four QTMovie objects on separate threads using the QTKit.
