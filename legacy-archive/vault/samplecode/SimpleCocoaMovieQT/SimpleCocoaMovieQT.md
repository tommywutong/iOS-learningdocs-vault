# SimpleCocoaMovieQT

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 A simple movie player showing how to use the NSMovieView and NSMovie Cocoa Objective-C classes. |
| __Build Requirements:__ | Mac OS X |
| __Runtime Requirements:__ | Mac OS X MacOS X, Project Builder 1.0.1 |

This sample contains code showing how to use the NSMovieView and NSMovie Cocoa AppKit classes. The code attemps to duplicate the functionality of the standard QuickTime movie controller using the NSMovieView/NSMovie methods. Requirements: MacOS X, Project Builder 1.0.1 Keywords: QuickTime, NSMovieView, NSMovie, movie
