# MoreNetworkSetup

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Network Setup library, which is currently only available as part of Mac OS 8.5. NetworkSetupHelpers provides compatibility glue for older systems and merely requires OT 1.1.1 or higher. |

This sample includes two source code libraries which provide simplified access to Network Setup. The first, MoreNetworkSetup, is a simple wrapper around Network Setup. The second, NetworkSetupHelpers, provides high-level functionality (for example, turning AppleTalk on/off, switching TCP/IP configurations) that works with both Network Setup and on pre-Mac OS 8.5 systems. Requirements: Network Setup library, which is currently only available as part of Mac OS 8.5. NetworkSetupHelpers provides compatibility glue for older systems and merely requires OT 1.1.1 or higher.
