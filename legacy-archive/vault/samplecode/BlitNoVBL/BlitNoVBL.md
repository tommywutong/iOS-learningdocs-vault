# BlitNoVBL

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Shows how to draw directly to the screen without syncing to the VBL of the monitor. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X, Project Builder |

The BlitNoVBL sample shows how to draw directly to the screen without syncing to the VBL of the monitor. See the separate BlitVBL sample to find out how to have Mac OS X try its best to sync to the VBL for you. Requirements: Mac OS X, Project Builder Keywords: VBL, blit, BlitVBL, tear-free, sync
