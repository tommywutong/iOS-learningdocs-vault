# BSDLLCTest

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-06-12 Program sample demonstrates how to send and receive raw LLC Ethernet packets. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Developer Tools Dec 2002 |

Carbon program sample demonstrating how to get a PFDRV socket and to use the socket to send and receive raw LLC Ethernet packets under Mac OS X. This version of the sample has been updated to use the MoreAuthSample fo demonstrate the use of a Tool to open the privileged socket and to use the MoreAuthSample code to transfer the opened socket back to the application. Requirements: Developer Tools Dec 2002 Keywords: Ethernet LLC 802.2 PFNDRV PF_NDRV raw-mode socket MoreAuthSample
