# ImageApp

Demonstrates basic image handling using the ImageIO API (CGImageSource/CGImageDestination). This includes the following:

Opening images

- getting image properties - image thumbnails - image profile issues

Displaying images with Quartz

- assigning default profiles for untagged images - matching across multiple display - respecting image orientation and aspect ratio

Filtering images (Core Image + color management)

- using Core Image filters - dealing with non-RGB images

Printing images

Saving images

- setting image properties - saving results from CI filtered images
