# qt3dtween

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Creates a QuickTime movie containing both a 3D track and a tween track. |
| __Build Requirements:__ | Carbon |
| __Runtime Requirements:__ | Carbon |

QT3DTween is a sample application that creates a QuickTime movie containing both a 3D track and a tween track. The 3D track is created by reading data from any 3DMF file. The tween track contains QuickDraw3D camera data. The camera data in the tween track specifies both an initial position for the camera and a final position for the camera. The result of the tween track can be seen as the movie is played: the objects in the scene will appear to move. Requires: QuickTime 5 Keywords: QuickTime, QD3D, tween, 3DMF
