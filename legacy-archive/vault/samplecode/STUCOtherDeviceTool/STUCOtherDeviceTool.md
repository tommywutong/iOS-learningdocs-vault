# STUCOtherDeviceTool

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2009-09-11 Sends SCSI commands to supported devices other than MMC authoring devices using SCSITask User Client. |
| __Build Requirements:__ | Xcode 3.1 or later, Mac OS X Leopard v10.5 or later |
| __Runtime Requirements:__ | Mac OS X Leopard v10.5 or later |

A command line tool that finds attached devices supported by the SCSITask User Client (STUC) API other than SCSI Multimedia Commands (MMC) authoring devices. Sends SCSI commands to these devices.
