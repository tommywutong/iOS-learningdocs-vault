# InputSprocketTestOld

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This sample demonstates the basic implmenetation of high and low level InputSprocket. It shows the following functionality: - ISpElementList_ExtractByKind - List all devices - List all elements - List all buttons - List all directional pads - List all axes - List all X-axes - Get events - Suspend - Resume - Create needs - Destroy needs - Get needs events - Configuration dialog - Enable mouse and keyboard - Disable mouse and keyboard - Reinitialize ADB bus - Allocate/Deallocate test - TestArbitraryAllocate test - TestAccelration - Enable speech - Disable speech Requires: PowerPC, System 8.1+, InputSprocket, and either Universal Interfaces 3.3 or InputSprocket SDK Keywords: InputSprocket, ISp, Needs, Elements, axes, buttons
