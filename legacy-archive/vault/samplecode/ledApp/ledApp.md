# ledApp

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

ledApp demonstrates controlling the lights on a U.S. extended ADB keyboard, installing a repetitive time manager task, including passing the A5 world and having the task wake up the main program when necessary, and making a notification manager call from a faceless background task. Requires: System 7.0 Keywords: ADB, led
