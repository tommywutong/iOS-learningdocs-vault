This sample code has been updated for QuickTime 5.0 README - QTMMaker QDMMaker is a sample application that creates movies that use the QuickDraw media handler. Select a menu item in the Make menu to create one of four different movies. You can use these movies to test the QuickDraw media handler. This code is based on the sample application code MakeMyMediaMovies. See develop magazine, issue 14, for more information about the QuickDraw derived media handler.
