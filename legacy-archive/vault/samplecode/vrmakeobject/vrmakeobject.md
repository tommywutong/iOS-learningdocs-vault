This sample code has been updated for QuickTime 5.0 VRMakeObject is a simple application that converts a linear QuickTime movie into a QuickTime VR object movie. The QuickTime VR movie created by VRMakeObject is either a version 2.0 QTVR movie or a version 1.0 QTVR movie; you select the version using the Test menu. 68k or PowerPC (or newer) machines running System 8.5 or later. PC with Intel Pentium or compatible processor. QuickTime 4.0 or later. CodeWarrior Pro 2 or later or Visual C++ 5.0 or later.
