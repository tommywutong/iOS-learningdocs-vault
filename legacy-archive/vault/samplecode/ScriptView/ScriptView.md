# ScriptView

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-01 Shows how to build a script editor application with a built-in script database using AppleScript Studio. |
| __Build Requirements:__ | Xcode 2.0 |
| __Runtime Requirements:__ | Mac OS X 10.4 |

This sample project shows how to use AppleScript Studio to build a script editing application with a built-in script database. It includes a detailed outline which describes each necessary step starting with creating a new project in Xcode as well as project milestones for each step and the final version.
