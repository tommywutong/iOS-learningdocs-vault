# NameAndAddress

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X or later |

NameAndAddress is a single window utility that can get a host name from an IP address or an IP address from a hostname. It uses the NSHost class. The application's interface demonstrates enabling and disabling interface elements based on the current state of the application, using both actions and notifications. Requirements: Mac OS X or later Keywords: NSHost,IP,TCP,Cocoa,Address
