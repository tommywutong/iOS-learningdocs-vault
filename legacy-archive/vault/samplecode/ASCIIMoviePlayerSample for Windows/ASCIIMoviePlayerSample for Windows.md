# ASCIIMoviePlayerSample for Windows

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-05-05 This sample demonstrates using a MovieDrawingCompleteProc to render a QuickTime movie in the Windows DOS Console. |
| __Build Requirements:__ | Visual Studio .NET 2003, Visual C++ .NET 2003 |
| __Runtime Requirements:__ | Windows XP |

Bring back the glory days of ASCII art with ASCIIMoviePlayer for Window! This sample demonstrates using a MovieDrawingCompleteProc to render a QuickTime movie in the Windows DOS Console. Yes, it's true, enjoy the latest QuickTime Movie Trailers without leaving the warmth of the DOS console.
