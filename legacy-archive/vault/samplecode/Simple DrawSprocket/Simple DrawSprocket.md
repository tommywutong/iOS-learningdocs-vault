# Simple DrawSprocket

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 Simple use of DrawSprocket to set screen resolution and size. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon CW2 or later and Universal Headers 3.2 (3.3 if building for DrawSprocket 1.7) |

This sample is designed to show simple use of DrawSprocket to set screen resolution and size within the confines of a standard Macintosh Toolbox environment. Additionally, it demonstrates how to get DrawSprocket's version with DSpGetVersion () and without it. Requirements: CW2 or later and Universal Headers 3.2 (3.3 if building for DrawSprocket 1.7) Keywords: DrawSprocket, GSpGetVersion, Toolbox
