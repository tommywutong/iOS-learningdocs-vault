# Color Gamut Showcase: Using wide color gamut in Cocoa and Cocoa Touch applications with SceneKit

This sample code illustrates how techniques and Metal shaders can be used in a SceneKit app to show the difference between the gamuts of the Display P3 and sRGB color spaces.

## Requirements

### Build

Xcode 8.0 or later, iOS 10.0 SDK or later, macOS 10.12 SDK or later

### Runtime

iOS 10.0 or later, macOS 10.12 or later
