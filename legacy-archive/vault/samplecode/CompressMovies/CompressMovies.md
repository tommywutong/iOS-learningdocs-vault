# CompressMovies

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Shows how to use QuickTime movie compression in an application. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Mac OS 8.6 and CodeWarrior 6, or Mac OS 10.1 and Project Builder 1.1, QuickTime 5 |

README -CompressMovieCompressMovie is a simple dragp and drop QuickTime application for compression of files. Drag and drop movie files on top of the application, and then specify the compression values (this happens the first time, after this the compression values are used for other movies dropped on the application at the same time).Note that it's not useful to re-compress already compressed movies, as such compression will introduce more lossiness in the quality of the images. If possible always compress using the original, non-compressed data. Requirements: Mac OS 8.6 and CodeWarrior 6, or Mac OS 10.1 and Project Builder 1.1, QuickTime 5 Keywords: QuickTime, Image Compression
