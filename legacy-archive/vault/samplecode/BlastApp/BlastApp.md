# BlastApp

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2012-06-07 BlastApp is a simple, "blast-everything-in-sight" type of game. |
| __Build Requirements:__ | Xcode 4.0 or later, Mac OS X v10.7 or later |
| __Runtime Requirements:__ | Mac OS X v10.7 or later |

BlastApp is a simple, "blast-everything-in-sight" type of game. It shows off use of NSView, NSImage, Cocoa drawing, and timers. It is also an ARC app.
