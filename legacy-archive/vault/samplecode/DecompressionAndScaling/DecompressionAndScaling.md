# DecompressionAndScaling

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Shows how to convert a version 2 PICT to a compressed QuickTime data buffer. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This example shows how to convert a version 2 PICT to a compressed QuickTime data buffer. Once the PICT is compressed, it is then decompressed to the window at one quarter its original size. Requires: QuickTime Keywords: QuickTime, PICT, compression
