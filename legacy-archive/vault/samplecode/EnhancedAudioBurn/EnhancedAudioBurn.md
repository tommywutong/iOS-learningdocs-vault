# EnhancedAudioBurn

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-07-06 This Objective-C sample demonstrates how to burn RedBook Audio CDs. |
| __Build Requirements:__ | Xcode 1.0 or later |
| __Runtime Requirements:__ | Mac OS X 10.2 or later |

EnhancedAudioBurn is an Objective-C sample demonstrating how to burn RedBook Audio CDs. The sample illustrates features of the audio track API. The sample also uses the DiscRecordingUI framework to present the standard burn setup and progress user interfaces.
