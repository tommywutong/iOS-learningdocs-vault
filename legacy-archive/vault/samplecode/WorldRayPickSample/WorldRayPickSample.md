# WorldRayPickSample

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

World ray picking is a new pick object type introduced with QuickDraw 3D 1.6 which helps applications detect which geometric objects are close to each other in world-space with respect to a ray vector. This sample demonstrates use of this new pick object type.
