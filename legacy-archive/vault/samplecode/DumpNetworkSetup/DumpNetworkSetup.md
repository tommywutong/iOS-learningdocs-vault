# DumpNetworkSetup

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Network Setup, Mac OS 8.5 |

DumpNetworkSetup dumps the entire contents of the Network Setup database to a text file. The purpose of this sample is twofold. First, it shows a simple use of the Network Setup API. Second, it is a useful tool for debugging other Network Setup code because it allows you to see the affect your code had on the database. For instance, DumpNetworkSetup was used extensively while developing the MoreNetworkSetup sample. Requirements: Network Setup, Mac OS 8.5 Keywords: Network Setup, network preferences, DumpNetworkSetup
