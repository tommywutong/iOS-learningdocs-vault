# Sprite Tour

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2013-06-03 Sprite Tour demonstrates the capabilities of the SKSpriteNode class, including many animated actions that apply only to sprite nodes. |
| __Build Requirements:__ | Xcode 5.0 or later |
| __Runtime Requirements:__ | Mac OS X v10.9 or later |

Sprite Tour demonstrates how to configure a SKSpriteNode object to perform many tasks, including colorization, texture stretching, and blending. This sample includes many common behaviors that you can use to implement your own apps.
