Sproing is a Cocoa application which shows how "springs" work to control view resizing when a window resizes. You can use it to explore springs by seeing what they do, to generate the code for a particular set of springs, or to encode or decode springs in hexadecimal. Requirements: Mac OS X Keywords: AppKit NSView view resizing autoresizing mask springs
