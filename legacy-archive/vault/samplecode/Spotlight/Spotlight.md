# Spotlight

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-01 Sample code that shows how to write Spotlight Importers. |
| __Build Requirements:__ | 10.4 or later |
| __Runtime Requirements:__ | 10.4 or later |

iff-importer is a simple Spotlight importer for the old IFF image file format.
dbg-importer is an example Spotlight importer that shows how to define new attributes.
NoteTaker is a Spotlight importer that shows how to deal with a package based file format.
