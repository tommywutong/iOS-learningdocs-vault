The "Hello World" of multi-touch applications, LightTable. This sample project demonstrates how to use mouse and multi-touch events to provide an enhanced user experience. Drop images on the Light table and resize them using two fingers and a multi-touch capable trackpad. Double-click the slide to adjust the image size and placement within the slide.
