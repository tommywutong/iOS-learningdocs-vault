# SimpleImageFilter

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2009-05-26 SimpleImageFilter is a filter service that converts IFF images to TIFF. |
| __Build Requirements:__ | Xcode 3.2 or later, Mac OS X v10.6 or later |
| __Runtime Requirements:__ | Mac OS X v10.6 or later |

SimpleImageFilter is a filter service that converts IFF (Interchange File Format) images to TIFF, allowing Cocoa applications to load and display IFF images.
