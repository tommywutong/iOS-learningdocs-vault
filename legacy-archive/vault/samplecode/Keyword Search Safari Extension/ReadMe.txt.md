### KeywordSearchSafariExtension ###

===========================================================================
DESCRIPTION:

This extension handles the "beforeSearch" event so the user can search bugs.webkit.org, trac.webkit.org, and developer.apple.com by simply typing the first letter of the site the user would like to search followed by a space and then the search term.
For example, if the user types "t FrameLoader" into the smart search field and hits enter, the extension will cancel the search and instead navigate to the search page of trac.webkit.org.

===========================================================================
BUILD REQUIREMENTS:

Safari v6 or later

===========================================================================
RUNTIME REQUIREMENTS:

Safari v6 or later

===========================================================================
PACKAGING LIST:

global.html
    The HTML file for the Global Page. Contains the logic for handling the beforeSearch event.
Info.plist
    The file generated by the Extension Builder with the configuration for this extension.
