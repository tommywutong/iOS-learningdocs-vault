# QTMP3Player

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X, Project Builder |

The QTMP3Player sample shows how to make a "one-page" MP3 player using QuickTime. Note that this isn't the most efficient way to play MP3s. For more in-depth information, see the other DTS sample MP3Player that shows how to use QuickTime and the Carbon Sound Manager to play VBR MP3 files. Requirements: Mac OS X, Project Builder Keywords: QuickTime, MP3, MP3Player
