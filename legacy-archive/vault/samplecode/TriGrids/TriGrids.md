QuickDraw 3D TriGrids This application has some examples on how to use trigrids to generate different geometries and how to texture them with PICTs. If you crash with a powerPC unmapped memory exception, and you are running with the metrowerks debugger, type GP to propogate the exception to the high level debugger.
