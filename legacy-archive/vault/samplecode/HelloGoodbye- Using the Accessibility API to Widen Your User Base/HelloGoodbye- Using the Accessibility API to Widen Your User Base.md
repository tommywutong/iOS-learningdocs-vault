# HelloGoodbye: Using the Accessibility API to Widen Your User Base

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2014-09-17 [(Full Revision History)](Document%20Revision%20History.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2dkojtfvjgk5tjonuw63sinfzxi33spewui33oorggs3tlivwgk3lfnz2esrc7ge) |
| __Build Requirements:__ | Xcode 6.0 or later; iOS 8 SDK or later. |
| __Runtime Requirements:__ | iOS 8 or later. |

This project shows you how to use the Accessibility API to widen your user base. It demonstrates how you can adjust your user interface when a user has Bold Text, Reduce Transparency, Darken Colors, or Reduce Motion enabled. It also contains examples of API you can implement to allow a VoiceOver or Switch Control user to interact with your app.
