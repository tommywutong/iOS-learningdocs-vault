# TexturePerformanceDemo

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-01 OpenGL texture optimization demo for WWDC Session 214 |
| __Build Requirements:__ | Xcode 2.0 or later |
| __Runtime Requirements:__ | Mac OS X 10.4 or later |

This is the texturing optimization demo used in WWDC Session 214: Hands-On Maximizing OpenGL Performance. It is a staged sample that shows both a slow path and a fast path for texture uploads on Mac OS X.
