# 3D Rotation Controller

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon System 7.0 or later |

This sample is the companion to the article "3-D Rotation using a 2-D Device" in the June 93 issue of develop. Rotation Controller demo 1.0.1 contains a demo program and an experiment showing five rotation controller interfaces for rotating three-dimensional objects with the mouse. Virtual Sphere Sample Code 1.1 contains the source code for implementing the Virtual Sphere rotation controller. For those who have asked me for source code, here it is!
