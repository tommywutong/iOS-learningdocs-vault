# databurntest

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Demonstrates how to create a DRFolderRef and burn it to disc. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X 10.2 or later |

databurntest is a simple example demonstrating some of the features of DRTrackRefs. The sample illustrates how to create a DRFolderRef from an existing folder on the source disk and burn it to disc, creating a hybrid ISO9660/Joliet/HFS+ data CD. Requirements: Mac OS X 10.2 or later Keywords: DiscRecording CD Burn Hybrid ISO9660 Joliet HFS+
