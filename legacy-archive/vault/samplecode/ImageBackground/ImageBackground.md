# ImageBackground

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-10-02 Shows how to draw an image in the background of an NSOutlineView and NSTableView. |
| __Build Requirements:__ | Xcode 2.3 |
| __Runtime Requirements:__ | Mac OS X 10.3.x |

ImageBackground shows how to draw an image in the background of an NSOutlineView and NSTableView. The application presents some hierarchical data with icons in its NSOutlineView and simple column data in its NSTableView.
