# TextLinks

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-29 Programmatically creates links to URLs and other objects and handles clicks in non-URL links. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X |

TextLinks is an example Cocoa application which shows how to programmatically create links to URLs and other objects, handle clicks in non-URL links, and display a custom mouse cursor over links. You can also use it to view the attributes in rich text. This version (0.2) fixes a minor bug in displaying the attributes under the mouse. Requirements: Mac OS X Keywords: Cocoa NSTextView NSAttributedString NSURL link attributes cursor
