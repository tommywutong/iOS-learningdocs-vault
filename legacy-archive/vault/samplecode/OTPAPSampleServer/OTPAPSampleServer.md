# OTPAPSampleServer

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon The PostScript query parser implemented in this sample is very simplistic and should not be used in production code. |

OTPAPSampleServer is a Native Open Transport implementation of a AppleTalk Printer Access Protocol (PAP) server. Features support for multiple handoff endpoints, self send mode so that you can print from the same system that the PAP Server is running on, demonstrates the use of Option Management to enable the EOMOption, and to set the server message. This sample was built with CodeWarrior and includes the Project file used to generate the program. System Software 7.5.5 with Open Transport 1.1.2 or greater present. The optimum SSW release is 8.6 with OT v2.0.3 present. Requirements: The PostScript query parser implemented in this sample is very simplistic and should not be used in production code. Keywords: AppleTalk, Printer Access Protocol, PAP, EOM Option, Self Send Option, EOF indication, OTPAPSampleServer
