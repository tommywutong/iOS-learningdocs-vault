# Color Picker

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Color QuickDraw, CarbonLib |

This sample has been updated for the Carbon API. This app provides a quick example of how to change palette colors using the Color Picker Package. The program simply creates a palette, attaches it to a window, then calls color picker routines whenever a user clicks in the window to change a color. Requirements: Color QuickDraw, CarbonLib Keywords: Color Picker, Palette, Carbon
