# Aperture Edit Plugin - Borders & Titles

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2008-06-02 "Borders & Titles" is a sample plugin for Aperture that demonstrates how to use the image editing API introduced with Aperture 2.1 |
| __Build Requirements:__ | Aperture 2.1 SDK, Mac OS X 10.5 |
| __Runtime Requirements:__ | Aperture 2.1, Mac OS X 10.5 |

"Borders & Titles" is a sample plugin for Aperture that demonstrates how to use the image editing API introduced with Aperture 2.1. This sample adds a custom border to an image and overlays attributed strings. The sample code illustrates how to interface with Aperture's Edit API to get images and metadata from Aperture, make changes those images, and add metadata information to the user's Aperture database.
