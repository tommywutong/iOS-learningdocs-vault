# WindowColors

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-30 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This application displays the default window colors stored in the System's 'wctb' resource. Note that this app is 7.0 only, since it only recognizes the 7.0 version of the resource.
