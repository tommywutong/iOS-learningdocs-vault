# CustomPicComments

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-10 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Color QuickDraw, CarbonLib |

This sample has been updated for the Carbon API. This sample groups a bunch of pictures together and takes them apart using PicComments and a QuickDraw bottleneck procedure. It's an example of how to store and retrieve custom PicComments, among other things. Requirements: Color QuickDraw, CarbonLib Keywords: PicComments, QuickDraw bottleneck, Carbon
