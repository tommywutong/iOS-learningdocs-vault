# InkSample

|  |  |
| --- | --- |

| __Build Requirements:__ |  |

This is the InkSample 1.1 sample code. It is designed to demonstrate some usage scenarios for the Ink.Framework APIs. The sample contains a window with a tabbed control in which there are four panes. Each pane demonstrates a different task using the Ink.Framework APIs. This sample requires Mac OS X 10.3 and later. Requirements: Mac OS X 10.3. Keywords: Ink Ink.framework handwriting recognition
