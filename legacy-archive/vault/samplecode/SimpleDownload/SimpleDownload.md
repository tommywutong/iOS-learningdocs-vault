# SimpleDownload

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Shows how to use the Image Capture APIs to download a user-selected file to the user's ~/Pictures directory. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X |

SimpleDownload A simple Cocoa application, that uses the new Image Capture APIs: ICADownloadFile and ICACopyObjectPropertyDictionary to download a user selected file to the Picture folder in the user's home directory. Requirements: Mac OS X Keywords: Image Capture download
