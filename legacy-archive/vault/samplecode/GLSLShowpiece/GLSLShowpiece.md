# GLSLShowpiece

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-07-17 GLSLShowpiece demonstrates several Vertex and Fragment shaders |
| __Build Requirements:__ | Xcode 2.2 - Mac OS X 10.4 (universal) SDK |
| __Runtime Requirements:__ | Mac OS X 10.4 |

This examples showcases the amazing visual results that can be obtained using the OpenGL Shading Language.
Several shaders from the "Orange Book" among others are exhibited.
Mac OS X 10.4 - > 10.4.2 uses the software renderer.
Mac OS X 10.4.3 provides hardware acceleration of shaders in graphics cards that support it.
