# MoreAutoPush

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS 9 Open Transport |

This sample serves two purposes: it contains a sample code library that simplifies access to the STREAMS "sad" (autopush) driver, and it includes a program that you can use to establish arbitrary autopushes for testing purposes. Requirements: Open Transport Keywords: Open Transport, autopush, sad driver
