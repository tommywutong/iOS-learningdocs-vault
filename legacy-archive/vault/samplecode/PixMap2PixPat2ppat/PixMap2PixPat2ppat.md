# PixMap2PixPat2ppat

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-27 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon (both 9 and X) Color QuickDraw, CarbonLib |

This sample has been updated for the Carbon API. PixMap2PixPat2Ppat has been updated to use GetPixRowBytes() and not leak a PixMap. This sample shows how to convert a 'icl8' image to a PixMap image and then to a PixPat and then finally to a 'ppat' resource. In this example, the 'ppat' resource is saved-off into a resource file. Requirements: Color QuickDraw, CarbonLib Keywords: QuickDraw PixMap PixPat ppat GetPixRowBytes, Carbon
