VRMovies uses the QuickTime VR API to provide support for playing QuickTime movies in a panorama. This sample includes a Project Builder project for Mac OS X 10.2 using the August 2002 developer tools, and also includes a CodeWarrior 8.2 Mach-O project. A Visual C++ 6.0 project is provided for Windows. Requirements: Mac OS X 10.2, QuickTime 6+, August 2002 Developer Tools, CodeWarrior 8.2, Mac OS 9, QuickTime 5+, CodeWarrior 7, Windows, QuickTime 5+ and SDK, Visual C++ 6.0 Keywords: QuickTime, VR, Panoramic, Playing, Movies
