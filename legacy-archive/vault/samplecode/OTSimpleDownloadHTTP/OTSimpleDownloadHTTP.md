# OTSimpleDownloadHTTP

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Demonstrates the easiest way to use Open Transport to download an HTTP URL. |
| __Build Requirements:__ | Project Builder |
| __Runtime Requirements:__ | Mac OS X or any version of Mac OS that includes Open Transport |

This sample demonstrates the easiest way to use Open Transport to download an HTTP URL from a web server. The code from this sample is featured in the latest release (v1.3) of the book "Inside Macintosh: Open Transport".
