# HelloGameKit: A skeleton app for turn based games on watchOS

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2016-10-27 First release |
| __Build Requirements:__ | Xcode 8.0 or later; iOS 10.0 SDK or later; watchOS 3.0 SDK or later |
| __Runtime Requirements:__ | iOS 10.0 or later; watchOS 3.0 or later |

This sample is an implementation of a simple turn based game for watchOS. It demonstrates the following technologies:

\* Game Center turn based multiplayer
\* SpriteKit Scenes/Nodes/Actions
\* Haptic Feedback
\* WKGestureRecognizer
