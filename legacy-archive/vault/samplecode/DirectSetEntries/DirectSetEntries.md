# DirectSetEntries

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon ColorQuickDraw |

The sample demonstrates the use of DirectSetEntries. The code scans throught the GDevice list for all monitors which are in 16 or 32 bit mode and then changes the entires on those monitors. It looks real ugly, but if you feel the need to animate colors on a direct monitor, then this is the way you do it. Requirements: ColorQuickDraw Keywords: GDevice, GetGDevice, GetDeviceList, PBControl, Gamma, Gamma Table
