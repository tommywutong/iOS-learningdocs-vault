# ColorCDEF

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-08-28 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This working sample defproc emulates the features of the standard button control for system software 7.0 on the macintosh. This defproc, while completely functional is intended as an explanatory example to show some of the basics of writing your own defproc. Keywords: CDEF
