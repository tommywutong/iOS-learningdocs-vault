# OTSimpleServerHTTP

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 A simple web (HTTP) server that demonstrates using the single-link multi-homing feature of OT 1.3. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon MacOS 8.1 or later, CarbonLib 1.0.4 or later. |

This sample is a very simple web (HTTP) server that demonstrates how to exploit the single-link multi-homing feature of OT 1.3. Requirements: MacOS 8.1 or later, CarbonLib 1.0.4 or later. Keywords: Single-Link Multi-Homing, OpenTransport, Networking
