# TextTrack

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-27 Demonstrates some simple operations on Final Cut Pro XML files |
| __Build Requirements:__ | 10.4 |
| __Runtime Requirements:__ | 10.4 plus Perl module XML::LibXML |

Two Applescript droplet/Perl script combinations. One extracts information from a Final Cut Pro XML file. The other adds some tags to a Final Cut Pro XML file based on the content of an input text file.
