# Quartz Composer Offline Rendering

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-01 Shows how to render a Quartz Composer composition as a series of images using an OpenGL pBuffer. |
| __Build Requirements:__ | Xcode 2.0 or later |
| __Runtime Requirements:__ | Mac OS X 10.4 or later and Quartz Extreme compatible machine |

A command-line tool that uses the QCRenderer API to render a Quartz Composer composition offscreen on the video card using an OpenGL pBuffer, download the pixels data, then save the frames to disk as separate compressed TIFF files.
