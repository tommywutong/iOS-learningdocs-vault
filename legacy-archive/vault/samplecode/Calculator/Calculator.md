# 计算器（Calculator）

|  |  |
| --- | --- |
| __最后修订：__ | 版本 1.0，2003-01-30　实现了一个简单的"四则运算"计算器。 |
| __构建要求：__ | Mac OS X |
| __运行要求：__ | Mac OS X |

本应用程序复刻了 Macintosh 的 Calculator 桌面附件（Desk Accessory），实现了一个简单的"四则运算"计算器（four-banger calculator）。

__构建代码__　本代码在 Mac OS X 上构建，开箱即可直接编译，不会遇到问题。

__已知问题__　原版的 Calculator DA 在往计算器里粘贴内容时会做一些奇怪的事情（比如高亮按键）。本版本不去处理这些行为，而且它也不懂得如何与太多其他应用程序进行剪切和粘贴。有时，剪切和粘贴可能会在视图中输入非法值。

要求：Mac OS X

关键词：Carbon、aglUseFont、OpenGL、text、agl、font
