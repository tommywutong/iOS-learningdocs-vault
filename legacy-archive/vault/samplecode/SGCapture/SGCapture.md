# SGCapture

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Displays live video within a QTCanvas using the SGDrawable class. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This demo program shows how to use the SGDrawable class to display live video within a QTCanvas. Requirements: - Common - Sun Compliant Java Runtime Environment 1.1 - QuickTime 3 - QTJava.zip - QTJava media samples - Mac OS: - System 8 or later - Macintosh Runtime for Java (MRJ) 2.1 - Windows 95, 98, or NT:: - JRE/JDK from Sun Microsystems, Inc. recommended Keywords: QuickTime, Java, MRJ
