| __Runtime Requirements:__ | Java 1.5 and QuickTime 7, or later, recommended |

MovieTextFinder shows how to search for text within the text track of a QuickTime movie. It brings up a window with a text movie and allows the user to search for a string inside the text track. Several Swing controls are used to allow the user to search forwards and backwards, toggle case sensitivity, and to wrap the searches past the end of the movie.
