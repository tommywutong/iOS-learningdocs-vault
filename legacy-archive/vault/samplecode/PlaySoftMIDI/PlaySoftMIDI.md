# PlaySoftMIDI

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2009-04-15 Plays a MIDI file using a sequence of audio units for sequencing and audio output |
| __Build Requirements:__ | Mac OS X v10.6 or later |
| __Runtime Requirements:__ | Mac OS X v10.6 or later |

The PlaySoftMIDI project uses a sequence of audio units, including the DLSSynth, PeakLimiter, and DefaultOutput units, to play back a specified MIDI file.
