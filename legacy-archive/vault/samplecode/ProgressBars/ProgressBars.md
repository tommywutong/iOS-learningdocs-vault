# ProgressBars

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-30 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

ProgressBars "ProgressBars" is a source code sample illustrating how to use the "standard" progress bar and the "barber pole" progress bar in an application. Inidicators displayed in this example are not based on the appearance manager controls. Developers creating applications for use with Mac OS 8 and later should use the appearance manager indicator controls.
