This sample demonstrates how to use UI elements available in the WatchKit framework. Refer to this sample to see how to use, configure, and interact with each UI element. This project also shows you how to use new capabilities in WatchKit for watchOS 3.0 including inline movie support, new API to work with the Digital Crown, and gesture recognizers.
