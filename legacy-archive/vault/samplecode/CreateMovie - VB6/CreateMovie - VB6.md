# CreateMovie - VB6

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-11-09 Using the QuickTime 7 COM Control to create a movie from images and save the movie to disk |
| __Build Requirements:__ | Microsoft Visual Basic 6 |
| __Runtime Requirements:__ | Windows 2000 or XP, QuickTime 7 |

CreateMovie - VB6 is a Microsoft Visual Basic 6 application which demonstrates how to use the QuickTime COM Control in QuickTime 7 to create a movie from a sequence of images and then save that movie to disk. This sample uses the CreateNewMovieFromImages method to create the movie.
