# iSync Sample Document

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-08-01 iSync Plug-in Maker sample document, illustrating how to build an iSync plug-in for a SyncML phone. |
| __Build Requirements:__ | iSync Plug-in Maker 1.0 |
| __Runtime Requirements:__ | Mac OS X 10.4 |

This is a sample document for the iSync Plug-in Maker developer tool.
Before being loaded by iSync, this document will need to be exported as a plug-in and installed in /Library/PhonePlugins or ~/Library/PhonePlugins.
This document illustrates some proposed configuration of a SyncML client behaving nicely with iSync.
