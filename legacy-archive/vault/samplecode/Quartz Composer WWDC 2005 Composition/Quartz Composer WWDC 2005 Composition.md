# Quartz Composer WWDC 2005 Composition

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-01 Shows how to build a parameterized motion graphics composition with Quartz Composer. |
| __Build Requirements:__ | Xcode 2.0 or later |
| __Runtime Requirements:__ | Mac OS X 10.4 or later and Quartz Extreme compatible machine |

This sample demonstrates how to build a basic motion graphics composition with Quartz Composer. The resulting composition is also parameterized so that it can be controlled from the host application.
