# Cocoa - SGDataProc

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Uses a Sequence Grabber data function and an NSQuickDrawView to simulate a preview operation for captured video. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X, Project Builder 1.1.1 (December 2001 Dev Tools) or better |

This sample is based on the existing SGDataProc sample, which is a Carbon application. This sample demonstrates how to use a Sequence Grabber data function in the Cocoa environment to simulate a "preview" operation for the captured video data. A NSQuickDrawView is used for display of the data. Requirements: Mac OS X, Project Builder 1.1.1 (December 2001 Dev Tools) or better Keywords: Sequence Grabber data function Cocoa NSQuickDrawView
