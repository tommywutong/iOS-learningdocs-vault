# ConvertToMovieJr

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Shows how to recompress QuickTime movies using the Image Compression Manager routines. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Mac OS 8.6 and CodeWarrior 6, or Mac OS 10.1 and Project Builder 1.1, QuickTime 5 |

This is an example application showing how to recompress QuickTime movies using the Image Compression Manager routines. Specifically, the sample makes use of an image compression sequence to recompress each frame of a given movie. The standard compression dialog is presented to allow the user to choose the various compression settings for the new movie. Requirements: Mac OS 8.6 and CodeWarrior 6, or Mac OS 10.1 and Project Builder 1.1, QuickTime 5 Keywords: QuickTime Image Compression
