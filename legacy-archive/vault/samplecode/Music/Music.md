# Music

| __Build Requirements:__ | XCode 2.2, or Java 2 SDK for Windows, and QuickTime 7 |
| __Runtime Requirements:__ | Java 1.5 and QuickTime 7, or later, recommended |

This demo shows how to use the Musical Instruments package that's part of QuickTime using a NoteAllocator component. The user is prompted to pick an instrument. The ToneDescription of the result is then printed out. The program then makes a new NoteChannel to play a note using the Nylon String Guitar sound.
