# OTClassicContext

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS 9 Open Transport 1.1.1 or higher, PowerPC |

OTClassicContext provides the glue necessary to call the Carbon "InContext" Open Transport APIs in an InterfaceLib environment. The goal is to allow you to build a Carbon and non-Carbon application (or extension) from the same source base without conditional compilation. Requirements: Open Transport 1.1.1 or higher, PowerPC Keywords: Open Transport, Carbon, OTClientContextPtr
