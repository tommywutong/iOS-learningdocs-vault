# ARPSample

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Open Transport 1.1.1 or higher |

Address Resolution Protocol (ARP) is a protocol for mapping protocol (eg IP) addresses to hardware (eg Ethernet) addresses. The OT ARP module provides an ARP service that is used by the OT TCP/IP stack. This sample demonstrates how you can get direct access to the ARP module to, amongst other things, add and remove ARP cache entries. Requirements: Open Transport 1.1.1 or higher Keywords: Open Transport, ARP, cache, add, delete, query, ARPSample
