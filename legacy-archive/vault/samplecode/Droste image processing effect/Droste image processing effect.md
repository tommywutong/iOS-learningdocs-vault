# Droste image processing effect

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2010-06-07 Core Image kernel for performing Droste effect on images & video implemented inside of Quartz Composer |
| __Build Requirements:__ | Mac OS X v10.6 or later |
| __Runtime Requirements:__ | Mac OS X v10.6 or later |

This Quartz Composer composition allows you to select two points which define an inner rectangle which will then get cut out and the remainder of the image will get replicated in an annular fashion. The idea is based upon an unfinished lithograph that M.C. Escher attempted to produce in 1956 and can now be performed in real-time using a custom kernel inside of Core Image.
