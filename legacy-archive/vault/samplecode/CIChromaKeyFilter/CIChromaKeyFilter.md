# CIChromaKeyFilter

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2009-08-27 Custom CIFilter developed inside of QuartzComposer for rapid prototyping of a CIKernel. The filter does a 'green screen' effect. |
| __Build Requirements:__ | QuartzComposer on Mac OS X v10.6 or later |
| __Runtime Requirements:__ | Mac OS X v10.6 or later |

Custom CIFilter developed inside of QuartzComposer for rapid prototyping of a CIKernel. The filter does a 'green screen' effect by removing pixels from an image based on their chroma and compositing it over another image.
