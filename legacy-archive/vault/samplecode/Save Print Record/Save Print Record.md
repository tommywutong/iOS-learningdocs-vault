# Save Print Record

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

Save a Print Record: Walks you through the style and job dialogs to create a print record ready-to-print-with, and then saves it to a resource file with resource type 'YO!!' and ID 128. The first step towards saving print records for multiple printers so you can set your favorite parameters before printing, since there's no API to do most of it. Keywords: print, record, save
