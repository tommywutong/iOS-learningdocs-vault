# OTTraceRouteSample

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Any Macintosh with Open Transport. |

This sample is a quick demonstration of how to implement traceroute on top of the Open Transport native APIs. The sample is useful because it gives a good demonstration of the setting the IP TTL option and of using a "rawip" endpoint to receive and process ICMP packets. Requirements: Any Macintosh with Open Transport. Keywords: Open Transport, OT, Traceroute, rawip, icmp, udp, OTTraceRouteSample
