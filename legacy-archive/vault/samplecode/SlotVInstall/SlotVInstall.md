# SlotVInstall

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This little program installs a slot VBL task for the main screen, even if the main screen uses built-in video, by getting the gdRefNum and calling GetDctlEntry to find the slot number. Requires: slots Keywords: SlotVInstall, vertical retrace interrupts, vertical blanking
