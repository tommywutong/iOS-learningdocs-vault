# LittleArrowsShowcase

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-11-09 How to increment and decrement the LittleArrows value when the user clicks on the up and down buttons. |
| __Build Requirements:__ | Mac OS X 10.4 |
| __Runtime Requirements:__ | Mac OS X 10.4 |

The LittleArrows control does not increment or decrement its value automatically when the user clicks on the up or down arrows.
The recommended way to deal with the incrementing or decrementing is to install a ControlAction on the control.
This sample code shows how to proceed when the control is instantiated from a nib or instantiated programmatically.
