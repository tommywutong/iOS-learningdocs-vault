# AVBNetworkBrowser

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2014-03-20 Usage of AudioVideoBridging framework for discovery and communications with AVB Entities. |
| __Build Requirements:__ | Mac OS X v10.9 or later |
| __Runtime Requirements:__ | Mac OS X v10.9 or later |

This project shows how to use the AudioVideoBridging framework to discover IEEE Std. 1722.1™-2013 (AVDECC) Entities available on a network and how to read information from them.
