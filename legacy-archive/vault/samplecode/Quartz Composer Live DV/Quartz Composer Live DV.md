# Quartz Composer Live DV

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-01 Shows how to export a Quartz Composer composition as a real-time DV stream on the FireWire port. |
| __Build Requirements:__ | Xcode 2.0 or later |
| __Runtime Requirements:__ | Mac OS X 10.4 or later, Quartz Extreme compatible machine and a DV camera with DV-in capability |

This sample shows how to use the QCRenderer API to render and export a Quartz Composer composition as a real-time DV stream on the FireWire port.
