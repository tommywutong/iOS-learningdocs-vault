# ListMania

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Demonstrates a variety of techniques for using Open Transport's list utility routines. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Mac OS X and Project Builder or CodeWarrior with Carbon SDK 1.2.5 and Universal Interfaces 3.3.2 |

This sample demonstrates a variety of techniques for using Open Transport's list utility routines. Specifically, it shows how to use OTLIFO lists in a simple producer/consumer application. The code from this sample is featured in the latest release (v1.2) of the book "Inside Macintosh: Open Transport". Requirements: Mac OS X and Project Builder or CodeWarrior with Carbon SDK 1.2.5 and Universal Interfaces 3.3.2 Keywords: OpenTransport, Open Transport, OT, List Management, OT Lists, OTLIFO, list utility, list management, network list.
