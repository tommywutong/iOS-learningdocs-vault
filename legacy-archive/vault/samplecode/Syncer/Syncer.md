# Syncer

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-08-01 A widget that demonstrates how to use handle a Dashboard Sync event. |
| __Build Requirements:__ | Leopard Preview |
| __Runtime Requirements:__ | Leopard Preview |

This widget saves a preference that's synced between Macs using Dashboard Sync. The widget provides a handler for the sync event that retrieves and applies any newly synced preferences.
