# DefaultOutputUnit

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2009-04-15 Sample project for creating an instance of the default output unit and using it to output a sine wave |
| __Build Requirements:__ | Mac OS X v10.6 or later |
| __Runtime Requirements:__ | Mac OS X v10.6 or later |

The DefaultOutputUnit project provides sample code for obtaining the default output unit (an instance of AUHAL that tracks the default output device) and uses it to play a sine wave at different bit depths, channel numbers, and sample rates.
