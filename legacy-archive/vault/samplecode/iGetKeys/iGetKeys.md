# iGetKeys

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-10 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X CarbonLib, Project Builder |

iGetKeys provides a set of keyboard state inquiry routines built on top of GetKeys that provide automatic mapping of ascii codes to their corresponding virtual key codes based on the current keyboard mapping table. On the fly translation of ascii codes to virtual key codes allows applications to use GetKeys in a keyboard layout independent way. Requirements: CarbonLib, Project Builder Keywords: KCHR, getkeys keyboard, key.
