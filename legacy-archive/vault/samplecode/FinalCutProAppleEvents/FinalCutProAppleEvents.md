# FinalCutPro_AppleEvents

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.2, 2009-07-24 Support for new Apple Events added in Final Cut Pro 7.0 [(Full Revision History)](Document%20Revision%20History.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpirkfgmjqgaydimjrgawvezlwnfzws33ojbuxg5dpoj4s2rdpnz2ey2lonncwyzlnmvxhiskel4yq) |
| __Build Requirements:__ | XCode 2.3 or later |
| __Runtime Requirements:__ | Final Cut Pro 5.1.2 or later |

Final Cut Pro version 5.1.2 and later provide support for Apple Events that external applications can use to import and export XML from the application. This is an Xcode project for a sample application that demonstrates the use of these Apple events. More Apple Events have been added subsequent to version 5.1.2. This application supports all the Apple Events added through version 7.0 of Final Cut Pro.
