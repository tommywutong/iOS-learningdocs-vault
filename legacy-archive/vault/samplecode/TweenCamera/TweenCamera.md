# TweenCamera

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Applying camera actions to a 3D model (track) in a movie using the Tween Media type of QuickTime. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This demo program shows how to apply camera actions to a 3D model (a 3D media track) in a movie using the Tween Media type of QuickTime. Requirements: - Common - Sun Compliant Java Runtime Environment 1.1 - QuickTime 3 - QTJava.zip - QTJava media samples - Mac OS: - System 8 or later - Macintosh Runtime for Java (MRJ) 2.1 - Windows 95, 98, or NT:: - JRE/JDK from Sun Microsystems, Inc. recommended Keywords: QuickTime, Java, MRJ
