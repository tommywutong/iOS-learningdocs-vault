# CarbonQTGraphicImport

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Illustrates how to use the QuickTime GraphicImporter components. |
| __Build Requirements:__ | Project Builder |
| __Runtime Requirements:__ | Carbon QuickTime 3.0 or later, Carbon 1.0.2 |

This sample shows how to use the QuickTime GraphicImporter components to draw files and handles. It shows how to use the GraphicImporter components with the Drag Manager. It shows how to do Carbon compatible printing with the GraphicImporter components as well. Demonstrates a basic Macintosh application that supports the basic Apple Events and the standard user events. Requirements: QuickTime 3.0 or later, Carbon 1.0.2 Keywords: Carbon, QuickTime, GraphicImporter, GIF, JPEG, Print
