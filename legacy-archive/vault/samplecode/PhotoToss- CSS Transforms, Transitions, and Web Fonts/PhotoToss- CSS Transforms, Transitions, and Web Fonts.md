# PhotoToss: CSS Transforms, Transitions, and Web Fonts

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2008-08-21 Demonstrates how to use CSS Transforms, Transitions, and Web Fonts. |
| __Build Requirements:__ | None |
| __Runtime Requirements:__ | Safari 3.1 and later |

The photo slideshow in this sample demonstrates how to use CSS transforms and transitions to position and animate elements of a web page. This sample also illustrates how to use CSS3 Web fonts (in this case, with text shadow). CSS3 Web fonts enable site authors to link to and retrieve fonts for display in their web content.
