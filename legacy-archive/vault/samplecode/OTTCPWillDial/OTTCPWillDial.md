# OTTCPWillDial

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This sample shows how to use the Network Setup library (as introduced in Mac OS 8.5) to determine whether opening a TCP/IP provider will cause a modem to dial. If the Network Setup library is not available, the sample will read the "TCP/IP Preferences" file directly. Keywords: network, setup, configuration, AppleTalk, TCP/IP
