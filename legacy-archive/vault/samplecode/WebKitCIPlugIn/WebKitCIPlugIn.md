# WebKitCIPlugIn

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2005-11-28 Updated to produce a universal binary. No code changes were required. |
| __Build Requirements:__ | Mac OS X v.10.4 or later |
| __Runtime Requirements:__ | Mac OS X v.10.4 or later |

This sample WebKit plugin for Safari demonstrate how to use CoreImage in a HTML page. It generates a plugin which has to be installed in either /Library/Internet Plug-Ins or ~/Library/Internet Plug-Ins. It also includes a sample HTML file that demonstrates how to use the plugin.

This sample code has been updated to include a project that produces a universal binary. No code changes were required for it to run correctly on the Developer Transition Systems.
