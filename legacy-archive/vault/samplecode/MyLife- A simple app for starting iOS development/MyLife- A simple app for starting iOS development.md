# MyLife: A simple app for starting iOS development

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2016-09-13 First release |
| __Build Requirements:__ | Xcode 8.0 or later; iOS 10.0 SDK or later |
| __Runtime Requirements:__ | iOS 10.0 or later |

MyLife is a starting point for building your first iPhone or iPad application. The app shows off the basics of how to display and edit data in a simple app that you can build off. The project includes a PDF that describes the app, how to run it on your device, and instructions for how you can customize the app further.
