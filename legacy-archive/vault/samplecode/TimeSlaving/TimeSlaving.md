# TimeSlaving

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Controls a scrolling text object by slaving a TimeBase to a movie. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X |

This demo program shows how the effects of using timing information to control the Scrolling Java Text object and how slaving its TimeBase to a movie alters the behaviour. Requirements: - Common - Sun Compliant Java Runtime Environment 1.1 - QuickTime 3 - QTJava.zip - QTJava media samples - Mac OS: - System 8 or later - Macintosh Runtime for Java (MRJ) 2.1 - Mac OS X - 10.0 or later - Windows 95, 98, or NT:: - JRE/JDK from Sun Microsystems, Inc. recommended Keywords: QuickTime, Java, MRJ
