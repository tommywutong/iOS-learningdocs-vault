# Quartz Composer WWDC 2006 Galaxy

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-08-07 Demonstrates use of Particle Systems and Core Image Filters in Quartz Composer |
| __Build Requirements:__ | Quartz Composer 2.1.1 or later |
| __Runtime Requirements:__ | Mac OS X 10.4.7 or later |

This Quartz Composer composition uses a custom Core Image filter to create a "galaxy"-like swirl effect. Use of the Particle System patch is also demonstrated. When inside the Quartz Composer editor, be sure to open the Inspector panel and read the Notes field for each patch.
