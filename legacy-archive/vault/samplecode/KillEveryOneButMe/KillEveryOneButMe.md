# KillEveryOneButMe

|  |  |
| --- | --- |
| __Last Revision:__ | Version 3.0, 2005-08-24 Updated to a modern Mac OS X application. Also updated to produce a universal binary. No code changes were required for the latter. |
| __Build Requirements:__ | Mac OS X v10.4 |
| __Runtime Requirements:__ | Mac OS X v10.4 |

This sample code shows how to kill all the other applications running on a machine for demos, school situations, kiosks, etc.
This sample code has been updated to include a project that produces a universal binary. No code changes were required for it to run correctly on the Developer Transition Systems.
