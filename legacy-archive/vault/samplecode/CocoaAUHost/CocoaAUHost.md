# CocoaAUHost

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2009-04-15 CocoaAUHost provides a sample Cocoa-based hosting application for AudioUnits |
| __Build Requirements:__ | Mac OS X v10.6 or later |
| __Runtime Requirements:__ | Mac OS X v10.6 or later |

The CocoaAUHost is a Cocoa-based application for hosting audio units available on the system. It provides an example of finding available audio units, loading and displaying their cviews, and manipulating their properties.
