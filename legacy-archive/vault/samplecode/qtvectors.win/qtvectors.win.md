This sample code has been updated for QuickTime 5.0 QTVectors is a simple application that constructs a QuickTime vector movie. It shows how to create a new movie, construct a series of QTAtoms that describe a vector picture, and then save the QTAtoms in the new movie. You can then open the movie to see what was drawn. 68k or PowerPC (or newer) machines running System 8.5 or later. PC with Intel Pentium or compatible processor. QuickTime 4.0 or later. CodeWarrior Pro 2 or later or Visual C++ 5.0 or later.
