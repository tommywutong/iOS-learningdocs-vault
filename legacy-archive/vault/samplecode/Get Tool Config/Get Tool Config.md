# Get Tool Config

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This sample shows how to use CMChoose and CMGetConfig to get the configuration string out of a connection tool and write it to a file. By saving and restoring a connection tool's configuration your application can avoid having to use the configuration alerts every time a connection tool is opened. Requires: Communications Toolbox (System 7 and higher, or separate install on System 6) Keywords: Communications Toolbox, connection tools, CMChoose, CMGetConfig
