# SoundRecord

|  |  |
| --- | --- |

| __Build Requirements:__ | XCode 2.2, or Java 2 SDK for Windows, and QuickTime 7 |
| __Runtime Requirements:__ | Java 1.5 and QuickTime 7, or later, recommended |

A more complex version of SoundMemRecord, that demonstrates how to adjust settings such as the input source, compression and recording format. Also illustrates how to save the recording to a QuickTime movie file. The saved recording is presented in a separate window when the user clicks "stop".
