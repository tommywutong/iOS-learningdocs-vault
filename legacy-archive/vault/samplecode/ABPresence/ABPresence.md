# ABPresence

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2006-08-04 Respond correctly to iChat's "Use shapes to indicate status" preference. Stop querying the status for all the Address Book people at startup, instead just wait for notifications. |
| __Build Requirements:__ | Xcode 3.0 |
| __Runtime Requirements:__ | Mac OS X 10.5 |

This sample application displays a list of all of the people in your Address Book. Using the Instant Message Framework, it communicates with iChat to find the current status of those people and displays the appropriate status gem next to their name. It will continue to receive notifications from iChat while it is running and will update the list as changes occur.
