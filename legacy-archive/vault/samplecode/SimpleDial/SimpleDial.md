# SimpleDial

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2005-07-26 This sample code has been updated to include a project (for Xcode 2.1) to produce a universal binary and there were no code changes required for it to run correctly on the Developer Transition Systems. |
| __Build Requirements:__ | Xcode 1.1 |
| __Runtime Requirements:__ | Mac OS X 10.3 |

SimpleDial demonstrates the management of dialup connections, such as PPP, using the System Configuration framework network connection API, introduced in Mac OS X 10.3.
