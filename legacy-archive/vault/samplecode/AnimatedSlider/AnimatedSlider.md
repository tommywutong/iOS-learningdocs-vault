# AnimatedSlider

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2011-07-18 Rewritten to use Core Animation. Project updated for Xcode 4. [(Full Revision History)](Document%20Revision%20History.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpirkfgmjqgaydamzxhawvezlwnfzws33ojbuxg5dpoj4s2rdpnz2ey2lonncwyzlnmvxhiskel4yq) |
| __Build Requirements:__ | Xcode 3.2, Mac OS X 10.6 Snow Leopard or later |
| __Runtime Requirements:__ | Mac OS X 10.6 Snow Leopard or later |

This sample defines a custom category to enable implicit animation of an NSSlider's value. An IBAction linked to a text cell creates an NSAnimationContext, adjusts the animation duration and uses the animator proxy to set the slider's value.
