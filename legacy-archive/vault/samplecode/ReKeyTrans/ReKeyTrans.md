# ReKeyTrans

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-30 Shows how to patch KeyTrans to ignore dead-key processing so you type fancy accented characters. |
| __Build Requirements:__ | Xcode |
| __Runtime Requirements:__ | Carbon |

This sample shows how to patch KeyTrans in order to completely ignore the dead-key processing that goes on and lets you type those fancy accented characters as if you were back in 7-bit ASCII days.
