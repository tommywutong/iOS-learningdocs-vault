# PictureShow

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-03-05 Shows how to create a Keynote document via code, demonstrated with a Java command-line tool. |
| __Build Requirements:__ | Mac OS X, JAXP (Java API for XML Processing) |
| __Runtime Requirements:__ | Mac OS X JAXP (Java API for XML Processing) |

PictureShow is a Java command line tool that takes a list of images and creates a Keynote document with a slide for each image, with the image's name below it. By default it will create a simple, white-on-black theme. Optionally a Keynote theme document (or a regular Keynote document) may be specified whose theme will be applied to the document created. Requirements: JAXP (Java API for XML Processing) Keywords: Keynote XML schema file format document APXL
