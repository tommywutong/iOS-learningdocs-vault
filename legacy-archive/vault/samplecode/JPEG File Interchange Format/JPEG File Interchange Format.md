# JPEG File Interchange Format

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Preview component which lets you make previews from JFIF files in the QuickTime StandardFilePreview dialog. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This is a preview component which lets you make previews from JFIF files in the QuickTime StandardFilePreview dialog. It also displays the JFIF thumbnail from those JFIF files which have JFIF thumbnails in the same dialog. It also converts JPEG interchange files to JPEG PICT files, which can be used by any application, and converts (some) JPEG PICT files to JFIF files. Requires: QuickTime Keywords: QuickTime, JPEG, JFIF, PICT
