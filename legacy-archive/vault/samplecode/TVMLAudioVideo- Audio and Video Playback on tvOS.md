# TVMLAudioVideo: Audio and Video Playback on tvOS

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2015-10-21 First public release. |
| __Build Requirements:__ | Xcode 7.1, tvOS 9.0 SDK |
| __Runtime Requirements:__ | tvOS 9.0 or later |

This sample demonstrates how to add audio and video playback support for TVML template applications on tvOS. This sample includes examples of playlists, chapter groups, overlays, metadata updates during playback, and bookmarks.
