# PageControl: Using a Paginated UIScrollView

|  |  |
| --- | --- |
| __Last Revision:__ | Version 7.0, 2017-09-21 Upgraded to Swift, now uses Storyboards. [(Full Revision History)](Document%20Revision%20History.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpirkfgnbqgaydonzzguwvezlwnfzws33ojbuxg5dpoj4s2rdpnz2ey2lonncwyzlnmvxhiskel4yq) |
| __Build Requirements:__ | iOS SDK 11.0 and later. |
| __Runtime Requirements:__ | iOS 10.0 and later. |

This application demonstrates how to use a "paginated" UIScrollView to display pages of images in a horizontal fashion as a mechanism for navigating between different pages of content. It is optimized to minimize the memory usage by loading only three image pages at a time the user user scrolls: the current page, the page before and after it.
This application was designed as universal to run on both iPhone and iPad devices.
