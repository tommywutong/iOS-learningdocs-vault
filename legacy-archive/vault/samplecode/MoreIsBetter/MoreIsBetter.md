# MoreIsBetter

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-27 Library providing indispensable wrapers and workarounds for many areas of Mac OS programming. |
| __Build Requirements:__ | Mac OS X 10.2.x with Dec 2002 Developer Tools, or CodeWarrior 8.3 |
| __Runtime Requirements:__ | Carbon (both 9 and X) |

A code sample and library which provides indispensable work-arounds and illustrations for Mac OS programming. Wrapper functions for: Control Manager, Appearance Manager, Dialog Manager, Window Manager, Menu Manager, Navigation Services, and many more. Requires: Mac OS X 10.2.x with Dec 2002 Developer Tools, or CodeWarrior 8.3 Keywords: high level, toolbox, hltb, MoreFiles, MoreIsBetter, glue, wrapper, library code
