# echoTouch - Using the Voice Processing I/O audio unit

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2016-11-29 First version. |
| __Build Requirements:__ | Xcode 8.1, iOS 10.0 SDK |
| __Runtime Requirements:__ | iOS 9.3+ |

Demonstrates using the Voice Processing I/O audio unit for handling audio input and output. The application tests local audio playback and simulated "far-talker" audio playback allowing you to record and listen back to the results. It also lets you to turn on/off the VPIO comparing the recorded results.
