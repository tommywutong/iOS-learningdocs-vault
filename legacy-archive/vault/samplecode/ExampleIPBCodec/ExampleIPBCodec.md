# ExampleIPBCodec

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0.1, 2005-08-16 Updated to produce a universal binary. Minor changes to .r files as documented in TN2012 were required. |
| __Build Requirements:__ | Mac OS X 10.4, or Mac OS X 10.3.9 and QuickTime 7.0 |
| __Runtime Requirements:__ | Mac OS X 10.4, or Mac OS X 10.3.9 with QuickTime 7.0 |

Shows how to write a modern video compressor component and decompressor component pair for QuickTime 7. The compressor and decompressor support a IPB frame pattern, which means that the compressor is allowed to reorder frames to help improve compression quality.
Xcode 2.1+ project builds universal binary.
