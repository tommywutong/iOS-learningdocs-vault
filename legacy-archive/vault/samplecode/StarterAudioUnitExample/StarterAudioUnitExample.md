TremoloUnit is a C++ sample project based on Core Audio SDK version 1.4.3. It demonstrates how to build a simple effect audio unit with a generic view. The TremoloUnit project corresponds to a tutorial in Audio Unit Programming Guide, available in the ADC Reference Library.
