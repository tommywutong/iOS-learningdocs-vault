# CompositedEffects.win

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Creates a layered Composited image from a file, then draws a Movie in front of the image. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This demo program shows the construction of a Composited image containing the layering of an image file, the ripple effect, an animation and some Java text. Over this is placed a Movie which is drawn in front of the composited image. Requirements: - Common - Sun Compliant Java Runtime Environment 1.1 - QuickTime 3 - QTJava.zip - QTJava media samples - Mac OS: - System 8 or later - Macintosh Runtime for Java (MRJ) 2.1 - Windows 95, 98, or NT:: - JRE/JDK from Sun Microsystems, Inc. recommended Keywords: QuickTime, Java, MRJ
