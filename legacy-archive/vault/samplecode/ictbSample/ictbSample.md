This snippet shows the an example of ictb resource this is discussed in Inside Macintosh:Macintosh Toolbox Essentials, page 6-158 t0 6-164. It is based on the Dialog Manager Q&A technote. There is no Rez template for ictb, and no ResEdit template or editor. This sample ictbSample.r shows how you can do one by hand. Resorcerer provides an excellent ictb editor to use ictb in your dialog boxes. Requirements: Keywords: ictb, Dialog Manager
