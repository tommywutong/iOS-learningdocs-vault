# IBFragmentView

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-08-01 Illustrates building an Interface Builder plugin including a custom inspector and library integration for a custom view. |
| __Build Requirements:__ | Leopard Preview |
| __Runtime Requirements:__ | Leopard Preview |

This example includes a custom view in a framework and a plugin to integrate it into Interface Builder. The plugin includes a custom inspector, a class description file, and a nib which integrates the custom view into IB's library.
