# TradDriverLoaderLib

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This package contains a number of routines that are helpful in installing traditional Mac OS device drivers (of type 'DRVR'). TradDriverLoaderLib mimics the API (application programming interface) of the PCI DriverLoaderLib library as much as possible, which makes TradDriverLoaderLib easier to use in an environment supporting both PCI native drivers (of type 'ndrv') and traditional Mac OS drivers.
