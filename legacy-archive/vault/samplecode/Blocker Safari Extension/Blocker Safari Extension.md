# Blocker Safari Extension

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2010-06-08 An extension that shows how to block page content from loading. |
| __Build Requirements:__ | Safari 5 and Safari Developer certificate |
| __Runtime Requirements:__ | Safari 5 |

An extension that shows how to block page content from loading. This extension also shows how to listen for message events and use content scripts and styles.
