# Vertex Optimization

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-07 Shows examples of optimized vertex throughput. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X ProjectBuilder, Mac OS X v10.2 or later |

This sample shows examples of optimized vertex throughput. It demonstrates different levels of optimization from not optimized to fully optimized using vertex programs and multi-threading. A GUI is provide to allow users to assess the different levels of optimization and their effect on system performance. Requirements: ProjectBuilder, Mac OS X v10.2 or later Keywords: OpenGL, performance, vertex, thread, multithread, vertex program, optimization
