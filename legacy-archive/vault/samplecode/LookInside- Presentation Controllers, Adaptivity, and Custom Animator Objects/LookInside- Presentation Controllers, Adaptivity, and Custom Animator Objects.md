# LookInside: Presentation Controllers, Adaptivity, and Custom Animator Objects

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2014-09-17 New sample code that demonstrates how to use a custom presentation controller to create a custom view controller presentation. |
| __Build Requirements:__ | iOS 8 SDK |
| __Runtime Requirements:__ | iOS 8 or later |

This example shows how to use a custom presentation controller to create a custom view controller presentation. It provides a transitioning delegate to the view controller, which vends a presentation controller and animator object.
