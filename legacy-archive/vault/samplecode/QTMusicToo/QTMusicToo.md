# QTMusicToo

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-03-19 Shows all of the QuickTime Music features introduced with QuickTime 2.0. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS 9 QuickTime |

These samples show all of the QuickTime Music features introduced with QuickTime 2.0. The project files in this sample have not been updated for Project Builder or CodeWarrior. The techniques used in these samples are still valid but should only be used for writing cross platform QuickTime applications using QTMA. We recommend using CoreMIDI technology for any new code being written for Mac OS X. Requirements: QuickTime Keywords: QuickTime, music
