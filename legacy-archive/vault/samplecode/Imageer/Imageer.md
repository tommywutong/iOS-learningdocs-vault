# Imageer

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon ColorQuickDraw, QuickDraw GX |

The current release of Imageer is a basic image manipulation application which is designed to show how both Color QuickDraw and QuickDraw GX can be integrated into a single application with each document window supporting either technology. Requirements: ColorQuickDraw, QuickDraw GX Keywords: QuickDraw GX
