# DispatchWebServer

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2009-05-29 Update to newer APIs, more comments. Overview section. Supports content compression. |
| __Build Requirements:__ | Mac OS X version 10.6 Snow Leopard |
| __Runtime Requirements:__ | Mac OS X version 10.6 Snow Leopard |

A web server that uses one queue per HTTP connection. Supports HTTP pipelining and on-the-fly compression. Also shows use of dispatch-style signal and vnode event handling.
