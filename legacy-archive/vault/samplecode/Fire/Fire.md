# Fire

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2011-04-15 Updated for building using latest Mac OS SDK installed on the machine. [(Full Revision History)](Document%20Revision%20History.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpirkfgnbqgaydsmbtgywvezlwnfzws33ojbuxg5dpoj4s2rdpnz2ey2lonncwyzlnmvxhiskel4yq) |
| __Build Requirements:__ | Xcode 3.2 |
| __Runtime Requirements:__ | Snow Leopard, Mac OS X 10.6 |

This application demonstrates the use of Core Animation's particle system classes: CAEmitterLayer and CAEmitterCell. Two emitters and cells are used to create fire and smoke effects. Particle images are loaded from the application's bundle and the properties of the particles and emitters are animated.
