# Direct Pixel Access

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-10 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Color QuickDraw, CarbonLib |

This sample has been updated for the Carbon API. This sample shows one example of how to directly change the pixel values stored in a pixel image. The original pixel image is obtained from a 'icl8' resource. Only the first 20 columns of the first 20 rows of the 'icl8' image is used. Requirements: Color QuickDraw, CarbonLib Keywords: PixMap, Direct Pixel Access, GetCPixel, GetPixBaseAddr, CopyBits, Carbon
