# audiocodec

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 A Sound Manager compressor and decompressor example supporting the uLaw format. |
| __Build Requirements:__ | QuickTime 5 |
| __Runtime Requirements:__ | Carbon |

This is a Sound Manager codec example. It will create a compressor and decompressor supporting the uLaw format. This compressor is a built-in codec already present in the Sound Manager. To install this example it would require the version to be greater than the one already installed by the Sound Manager. The example has a high version of 5.0 only for this reason. Requires: QuickTime 5 Keywords: QuickTime, codec, uLaw,Sound Manager
