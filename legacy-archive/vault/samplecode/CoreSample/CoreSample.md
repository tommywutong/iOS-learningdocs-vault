# CoreSample

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This sample illustrates how to create an application that is Apple Event-aware, Scripting Compatible, and recordable. CoreSample supports the Required Apple events and Core Suite of Apple events, the Apple event Object Model, and the Apple event Open Scripting Architecture. Requires: System 7.0 Keywords: AppleEvents, AppleScript, AppleEvent Object Model
