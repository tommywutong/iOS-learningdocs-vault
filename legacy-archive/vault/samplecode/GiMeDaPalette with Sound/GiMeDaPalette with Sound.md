# GiMeDaPalette with Sound

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-03-12 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Sound Manager 3.0 or later |

This is the original version of GiMeDaPalette with the change to it to make it possible to play a sound at the same time as the colors are being animated. The method which is being used to play the sound is to use Double Buffering. Whenever you select some form of Animation from the menu, there will be sound to go with it. Requirements: Sound Manager 3.0 or later Keywords: sound, double buffer, GiMeDaPalette, GiMeDaPalette with Sound
