# Gradients

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2011-04-15 Updated for building using latest Mac OS SDK installed on the machine. [(Full Revision History)](Document%20Revision%20History.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpirkfgnbqgaydsmbsgywvezlwnfzws33ojbuxg5dpoj4s2rdpnz2ey2lonncwyzlnmvxhiskel4yq) |
| __Build Requirements:__ | Xcode 3.2 |
| __Runtime Requirements:__ | Snow Leopard, Mac OS X 10.6 |

This simple application demonstrates use of the CAGradientLayer class, simple implicit animations, and using the CATransaction class to control the length of implicit animations. A single gradient layer is displayed and continuously animated using new random colors. The gradient layer is also scaled to match the window, if resized.
