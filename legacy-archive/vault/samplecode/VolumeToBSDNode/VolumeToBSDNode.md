# VolumeToBSDNode

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2006-10-16 Updated to produce a universal binary. Modernized and incorporated bug fixes. [(Full Revision History)](Document%20Revision%20History.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpirkfgmjqgaydanbtgqwvezlwnfzws33ojbuxg5dpoj4s2rdpnz2ey2lonncwyzlnmvxhiskel4yq) |
| __Build Requirements:__ | Xcode 2.2.1 or later. |
| __Runtime Requirements:__ | Mac OS X 10.2 or later |

Shows how to iterate across all mounted volumes and retrieve the BSD node name (/dev/disk\*) for each volume. That information is used to determine if the volume is on a CD, DVD, or some other storage media.
This sample code has been updated to include a project that produces a universal binary.
