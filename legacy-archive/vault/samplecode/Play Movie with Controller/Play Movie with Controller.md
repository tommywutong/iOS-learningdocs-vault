# Play Movie with Controller

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Playing a QuickTime movie using a movie controller. Part of "An Introduction to QuickTime". |
| __Build Requirements:__ | Both A Power Macintosh Computer running Mac OS 9 (9.2.2 or later recommended), |
| __Runtime Requirements:__ | Both A Power Macintosh Computer running Mac OS 9 (9.2.2 or later recommended), |

Demonstrates how to play a QuickTime movie using a movie controller. Part of An Introduction to QuickTime. Requirements: A Power Macintosh Computer running Mac OS 9 (9.2.2 or later recommended), Metrowerks CodeWarrior Pro version 7.0 or later, QuickTime 5.0.2, CarbonLib 1.5 and Universal Interfaces 3.3.4 or later. A Power Macintosh Computer running Mac OS X (10.1.2 or later recommended) with Mac OS X Developer Tools December 2001 or later.
