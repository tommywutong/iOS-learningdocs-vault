# ModeWhacker

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Shows how to enumerate, select, capture, manipulate, and release displays using the CGDirectDisplay API. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X, Project Builder |

A CGDirectDisplay API demonstration command line tool. It shows how to identify the displays, select one, capture it, change the display mode, restore the display mode, and release the display. ModeWhacker looks for each of three different modes in turn, switches to the closest matching mode for each, pauses for five seconds, and moves on. Requirements: Mac OS X, Project Builder Keywords: CGDirectDisplay, DrawSprocket, Display Manager, screen resolution, bit depth
