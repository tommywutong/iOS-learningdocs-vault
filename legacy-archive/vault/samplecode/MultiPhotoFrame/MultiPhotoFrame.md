This project demonstrates the use of the multi-image dragging API introduced in OS X 10.7. It shows how to change the dragging image for your destination view and animate the dragging image from the drop location to its final location in the view while simultaneously animating a gap for the dropped items. Also learn how to start a multi-image drag and change the image when the drag leaves the view.
