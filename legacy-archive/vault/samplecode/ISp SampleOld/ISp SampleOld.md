# ISp SampleOld

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

ISp Sample is a reasonably complete example implementation of high level InputSprocket. It shows how to set up needs and retrieve states and events for the associated elements. Requires: PowerPC, System 8.1+, InputSprocket, and either Universal Interfaces 3.3 or InputSprocket SDK Keywords: InputSprocket, ISp, Needs, Elements, axes, buttons
