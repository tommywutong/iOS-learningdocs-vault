# NameAndPassword

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-07-28 NameAndPassword is a SFAuthorizationPluginView subclass example. |
| __Build Requirements:__ | Mac OS X "Leopard" |
| __Runtime Requirements:__ | Mac OS X "Leopard" |

Demonstrates how a developer could subclass SFAuthorizationPluginView to create an authorization plugin to display UI within Apple's authorization dialogs. The example is just an alternative NameAndPassword or just Password UI, but the potential is there to display the UI for a fingerprint reader, a card reader, or other authentication device.
