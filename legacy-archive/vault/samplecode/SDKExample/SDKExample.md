# SDKExample

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-06 First Version |
| __Build Requirements:__ | Mac OS X 10.4 or later, Xcode 2.1 |
| __Runtime Requirements:__ | Mac OS X 10.2.8 and later |

A Carbon application that calls Carbon APIs that are available in different versions of the Mac OS. It weak-links against the Carbon framework using Xcode's SDK mecahnism, and checks API calls before invocation.
