# kcapApp

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-30 Demonstrates drawing the key caps, given a set of modifiers and KCHR and KCAP resource IDs. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

The DrawKeyCaps function draws the key caps, given a set of modifiers (in the high byte of the modifier short parameter) and KCHR and KCAP resource IDs, using the current pen in the current GrafPort. If keyCodesFlag is true, the virtual keycodes for the KCAP are drawn (in 9 point) instead of the labels. Requirements: Keywords: KCHR, KCAP, key caps
