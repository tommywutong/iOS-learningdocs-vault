# OTCodeResource

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Macintosh with 68030 processor or later, Open Transport 1.1 or greater installed. The sample can be compiled using the Open Transport 1.3 SDK and Metrowerks CodeWarrior Pro 1 or 2 or ETO 23 |

This sample shows how to call Open Transport from a 68K code resource written in either Metrowerks CodeWarrior C or Symantec C for MPW. The sample creates a HyperCard XCMD which returns the default Ethernet address for the machine using Open Transport calls. Requirements: Macintosh with 68030 processor or later, Open Transport 1.1 or greater installed. The sample can be compiled using the Open Transport 1.3 SDK and Metrowerks CodeWarrior Pro 1 or 2 or ETO 23 Keywords: Open Transport, code resource, XCMD, CodeWarrior, MPW, 68K, ethernet address, hardware address
