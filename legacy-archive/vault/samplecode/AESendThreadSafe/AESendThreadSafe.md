# AESendThreadSafe

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2007-03-09 Demonstrates how to send Apple events from threads other than the main thread. |
| __Build Requirements:__ | Xcode 2.4.1 |
| __Runtime Requirements:__ | Mac OS X 10.2 |

Demonstrates how to send Apple events from threads other than the main thread. It includes an important bug fix compared with the previous technique that was documented in Technote 2053.
