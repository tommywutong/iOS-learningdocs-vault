# Quartz Composer SpotlightSearch

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2009-10-27 A plug-in that searches for files of a given type |
| __Build Requirements:__ | Xcode 3.2 or later, Mac OS X v10.6 or later |
| __Runtime Requirements:__ | Mac OS X v10.6 or later |

A Quartz Composer plug-in that searches for files of a given type matching a Spotlight query. The file type is expressed as Uniform Type Identifier e.g. "public.image".
