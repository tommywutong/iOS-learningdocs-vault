# SOAPServer

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Provides SOAP (Simple Object Access Protocol) services, to be used with SOAPClient sample code. |
| __Build Requirements:__ | Mac OS X, WebObjects 5 |
| __Runtime Requirements:__ | Mac OS X, WebObjects 5 |

WebObjects example providing SOAP (Simple Object Access Protocol) services. Example code from WWDC 2001, session 607 - Practical Uses of XML with WebObjects. This demo is part of a pair and is meant to be used with the WebObjects example SOAPClient.
