# MenuViews

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-24 Demonstrates a variety of interesting uses of HIView-based menus in Mac OS X 10.3. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X Panther |

The MenuViews sample code demonstrates a variety of interesting uses of HIView-based menus in Mac OS X Panther, including how to write a custom HIView that can be used in a menu, how to place a trackable control into a menu, how to place a picture behind the text of a menu, and how to write a custom HIView and insert it as a subview of a menu. Requirements: Mac OS X Panther Keywords: HIView, menu, label
