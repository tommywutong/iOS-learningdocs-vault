# MemoryBasedBundle

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2005-08-10 Updated to produce universal binaries. Necessary code changes are documented within the project. |
| __Build Requirements:__ | Xcode 2.1 |
| __Runtime Requirements:__ | Mac OS X 10.3 or later |

MemoryBasedBundle is a sample that shows how to execute Mach-O code from memory, rather than from a file. If you're trying to port from CFM to Mach-O, and you're looking for a replacement for GetMemFragment, this is the sample is for you.
