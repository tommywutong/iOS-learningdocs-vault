# MakeITable

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon System 6 or later |

This is a very boring app which just forces QuickDraw to update the ITable of all the monitors. The Resolution will end up at 5 bits. The ITable will change when you select start from the file menu. Requirements: System 6 or later Keywords: GetDeviceList, GDeviceChanged, GetNextDevice, GetMainDevice, NewPalette, SetPalette
