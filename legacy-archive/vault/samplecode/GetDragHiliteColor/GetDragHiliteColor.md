# GetDragHiliteColor

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-30 Shows how to obtain the color that Drag Manager uses to hilite regions when calling ShowDragHilite. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This shows how to obtain the color that the Drag Manager uses to hilite regions when ShowDragHilite is called. Check out GetDragHilite.c for the code. Please note this is only how it's done presently. Since it is undocumented it can and will change in the future. Requirements: Keywords: ShowDragHilite, Drag Manager
