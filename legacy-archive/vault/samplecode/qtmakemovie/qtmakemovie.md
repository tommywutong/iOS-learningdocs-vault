QTMakeMovie illustrates how to create a QuickTime movie file. It creates a movie that is 10 seconds long and that contains one video track. The video track shows a penguin gradually appearing in an initially empty rectangle. The movie-building code is found in the file QTMakeMovie.c. Requires: QuickTime 5 Keywords: QuickTime, movie file, video track
