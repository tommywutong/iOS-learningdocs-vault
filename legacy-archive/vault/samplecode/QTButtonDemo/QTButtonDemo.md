# QTButtonDemo

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Shows how to use the quicktime.ui Package classes to show a QTButton. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X QTJava, QuickTime 3 or later, JDK 1.1 or later |

Shows how to use the quicktime.ui Package classes. These classes demonstrate the usage of QTJava for making Custom UI elements. This demo shows the custom button classes of QTJava. Requirements: QTJava, QuickTime 3 or later, JDK 1.1 or later Keywords: QTJava, QuickTime
