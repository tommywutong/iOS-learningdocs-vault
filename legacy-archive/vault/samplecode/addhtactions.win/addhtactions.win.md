# addhtactions.win

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-02-25 Adds two go-to-URL actions to parts of the text track. |
| __Build Requirements:__ | QTWindows SDK |
| __Runtime Requirements:__ | Carbon |

This sample code has been updated for QuickTime 5.0 CreateHyperText is a sample application that adds a few wired actions to a movie that has a text track. In particular, it adds two go-to-URL actions to parts of the text track. 68k or PowerPC (or newer) machines running System 8.5 or later. PC with Intel Pentium or compatible processor. QuickTime 4.0 or later. CodeWarrior Pro 2 or later or Visual C++ 5.0 or later.
