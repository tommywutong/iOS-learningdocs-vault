# Using the Watch Connectivity API

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2017-10-26 First Release |
| __Build Requirements:__ | iOS 11 SDK or later, WatchOS 4 SDK or later |
| __Runtime Requirements:__ | iOS 10.2 or later, WatchOS 3.1 or later |

This sample demonstrates how to use the Watch Connectivity API to update an app context, transfer user info, transfer a file, and send a message between an iPhone and its paired watch. How to handle a Watch Connectivity background task, update current complications from an iOS app, and work with a watch app setting bundle are also covered in this sample.
