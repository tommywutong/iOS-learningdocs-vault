# Contacts Safari Extension

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2010-06-08 An extension that shows how to share data and functions from a global page with extension bars. |
| __Build Requirements:__ | Safari 5 and Safari Developer certificate |
| __Runtime Requirements:__ | Safari 5 |

An extension that shows how to share data and functions from a global page with extension bars. This extension also shows how to keep all bars synchronized, showing the same information in all windows.
