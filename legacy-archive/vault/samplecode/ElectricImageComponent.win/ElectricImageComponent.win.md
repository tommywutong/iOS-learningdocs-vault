# ElectricImageComponent.win

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2004-01-23 Demonstrates how to build five QuickTime Components. |
| __Build Requirements:__ | Visual Studio.net 7.0 or Visual C++ 6.0, QuickTime 6 Windows SDK |
| __Runtime Requirements:__ | Windows XP, QuickTime for Windows |

This sample demonstrates how to build five QuickTime Components; a Graphics Importer, Graphics Exporter, Movie Importer, Movie Exporter and Image Decompressor. These components all work together to allow QuickTime to use Electric Image format image files.
