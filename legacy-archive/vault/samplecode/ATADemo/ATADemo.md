# ATADemo

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS 9 ATA Manager, Mac OS 8.5+ |

ATADemo is a CodeWarrior C sample that will call the ATA Manager, scan the ATA bus, list the various device configuration data, and read and display the first sector of each device found. This sample has been updated to properly work with the .AppleCD driver installed and includes examples of how to send ATA and ATAPI commands. Requirements: ATA Manager, Mac OS 8.5+ Keywords: ATADemo, ATA, ATAPI, CD-ROM, CD ROM, ATA Demo
