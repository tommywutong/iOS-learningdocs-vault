# CryptoSample

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-02-06 Contains sample code showing symmetric encryption and message digest calculation. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X 10.2 or later |

The CryptoSample contains source code for libCdsaCrypt, a library intended to facilitate the use of Security.framework's Common Data Security Architecture (CDSA), specifically in the areas of symmetric encryption and message digest calculation. This sample also contains the source for several example programs demonstrating the use of libCdsaCrypt. Requirements: Mac OS X 10.2 or later Keywords: CryptoSample CDSA Diffie Hellman Security Signing Encryption Digest RSA
