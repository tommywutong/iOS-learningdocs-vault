# GetEnetAddrDirect.ppc

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon This program wil not be supported under Mac OS X as it implement direct memory access to the ROM. |

Sample program to demonstrate the direct access to the ethernet address for Power Macs that have Ethernet built-in to the motherboard. The sample also includes the use of OT to show all of the ethernet addresses of all Ethernet Network Interface Cards present. Includes source code, and CodeWarrior Pro v3.0 IDE project file. CodeWarrior Pro v3.0 IDE to open the project file. The program requires Open Transport 1.1.1 or greater; however, the program can be modified to remove the OT dependency. Requirements: This program wil not be supported under Mac OS X as it implement direct memory access to the ROM. Keywords: Ethernet built-in, Enet Address, Burned-in Address, GetEnetAddrDirect.ppc
