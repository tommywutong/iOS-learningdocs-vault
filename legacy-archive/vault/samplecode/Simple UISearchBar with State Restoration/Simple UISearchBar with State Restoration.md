"TableSearch" demonstrates how to use a UISearchDisplayController object. When you present a large amount of data in a table view, you can use a search display controller to let the user search the contents of the table view to quickly find items of interest. The sample shows how you can display data in a table view and use a search display controller to display a search bar and another table view that shows the results of a search. The sample also illustrates use of state restoration.
