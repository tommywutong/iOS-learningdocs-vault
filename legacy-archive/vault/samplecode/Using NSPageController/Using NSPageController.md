# Using NSPageController

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2014-02-21 First public version |
| __Build Requirements:__ | Xcode 5.0, OS X 10.9 |
| __Runtime Requirements:__ | OS X 10.8 or later |

"FileCards" demonstrates how to use of NSPageController, displaying the contents of the user's Documents folder. You can swipe, click the arrow buttons or click on the entry in the table to switch between cards.
