# DigitizerShell

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Simple sequence grabber and vdig test bed for testing vdig and digitizer functionality. |
| __Build Requirements:__ | Metrowerks CodeWarrior Pro 2.1 |

DigitizerShell is a simple sequence grabber and vdig related test bed for testing vdig and digitizer functionality, QuickTime/Mac. If you want to check out a more complete example of a video capture application, check out John Wang's My Capture App (develop # 19).
