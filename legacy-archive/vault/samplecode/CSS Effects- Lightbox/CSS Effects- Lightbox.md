# CSS Effects: Lightbox

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2010-11-01 Updated images, minor code revisions. |
| __Build Requirements:__ | Safari 4.0 or later, iPhoneOS 3.2 or later |
| __Runtime Requirements:__ | Safari 4.0 or later, iPhoneOS 3.2 or later |

Shown in session 504 at WWDC 2010, this sample shows you how to create a "lightbox" photo viewer using CSS3 transitions, transforms and animations. It provides a sample page with few images, where we have referenced the javascript and CSS files that are needed to implement the lightbox.
