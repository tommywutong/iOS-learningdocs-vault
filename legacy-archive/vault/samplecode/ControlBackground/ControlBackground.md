# ControlBackground

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-30 Shows how to affect the background color of a control when drawing it. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

Shows how to affect the background color of a control when drawing it. It works regardless of the presence of Appearance, with color windows, and with or without control embedding turned on. Keywords: control, draw, background, color, appearance
