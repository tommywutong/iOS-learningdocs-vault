# CreatePictFile

| __Runtime Requirements:__ | Java 1.5 and QuickTime 7, or later, recommended |

Imports a PICT, JPEG or GIF file using a GraphicsImporter into a QTComponent. The user is able to select a desired input image using the standard file dialogue. The resulting QTComponent is added to a window frame for display. Clicking on a button at the top of this window provides the facility to save the image as a pict file. The output file, called results.pict, is located in the application startup directory.
