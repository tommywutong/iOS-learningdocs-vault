# ColorizePict

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-10 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Color QuickDraw |

Routine to colorize a pixmap. This puts up a dialog with two colored boxes, click in the box to select a foreground a background image to used to colorize the picture. The image colorization is done using copybits, the color selection is done using the standard color picker. Requirements: Color QuickDraw Keywords: Color Picker, Colorize, CopyBits, foreground color, background color
