# SeedCFill

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-27 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon (both 9 and X) Color QuickDraw, CarbonLib |

This sample has been updated for the Carbon API. This sample shows how to use the SeedCFill routine to create a mask given a source image. This routine computes a destination bitmap image with 1's only in the pixels where paint can not leak from the starting seed point. This is similar to the paint- bucket tool. Requirements: Color QuickDraw, CarbonLib Keywords: SeedCFill, CopyMask, Carbon
