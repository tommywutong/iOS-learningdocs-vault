# Magnify

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-10 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon MacOS 8.6 or later, CarbonLib |

This is a Carbon based sample which compiles into both a CFM and Mach-O, Nib based application bundle. The application simply creates a window in which pixels around the cursor are magnified and displayed. The user may specify through its preferences weather the window be created as a floating or utility window as well as the magnification amount. The sample application works on both Mac OS 8/9 and Mac OS X. Requirements: MacOS 8.6 or later, CarbonLib Keywords: Carbon, Nib, bundle, magnify, window, CFPreferences, CarbonEvents
