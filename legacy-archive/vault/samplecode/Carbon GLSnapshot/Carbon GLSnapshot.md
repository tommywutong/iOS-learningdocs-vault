# Carbon GLSnapshot

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-07 Demonstrates the use of OpenGL with Quicktime to capture OpenGL content. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | null Mac OS X 10.1, OpenGL-capable video hardware |

The Carbon GLSnapshot sample demonstrates the use of OpenGL with Quicktime. It reads data out of OpenGL and uses QuickTime's image and file processing utilities to generate "snapshots" of the OpenGL context. Requirements: Mac OS X 10.1, OpenGL-capable video hardware Keywords: OpenGL, Snapshot, Carbon, Quicktime,
