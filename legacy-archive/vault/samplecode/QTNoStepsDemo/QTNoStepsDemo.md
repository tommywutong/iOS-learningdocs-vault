# QTNoStepsDemo

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-08-01 Shows how to subclass QTMovieView to override its default behaviors. |
| __Build Requirements:__ | Leopard Preview |
| __Runtime Requirements:__ | Leopard Preview |

This sample shows how to create a simple subclass of QTMovieView that ignores the left and right arrow keys when targeted at that view. Creating a subclass of QTMovieView was made possible with QuickTime 7.0.4. However, the sample itself requires Leopard Preview to build and run.
