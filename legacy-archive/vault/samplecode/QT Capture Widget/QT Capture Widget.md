# QT Capture Widget

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2007-08-27 A Dashboard widget that uses the QTKit capture API to provide video and audio capture. |
| __Build Requirements:__ | Xcode 3.0 |
| __Runtime Requirements:__ | Mac OS X Leopard |

This Dashboard widget uses a widget plug-in to perform video and audio capture using the QTKit capture API. In addition, you can record captured video and audio to a QuickTime movie file on disk. The widget works with any device supported by QTKit capture.
