# PhotoHandoff: Implementing NSUserActivity to hand off user actions

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2014-09-17 New sample code that demonstrates how to use NSUserActivity, based on “CollectionView-Simple” sample. |
| __Build Requirements:__ | iOS 8.0 SDK |
| __Runtime Requirements:__ | iOS 8.0 or later |

Demonstrates how to use NSUserActivity, based on “CollectionView-Simple” sample. It is a universal sample that runs native both on iPhone and iPad.
- Enable Handoff for both devices (Settings -> General -> Enable Handoff)
- Both devices must be logged into the same iCloud account
- Bluetooth must be turned on (Settings -> Bluetooth)
