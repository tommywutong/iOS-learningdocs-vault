# BackGround

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

QuickDraw 3D Background Shows how to use a pixmap draw context, in this case to draw 3D data over a background. We image the 3DMF data from a metafile into a pixmap draw context, and draw this over a PICT file read from the disk.
