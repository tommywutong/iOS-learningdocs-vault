# Inline Input for TextEdit

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon System 6.0 or later |

InlineInputSample is a sample application whose main purpose is to show you how to use the TSMTE extension to provide inline input for TextEdit. It is intended as a companion to the Macintosh Technical Note TE 27, Inline Input for TextEdit with TSMTE. In fact, almost all code shown in that Note is taken from InlineInputSample. Requirements: System 6.0 or later Keywords: Text Services Manager, Text Services with TextEdit, TSMTE, Inline Input
