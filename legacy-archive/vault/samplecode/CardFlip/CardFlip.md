# CardFlip

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2008-06-19 Updated the value of the -webkit-transform-style property from 'perspective' to 'preserve-3d'. |
| __Build Requirements:__ | iPhone OS 2.0 |
| __Runtime Requirements:__ | iPhone Simulator with iPhone OS 2.0 or iPhone or iPod touch running OS 2.0 |

"CardFlip" illustrates how to use CSS transform and transition properties to render and animate elements in the 3D space. It displays a card that is flipped when the user taps on it.
