# NetworkAuthentication

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-01 Demonstrates authentication with Open Directory APIs and GSSAPI |
| __Build Requirements:__ | Mac OS X 10.4 or later |
| __Runtime Requirements:__ | Mac OS X 10.4 or later |

Demonstrates authentication using Challenge-Response, Cleartext, and GSSAPI-based authentication methods using Open Directory APIs and Kerberos APIs. Utility routines are included that can be re-used for common authentication cases.
