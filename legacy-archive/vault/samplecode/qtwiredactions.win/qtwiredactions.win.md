QTWiredActions shows how to attach wired actions to text tracks. It also shows how to use wired actions to make sprites bounce around inside their track rectangle and how to collide with one another. Requirements: This sample can be built using the Metrowerks CodeWarrior Keywords: Wired Movies, Wired Actions, Text Tracks
