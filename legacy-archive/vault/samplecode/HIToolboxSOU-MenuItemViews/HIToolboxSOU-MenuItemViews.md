# HIToolboxSOU-MenuItemViews

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-08-04 Shows how to use the Menu Item View API. |
| __Build Requirements:__ | Leopard Preview |
| __Runtime Requirements:__ | Leopard Preview |

This project is a demo of the Menu Item View API discussed in WWDC 2006 session 105, HIToolbox State of the Union. The only addition to this source file for the demo is located in the main function; look there for a sample of making a menu item use an embedded HIView.
