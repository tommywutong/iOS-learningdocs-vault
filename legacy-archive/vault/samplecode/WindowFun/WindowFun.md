# WindowFun

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.1, 2005-08-24 Fixed window layering bug exposed in Mac OS X 10.4. Updated to produce a universal binary. No code changes were required. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Mac OS X |

WindowFun demonstrates how to: Create an arbitrary number of window layers within your application Display an overlay window which is attached to the main window A method of drawing transparent lines by drawing to an overlay window How to display the "Poof" the toolbar uses. Requirements: Mac OS X Keywords: Window Overlay group CarbonEvents
