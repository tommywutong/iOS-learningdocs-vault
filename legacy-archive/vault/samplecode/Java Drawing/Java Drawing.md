# Java Drawing

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Demonstrates using QTImageDrawer to allow QuickTime to draw the results of painting into a Java offscreen Image. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This demo program shows the usage of the QTImageDrawer to allow QuickTime to draw the results of painting into a Java offscreen Image and its associated Java Graphics. Requirements: - Common - Sun Compliant Java Runtime Environment 1.1 - QuickTime 3 - QTJava.zip - QTJava media samples - Mac OS: - System 8 or later - Macintosh Runtime for Java (MRJ) 2.1 - Windows 95, 98, or NT:: - JRE/JDK from Sun Microsystems, Inc. recommended Keywords: QuickTime, Java, MRJ
