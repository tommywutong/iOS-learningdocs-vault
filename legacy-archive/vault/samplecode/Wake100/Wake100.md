# Wake100

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Power Manager |

Wake100 is a sample INIT which reads the wake up time in a PowerBook 100 and old Portable. If the wake up date has elapsed then a day gets added to it so that the machine wakes up at the same time every day. Requirements: Power Manager Keywords: Power Manager, sleep queue, SetWakeupTimer, PowerBook, Wake100
