# SimpleCocoaJavaMovie

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 A simple movie player showing how to use the NSMovieView and NSMovie Cocoa Java classes. |
| __Build Requirements:__ | Mac OS X |
| __Runtime Requirements:__ | MacOS 10.1 or later |

This sample contains code showing how to use the NSMovieView and NSMovie Cocoa Java AppKit classes. The code attemps to duplicate the functionality of the standard QuickTime movie controller using the NSMovieView/NSMovie methods. Requirements: MacOS 10.1 or later Keywords: QuickTime, movie, Cocoa, NSMovie, NSMovieView, Java
