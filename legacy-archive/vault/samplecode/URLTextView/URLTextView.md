# URLTextView

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-30 An HIView subclass which uses LaunchServices to open the URL attached to the view. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Mac OS X 10.2 |

URLTextView is an HIView subclass which displays a static text string. When clicked, the view uses LaunchServices to open a URL attached to the view. Requirements: Mac OS X 10.2 Keywords: HIView, LaunchServices, Carbon, URL
