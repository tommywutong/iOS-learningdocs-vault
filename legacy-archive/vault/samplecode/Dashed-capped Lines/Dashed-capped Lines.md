# Dashed-capped Lines

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-03-26 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This sample demonstrates how to draw dashed line objects on PostScript printers. In this case, they are capped PostScript lines. I use round caps, which means that the ends of the lines are rounded. This simple example does not deal with QuickDraw printers, on which it draws solid black lines. Requires: PostScript printer Keywords: PostScript, print, capped, dash, line
