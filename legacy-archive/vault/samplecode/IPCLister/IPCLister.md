# IPCLister

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-03-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

A small example of how to use IPCListPorts This sample collects and displays all the PPC/AppleEvent capable machines in your current zone and puts them in a nice list. Click on one of the machines, and the other list will display all the PPC port names currently open on that machine. This is all the IAC capable applications, plus all the PPC ports that have been open for other reasons (unless they were opened non-Network capable). It's what the PPC browsers does, but this shows you how you can do it silently, without putting up a dialog. Requires: System 7.0 Keywords: ICPListPorts, PPC Toolbox, PPCBrowser, network AppleEvents
