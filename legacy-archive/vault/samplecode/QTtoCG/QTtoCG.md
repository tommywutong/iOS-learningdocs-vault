# QTtoCG

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Shows how to create a CGImageRef with the proper ColorSync profile from a QuickTime image on disk. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Mac OS X |

This sample shows how to create a CGImageRef from a QuickTime image on disk. It loads the image in using QuickTime and then draws it into a window, once without any embedded ColorSync profile and once with the profile. The images are drawn with alpha support on top of a gray and white checkerboard background. Requirements: Mac OS X Keywords: Quartz 2D QuickTime ColorSync CGImageRef image alpha
