# CASoundLab2

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X, Project Builder |

CASoundLab2 is a Cocoa sample that demonstrates low-level access to Core Audio at the Harware Abstraction Layer (HAL). CASoundLab2 implements a very simple tone generator capable of sine, square, and sawtooth waveforms of varying amplitudes and phases. Requirements: Mac OS X, Project Builder Keywords: Core Audio, sound, HAL, tone generator, sine, square, sawtooth, CoreAudio
