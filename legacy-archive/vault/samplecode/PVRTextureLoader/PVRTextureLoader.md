# PVRTextureLoader

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.6, 2014-03-25 Removed warnings. Updated for iOS 7. Updated for 64-bit. [(Full Revision History)](Document%20Revision%20History.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpirkfgnbqgaydqmjsgewvezlwnfzws33ojbuxg5dpoj4s2rdpnz2ey2lonncwyzlnmvxhiskel4yq) |
| __Build Requirements:__ | iOS 6.0 SDK |
| __Runtime Requirements:__ | iPhone OS 6.0 or later |

This application illustrates how to load PVR texture files using the included PVRTexture class and then display them using OpenGL.

The sample image, encoded as an xcode project build phase, is rendered on a rotatable and scalable quad. Controls are provided for experimenting with various texture compression and filter settings.
