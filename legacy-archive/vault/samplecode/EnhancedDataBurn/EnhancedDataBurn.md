# EnhancedDataBurn

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Objective-C sample which shows how to burn a data disc containing a complete virtual filesystem. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X 10.2.3 or later |

EnhancedDataBurn is an application written in Objective-C which shows how to burn a more advanced data disc containing a complete virtual filesystem. The application presents a simple interface to create the virtual filesystem and panels to set the various options that DiscRecording provides for data burning. Requirements: Mac OS X 10.2.3 or later Keywords: DiscRecording Virtual Filesystem
