# ColorBars

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Shows how to enumerate, select, capture, manipulate, draw to, and release displays using the CGDirectDisplay API. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X, Project Builder |

This is a CGDirectDisplay API demonstration command line tool. It shows how to identify the displays, select one, capture it, change the display mode, draw to the screen using direct pixel access, and release the display. Requirements: Mac OS X, Project Builder Keywords: CGDirectDisplay, DrawSprocket, Display Manager, screen resolution, bit depth
