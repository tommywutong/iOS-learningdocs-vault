# TimeZone.Daylight

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Shows how to read the current location and time zone that is set in Date & Time. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This program shows how you can use the ReadLocation function to show the current location and time zone information that is in the Date & Time Control Panel. The program also shows how you can determine if Daylight Savings Time is on or off. Requires: System 7.5 Keywords: daylight savings time, time zone, ReadLocation, MachineLocation
