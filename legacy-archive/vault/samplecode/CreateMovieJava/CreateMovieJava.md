# CreateMovieJava

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Creates a Movie from Java drawing and a sound file. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This demo program shows how to select create a movie from the results of using Java drawing capabilites and a sound file. It roughly translates the sample code in the QuickTime SDK - the Inside Macintosh:QuickTime examples of Chapter 2 (listings 2-5 through 2-12, starting at page 2-47 of the unbound edition). Requirements: - Common - Sun Compliant Java Runtime Environment 1.1 - QuickTime 3 - QTJava.zip - QTJava media samples - Mac OS: - System 8 or later - Macintosh Runtime for Java (MRJ) 2.1 - Windows 95, 98, or NT:: - JRE/JDK from Sun Microsystems, Inc. recommended Keywords: QuickTime, Java, MRJ
