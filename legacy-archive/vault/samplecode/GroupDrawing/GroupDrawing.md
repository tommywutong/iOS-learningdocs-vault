# GroupDrawing

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Groups QuickTime drawing-capable objects into the display space of a single QTCanvas. |
| __Build Requirements:__ | Mac OS X |
| __Runtime Requirements:__ | Mac OS X |

This demo program shows how to select group QuickTime drawing capable objects into the same display space of the QTCanvas. Requirements: - Common - Sun Compliant Java Runtime Environment 1.1 - QuickTime 3 - QTJava.zip - QTJava media samples - Mac OS: - System 8 or later - Macintosh Runtime for Java (MRJ) 2.1 - Mac OS X - 10.0 or later - Windows 95, 98, or NT:: - JRE/JDK from Sun Microsystems, Inc. recommended Keywords: QuickTime, Java, MRJ
