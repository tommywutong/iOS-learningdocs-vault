# PDEProject

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Demonstrates an application-hosted printing dialog extension (PDE) that displays a custom pane in the Print dialog. |
| __Build Requirements:__ | Mac OS X 10.1 |
| __Runtime Requirements:__ | Mac OS X 10.1 |

This project demonstrates the correct way to develop an application-hosted printing dialog extension that displays a custom pane in the Print dialog. It also shows how to integrate this plug-in with a sample printing application. This project is fully documented in the Apple publication Inside Mac OS X: Extending Printing Dialogs (June 2002).
