# DrillDown

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2008-06-19 Shows how to build a 2-level drill-down style application using Dashcode 2.0. |
| __Build Requirements:__ | none |
| __Runtime Requirements:__ | Safari 3 or iPhone or iPod touch or Dashcode 2.0 |

"DrillDown" illustrates how to create a drill-down style application using Dashcode 2.0. It contains two views. The first view shows a list of categories. Click on any of these categories to navigate to a second view that contains products associated with the selected category.
