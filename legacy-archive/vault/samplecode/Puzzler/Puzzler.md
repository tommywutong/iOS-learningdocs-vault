"Puzzler" is a fun and interactive game that illustrates the use of web standards and JavaScript for the iPhone. This application makes advanced usage of mouse-handlers for user-input. The goal is to clear all the balls from the screen. To play the game simply tap on any set of 2 or more balls of the same color that are touching; the balls turn grey; tap them again to remove them.
