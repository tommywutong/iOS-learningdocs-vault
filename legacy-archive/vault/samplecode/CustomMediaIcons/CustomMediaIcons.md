# CustomMediaIcons

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2007-07-10 Providing custom media icons for storage |
| __Build Requirements:__ | Xcode 2.2.1 or higher |
| __Runtime Requirements:__ | Mac OS X 10.3 or higher on PowerPC Macs and Mac OS X 10.4 or higher on Intel Macs |

A demonstration of using a codeless KEXT to provide custom media icons for storage devices. Examples are shown for providing a custom icon for both a given USB device and for providing a custom icon at the SCSI Architecture Model target level.
