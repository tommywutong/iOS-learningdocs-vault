# CreateMovieFromReferences

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2007-08-31 Shows how to create a movie from existing video samples in a file using AddMediaSampleReferences. |
| __Build Requirements:__ | XCode 2.4.1 for Mac, Microsoft Visual Studio 2005 for Windows |
| __Runtime Requirements:__ | QuickTime 7, Mac OS X 10.4, Windows XP or Vista |

This sample shows how to create a QuickTime movie from a series of video frames where the media for the video track is the frame data in the file itself (in QuickTime terminology we say the media for the video track has the file as its "data reference" or data source).
