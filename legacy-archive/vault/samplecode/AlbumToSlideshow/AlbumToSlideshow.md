# AlbumToSlideshow

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.2, 2008-05-15 Adds the resizing of images to fit in the generated XML sequence and allows for multiple albums with the same name. | __Runtime Requirements:__ | Mac OS X version 10.4 or greater, Final Cut Pro 4.5 or greater |

Demonstrates using CF and NSXML to create Final Cut Pro XML by taking iPhoto Album data and user inputs to generate Final Cut Pro XML. The XML exported can be imported into any Final Cut Pro supporting xmeml version 1 (FCP 4.5 or greater).

Xcode 2.1 project builds universal binary.
