# FindSerialPorts

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-15 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This is a little snippet adapted from the "Inside the Macintosh Communications Toolbox" book that illustrates how to use the Communications Resource Manager to obtain a list of serial ports installed on the computer. See also Technote 1119 "Serial Port Apocrypha" <http://developer.apple.com/technotes/tn/tn1119.html>. Requires: Communications Toolbox (System 7 and higher, or separate install on System 6) Keywords: Communications Toolbox, serial ports, Communications Resource Manager, CRM
