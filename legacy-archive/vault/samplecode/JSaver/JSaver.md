|  |  |

JSaver is a Screen Saver module for Berkeley Systems After Dark package that uses the JManager API to run Java applets as screen saver modules. Requires: After Dark 3.0 or later, Mac OS Runtime for Java (http://developer.apple.com/java/) Keywords: java, cfm, after dark, JManager
