# ClipboardViewer

|  |  |
| --- | --- |

| __Runtime Requirements:__ | Mac OS X v10.7 or later |

This small application shows the contents of any clipboard. A combo box lets you choose the clipboard to be examined (either from the built-in list, or by entering the name of an arbitrary clipboard); the list of types on the selected clipboard are displayed in a table view; and clicking on a type in the table view shows the data for that type in a text view.
