# FormatAsDOS

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon PC Exchange |

FormatAsDOS is a snippet demonstrating how to use the newer Disk Initialization Package calls DIXFormat() and DIXZero() to format a floppy disk as a DOS disk. DIXFormat, DIXZero, and DIReformat are documented in the Inside Macintosh: Files Errata Tech Note (TN 1041). Please note this snippet does not provide any prompts. It merely takes the floppy in the first floppy drive and reformats it as a DOS disk with the name "MS-DOS Disk". Requirements: PC Exchange Keywords: format, FSM, foreign file system, floppy, disk, DOS, FAT, DIXZero, FormatAsDOS
