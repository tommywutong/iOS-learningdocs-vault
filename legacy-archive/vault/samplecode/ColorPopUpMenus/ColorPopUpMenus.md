# ColorPopUpMenus

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-30 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Color Macintosh |

This folder contains an example illustrating how to show swatches of color in a labels-like menu in your own application. It also illustrates how to add a user adjustable color item to the menu that can be changed by way of the color picker interface. Contains routines for getting/setting particular elements in a color icon's color table. Requirements: Color Macintosh Keywords: Icon, color icon, colour table, CIconHandle, CTabHandle, clut
