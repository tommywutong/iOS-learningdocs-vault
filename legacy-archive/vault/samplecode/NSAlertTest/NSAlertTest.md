NSAlertTest is a Cocoa application that demonstrates how to use the NSAlert class. It covers all aspects of setting up an NSAlert for customization. It's also useful for visually prototyping your alerts before actually writing any code. As a bonus, it illustrates how to integrate a Help Book connected with the alert, complete with help anchors.
