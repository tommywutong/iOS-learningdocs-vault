# Compressed PICT Info

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Color QuickDraw |

This snippet shows how to use the StdPix proc to intercept and display the compression type and depth of any compressed PICT within a PICT resource. The same procedure can be used to gather other information about the compressed PICT. Note that all compressed PICTs get passed into StdPix before getting decom- pressed and passed to StdBits. Requirements: Color QuickDraw Keywords: Compression, StdPic, StdBits, PICT, Compressed, PICT Info
