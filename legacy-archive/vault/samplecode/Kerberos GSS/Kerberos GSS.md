# Kerberos GSS

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2008-06-04 Kerberos GSS-API Sample |
| __Build Requirements:__ | Xcode 3.0 |
| __Runtime Requirements:__ | Kerberos, Mac OS X 10.5 |

Sample GSS-API client and server. Negotiates a security context and send some integrity and confidentiality protected messages between the client and the server. The sample is independent of security mechanism, but commonly Kerberos is used.
