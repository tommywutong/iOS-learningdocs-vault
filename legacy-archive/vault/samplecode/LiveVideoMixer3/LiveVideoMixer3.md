# LiveVideoMixer3

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-08-01 LiveVideoMixer3 is extended to support Video In via QTKit |
| __Build Requirements:__ | Xcode 3.0 |
| __Runtime Requirements:__ | Leopard Preview |

LiveVideoMixer3 extends the LiveVideoMixer sample and shows the compositing of video streams using the QTVisualContext and OpenGL. LiveVideoMixer3 adds video input capabilites using QTKit and the QTCapture API.
