# QTControlCommandLine

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2008-01-29 Using the QuickTime COM Control object from the command line to export a movie to a different file format |
| __Build Requirements:__ | Microsoft Visual Studio 2005, QuickTime 7.3 |
| __Runtime Requirements:__ | Windows XP SP2, Windows Vista, QuickTime 7.3 |

Demonstrates how to use the QuickTime COM Control object (the QTControl object) from the command line to export a QuickTime movie to a different file format. Optionally, the export settings dialog can also be displayed, and the exporter settings can be saved to a file or even retrieved from a file to configure the exporter.
