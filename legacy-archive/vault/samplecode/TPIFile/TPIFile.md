# TPIFile

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

TPIFile is a sample TPI module that lets you open a TPIFile endpoint, connect that endpoint to a Mac OS file using an FSSpec, and then read that file using standard Open Transport API calls (eg OTRcv). Open Transport 1.1.1 or higher Open Transport STREAMS module driver asynchronous I/O
