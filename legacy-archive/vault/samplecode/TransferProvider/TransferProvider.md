# TransferProvider

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Open Transport 1.1.1 or later |

This sample demonstrates how to use OTTransferProviderOwnership to transfer the ownership of an Open Transport provider (eg an endpoint) between Open Transport clients. In this example, an endpoint is transferred between a shared library and an application that calls that shared library. The code from this sample is featured in the latest release (v1.2) of the book "Inside Macintosh: Open Transport". Requirements: Open Transport 1.1.1 or later Keywords: OTTransferProviderOwnership client library OT, TransferProvider
