# WatchKitAudioRecorder: Audio Recording and Playback

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2015-09-16 First public release. |
| __Build Requirements:__ | Xcode 7.0, iOS 9.0 SDK, watchOS 2.0 SDK |
| __Runtime Requirements:__ | iOS 9.0, watchOS 2.0 |

This sample demonstrates how to use WKInterfaceController to perform an audio recording. Refer to this sample if you want to learn how to present an AudioRecordingViewController to record and save audio. This project also demonstrates how to playback an audio file that has been produced.
