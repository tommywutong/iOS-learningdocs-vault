# HTML Video Example

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2008-06-02 HTML video example with plug-in fallback |
| __Build Requirements:__ | Mac OS X v10.5 and later |
| __Runtime Requirements:__ | Mac OS X v10.5 and later |

Demonstrates canonical mark-up for use of video content in HTML, taking advantage of the HTML 5 <video> tag where available and falling back to use of the QuickTime plug-in otherwise. A browser that supports Ogg containers and Theora video will display the Ogg encoding, while a browser such as Safari that supports MPEG-4 and H.264 will display the MPEG-4 encoding.
