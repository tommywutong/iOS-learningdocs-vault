# CoreAnimationText

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2010-04-08 Demonstrates using CAShapeLayers to layout and render vector based text. |
| __Build Requirements:__ | Mac OS X 10.6, Xcode 3.2 |
| __Runtime Requirements:__ | Mac OS X 10.6 |

This sample demonstrates using CAShapeLayers to layout and render vector text. For simplicity, this sample only lays out a single line of text and does not support all text attributes.
