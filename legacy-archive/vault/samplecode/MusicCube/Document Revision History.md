# Document Revision History

This table describes the changes to _MusicCube_.

| 2014-05-06 | Updated with GLKit. Removed compiler and Static Analyzer warnings. |
| 2010-06-23 | Upgraded project to build with the iOS 4.0 SDK. |
| 2009-10-02 | Updated for iPhone OS 3.1. Use CADisplayLink as the preferred method for controlling animation timing, and fall back to NSTimer when running on a pre 3.1 device where CADisplayLink is not available. |
