# WiredSprites

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-02-25 Demonstrates creating a wired sprite movie containing one sprite track. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon (both 9 and X) A Power Macintosh Computer running Mac OS X (10.1.2 or later recommended) with Mac OS X Developer Tools December 2001 or later. |

Demonstrates creating a wired sprite movie containing one sprite track. The sprite track contains six sprites; two penguins and four buttons. Part of An Introduction to QuickTime. A Power Macintosh Computer running Mac OS 9 (9.2.2 or later recommended), Metrowerks CodeWarrior Pro version 7.0 or later, QuickTime 5.0.2, CarbonLib 1.5 and Universal Interfaces 3.3.4 or later. Requirements: A Power Macintosh Computer running Mac OS X (10.1.2 or later recommended) with Mac OS X Developer Tools December 2001 or later. Keywords: QuickTime, Sprites
