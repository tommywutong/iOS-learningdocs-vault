# DREraseCarbonUI

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2004-04-09 DREraseCarbonUI shows how to use the DiscRecording erase setup and progress panel from Carbon. |
| __Build Requirements:__ | Xcode 1.0 or later |
| __Runtime Requirements:__ | Mac OS X 10.3 or later |

DREraseCarbonUI is a simple example showing how to use the standard DiscRecording erase setup and progress panel from a Carbon application.
