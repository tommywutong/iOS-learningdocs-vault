# FSRemoveInheritedACEs

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-01 Demonstrates manipulating access control lists of existing file system objects using the File Manager. |
| __Build Requirements:__ | Tiger |
| __Runtime Requirements:__ | Tiger |

This sample is a tool which will remove any access control entries marked as inherited. The main purpose of this sample is to illustrate the getting and setting of extended security (access control list) information using the File Manager (through FSGetCatalogInfo and FSSetCatalogInfo).
