# SignatureToApp

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Takes a signature (creator code) and finds the corresponding application, running or on disk. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon System 7 |

The SignatureToApp function takes an application's signature or creator code (a four-byte identifier) and attempts to find a running application, or an application on disk, with that signature. It can also launch the application if you allow it to and if the application is not already running. Requires: System 7.0 Requirements: System 7 Keywords: Process Manager, Desktop Database, finding applications by creator
