# DeviceSelectCL

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2014-04-18 This example shows how to select an OpenCL device not being used for display on the Mac Pro. |
| __Build Requirements:__ | Mac OS X v10.9 or later |
| __Runtime Requirements:__ | Mac OS X v10.9 or later |

This example shows how to select an OpenCL device not being used for display on the Mac Pro.

The program selects an OpenCL device without using OpenGL and then runs a simple kernel to compute an effect on an input image.
