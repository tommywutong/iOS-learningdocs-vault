# FinderDragPro

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Sample file illustrating drag and drop techniques for use with file system objects. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Mac OS with the drag manager and the thread manager installed |

Sample file illustrating drag and drop techniques for use with file system objects. This file illustrates how applications can use drag and drop commands in a way compatible with current and past versions of the Finder. Illustrates translucent drags, dragging hfs objects to the Finder (in a way that is compatible with current and past versions of the Finder), and the correct way to send and receive promised HFS flavors. Requirements: Mac OS with the drag manager and the thread manager installed Keywords: Drag and Drop, PromiseHFSFlavor, hfs, promise, finder
