# Monochrome Image

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-16 Applies the NTSC color weighting formula to an image to generate a monochrome version of the image. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X 10.2 |

This example shows how to convert an NSImage instance to monochrome, by applying the NTSC color weighting formula. Please note that this is not the fastest way to perform this conversion, but it shoud generate results that are pretty accurate. Requirements: Mac OS X 10.2 Keywords: monochrome NSImage NSBitmapImageRep
