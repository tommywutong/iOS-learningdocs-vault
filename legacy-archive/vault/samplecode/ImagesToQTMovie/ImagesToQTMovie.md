# ImagesToQTMovie

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Creates a QuickTime movie from the images of any connected camera. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS X Mac OS X |

ImagesToQTMovie A Cocoa application that creates a QuickTime movie out of the images of a connected camera. The application is looking for the first connected device and puts all images of it into a QuickTime movie. All Image Capture APIs are used in synchronous calls. Requirements: Mac OS X Keywords: Image Capture QuickTime movie
