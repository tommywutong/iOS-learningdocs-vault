# MakeEffectMovie

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Creating a movie with an effects track allowing the user to specify the effect using the standard effects dialog. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Both A Power Macintosh Computer running Mac OS 9 (9.2.2 or later recommended), |

Demonstrates how to create a movie with an effects track allowing the user to specify the effect using the standard effects dialog. Part of An Introduction to QuickTime. Requirements: A Power Macintosh Computer running Mac OS 9 (9.2.2 or later recommended), Metrowerks CodeWarrior Pro version 7.0 or later, QuickTime 5.0.2, CarbonLib 1.5 and Universal Interfaces 3.3.4 or later. A Power Macintosh Computer running Mac OS X (10.1.2 or later recommended) with Mac OS X Developer Tools December 2001 or later. Keywords: QuickTime, Effects
