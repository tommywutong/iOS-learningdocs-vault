# OTFindSerialPorts

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-07-22 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon Open Transport 1.1.1 or higher |

This sample demonstrates how to use the Open Transport API to find all the serial ports available to Open Transport programs. The code from this sample is featured in the latest release (v1.2) of the book "Inside Macintosh: Open Transport". Requirements: Open Transport 1.1.1 or higher Keywords: Open Transport, serial port, registry, OTGetUserPortNameFromPortRef, OTFindSerialPorts
