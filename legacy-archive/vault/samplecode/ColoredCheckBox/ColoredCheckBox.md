# ColoredCheckBox

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-30 Demonstrates how to create a colored check box on a gray window backgrounds. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This application demonstrates how to create a check box on the gray window backgrounds.The key to this is making sure that the background color for the window is set. a 'wctb' was created using ResEdit which provides the gray content for the window. The file coloredCheckBox.r shows you what's going on in the 'wctb' structure. Requirements: wctb, checkbox, control, color
