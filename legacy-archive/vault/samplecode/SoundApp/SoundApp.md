# SoundApp

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-03-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon 6.0.x and higher, Sound Manager 3.0 or later |

SoundApp.p is a sample application source file for demonstrating the Sound Manager. It requires the use of the SoundUnit to handle all of the sound routines. This portion of the source code handles the application's management of memory, errors, user interface, etc.. The read me notes are here in the source code because people tend to not read them otherwise. Requirements: 6.0.x and higher, Sound Manager 3.0 or later Keywords: sound, SoundApp
