# GrayText

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

This sample demonstrates two methods of printing gray text. On PostScript printers it sends PostScript, on QuickDraw printers it sends Color QuickDraw calls. If a QuickDraw printer does not use a CGrafPort, the gray text comes out as black. Unfortunately, there's currently no good way to handle that situation. Requires: Keywords: print, gray, text, PostScript, QuickDraw
