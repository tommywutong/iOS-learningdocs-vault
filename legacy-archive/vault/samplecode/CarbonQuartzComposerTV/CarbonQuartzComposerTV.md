| __Runtime Requirements:__ | Intended to be used with an iSight or other video input |

The QuartzComposer composition is based on the "QuartzComposer_WWDC_QCTV" demonstrated at WWDC 2005, and then modified to allow the title strings to be set directly from the UI by exposing and making use of bindings to the underlying composition. From Interface Builder click on the views at the bottom of the window and select the "Bindings" popup to examine the settings. Those bindings are exposed within the "QCTV.qtv" composition by <control>-clicking on the inputs bringing up the contextual menu allowing you to export and name the inputs.
