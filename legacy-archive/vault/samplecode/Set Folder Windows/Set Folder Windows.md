# Set Folder Windows

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Shows an AppleScript droplet to set up drive and folder windows in preparation for burning a CD. |
| __Build Requirements:__ | N/A |
| __Runtime Requirements:__ | Carbon |

This little AppleScript droplet is used to setup drive and folder windows in preperation for burning a CD. It requires the scriptable Finder from System 7.5 or later. It scripts the Finder rather than directly manipulating desktop information. Requires: Mac OS 8.5 Keywords: Finder scripting, window positions, burning a CD
