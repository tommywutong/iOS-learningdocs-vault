# ScreenSnapshot

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2011-07-19 Uses Quartz Display Services to obtain an image containing the contents of any of the connected displays |
| __Build Requirements:__ | Mac OS X 10.6 SDK, Xcode 3.2.6 |
| __Runtime Requirements:__ | Mac OS X 10.6 and later |

Uses Quartz Display Services to obtain an image containing the contents of any of the connected displays. Also allows the user to save the image to a file on disk.
