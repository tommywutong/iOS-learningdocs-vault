# SpotlightAPI

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-01 Some small sample programs that Show how to use the Spotlight API in your programs. |
| __Build Requirements:__ | Tiger |
| __Runtime Requirements:__ | Tiger |

Some small sample programs that Show how to use the Spotlight API in your programs.
First MDItemREf uses MDItemRef to get metadata for a file dragged into the window.
MDItemREf2 localizes the results
MDQueryRef1 does a query
MDQueryRef2 does a query for only images and show the metadata.
