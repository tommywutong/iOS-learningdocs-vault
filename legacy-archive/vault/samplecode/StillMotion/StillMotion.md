# StillMotion

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0.1, 2007-11-14 Minor changes to MyDocument NIB and rebuilt with Mac OS X 10.5 GM tools. |
| __Build Requirements:__ | Xcode 3.0 |
| __Runtime Requirements:__ | Mac OS X 10.5 |

This sample demonstrates how to use the QTKit Capture decompressed video output API to build a simple application that creates stop motion animations. The application will capture individual frames taken from a video camera connected to the computer and assemble them in a QuickTime movie that can be saved to disk.
