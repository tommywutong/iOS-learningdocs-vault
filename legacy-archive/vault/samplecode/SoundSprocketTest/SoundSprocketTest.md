# SoundSprocketTest

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-10-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon PowerPC, System 8.1+, SoundSprocket, QuickDraw 3D, and either Universal Headers 3.3 or the SoundSprocket SDK. |

This sample is a demonstration and test of the SoundSprocket API with QuickDraw 3D. If allows the user to config various options of SoundSprocket to show how effects work and their interactions. Requirements: PowerPC, System 8.1+, SoundSprocket, QuickDraw 3D, and either Universal Headers 3.3 or the SoundSprocket SDK. Keywords: SoundSprocket, 3D sound, reverb, effects
