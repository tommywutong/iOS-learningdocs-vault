# Proactive Toolbox: Increasing usage of your app with proactive suggestions using NSUserActivity

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2016-10-04 First release |
| __Build Requirements:__ | Xcode 8.0 or later; iOS 10.0 SDK or later |
| __Runtime Requirements:__ | iOS 10.0 or later |

This sample demonstrates how to use NSUserActivity to integrate with location suggestions throughout the system. It shows how to create, configure, and manage NSUserActivities for features like Handoff, App Search or Location Suggestions. This project also shows how to best participate in location suggestions and inform the system on when to promote your app. You can use the Proactive Toolbox app to test your integration with these APIs, to interact with locations or consume locations viewed in your app.
