AddressBookCocoa is a Cocoa application that demonstrates how to create, access, add, search, and retrieve Address Book records using the Address Book's Objective-C APIs.

The application displays the 'Add this person to the Address Book' and 'Find this info for LastName Elba' buttons. Use these buttons to respectively add a contact to the Address Book and search for information about the contact named Elba.
