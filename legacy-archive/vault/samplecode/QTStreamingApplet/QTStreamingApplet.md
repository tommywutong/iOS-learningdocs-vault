| __Build Requirements:__ | XCode 2.2, or Java 2 SDK for Windows, and QuickTime 7 |
| __Runtime Requirements:__ | Java 1.5 and QuickTime 7, or later, recommended |

Demonstrates how to play a QuickTime stream, or a QuickTime file at a remote resource, by providing a URL from within an applet.

Enter a URL eg. file:///.... to play a movie (or read in an image file) in the text box at the bottom of the applet. Other supported protocols include rtsp and http.
