# TESample

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 First Version |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Carbon |

TESample is an example application that demonstrates how to initialize the commonly used Toolbox managers, operate successfully under MultiFinder, handle desk accessories, and create, grow, and zoom windows. It demonstrates fundamental TextEdit toolbox calls and TextEdit automatic scrolling, and it shows how to create and maintain scroll bar controls. Keywords: TextEdit, TESample
