# CIColorTracking

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.3, 2008-04-24 More comments. Fixed some errors in the project. |
| __Build Requirements:__ | Xcode version 2.3 Interface Builder version 2.5 |
| __Runtime Requirements:__ | Mac OS X v10.5 or later. Macintosh with Intel or G5 processor. Preferably with an nVidia 7300GT or newer graphic card. |

The CIColorTracking sample application is an Objective-C applicaton that implements a GPU-based technique to find the location of a uniquely colored object in a scene and then uses the position information to apply video effects.
