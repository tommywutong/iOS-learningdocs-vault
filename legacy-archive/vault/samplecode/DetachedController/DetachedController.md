# DetachedController

|  |  |
| --- | --- |

| __Build Requirements:__ |  |

This demo program shows how to select and then play a QuickTime movie with its controller detached. Requirements: - Common - Sun Compliant Java Runtime Environment 1.1 - QuickTime 3 - QTJava.zip - QTJava media samples - Mac OS: - System 8 or later - Macintosh Runtime for Java (MRJ) 2.1 - Windows 95, 98, or NT:: - JRE/JDK from Sun Microsystems, Inc. recommended Keywords: QuickTime, Java, MRJ
