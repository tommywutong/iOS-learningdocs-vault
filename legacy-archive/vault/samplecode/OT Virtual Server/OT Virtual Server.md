# OT Virtual Server

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Sample code which uses Open Transport and demonstrates real world issues. |
| __Build Requirements:__ |  |
| __Runtime Requirements:__ | Mac OS 9 Open Transport 1.1.1 |

The Virtual Server is an attempt to provide a piece of sample code which uses the native Open Transport API and is complex enough to demonstrate real issues an application developer will need to deal with. It also demonstrates the speed of Open Transport when used properly. Requirements: Open Transport 1.1.1 Keywords: Open Transport, server, tilisten, notifiers, listen/accept handoff, OT Virtual Server
