# MPRemoteCommandSample: Using MPRemoteCommandCenter respond to remote control events

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2016-10-27 First public release |
| __Build Requirements:__ | Xcode 8.1 or later, iOS 10.0 SDK or later, tvOS 10.0 SDK or later, macOS 10.12 SDK or later, Swift 3.0 |
| __Runtime Requirements:__ | iOS 10.0 or later, tvOS 10.0 or later, macOS 10.12.1 or later |

This sample demonstrates how to use the MediaPlayer MPRemoteCommandCenter APIs to handle remote control events. Refer to this sample if you want to know how to respond to remote control events, customize your Control Center and Lock Screen controls, and support Siri commands related to remote control events.
