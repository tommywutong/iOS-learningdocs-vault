# Quartz Composer Matrix

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2005-06-01 First Version |
| __Build Requirements:__ | Xcode 2.0 or later |
| __Runtime Requirements:__ | Mac OS X 10.4 or later and Quartz Extreme compatible machine |

This sample code demonstrates how to use a Quartz Composer composition in combination with QuickTime 7 APIs and Core Video to display a movie as a series of frames in a 3D world.
