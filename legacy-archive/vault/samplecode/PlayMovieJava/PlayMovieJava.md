# PlayMovieJava

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2003-01-14 Display any QuickTime content within an AWT container using the QTCanvas. |
| __Build Requirements:__ | N/A |
| __Runtime Requirements:__ | Carbon |

This demo program shows how to display any QuickTime content within a java.awt display space using the QTCanvas. It also demonstrates the use of the different resize options of the QTCanvas (with the QTCanvas' alignment set to centre it in the display space). Requirements: - Common - Sun Compliant Java Runtime Environment 1.1 - QuickTime 3 - QTJava.zip - QTJava media samples - Mac OS: - System 8 or later - Macintosh Runtime for Java (MRJ) 2.1 - Windows 95, 98, or NT:: - JRE/JDK from Sun Microsystems, Inc. recommended Keywords: QuickTime, Java, MRJ
