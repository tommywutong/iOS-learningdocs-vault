# HelloStudio

|  |  |
| --- | --- |
| __Last Revision:__ | Version 1.0, 2006-07-28 This is a Hello, world application built using AppleScript Studio. |
| __Build Requirements:__ | XCode 2.2 |
| __Runtime Requirements:__ | Mac OS X 10.2 |

This is a Hello, world application built using AppleScript Studio in two milestones. A complete outline and script source text clippings are provided to enable the developer to create the application from scratch. A test script is also provided for scripting the complete application from Script Editor.
