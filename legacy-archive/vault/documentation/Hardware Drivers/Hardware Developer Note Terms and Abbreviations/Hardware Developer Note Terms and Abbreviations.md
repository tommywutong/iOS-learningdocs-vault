# Hardware Developer Note Terms and Abbreviations

The following sections list the standard units of measure and common computer industry terms, acronyms, and abbreviations.

Standard units of measure used in Developer Notes include:

|  |  |  |  |  |
| --- | --- | --- | --- | --- |
| A | amperes |  | MB | megabytes |
| dB | decibels |  | Mbps | megabits per second |
| GB | gigabytes |  | Mbit | megabits |
| GHz | gigahertz |  | MHz | megahertz |
| Hz | hertz |  | mm | millimeters |
| KB | kilobytes |  | ns | nanoseconds |
| kg | kilograms |  | V | volts |
| kHz | kilohertz |  | VDC | volts direct current |
| mA | milliamperes |  |  |  |
