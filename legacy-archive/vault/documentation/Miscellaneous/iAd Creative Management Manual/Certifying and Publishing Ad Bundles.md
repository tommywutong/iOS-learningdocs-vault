# Certifying and Publishing Ad Bundles

The iAd Certification team can easily mark ad bundles as either Approved or Needs Revision. The iAd Certification team should follow the process below:

- Navigate to the ad bundle of interest
- In the Details screen, select the “Change Status” menu option
- Select the appropriate status from the Status dropdown
- Select the “Save” button

__Figure 5-1__  Change Ad Bundle Status

!!

Once the ad bundle status has changed, a confirmation message will appear at the top of the screen to indicate the change in status.

__Figure 5-2__  Successful submission

!

Once the status has been changed to Approved, the ad bundle can be pushed to a production environment and marked as in production. The iAd NOC team should follow the process below:

- Navigate to the ad bundle of interest
- In the Details screen, select the Download Ad bundle option. Use the existing script process outside of iAd Creative Management portal to upload the ad bundle into production and receive production links.
- Send the appropriate Account Manager the production links so that she/he can Update the Creative Workbook with the production links.
- In the Details screen, select the “Change Status” menu option
- Select “Publish” from the Status dropdown
- Enter comments as necessary
- Select the “Save” button

__Figure 5-3__  Change Ad Bundle status

!!

Once the ad bundle status has changed, a confirmation message will appear at the top of the screen to indicate the change in status.

__Figure 5-4__  Published

!
