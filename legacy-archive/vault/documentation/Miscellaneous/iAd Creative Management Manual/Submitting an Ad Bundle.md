# Submitting an Ad Bundle

When the user is ready to submit the ad bundle, the user should follow the process below:

- Navigate to the ad bundle of interest
- In the Details screen, select the “Change Status” menu option
- Select “Submit” from the Status dropdown
- Select the “Save” button

__Figure 4-1__  Change Ad Bundle Status

!!

| Field | Description |
| --- | --- |
| Status Selector | From Draft status, the only option is to Submit the ad bundle. |
| Comments field | Enter notes which pertain to the submission of this version of the ad bundle. |
| Action Buttons | Allows the user to Submit the change in statuses or cancel the submission process. |

When the ad bundle has been submitted successfully, a confirmation will appear at the top of the screen.
