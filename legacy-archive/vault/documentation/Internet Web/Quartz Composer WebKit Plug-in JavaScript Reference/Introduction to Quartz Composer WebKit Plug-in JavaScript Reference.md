# Introduction to Quartz Composer WebKit Plug-in JavaScript Reference

Quartz Composer is a development tool for processing and rendering graphical data using an easy-to-use visual programming approach and the rich media technologies available in OS X. The Quartz Composer WebKit plug-in, available in OS X v10.4.7 and later, displays Quartz Composer compositions in webpages and Dashboard widgets.

_Quartz Composer WebKit Plug-in JavaScript Reference_ is for web content and Dashboard widget creators who want to manipulate a Quartz Composer composition used in a webpage or Dashboard widget via JavaScript. You will find a reference for the JavaScript API available from the Quartz Composer WebKit plug-in.

To learn how to create a composition using Quartz Composer, read _[Quartz Composer Programming Guide](../../Graphics%20Imaging/Quartz%20Composer%20Programming%20Guide/Introduction%20to%20Quartz%20Composer%20Programming%20Guide.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaytgnjx)_.
