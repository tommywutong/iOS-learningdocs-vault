# Game Center 属性

此附录介绍了 iTunes Connect 为配置您的某个版本的游戏和 Game Center 之间的接口以及显示 Game Center 中的排行榜和成就而收集的元数据。

## 排行榜

排行榜元数据确定 iTunes Connect 中的每个排行榜，介绍其得分并收集在排行榜显示中使用的语言特定文本。iTunes Connect 跟踪排行榜类型和状态（指示该排行榜是否获得批准并在 app 中生效）的元数据。

在 app 的 Game Center 页面的“Leaderboard”（排行榜）部分中设置这些属性，如 [排行榜和排行榜集合](%E6%8E%92%E8%A1%8C%E6%A6%9C%E5%92%8C%E6%8E%92%E8%A1%8C%E6%A6%9C%E9%9B%86%E5%90%88.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diojqfvbuqmrnknltc)。

### 排行榜属性

主要的排行榜属性确定 iTunes Connect 中的每个排行榜，并介绍得分的安排方式和格式。

| 属性 | 说明 | 可以编辑 |
| --- | --- | --- |
| 排行榜引用名称 | 必须为每个排行榜提供的内部名称。如果您搜索 iTunes Connect 中的排行榜，则使用此内部名称。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |
| 排行榜 ID | 为您的排行榜选择的字母数字标识符。此 ID 仅限于 100 个字符（假设使用单字节字符）。请注意，排行榜 ID 相当于 Game Kit API 中的“类别”。您的排行榜 ID 属于永久设置，因此无法在以后进行编辑。 | 无法在提交二进制文件后进行编辑 |
| 得分格式类型 | 您希望此 app 的得分在排行榜中的表达格式类型，例如，整数、经过时间或金钱。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 |
| 得分提交类型 | 在排行榜中显示的玩家得分：最高得分或最近得分。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 |
| 排列顺序 | 得分的排序：在“从低到高”和“从高到低”之间进行选择。如果您希望先显示最低得分，则选择“从低到高”。如果您希望先显示最高得分，则选择“从高到低”。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 |
| 得分范围： | 使用 64 位带符号整数的得分范围。这些值必须介于 long 最小值 (-2^63) 和 long 最大值 (2^63 - 1) 之间。超出此范围的任何得分都将被删除。得分范围值是可选的，但是如果添加范围值，就必须同时设置这两个值，且它们不能相等。第一次添加得分范围时，或者在以后将其更改为限制数据的更小范围时，超出此范围的所有数据都将丢失，且无法恢复。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |

### 排行榜语言属性

排行榜语言属性收集在排行榜显示中使用的语言特定文本。您必须添加至少用一种语言表达的这些属性。

| 属性 | 说明 | 可以编辑 |
| --- | --- | --- |
| 语言 | 您的排行榜将以此语言进行显示。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后   必须至少定义一种语言。无法删除最后一种语言。 |
| 名称 | 指定语言中的排行榜的引用名称。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |
| 得分格式 | 该格式决定您的得分在指定语言的排行榜中的显示方式。例如，如果您的 app 使用金钱进行计分，则您可能需要根据您选择的语言指定不同类型的金钱。此菜单中的值反映了排行榜的“Score Format Type”（得分格式类型）。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |
| 得分格式后缀（单数） | 将此后缀添加到以单数形式显示的得分末尾。此后缀是可选的，但是对于阐明排行榜中存储的得分类型有很大的帮助。例如，包括“点”、“金币”以及“下”。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |
| 得分格式后缀（复数） | 将此后缀添加到以复数形式显示的得分末尾。此后缀是可选的，但是对于阐明排行榜中存储的得分类型有很大的帮助。例如，包括“点”、“金币”以及“下”。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |
| Image | 代表排行榜的本地化图像。图片必须是 `.jpeg`、 `jpg`、 `tif`、 `tiff` 或 `.png` 文件，像素为 512 x 512 或 1024 x 1024，dpi 至少为 72 以及采用 RGB 色彩空间。这是可选属性。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |

### 排行榜类型

iTunes Connect 跟踪排行榜类型的元数据，该数据确定将哪些得分添加到排行榜中。

| 类型 | 说明 |
| --- | --- |
| 单个 | 未与其他排行榜进行组合的单个排行榜。 |
| 合并 | 从多个单个排行榜中合并玩家的得分并对得分一起进行排名的排行榜。 |
| 随附 | 与其他排行榜组合的单个排行榜，即组合排行榜的随附子排行榜。 |

### 排行榜状态

排行榜状态指明排行榜是否获得批准以及是否在 app 中生效。

| 状态 | 说明 |
| --- | --- |
| 审核中 | 已将排行榜提交至 Apple 进行审核。 |
| Live | 已批准 app 的排行榜。 |
| 未生效 | app 的排行榜之前有效，但是已被移至某个组，且尚未针对该组获得批准。只适用于添加到组的排行榜。 |

## 成就

成就元数据确定 iTunes Connect 中的每个成就及其行为，并收集在成就显示中使用的语言特定文本。iTunes Connect 还跟踪状态，以指明成就是否获得批准以及是否在 app 中生效。

在 app 的 Game Center 页面的“Achievements”（成就）部分中设置这些属性，如 [成就](%E6%88%90%E5%B0%B1.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diojqfvbuqmznknltc)。

### 成就属性

主要的成就属性确定 iTunes Connect 中的每个成就，并介绍成就的行为方式。

| 属性 | 说明 | 可以编辑 |
| --- | --- | --- |
| 成就应用名称 | 必须为每个成就提供的内部名称。如果您搜索 iTunes Connect 中的成就，则使用此内部名称。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |
| 成就 ID | 为您的成就选择的字母数字标识符。此 ID 仅限于 100 个字符（假设使用单字节字符）。您的成就 ID 属于永久设置，因此无法在以后进行编辑。 | 保存成就后，无法对其进行编辑。 |
| 点值 | 您的成就价值的点数。每个成就的最大点数为 100，所有成就的最大总计点数为 1000。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 |
| 隐藏 | 标记为“Hidden”（隐藏）的成就在 Game Center 中将保持隐藏状态，直到玩家获得这些成就。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |
| 可多次获得 | 指示玩家是否可以多次获得成就。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |

### 成就语言属性

成就语言属性收集在成就显示中使用的语言特定文本。您必须添加至少用一种语言表达的这些属性。

| 属性 | 说明 | 可以编辑 |
| --- | --- | --- |
| 语言 | 您希望此成就显示的语言。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后   必须至少定义一种语言。无法删除最后一种语言。 |
| 标题 | 您希望此成就在 Game Center 中显示的本地化标题。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |
| 获取前说明 | 在 Game Center 用户获取您的成就前显示的成就说明。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |
| 获取后说明 | 在 Game Center 用户获取您的成就后显示的成就说明。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |
| Image | 代表成就的本地化图像。图片必须是 `.jpeg`、 `jpg`、 `tif`、 `tiff` 或 `.png` 文件，像素为 512 x 512 或 1024 x 1024，dpi 至少为 72 以及采用 RGB 色彩空间。这是必选属性。 | - 在批准二进制前 - “开发者已拒绝”状态 - “已拒绝”状态 - 在批准一个二进制后 |

### 成就状态

成就状态指明成就是否获得批准以及是否在 app 中生效。

| 状态 | 说明 |
| --- | --- |
| 审核中 | 已将成就提交至 Apple 进行审核。 |
| Live | 已批准 app 的成就。 |
| 未生效 | app 的成就之前有效，但是已被移至某个组，且尚未针对该组获得批准。只适用于添加到组的成就。 |

## 组属性

组属性确定添加到组中的 app、排行榜和成就。在 app 的 Game Center 页面上设置这些属性，如 [组](%E7%BB%84.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diojqfvbuqnbnknltc)。

| 属性 | 说明 |
| --- | --- |
| 引用名称 | 必须为每个组提供的内部名称。这是您在 iTunes Connect 中看到的名称。 |
| 此组中的 app | 附加到此组的 app。 |
| 组排行榜 | 此组的共享排行榜。 |
| 组成就 | 此组的共享成就。 |
| 默认排行榜 | 在您的 app 中默认显示的排行榜。 |

## app 版本

app 版本属性允许 iTunes Connect 跟踪哪些 Game Center 属性适用于特定的 app 版本。您可以在 app 的“Version Details”（版本详细信息）页面上进行选择，如 [为 app 版本启用 Game Center](%E5%8F%91%E5%B8%83%20Game%20Center%20app.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diojqfvbuqmrwfvjvomrq)中所述），以设置这些元数据属性。

| 属性 | 说明 |
| --- | --- |
| 排行榜 | 排行榜显示所有使用您的 app 的 Game Center 用户的最高得分。无法删除正在您的 app 的任意版本的 Game Center 中使用的排行榜。每个 app 最多可包含 100 个排行榜。排行榜是可选的。 |
| 成就 | 成就是玩家为达到某个阶段或执行某项操作而获得的荣誉，可通过您的 app 进行定义。无法删除正在您的 app 的任意版本的 Game Center 中使用的成就。成就是可选的。 |
