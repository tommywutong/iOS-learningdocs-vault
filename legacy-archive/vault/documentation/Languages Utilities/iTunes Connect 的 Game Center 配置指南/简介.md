# 简介

Game Center 是一项在游戏中提供社交游戏功能的 Apple 网络服务。要支持多项 Game Center 功能，您需要向 Apple 服务提供有关您的 app 的信息：在 Game Center 中显示的文本或图像以及如何管理从玩家收集的数据等信息。要向 Game Center 服务器提供此类信息，您需要创建 iTunes Connect 记录，并向其中添加 Game Center 配置详细信息。此文档介绍了如何将 Game Center 配置信息添加到 app 的现有 iTunes Connect 记录。

在开始开发 app 并设计其社交游戏功能后，您可以将 Game Center 配置信息添加到 iTunes Connect 中，然后才能在 Game Center 中测试这些功能。

（原归档配图获取待重试：`gc_flow_big_picture_2x.png`）

开发游戏时，最好同时开发、设计、配置和测试 Game Center 组件，而不是在完成当前步骤之后再进行下一步操作。

如果您对 Game Center 功能尚不熟悉，请先阅读 _[Game Center Programming Guide](../../Networking%20Internet/Game%20Center%20Programming%20Guide/About%20Game%20Center.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4dgmbu)_ ，然后再阅读本文档。如果您对 iTunes Connect 尚未熟悉，请阅读 _iTunes Connect 开发者指南 (iTunes Connect Developer Guide)_ ，然后再阅读本文档。

## 概况一览

使用 iTunes Connect 为您的 app 配置 Game Center 组件所涉及的流程包括启用 Game Center 功能、配置 Game Center 组件以及将 Game Center 功能与您要提交到商店的 app 版本相关联。

（原归档配图获取待重试：`gc_flow_detail_2x.png`）

### iTunes Connect 中的 Game Center 配置

为 app 的所有版本启用 Game Center 并配置 Game Center 组件。当您准备向商店提交某个 app 版本时，您需要将特定 Game Center 组件与该 app 版本相关联。这样，您就可以配置 Game Center 组件的超集，并逐渐使其在 app 的后续版本中可用。

__相关章节：__ [访问和启用 Game Center 功能](%E8%AE%BF%E9%97%AE%E5%92%8C%E5%90%AF%E7%94%A8%20Game%20Center%20%E5%8A%9F%E8%83%BD.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diojqfvbuqmryfvjvomi)、 [分发 Game Center app](%E5%8F%91%E5%B8%83%20Game%20Center%20app.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diojqfvbuqmrwfvjvomq)

### Game Center 组件

在 iTunes Connect 中配置 Game Center 功能后，您将会碰到以下几个描述 Game Center 组件的术语：

- __排行榜__ 收集 Game Center 中游戏玩家的得分，并进行排名。您使用 iTunes Connect 配置 Game Center 收集的得分、排名方式以及排名以 app 支持的每种语言显示的方式。
- __排行榜集__ 组织游戏的排行榜，使得每个游戏 100 个排行榜的限制扩展为允许在多达 100 个排行榜集中组织 500 个排行榜。
- __成就__ 列出玩家在您的游戏中达到的成绩。您使用 iTunes Connect 配置 Game Center 收集的成就以及成就以 app 支持的每种语言显示的方式。
- __游戏组__ 允许您定义排行榜和成就，以便对多个游戏的玩家进行排名，例如不同平台或支付级别的游戏。向 iTunes Connect 中的现有组中添加 app 时，您决定该组使用单个游戏中的哪些排行榜和成就。
- __多人游戏兼容性列表__ 标识可以同时玩的游戏和游戏版本。您可在 iTunes Connect 中配置这些列表。

Game Center 包括其他功能，例如不具有相应 iTunes Connect 配置的比赛匹配机制和挑战。

### 使用您的 app 测试 Game Center

测试 Game Center 功能需要访问 Game Center 服务，然后才能向用户提供您的游戏。在 iTunes Connect 中，您可以创建允许您的游戏的开发版本使用 Game Center 的测试用户帐户。在将游戏发布到商店之前，切勿忘记删除这些测试帐户中的得分。

__相关章节：__ [测试您的 app](%E6%B5%8B%E8%AF%95%E6%82%A8%E7%9A%84%20app.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diojqfvbuqmrvfvjvomi)

### 导入 Game Center 元数据

您可以配置许多 Game Center 组件，并使用 Transporter 传递 App Store 包中的数据。请参阅 _《app 元数据规范》_ 和 _《Transporter 快速入门指南》_。 iTunes Connect 用户可以在“Manage Your Apps”（管理您的 app）页面底部的“Deliver Your Apps”（传送您的 app）下访问这些文档。
