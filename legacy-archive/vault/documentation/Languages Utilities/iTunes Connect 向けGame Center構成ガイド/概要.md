# 概要

Game Centerはゲームにソーシャルゲーム機能を提供するAppleのネットワークサービスです。Game Centerの多くの機能をサポートするには、Game Centerを表示するためのテキストや画像、プレーヤーから収集したデータの管理方法など、アプリケーションに関する情報をAppleサービスに提供する必要があります。この情報をGame Centerサーバに送信するには、iTunes Connect記録を作成し、Game Centerの設定の詳細を追加します。このドキュメントでは、Game Centerの設定情報をアプリケーションの既存のiTunes Connect記録に追加する方法について説明します。

Game Centerの設定情報をiTunes Connectに追加できるのは、アプリケーションの開発とソーシャルゲーム機能の設計を開始した後、Game Centerで機能のテストを行う前です。

（原归档配图获取待重试：`gc_flow_big_picture_2x.png`）

ゲーム開発では、一般的に、Game Centerコンポーネントの開発、設計、設定、テストを順番に実行するのではなく並行して行います。

Game Centerの機能の詳細については、このドキュメントの前に _[iTunes Connect 向けGame Center構成ガイド](https://developer.apple.com/library/archive/documentation/LanguagesUtilities/Conceptual/iTunesConnectGameCenter_Guide_Jpn/index.html)_ を参照してください。iTunes Connectについては、このドキュメントの前に _iTunes Connect デベロッパガイド_ を参照してください。

## 概要

iTunes Connectを使用してアプリケーションのGame Centerコンポーネントを設定するプロセスでは、Game Centerの機能の有効化、Game Centerコンポーネントの設定、Game Centerの機能とストアに登録するアプリケーションの版の関連付けを行います。

（原归档配图获取待重试：`gc_flow_detail_2x.png`）

### iTunes ConnectでのGame Centerの設定

Game Centerを有効にし、アプリケーションのすべての版に対してGame Centerコンポーネントを設定します。アプリケーションの版をストアに登録する準備ができたら、特定のGame Centerコンポーネントをその版と関連付けます。このように、Game Centerコンポーネントのスーパーセットを設定しておき、後続の版で段階的に対応できます。

__関連する章：__ [Game Centerの機能にアクセスして有効にする](Game%20Center%E3%81%AE%E6%A9%9F%E8%83%BD%E3%81%AB%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B9%E3%81%97%E3%81%A6%E6%9C%89%E5%8A%B9%E3%81%AB%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmryfvjvomi)、 [Game Centerアプリケーションを配布する](Game%20Center%E3%82%A2%E3%83%97%E3%83%AA%E3%82%B1%E3%83%BC%E3%82%B7%E3%83%A7%E3%83%B3%E3%82%92%E9%85%8D%E5%B8%83%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmrwfvjvomq)

### Game Centerのプロパティ

iTunes ConnectでGame Centerの機能の設定では、Game Centerコンポーネントについて次のような用語を使用します。

- __Leaderboard__ Game Centerのゲームからプレーヤーのスコアの収集と順位づけを行います。iTunes Connectを使用して、Game Centerが収集するスコアや順位づけの方法、アプリケーションがサポートする各言語での表示方法を設定します。
- __Leaderboardセット__ ゲームのLeaderboardを整理します。ゲーム1つあたりのLeaderboardは100個までですが、100個のLeaderboardセットを使用することで、使用できるLeaderboardが500個まで増えます。
- __アチーブメント__ ゲームでプレーヤーが達成する項目です。iTunes Connectを使用して、Game Centerが収集するアチーブメント、アプリケーションがサポートする各言語での表示方法を設定します。
- __ゲームグループ__ プラットフォームや支払いレベルの異なる複数のゲームからプレーヤーの順位づけをするため、Leaderboardおよびアチーブメントを定義できます。iTunes Connectでアプリケーションを既存のグループに追加する際、そのグループで個々のゲームのどのLeaderboardおよびアチーブメントを使用するかを決めます。
- __マルチプレーヤー互換性リスト__ プレーヤー同士が対戦できるゲームおよびゲームの版を示します。このリストをiTunes Connectで設定します。

そのほかにも、Game Centerにはマッチメークやチャレンジなどの機能がありますが、これらに対応するiTunes Connectの設定はありません。

### アプリケーションでGame Centerをテストする

Game Centerの機能をテストするには、ゲームをユーザに提供する前に、Game Centerサービスにアクセスする必要があります。iTunes Connectでテスト用ユーザアカウントを作成し、ゲームの開発版でGame Centerを使用できるようにします。ゲームをストアに登録する前に、このテスト用アカウントからスコアを削除するのを忘れないようにしてください。

__関連する章：__ [アプリケーションをテストする](%E3%82%A2%E3%83%97%E3%83%AA%E3%82%B1%E3%83%BC%E3%82%B7%E3%83%A7%E3%83%B3%E3%82%92%E3%83%86%E3%82%B9%E3%83%88%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmrvfvjvomi)

### Game Centerメタデータをインポートする

多くのGame Centerコンポーネントを設定し、Transporterを使用してメタデータをApp Storeに配信できます。詳しくは、 _『App Metadata Specification(アプリケーションメタデータ規格)』_ および _『Transporter Quick Start Guide(Transporterクイックスタートガイド)』を参照してください_。iTunes Connectユーザーは、「Manage Your Apps」ページ下部の「Deliver Your Apps」でこれらのドキュメントを参照できます。

（原归档配图获取待重试：`links_bottom_manage_apps_2x.png`）

## 本書の使い方

このドキュメントは、iTunes Connectの手順を補完するものとして使用してください。

## 必要事項

このドキュメントでは、Game Center対応のゲームを開発しており、次の準備ができていることを前提としています。

- Game Centerの機能の設計に取り掛かっている _[iTunes Connect 向けGame Center構成ガイド](https://developer.apple.com/library/archive/documentation/LanguagesUtilities/Conceptual/iTunesConnectGameCenter_Guide_Jpn/index.html)_
- アプリケーションのiTunes Connectレコードを作成した (『iTunes Connectデベロッパガイド』 の _“新規アプリケーションの追加”を参照)_
