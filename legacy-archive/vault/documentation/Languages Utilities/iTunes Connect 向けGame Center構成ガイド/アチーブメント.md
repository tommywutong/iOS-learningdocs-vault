# アチーブメント

ゲームにアチーブメントを組み込むには、iTunes Connectを使用して、Game Centerがプレーヤーにアチーブメントを表示するために必要なデータを入力する必要があります。デザインと開発の情報については、 [『Game Centerプログラミングガイド』](../../Networking%20Internet/Game%20Center%20Programming%20Guide/Leaderboards%2C%20Achievements%2C%20and%20Challenges.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4dgmbufvbuqny) の _“アチーブメント”_ を参照してください。

（原归档配图获取待重试：`achievement_2x.png`）

## アチーブメントを作成する

iTunes Connectでアチーブメントを設定するとき、獲得したポイント、プレーヤーが目標を達成するまでアチーブメントを非表示にするかどうか、プレーヤーがアチーブメントを複数回達成できるかどうかなど、アチーブメントの詳細を指定します。アチーブメントを表示する言語または地域ごとに、アチーブメント名とアチーブメントの達成前後にプレーヤーに表示するメッセージも指定する必要があります。また、アチーブメントを表す画像も指定が必要です。アプリケーションごとに100までのアチーブメントを作成できます。

iTunes Connectでアプリケーションのアチーブメントを設定できるのは、アプリケーションの状態が「In Review」以外である場合です。

__注意：__ アプリケーションのある版でプレーヤーが達成できるようにしたアチーブメントを、後で削除することはできません。

アチーブメントに関する情報を入力する場合は、 [アチーブメントのプロパティ](Game%20Center%E3%81%AE%E3%83%97%E3%83%AD%E3%83%91%E3%83%86%E3%82%A3.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmrzfvjvomjz) を参照してください。

![bullet](attachments/Resources/1282/Images/task_2x.png)アチーブメントを追加するには、

1. アプリケーションの「Game Center」ページを開きます [(アプリケーションの「Game Center」ページを開くを参照)](Game%20Center%E3%81%AE%E6%A9%9F%E8%83%BD%E3%81%AB%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B9%E3%81%97%E3%81%A6%E6%9C%89%E5%8A%B9%E3%81%AB%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmryfvjvonrv)。
2. 必要に応じて、Game Centerを有効にします。
3. 「Achievements」セクションの「Add Achievement」をクリックします。

   （原归档配图获取待重试：`gc_add_achievement_2x.png`）

   表示されるフォームには、 [アチーブメントのプロパティで説明されているアチーブメントオプションが含まれます](Game%20Center%E3%81%AE%E3%83%97%E3%83%AD%E3%83%91%E3%83%86%E3%82%A3.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmrzfvjvomjz)。
4. 「Achievement Reference Name」欄にアチーブメントの内部参照名を入力します。
5. 「Achievement ID」欄に一意の識別子を入力します。

   英数字文字列ですが、ピリオドおよびアンダースコアも入れることができます。
6. 「Point Value」欄にアチーブメントのポイント数を入力します。

   割り当て可能な残りポイント数が、この欄の下に表示されます。アプリケーションのアチーブメントすべてを合算して、1000ポイントまで割り当て可能です。
7. まだ達成されていないアチーブメントを表示しないでおく場合は「Hidden」で「Yes」、そうでなければ「No」を選択します。
8. 同じアチーブメントを何度でも達成できるようにする場合は「Achievable More Than Once」で「Yes」、そうでなければ「No」を選択します。
9. 「Add Language」をクリックして、アチーブメントを表示するためのテキストを指定します。

   アプリケーションがサポートする表示言語または地域ごとに、 [アチーブメントの表示言語を追加するにはで説明されている手順を繰り返します](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmznknlteoa)。

   （原归档配图获取待重试：`gc_ach_add_filled_2x.png`）
10. 「Save」をクリックします。

## アチーブメントを設定する

審査を受けるためにアプリケーションを提出するまで、アプリケーションのアチーブメントのプロパティは変更可能です。アプリケーションの提出後は、アチーブメントIDを編集できなくなります。アプリケーションのすべての版でプレーヤーがアチーブメントを使用できるようにした後は、削除もポイント数の変更もできません。

グループに追加されたアチーブメントの管理については、 [アプリケーションデータをグループに移動する](%E3%82%B0%E3%83%AB%E3%83%BC%E3%83%97.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqnbnknltima) および [グループを設定するを参照してください](%E3%82%B0%E3%83%AB%E3%83%BC%E3%83%97.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqnbnknltini)。

アチーブメントに関する情報を入力する場合は、 [アチーブメントのプロパティ](Game%20Center%E3%81%AE%E3%83%97%E3%83%AD%E3%83%91%E3%83%86%E3%82%A3.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmrzfvjvona) を参照してください。アチーブメントの状態の意味については、 [アチーブメントの状態](Game%20Center%E3%81%AE%E3%83%97%E3%83%AD%E3%83%91%E3%83%86%E3%82%A3.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmrzfvjvoni) を参照してください。

![bullet](attachments/Resources/1282/Images/task_2x.png)アチーブメントの設定を編集するには

1. アプリケーションの「Game Center」ページを開きます [(アプリケーションの「Game Center」ページを開くを参照)](Game%20Center%E3%81%AE%E6%A9%9F%E8%83%BD%E3%81%AB%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B9%E3%81%97%E3%81%A6%E6%9C%89%E5%8A%B9%E3%81%AB%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmryfvjvonrv)。
2. 「Achievements」セクションで、編集するアチーブメントをダブルクリックします（行内のどこでも可）。
3. 必要に応じてアチーブメントに関するプロパティを編集します。

   プロパティについては、 [アチーブメントのプロパティで説明されています](Game%20Center%E3%81%AE%E3%83%97%E3%83%AD%E3%83%91%E3%83%86%E3%82%A3.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmrzfvjvona)。
4. 「Save」をクリックします。

Game Centerでは、iTunes Connectで表示されている順にアチーブメントがプレーヤーに表示されます。アチーブメントの順序はアプリケーションの「Game Center」ページで変更できます。

![bullet](attachments/Resources/1282/Images/task_2x.png)アチーブメントの順序を変更するには

1. アプリケーションの「Game Center」ページを開きます [(アプリケーションの「Game Center」ページを開くを参照)](Game%20Center%E3%81%AE%E6%A9%9F%E8%83%BD%E3%81%AB%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B9%E3%81%97%E3%81%A6%E6%9C%89%E5%8A%B9%E3%81%AB%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmryfvjvonrv)。
2. 「Achievements」セクションで順序を変更するアチーブメントを選択します。
3. 最初の列のアイコンを使用して、アチーブメントをテーブル内の新しい場所にドラッグします。

   （原归档配图获取待重试：`gc_ach_reorder_2x.png`）

アチーブメントの状態は、表の一番右の列に表示されます。取りうる状態については、 [アチーブメントの状態で説明されています](Game%20Center%E3%81%AE%E3%83%97%E3%83%AD%E3%83%91%E3%83%86%E3%82%A3.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmrzfvjvoni)。この列に「Delete」ボタンが現れていればこれ以外の状態であり、削除しても問題ありません。

![bullet](attachments/Resources/1282/Images/task_2x.png)アチーブメントを削除するには

1. アプリケーションの「Game Center」ページを開きます [(アプリケーションの「Game Center」ページを開くを参照)](Game%20Center%E3%81%AE%E6%A9%9F%E8%83%BD%E3%81%AB%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B9%E3%81%97%E3%81%A6%E6%9C%89%E5%8A%B9%E3%81%AB%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmryfvjvonrv)。
2. 「Achievements」セクションで削除するアチーブメントを選択します。
3. 「Status」列で「Delete」をクリックします。

   このボタンを押せるのは、削除しても問題ない場合に限ります。
4. 表示される確認ダイアログで「削除」をクリックします。

## アチーブメントの表示言語を設定する

アチーブメントの説明と画像をアプリケーションでサポートされている言語ごとに設定できる必要があるため、これらの値は言語構成に組み込まれています。アチーブメントの説明を組み込むには、アチーブメントの作成時に1つ以上の言語を追加する必要があります。アプリケーションを多くの国に配布する場合、各地域に合わせてアチーブメントもローカライズしなければなりません。アチーブメントをローカライズする場合は、 [言語に関係するアチーブメントのプロパティ](Game%20Center%E3%81%AE%E3%83%97%E3%83%AD%E3%83%91%E3%83%86%E3%82%A3.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmrzfvjvony) を参照してください。

![bullet](attachments/Resources/1282/Images/task_2x.png)アチーブメントの表示言語を追加するには

1. アプリケーションの「Game Center」ページを開きます [(アプリケーションの「Game Center」ページを開くを参照)](Game%20Center%E3%81%AE%E6%A9%9F%E8%83%BD%E3%81%AB%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B9%E3%81%97%E3%81%A6%E6%9C%89%E5%8A%B9%E3%81%AB%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmryfvjvonrv)。
2. 「Achievements」セクションで、編集するアチーブメントをダブルクリックします（行内のどこでも可）。
3. 「Achievement Localization」セクションで「Add Language」をクリックします。
4. 「Language」メニューから言語を選択します。
5. 「Title」欄にアチーブメントのローカライズされた名前を入力します。
6. 「Pre-earned Description」欄にアチーブメントのローカライズされた説明を入力します。
7. 「Earned Description」欄にアチーブメントのローカライズされた説明を入力します。
8. 「Choose File」をクリックし、アチーブメントを表すローカライズ済みの画像を選択します。

   （原归档配图获取待重试：`gc_ach_lang_2x.png`）
9. 「Save」をクリックします。
10. 「Add Achievement」(または「Edit Achievement」)ページで「Save」をクリックします。

アプリケーションの状態が「In Review」以外であれば、アチーブメント表示言語のプロパティを編集できます。

![bullet](attachments/Resources/1282/Images/task_2x.png)アチーブメントの表示言語を編集するには

1. アプリケーションの「Game Center」ページを開きます [(アプリケーションの「Game Center」ページを開くを参照)](Game%20Center%E3%81%AE%E6%A9%9F%E8%83%BD%E3%81%AB%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B9%E3%81%97%E3%81%A6%E6%9C%89%E5%8A%B9%E3%81%AB%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmryfvjvonrv)。
2. 「Achievements」セクションで編集するアチーブメントを選択します。
3. 「Achievement Localization」セクションで、編集する言語をダブルクリックします（行内のどこでも可）。
4. 表示されるダイアログでプロパティを変更します。
5. 「Save」をクリックします。
6. 「Edit Achievement」ページで「Save」をクリックします。

言語を削除できるのは、設定済みの言語が2つ以上ある場合に限ります。

![bullet](attachments/Resources/1282/Images/task_2x.png)アチーブメントの表示言語を削除するには

1. アプリケーションの「Game Center」ページを開きます [(アプリケーションの「Game Center」ページを開くを参照)](Game%20Center%E3%81%AE%E6%A9%9F%E8%83%BD%E3%81%AB%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B9%E3%81%97%E3%81%A6%E6%9C%89%E5%8A%B9%E3%81%AB%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmryfvjvonrv)。
2. 「Achievements」セクションで編集するアチーブメントを選択します。
3. 「Edit Achievement」ページの「Achievement Localization」セクションで、削除する言語を見つけます。
4. 削除する言語の最後の行にある「Delete」をクリックします。
5. 表示される確認ダイアログで「削除」をクリックします。
6. 「Edit Achievement」ページで「Save」をクリックします。

## iTunes Connectにアチーブメントのメタデータを一括アップロードする

iTunes Connectで多数のアチーブメントを設定する場合、Transporterを使用して、アチーブメントおよびその他のiTunes Connect構成メタデータをApp Storeパッケージとして配信できます。詳しくは、 _『App Metadata Specification(アプリケーションメタデータ規格)』_ および _『Transporter Quick Start Guide(Transporterクイックスタートガイド)』を参照してください_。iTunes Connectユーザは、「Manage Your Apps」ページ下部の「Deliver Your Apps」でこれらのドキュメントを参照できます。
