# アプリケーションをテストする

Appleでは、Game Centerのテスト用の開発環境を用意しています。ここで、アプリケーションとGame Centerの連携をテストできます。この環境を使用するには、iTunes Connectでテスト用ユーザアカウントを作成し、そのテスト用アカウントを使用して開発環境のゲームにログインします。アプリケーションがグループに属していても、最初はそのためのセットアップをしない状態で、Leaderboardやアチーブメントをテストしてください。ただし、マルチプレーヤー互換性をテストする際には、iTunes Connectで若干の設定が必要です。

Game Centerの機能のテストに関する具体的な情報については、 『Game Centerプログラミングガイド』 の _“Game Centerに対応したゲームのテスト”を参照してください_。

__重要：__ iOSやOS Xの未公開ソフトウェアリリース上で動作するアプリケーションを開発している場合、開発環境でテストは可能ですが、当該OSが出荷されるまで、App Storeに登録することはできません。

## アプリケーションでGame Centerの機能をテストする

Game Center対応アプリケーションをテストするには、次の手順に従います。

1. このドキュメントの説明に従って、アプリケーションに対してGame Centerコンポーネントを設定します。
2. 登録する準備ができたアプリケーションのバージョンに対して、特定のLeaderboardやアチーブメントを有効にします [(アプリケーションのある版をGame Center対応として有効化するにはを参照)](Game%20Center%E3%82%A2%E3%83%97%E3%83%AA%E3%82%B1%E3%83%BC%E3%82%B7%E3%83%A7%E3%83%B3%E3%82%92%E9%85%8D%E5%B8%83%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmrwfvjvomrz)。
3. テストしているアプリケーションとともに実行できるようにする追加のアプリケーションを指定します [(マルチプレーヤー互換性のテストを設定するを参照)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmrvfvjvoni)。
4. iTunes Connectのテスト用ユーザを設定します (テスト用ユーザアカウントの生成を参照)。
5. 『Game Centerプログラミングガイド』の Game Centerに対応したゲームのテスト で説明されているガイドラインに従って、 _アプリケーションをテストします_。
6. Leaderboardのテストデータを消去します [(テスト後にクリーンアップするを参照)](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmrvfvjvomq)。

## マルチプレーヤー互換性のテストを設定する

マルチプレーヤー互換性の設定は、アプリケーションの異なる版を実行しているどのユーザがGame Center上でお互いの結果を表示できるかを指定するものです。マルチプレーヤー互換性の設定は、アプリケーションの「Version Details」ページで行います。

異なる複数のアプリケーションを起動して対戦のテストをする場合、「Version Details」ページで、該当するアプリケーションをマルチプレーヤー互換性リストに追加してください。同じアプリケーションの複数の版をテストする場合、追加の設定は不要です。

![bullet](attachments/Resources/1282/Images/task_2x.png)テストのためにアプリケーション間の互換性を設定するには

1. アプリケーションの「Game Center」ページを開きます [(アプリケーションの「Game Center」ページを開くを参照)](Game%20Center%E3%81%AE%E6%A9%9F%E8%83%BD%E3%81%AB%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B9%E3%81%97%E3%81%A6%E6%9C%89%E5%8A%B9%E3%81%AB%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmryfvjvonrv)。
2. テストするアプリケーションの版に対応する「View Details」をクリックします。
3. 「Game Center」セクションでGame Centerを有効にします(まだ有効になっていない場合)。

   「Version Details」に「Game Center」セクションが表示されない場合、このアプリケーションはGame Centerに対して有効になっていませえん。詳しくは、 [Game Centerの機能にアクセスして有効にするを参照してください](Game%20Center%E3%81%AE%E6%A9%9F%E8%83%BD%E3%81%AB%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B9%E3%81%97%E3%81%A6%E6%9C%89%E5%8A%B9%E3%81%AB%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmryfvjvomi)。
4. 「Multiplayer Compatibility」セクションで「Edit」をクリックします。
5. (アプリケーションリストの下にある)「Add」ポップアップメニュー(+)から、このアプリケーションと互換性を持たせるアプリケーションを選択します。

   （原归档配图获取待重试：`gc_mc_add_app_2x.png`）

   「Add」ポップアップメニュー(+)には、追加可能な各アプリケーションの名前とプラットフォームが表示されます(Game Center対応アプリケーションのみ)。
6. 「Save」をクリックします。

## テスト後にクリーンアップする

Leaderboardのテストが終了したら、アプリケーションを登録する前に、Leaderboardのテスト用データを削除してください。

![bullet](attachments/Resources/1282/Images/task_2x.png)Leaderboardのテストデータを削除するには

1. アプリケーションの「Game Center」ページを開きます [(アプリケーションの「Game Center」ページを開くを参照)](Game%20Center%E3%81%AE%E6%A9%9F%E8%83%BD%E3%81%AB%E3%82%A2%E3%82%AF%E3%82%BB%E3%82%B9%E3%81%97%E3%81%A6%E6%9C%89%E5%8A%B9%E3%81%AB%E3%81%99%E3%82%8B.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2diobzfvbuqmryfvjvonrv)。
2. 「Leaderboards」セクションの「Delete Test Data」をクリックします。

   テスト用データの削除要求がAppleに送信されます。通常は1日以内に処理され、復元はできません。

   （原归档配图获取待重试：`gc_lb_delete_data_2x.png`）
