# 1.0 Introduction

HTTP Live Streaming supports inclusion of timed metadata in ID3 format, carried in the MPEG-2 transport stream.

This document describes how ID3 (reference [[3]](../3/3.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgeydimzvfvbuqmznknltg)) metadata is carried as timed metadata in MPEG-2 Transport Streams (reference [[1]](../3/3.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgeydimzvfvbuqmznknltc)) as used by the HTTP Live Streaming protocol (reference [[2]](../3/3.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgeydimzvfvbuqmznknlte)). See section 3.0, References, for the relevant specifications.
