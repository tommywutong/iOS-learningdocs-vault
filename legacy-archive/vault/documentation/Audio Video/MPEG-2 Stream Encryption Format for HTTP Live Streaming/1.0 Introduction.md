# 1.0 Introduction

This document describes a sample-level encryption format for several types of elementary streams that can be carried in MPEG-2 transport streams [ISO/IEC 13818-1](4.0%20References.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgezdqnrsfvbuqnbnknltc) and MPEG elementary audio streams. This format is used by the [HTTP Live Streaming](4.0%20References.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgezdqnrsfvbuqnbnknlte) protocol.

This document specifies:

- How the media data of audio and video streams are encrypted.
- How encrypted streams are identified in the transport stream.
- How audio setup information is carried.
