# Xcode Help Topics

Xcode is Apple’s integrated development environment (IDE). You use Xcode to build apps for Apple products, including iPad, iPhone, Apple Watch, Apple TV, and Mac.

[Welcome to Xcode](https://help.apple.com/xcode/mac/current/#/devc8c2a6be1): You use Xcode to create your app: lay out the app’s user interface, write code, run your app, and debug it.

[Create your Xcode project](https://help.apple.com/xcode/mac/current/#/dev07db0e578): You can create an Xcode project from a template.

[Run your app on a simulated or real device](https://help.apple.com/xcode/mac/current/#/dev2809b6cff): You can build and run your app on a simulated or real device.

[Create the user interface](https://help.apple.com/xcode/mac/current/#/dev1a26b4fb4): You layout the user interface of your app directly in Xcode using Interface Builder.

[Debug your app](https://help.apple.com/xcode/mac/current/#/dev17c8b1d50): You use the debugger to control the execution of your code, inspect variables, and view output of a running app.

[Use source control](https://help.apple.com/xcode/mac/current/#/dev6188033ec): You can use source control directly in the Project navigator and editor area.

[Test your app](https://help.apple.com/xcode/mac/current/#/dev5c935e39c): You should thoroughly test your app in Xcode before submitting it to App Review or distributing it outside of the App Store.

[Distribute your app](https://help.apple.com/xcode/mac/current/#/dev8b4250b57): After you test your app in Xcode, you can distribute it to internal and external testers, then release it on the App Store.
