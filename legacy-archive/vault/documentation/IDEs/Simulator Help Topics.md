# Simulator Help Topics

[Simulator overview](https://help.apple.com/simulator/mac/current/#/deve44b57b2a): Use Simulator to rapidly prototype and test builds of your app on iOS, watchOS, and tvOS.

[Open and close a simulator](https://help.apple.com/simulator/mac/current/#/devd856f9e4c): Choose a device from the Hardware > Devices submenu to start a simulator. Close a simulator by selecting the window and choosing File > Close Window.

[Resize a simulator window](https://help.apple.com/simulator/mac/current/#/deva81507b64): Resize a simulator by dragging the window frame or bezel, or by choosing an item from the Window menu.

[Install your app on a simulated device](https://help.apple.com/simulator/mac/current/#/deve2c6f33cc): Install your app on a simulated device by building and running from Xcode or dragging the app built by Xcode into the simulator.

[Synchronize the clipboard contents](https://help.apple.com/simulator/mac/current/#/dev499ee7542): Choose Edit > Automatically Sync Pasteboard to turn on and turn off automatic synchronization of the clipboard contents between the simulated device and the Mac. A checkmark indicates the clipboard content is being synchronized.

[Capture the screen of the simulated device](https://help.apple.com/simulator/mac/current/#/devdefc2debe): Save an image of the current screen by choosing File > New Screen Shot, or copy the screen by choosing Edit > Copy Screen.

[Removing simulator runtimes](https://help.apple.com/simulator/mac/current/#/dev8cb1bffbd): Remove simulator runtimes by deleting the file in /Library/Developer/CoreSimulator/Profiles/Runtimes.

[Add a complication to the gallery of the Watch App](https://help.apple.com/simulator/mac/current/#/dev598d32a7d): Add a complication to the gallery in the Watch App by implementing getLocalizableSampleTemplateForComplication:withHandler:, launching your app in Simulator, choosing File > Save Complication Bundle, and adding the resulting bundle to the resources of your iOS app.

[Interact with iOS](https://help.apple.com/simulator/mac/current/#/deva6cdf367f): Use the pointer, keyboard, menu items, and buttons on the bezel to interact with simulated iOS devices.

[Interact with watchOS](https://help.apple.com/simulator/mac/current/#/dev275c411a7): Use the pointer, keyboard, menu items, and buttons on the bezel to interact with simulated watchOS devices.

[Interact with tvOS](https://help.apple.com/simulator/mac/current/#/dev226af0143): Control the focus on a simulated tvOS device with a keyboard, a simulated Apple TV Remote, or a physical remote.

[Toggle light and dark appearance on tvOS](https://help.apple.com/simulator/mac/current/#/dev18359ad41): Press Command-Shift-D to toggle between the light and dark appearances for tvOS.

[Show and hide the bezel for a simulator](https://help.apple.com/simulator/mac/current/#/dev211ab872e): Chose Window > Show Device Bezels to show and hide he bezel.

[Restart or reset a simulated device](https://help.apple.com/simulator/mac/current/#/devb4e6888f0): Restart the simulated device by choosing Hardware > Restart. Reset the device by choosing Hardware > Reset Content and Settings.

[Simulate drag and drop on iOS](https://help.apple.com/simulator/mac/current/#/devef03b3518): Simulate drag and drop by using the Control key to hold the first finger over the drag item, navigating to the drag location, then moving the drag item to the location.

[Set the source for audio input and the device for audio output](https://help.apple.com/simulator/mac/current/#/deve63797392): Select the audio input or audio output of simulated devices by choosing an item form the Hardware > Audio Input or the Hardware > Audio Output menus .

[Redirect keyboard shortcuts to a simulated device](https://help.apple.com/simulator/mac/current/#/devf05889b4e): Choose Hardware > Keyboard > Send Menu Keyboard Keyboard Shortcuts to Device to toggle sending keyboard shortcuts to a device.

[Enter text using the Mac Keyboard](https://help.apple.com/simulator/mac/current/#/devb7894260a): Use the keyboard on your Mac as input to the simulated device by choosing Hardware > Keyboard > Connect Hardware Keyboard.

[Debug and optimize graphics using color overlays](https://help.apple.com/simulator/mac/current/#/dev20f446337): Use Debug menu items to color on-screen elements that can impact performance and memory by choosing Debug > Color Blended Layers, Copied Images, Misaligned Images, or Offscreen-Rendered Images.

[Examine animations](https://help.apple.com/simulator/mac/current/#/devdc48bfa22): Choose Debug > Slow Animations and examine the animations for skipped frames, rendering problems, and other issues. Choose the menu item again to clear the checkmark and return the animation speed to normal.

[Examine the system log](https://help.apple.com/simulator/mac/current/#/dev431a02c91): Choose Debug > Open System Log to open the system log for the simulated device in the Console app.

[Differences between simulated and physical devices](https://help.apple.com/simulator/mac/current/#/devb0244142d): There are differences between simulated and physical devices including performance, and supported hardware and APIs.

[Send data to a simulator from your Mac](https://help.apple.com/simulator/mac/current/#/dev93735e156): Share images, website URLs, locations, and routes with a simulator using the Share menu on your Mac or by dragging in the data.

[Set a location or route](https://help.apple.com/simulator/mac/current/#/devc6eac95d6): Test your layout when the in-call status bar is showing by choosing Hardware > Toggle In-Call Status Bar.

[Test your app receiving a memory warning](https://help.apple.com/simulator/mac/current/#/dev92c65e64e): Choose Debug > Simulate Memory Warning to send a memory warning to your app delegate and view controllers, and to send the system notification.

[Test iCloud](https://help.apple.com/simulator/mac/current/#/devaf32545b3): Choose Debug > Trigger iCloud Sync to trigger the system to download updates from the server.

[Test authentication](https://help.apple.com/simulator/mac/current/#/dev33a86a4a3): Use the items in Hardware > Touch ID or Hardware > Face ID to test if your code checks for enrolled fingers, and if it responds correctly to matching and non-matching touches.

[Test Apple Pay](https://help.apple.com/simulator/mac/current/#/devd5367d9a3): Choose Hardware > Authorize Apple Pay to complete an Apple Pay transaction on iOS and watchOS.

[Test your layout with the in-call status bar](https://help.apple.com/simulator/mac/current/#/dev1e0c93ec3): Test your layout when the in-call status bar is showing by choosing Hardware > Toggle In-Call Status Bar.

[Simulate an external display](https://help.apple.com/simulator/mac/current/#/dev40a1b22bf): Simulate a connected external display by choosing a size from Hardware > External Display. Choose Disabled to disconnect the simulated display.

[Insufficient resources error when trying to launch a simulator](https://help.apple.com/simulator/mac/current/#/dev8a5f2aa4e): To fix the insufficient resources error, close simulators and Mac apps that are not required to free up resources.

[Scrolling or animation are slow](https://help.apple.com/simulator/mac/current/#/dev328c18a3c): Choose Debug > Graphics Quality Override > Low Quality to force Simulator to use lower quality.

[The simulated screen renders slowly](https://help.apple.com/simulator/mac/current/#/dev55263e447): Choose Debug > Optimize Rendering for Window Scale until a checkmark appears. If that does not work, try setting the sale to 100% or full size.

[Reporting bugs](https://help.apple.com/simulator/mac/current/#/dev6e3b8f087): File bugs through the Apple Developer website and list the version number of Xcode.
