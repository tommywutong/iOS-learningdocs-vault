# Introduction to PowerMac G4

This developer note describes the PowerMac G4 computer. The note provides information about the internal design of the computer, its input-output and expansion capabilities, and issues affecting compatibility.

This developer note is intended to help hardware and software developers design products that are compatible with the Macintosh products described here. If you are not already familiar with Macintosh computers or if you would simply like additional technical information, refer to [Supplemental Reference Documents](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/PowerMacG4/aReferences/jos_refs.html#//apple_ref/doc/uid/TP30000307-TPXREF101) for additional information.

The information is arranged in four chapters and two appendixes:

- [Overview of PowerMac G4](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/PowerMacG4/1Introduction/jos_intro.html#//apple_ref/doc/uid/TP30000303-TPXREF101) gives a summary of the features of the PowerMac G4 computer, describes the physical appearance of the enclosure, and lists compatibility issues of interest to developers.
- [Architecture](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/PowerMacG4/2Architecture/jos_archi.html#//apple_ref/doc/uid/TP30000304-TPXREF101) describes the internal organization of the computer. It includes a functional block diagram and descriptions of the main components on the logic board.
- [Input and Output Devices](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/PowerMacG4/3Input-Output/jos_innout.html#//apple_ref/doc/uid/TP30000305-TPXREF101) describes the built-in I/O devices and the external I/O ports.
- [Expansion](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/PowerMacG4/4Expansion/jos_expan.html#//apple_ref/doc/uid/TP30000306-TPXREF101) describes the expansion slots on the logic board and provides specifications for the expansion modules.
- [Supplemental Reference Documents](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/PowerMacG4/aReferences/jos_refs.html#//apple_ref/doc/uid/TP30000307-TPXREF101) provides sources of additional information about the technologies used in the PowerMac G4 computer.
- [Conventions and Abbreviations](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/PowerMacG4/bAbbreviations/jos_abbrev.html#//apple_ref/doc/uid/TP30000308-TPXREF101) lists standard units of measure and other abbreviations used in this developer note.
