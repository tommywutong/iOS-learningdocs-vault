# Introduction to 17-inch PowerBook G4 Developer Note

This developer note is a technical description of the 17-inch PowerBook G4. The note provides information about the computer’s internal design, input-output features, and expansion capabilities.

This developer note is intended to help hardware and software developers design products that are compatible with the Macintosh products described here. If you are not already familiar with Macintosh computers or if you would like additional technical information, you may wish to read the supplementary reference documents described in [Supplemental Reference Documents](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/17inchPowerBookG4/aReferences/Q41c_ref.html#//apple_ref/doc/uid/TP40003166-CH209-TPXREF101).

The information in this note is arranged in four chapters and two appendixes.

- [Overview of 17-inch PowerBook G4](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/17inchPowerBookG4/1Overview/Q41c_overview.html#//apple_ref/doc/uid/TP40003166-CH205-TPXREF101) introduces the 17-inch PowerBook G4 and describes its features.
- [Architecture](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/17inchPowerBookG4/2Architecture/Q41c_arch.html#//apple_ref/doc/uid/TP40003166-CH206-TPXREF101) describes the internal logic of the computer, including the main ICs that appear in the block diagram.
- [Devices and Ports](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/17inchPowerBookG4/3Input-Output/Q41c_inout.html#//apple_ref/doc/uid/TP40003166-CH207-TPXREF101) describes the standard I/O ports and the built-in I/O devices.
- [Expansion Features](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/17inchPowerBookG4/4Expansion/Q41c_expan.html#//apple_ref/doc/uid/TP40003166-CH208-TPXREF101) describes the expansion features of interest to developers. It includes development guides for expansion-bay devices, the RAM expansion modules, and the PC Card slot.
- [Supplemental Reference Documents](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/17inchPowerBookG4/aReferences/Q41c_ref.html#//apple_ref/doc/uid/TP40003166-CH209-TPXREF101) contains links to supplemental reference documents.
- [Abbreviations](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/17inchPowerBookG4/bAbbreviations/Q41c_abbrev.html#//apple_ref/doc/uid/TP40003166-CH210-TPXREF101) is a list of the abbreviations used in this developer note.
