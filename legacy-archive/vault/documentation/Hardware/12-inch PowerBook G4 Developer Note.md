# Introduction to 12-inch PowerBook G4 Developer Note

This developer note gives a technical description of the new 12-inch PowerBook G4. The note provides information about the computer’s internal design, input-output features, and expansion capabilities.

This developer note is intended to help hardware and software developers design products that are compatible with the Macintosh products described here. For additional technical information on Macintosh computers, refer to [Supplemental Reference Documents](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/12inchPowerBookG4/A_References/q54B_references.html#//apple_ref/doc/uid/TP40001763-CH209-BAJHAEAH).

The information in this note is arranged in four chapters and two appendixes.

- [Chapter 1, Overview of the 12-inch PowerBook G4,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/12inchPowerBookG4/1_Overview/q54B_overview.html#//apple_ref/doc/uid/TP40001763-CH205-BCIEGBID) introduces the 12-inch PowerBook G4 and describes its features.
- [Chapter 2, Architecture,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/12inchPowerBookG4/2_Architecture/q54B_archi.html#//apple_ref/doc/uid/TP40001763-CH206-BCICBHBA) describes the internal logic of the 12-inch PowerBook G4, including the main ICs that appear in the block diagram.
- [Chapter 3, Devices and Ports,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/12inchPowerBookG4/3_Input-Output/q54B_inout.html#//apple_ref/doc/uid/TP40001763-CH207-BCIIEDDG) describes the standard I/O ports and the built-in I/O devices.
- [Chapter 4, RAM Expansion,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/12inchPowerBookG4/4_Expansion/q54B_expansion.html#//apple_ref/doc/uid/TP40001763-CH208-BBCJCAHJ) describes the RAM expansion module.
- [Appendix A, Supplemental Reference Documents,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/12inchPowerBookG4/A_References/q54B_references.html#//apple_ref/doc/uid/TP40001763-CH209-BAJHAEAH) tells where to find more information about specific technologies used in the new 12-inch PowerBook G4.
- [Appendix B, Conventions and Abbreviations,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/12inchPowerBookG4/B_Abbreviations/q54B_abbrev.html#//apple_ref/doc/uid/TP40001763-CH210-TPXREF101) lists the standard units and abbreviations used in this developer note.
