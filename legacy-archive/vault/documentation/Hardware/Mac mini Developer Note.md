# Introduction to Mac mini Developer Note

This developer note gives a technical description of the Mac mini. The note provides information about the computer’s internal design, input-output features, and expansion capabilities.

This developer note is intended to help hardware and software developers design products that are compatible with the products described here. If you are not already familiar with Macintosh computers or if you would simply like additional technical information, refer to [Appendix A, Supplemental Reference Documents,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/MacMiniG4/aReferences/q88_refs.html#//apple_ref/doc/uid/TP40001865-CH209-BAJIJAEJ) for details

The information in this note is arranged in four chapters and two appendixes.

- [Chapter 1, Overview to the Mac mini,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/MacMiniG4/1overview/q88_overview.html#//apple_ref/doc/uid/TP40001865-CH205-BBCDEFFJ) introduces the Mac mini, describes its features, and mentions a few software issues of interest to developers.
- [Chapter 2, Architecture,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/MacMiniG4/2Architecture/q88_archi.html#//apple_ref/doc/uid/TP40001865-CH206-BBCHABCC) describes the internal organization of the computer. It includes a functional block diagram and descriptions of the main components on the logic board.
- [Chapter 3, Devices and Ports,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/MacMiniG4/3Input-Output/q88_inout.html#//apple_ref/doc/uid/TP40001865-CH207-BBCCBCGD) describes the I/O ports and the built-in I/O devices.
- [Chapter 4, RAM Expansion,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/MacMiniG4/4Expansion/q88_expan.html#//apple_ref/doc/uid/TP40001865-CH208-BBCJJHCG) includes development guidelines for the RAM expansion modules.
- [Appendix A, Supplemental Reference Documents,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/MacMiniG4/aReferences/q88_refs.html#//apple_ref/doc/uid/TP40001865-CH209-BAJIJAEJ) provides sources of additional information about the technologies used in the Mac mini.
- [Appendix B, Abbreviations,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/MacMiniG4/bAbbreviations/q88_abbr.html#//apple_ref/doc/uid/TP40001865-CH210-TPXREF101) lists standard units of measure and other abbreviations used in this developer note.
