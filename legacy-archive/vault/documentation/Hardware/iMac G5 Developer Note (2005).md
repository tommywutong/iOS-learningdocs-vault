# Introduction to iMac G5 Developer Note

This developer note gives a technical description of the 17” and 20” iMac G5. The note provides information about the computer’s internal design, input-output features, and expansion capabilities.

This developer note is intended to help hardware and software developers design products that are compatible with the products described here. If you are not already familiar with Macintosh computers or if you would simply like additional technical information, you should refer to [Supplemental Reference Documents](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/iMacG5_May05/A_References/q45CD_refs.html#//apple_ref/doc/uid/TP40002046-CH209-BAJIIIGI)“.

The information in this note is arranged in the following chapters.

- [Chapter 1, Overview of the iMac G5,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/iMacG5_May05/01_Overview/q45CD_overview.html#//apple_ref/doc/uid/TP40002046-CH205-BBCJCHCH) introduces the configurations, describes the features, and mentions a few software issues of interest to developers.
- [Chapter 2, Architecture,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/iMacG5_May05/02_Architecture/q45CD_archi.html#//apple_ref/doc/uid/TP40002046-CH206-BBCGCJCF) describes the internal organization of the computer. It includes a functional block diagram and descriptions of the main components on the logic board.
- [Chapter 3, Devices and Ports,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/iMacG5_May05/03_Input-Output/q45CD_inout.html#//apple_ref/doc/uid/TP40002046-CH207-BBCDBHAG) describes the I/O ports and the built-in I/O devices for the computer.
- [Chapter 4, RAM Expansion,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/iMacG5_May05/04_Expansion/q45CD_expan.html#//apple_ref/doc/uid/TP40002046-CH208-BBCJADAF) includes development guidelines for the RAM expansion modules for the computer.
- [Appendix A, Supplemental Reference Documents,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/iMacG5_May05/A_References/q45CD_refs.html#//apple_ref/doc/uid/TP40002046-CH209-BAJIIIGI) tells where to find more information about specific technologies used in the iMac G5.
- [Appendix B, Abbreviations,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/iMacG5_May05/B-Abbreviations/q45CD_abbr.html#//apple_ref/doc/uid/TP40002046-CH210-TPXREF101) lists the standard units and abbreviations used in this developer note.
