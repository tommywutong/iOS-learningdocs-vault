# Introduction to Power Mac G5 Developer Note

This developer note describes the 64-bit Power Mac G5. The note provides information about the internal design of the computer, its input-output and expansion capabilities, and issues affecting compatibility.

This developer note is intended to help hardware and software developers design products that are compatible with the Macintosh products described here. If you are not already familiar with Macintosh computers or if you would simply like additional technical information, refer to [Appendix A, Supplemental Reference Documents,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/PowerMacG5/aReferences/Q87_refs.html#//apple_ref/doc/uid/TP40002012-CH209-TPXREF101) for additional information.

The information is arranged in four chapters and two appendixes:

- [Chapter 1, Overview to the Power Mac G5,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/PowerMacG5/1Overview/Q87_overview.html#//apple_ref/doc/uid/TP40002012-CH205-TPXREF101) gives a summary of the features of the Power Mac G5 computer, describes the physical appearance of the enclosure, and lists compatibility issues of interest to developers.
- [Chapter 2, Architecture,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/PowerMacG5/2Architecture/Q87_archi.html#//apple_ref/doc/uid/TP40002012-CH206-TPXREF101) describes the internal organization of the computer. It includes a functional block diagram and descriptions of the main components on the logic board.
- [Chapter 3, Input and Output Devices,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/PowerMacG5/3Input-Output/Q87_innout.html#//apple_ref/doc/uid/TP40002012-CH207-TPXREF101) describes the built-in I/O devices and the external I/O ports.
- [Chapter 4, Expansion,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/PowerMacG5/4Expansion/Q87_expan.html#//apple_ref/doc/uid/TP40002012-CH208-TPXREF101) describes the expansion slots on the logic board and provides specifications for the expansion modules.
- [Appendix A, Supplemental Reference Documents,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/PowerMacG5/aReferences/Q87_refs.html#//apple_ref/doc/uid/TP40002012-CH209-TPXREF101) provides sources of additional information about the technologies used in the Power Mac G5 computer.
- [Appendix B, Conventions and Abbreviations,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G5/PowerMacG5/bAbbreviations/Q87_abbrev.html#//apple_ref/doc/uid/TP40002012-CH210-TPXREF101) lists standard units of measure and other abbreviations used in this developer note.
