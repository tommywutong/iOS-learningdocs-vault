# Introduction to Audio Developer Note

Developers who are designing peripheral audio devices that connect to a Macintosh computer will find this document useful.

This document is organized into the following articles:

- [Audio Concepts](Audio%20Concepts.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaztsnzzfvjvomk7gezdambtgmytcnrx) describes Apple's implementation of audio input and output and defines the key concepts you need to ensure that your audio device is compatible with Macintosh computers.
- [Audio Product-Specific Details](Audio%20Product-Specific%20Details.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaztsnzyfvjvomk7gezdambtgmytcnrx) provides details specific to particular Macintosh computers.

For specific information about a particular Macintosh computer, see the product Developer Note for that computer in [Guides > Hardware & Drivers > Apple Hardware](https://developer.apple.com/library/archive/navigation/redirect.html#//apple_ref/doc/uid/TP30000440-TP40003576-TP30000519).

For a list of the standard units of measure and abbreviations used in this developer note, refer to _[Hardware Developer Note Terms and Abbreviations](../../Hardware%20Drivers/Hardware%20Developer%20Note%20Terms%20and%20Abbreviations/Introduction%20to%20Hardware%20Developer%20Note%20Terms%20and%20Abbreviations.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaztkmbt)_.

Apple offers the following additional resources for audio:

- _[Getting Started with Audio & Video](https://developer.apple.com/library/archive/referencelibrary/GettingStarted/GS_MusicAudio/_index.html#//apple_ref/doc/uid/TP30001095)_ introduces audio-related resources for Macintosh developers.
- _[Audio Device Driver Programming Guide](../../Device%20Drivers/Audio%20Device%20Driver%20Programming%20Guide/Introduction%20to%20Audio%20Device%20Driver%20Programming%20Guide.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridgmbqgaydomrz)_ describes the requirements for Mac OS X audio device drivers.
- _[Apple Core Audio Format Specification 1.0](../../Music%20Audio/Apple%20Core%20Audio%20Format%20Specification%201.0.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaytqnrs)_ provides a detailed description of the format for Core Audio, Apple's audio architecture.
- The [Core Audio developer mail list](http://lists.apple.com/mailman/listinfo/) provides a forum for those developing audio products compatible with Macintosh computers and Mac OS X.
