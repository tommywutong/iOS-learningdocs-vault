# Introduction to Video Developer Note

This technology developer note describes details of Apple’s support for video output from Mac computers.

Developers who are designing video cards, external display devices, or display processing software will find this note helpful.

This document is contains the following articles:

- [Video Concepts](Video%20Concepts.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaztsojvfvjvomk7gezdambtgmytcobr) describes Apple's implementation of video technology on Mac computers.
- [Video Product-Specific Details](Video%20Product-Specific%20Details.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaztsojufvjvomk7gezdambtgmytcobr) provides details specific to particular Mac computers.

For specific information about a particular Mac computer, see the product Developer Note for that computer in the [Guides > Hardware & Drivers > Apple Hardware](https://developer.apple.com/library/archive/navigation/redirect.html#//apple_ref/doc/uid/TP30000440-TP40003576-TP30000519).

For a list of the standard units of measure and abbreviations used in this developer note, refer to the _[Hardware Developer Note Terms and Abbreviations](../../Hardware%20Drivers/Hardware%20Developer%20Note%20Terms%20and%20Abbreviations/Introduction%20to%20Hardware%20Developer%20Note%20Terms%20and%20Abbreviations.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaztkmbt)_.

Apple offers the following additional resources for video development:

- _[Core Video Programming Guide](../../Graphics%20Imaging/Core%20Video%20Programming%20Guide/Introduction%20to%20Core%20Video%20Programming%20Guide.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaytkmzw)_ describes the C and Objective-C APIs that support video processing.
- _[Getting Started with Graphics & Animation](https://developer.apple.com/library/archive/referencelibrary/GettingStarted/GS_GraphicsImaging/_index.html#//apple_ref/doc/uid/TP30001000)_ introduces technologies and tools available to developers of applications that process video.
