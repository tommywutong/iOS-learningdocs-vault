# Introduction to Xserve G5 Developer Note

This developer note describes Apple Computer’s Xserve G5. The note provides information about the internal design of the computer, its input-output and expansion capabilities, and issues affecting compatibility.

This developer note is intended to help hardware and software developers design products that are compatible with the Macintosh products described here. If you are not already familiar with Macintosh computers or if you would simply like additional technical information, refer to [Supplemental Reference Documents](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Servers/XserveG5/aReferences/Q42B_refs.html#//apple_ref/doc/uid/TP30001164-CH209-TPXREF101)

The information is arranged in four chapters and two appendixes:

- [Overview of the Xserve G5](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Servers/XserveG5/1Overview/Q42B_overview.html#//apple_ref/doc/uid/TP30001164-CH205-TPXREF101) gives a summary of the features of the Xserve G5, describes the physical appearance of the enclosure, and lists compatibility issues of interest to developers.
- [Architecture](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Servers/XserveG5/2Architecture/Q42B_archi.html#//apple_ref/doc/uid/TP30001164-CH206-TPXREF101) describes the internal organization of the computer. It includes a functional block diagram and descriptions of the main components on the logic board.
- [Input and Output Devices](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Servers/XserveG5/3Input-Output/Q42B_innout.html#//apple_ref/doc/uid/TP30001164-CH207-TPXREF101) describes the built-in I/O devices and the external I/O ports.
- [Expansion](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Servers/XserveG5/4Expansion/Q42B_expan.html#//apple_ref/doc/uid/TP30001164-CH208-TPXREF101) describes the expansion slots on the logic board and provides specifications for the expansion modules.
- [Supplemental Reference Documents](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Servers/XserveG5/aReferences/Q42B_refs.html#//apple_ref/doc/uid/TP30001164-CH209-TPXREF101) provides sources of additional information about the technologies used in the Xserve G5 computer.
- [Conventions and Abbreviations](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Servers/XserveG5/bAbbreviations/Q42B_abbrev.html#//apple_ref/doc/uid/TP30001164-CH210-TPXREF101) lists standard units of measure and other abbreviations used in this developer note.
