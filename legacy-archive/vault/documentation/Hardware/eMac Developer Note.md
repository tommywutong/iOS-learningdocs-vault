# Introduction to eMac Developer Note

This developer note gives a technical description of the eMac. The note provides information about the computer’s internal design, input-output features, and expansion capabilities.

This developer note is intended to help hardware and software developers design products that are compatible with the products described here. If you are not already familiar with Macintosh computers or if you would simply like additional technical information, refer to [Appendix A, Supplemental Reference Documents,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/eMac/aReferences/q86j_refs.html#//apple_ref/doc/uid/TP40002047-CH209-BAJIJAEJ) for details.

The information in this note is arranged in four chapters and two appendixes.

- [Chapter 1, Overview to the eMac,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/eMac/1overview/q86j_overview.html#//apple_ref/doc/uid/TP40002047-CH205-BBCDEFFJ) introduces the eMac, describes its features, and mentions a few software issues of interest to developers.
- [Chapter 2, Architecture,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/eMac/2Architecture/q86j_archi.html#//apple_ref/doc/uid/TP40002047-CH206-BBCHABCC) describes the internal organization of the computer. It includes a functional block diagram and descriptions of the main components on the logic board.
- [Chapter 3, Devices and Ports,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/eMac/3Input-Output/q86j_inout.html#//apple_ref/doc/uid/TP40002047-CH207-BBCCBCGD) describes the I/O ports and the built-in I/O devices.
- [Chapter 4, RAM Expansion,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/eMac/4Expansion/q86j_expan.html#//apple_ref/doc/uid/TP40002047-CH208-BBCJJHCG) includes development guidelines for the RAM expansion modules.
- [Appendix A, Supplemental Reference Documents,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/eMac/aReferences/q86j_refs.html#//apple_ref/doc/uid/TP40002047-CH209-BAJIJAEJ) provides sources of additional information about the technologies used in the eMac.
- [Appendix B, Abbreviations,](https://developer.apple.com/library/archive/documentation/Hardware/Developer_Notes/Macintosh_CPUs-G4/eMac/bAbbreviations/q86j_abbr.html#//apple_ref/doc/uid/TP40002047-CH210-TPXREF101) lists standard units of measure and other abbreviations used in this developer note.
