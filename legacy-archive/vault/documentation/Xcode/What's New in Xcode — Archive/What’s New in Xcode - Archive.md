# What’s New in Xcode - Archive

Xcode is the complete developer toolset used to create apps for Apple Watch, iPad, iPhone, and Mac. The Xcode development environment bundles the Instruments analysis tool, Simulator, and frameworks in the form of tvOS SDKs, watchOS SDKs, iOS SDKs, and OS X SDKs.

_What’s New in Xcode_ documents the highlighted features of each Xcode release. This document archives _What’s New in Xcode_ for releases prior to the current release. To access the latest revision for the current release, see _[What’s New in Xcode](../../Developer%20Tools/What%E2%80%99s%20New%20in%20Xcode/What%27s%20New%20in%20Xcode%209.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga2dmmrw)_.

The chapters in this archive are organized by major Xcode release. Each chapter includes new feature information for all versions, ordered from first to last, for each major release.

- __Xcode 7__ includes revisions 7.0 to 7.3.1: [New Features in Xcode 7](New%20Features%20in%20Xcode%207.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2tenbsfvjvomi).
- __Xcode 6__ includes revisions 6.0 to 6.3.2: [New Features in Xcode 6](New%20Features%20in%20Xcode%206.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2dkmbzfvjvomi).
- __Xcode 5__ includes revisions 5.0 to 5.1.1: [New Features in Xcode 5](New%20Features%20in%20Xcode%205.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgezdsnjtfvjvomi).
- __Xcode 4__ includes revisions 4.1 to 4.6.3: [New Features in Xcode 4](New%20Features%20in%20Xcode%204.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge3dcnbxfvjvomi).

Apple Developer Programs provide additional support, documentation, and signing resources for testing and deployment on all Apple devices. Visit the [Apple Developer website](https://developer.apple.com/programs/) for information about Apple Developer Programs.

The [Xcode homepage](https://developer.apple.com/xcode/) provides high-level information about the latest release of Xcode and quick access to download links for current and beta releases.

The [Apple Developer Forums](http://devforums.apple.com/) hosts discussions about Apple developer software, including prerelease products.

For the latest security information, visit [http://support.apple.com/kb/HT1222](http://support.apple.com/kb/HT1222).
