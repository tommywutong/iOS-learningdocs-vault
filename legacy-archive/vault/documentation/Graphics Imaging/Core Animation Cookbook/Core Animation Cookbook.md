# Core Animation Cookbook

This document provides instructions and code fragments that describe how to perform common Core Animation tasks.

This document has the following chapters:

- [Drawing](Drawing.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga2timjufvjvomi) describes various drawing techniques when working with layers.
- [Timing](Timing.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga3danzxfvjvomi) describes various timing techniques when working with animations.

These programming guides discuss some of the technologies that are used by Core Animation:

- _[Core Animation Programming Guide](../../Cocoa/Core%20Animation%20Programming%20Guide/About%20Core%20Animation.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga2dkmju)_ describes the Core Animation technology and shows how to use the Core Animation API.
- _[Quartz 2D Programming Guide](../Quartz%202D%20Programming%20Guide/Introduction.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridgmbqgaytanrw)_ describes the two-dimensional drawing engine used to draw the content of an `CALayer` instance.
- _[Core Image Programming Guide](../Core%20Image%20Programming%20Guide/About%20Core%20Image.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridgmbqgaytcobv)_ describes the OS X image processing technology and shows how to use the Core Image API.
