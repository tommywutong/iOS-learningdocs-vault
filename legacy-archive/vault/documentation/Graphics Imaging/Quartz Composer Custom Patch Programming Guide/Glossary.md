# Glossary

- __custom patch__

  A subclass of `QCPlugIn` that performs custom processing in the Quartz Composer development environment.

- __plug-in__

  An [NSBundle](https://developer.apple.com/library/archive/documentation/LegacyTechnologies/WebObjects/WebObjects_3.5/Reference/Frameworks/ObjC/Foundation/Classes/NSBundle/Description.html#//apple_ref/occ/cl/NSBundle) used to package one or more custom patches.

- __QCPlugIn__

  A class defined by the Quartz framework that provides the base class to subclass for writing custom patches.
