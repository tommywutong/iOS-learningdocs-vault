# Glossary

- __application music player__

  An object that plays media items without affecting the state of the iPod application. See also [iPod music player](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzt), [music player](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzs).

- __default media library__

  The object that provides library change notifications to your application.

- __filterable__

  Describes a media item property key that can be used to build a valid search [predicate](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzv).

- __filtering__

  Describes obtaining a subset of media items from the [iPod library](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzsgi) by employing a search based on one or more [media property predicate](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzu) objects.

- __Genius Playlist__

  A sequence of music media items that is created algorithmically based on music characteristics. See also [on-the-go playlist](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzrha), [Smart Playlist](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzsga).

- __iPod library__

  The set of media items on a device that a user has synced from iTunes on the desktop.

- __iPod music player__

  An object that plays media items by controlling the built-in iPod application, sharing its state. See also [application music player](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzr), [music player](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzs).

- __media item__

  A single piece of media (such as one song) in the [iPod library](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzsgi). A media item can be of various types including audio, audio book, and podcast.

- __media item artwork__

  An object that represents a graphical image, such as album cover artwork, associated with a [media item](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzrgi).

- __media item collection__

  A set of related media items from the [iPod library](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzsgi).

- __media item picker__

  A specialized view controller that you employ to provide a graphical interface for selecting media items.

- __media property predicate__

  A filter in a [media query](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzrgy) for retrieving a specified subset of media items from the [iPod library](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzsgi).

- __media query__

  An object that contains a description of what to retrieve from the iPod library and how those retrieved items should be arranged.

- __music player__

  An object that plays media items. See also [application music player](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzr), [iPod music player](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzt).

- __on-the-go playlist__

  A sequence of media items created by a user on a device, rather than on a notebook or desktop computer. See also [Genius Playlist](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzrge), [Smart Playlist](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzsga).

- __playback queue__

  A list of media items for playback by a [music player](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzs).

- __playback state__

  For iPod library access, describes the playback state of a music player; one of playing, stopped, paused, fast forward, or rewind.

- __predicate__

  For iPod library access, a specification of a single logical condition to test media items against when searching the [iPod library](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzsgi).

- __repeat mode__

  For iPod library access, indicates whether or not the current playback queue repeats or plays through just once.

- __shuffle mode__

  For iPod library access, indicates whether or not the current playback queue plays in user-specified order or in a shuffled order.

- __Smart Playlist__

  A sequence of media items created automatically according to user-specified criteria. See also [Genius Playlist](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzrge), [on-the-go playlist](#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4donrvfvbuqmjqgiwvgvzrha).
