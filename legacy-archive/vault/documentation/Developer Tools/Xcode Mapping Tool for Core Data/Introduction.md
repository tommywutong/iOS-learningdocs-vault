# Introduction

The purpose of the mapping model tool is to create a mapping model for use with the Core Data framework to support data migration. For a discussion of data migration, see _[Core Data Model Versioning and Data Migration Programming Guide](../../Cocoa/Core%20Data%20Model%20Versioning%20and%20Data%20Migration%20Programming%20Guide/Core%20Data%20Model%20Versioning%20and%20Data%20Migration.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga2dgojz)_; for more about Core Data, see _[Core Data Programming Guide](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/CoreData/index.html#//apple_ref/doc/uid/TP40001075)_.

You should read this document to understand the features of the Xcode mapping model tool, the fundamentals of how to create a mapping model and how to use the tool to edit the model.

The document is organized into the following sections:

- [Creating and Updating a Mapping Model](Creating%20and%20Updating%20a%20Mapping%20Model.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga3dqnrxfvjvomq) describes how to create and update a mapping model.
- [The Mapping Model Pane](The%20Mapping%20Model%20Pane.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga3dqnrvfvjvomi) describes the features of the mapping model tool.
- [Displaying Differences Between Models](Displaying%20Differences%20Between%20Models.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga3dqnrwfvjvomi) describes how you can show the differences between two mapping models.
