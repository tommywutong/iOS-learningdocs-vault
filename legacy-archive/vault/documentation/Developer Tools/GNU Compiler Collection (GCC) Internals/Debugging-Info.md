### 13.20 Controlling Debugging Information Format

This describes how to specify debugging information.

- [All Debuggers](All-Debuggers.md#apple-ifwgylkemvrhkz3hmvzhg): Macros that affect all debugging formats uniformly.
- [DBX Options](DBX-Options.md#apple-irbfqlkpob2gs33oom): Macros enabling specific options in DBX format.
- [DBX Hooks](DBX-Hooks.md#apple-irbfqlkin5xww4y): Hook macros for varying DBX format.
- [File Names and DBX](File-Names-and-DBX.md#apple-izuwyzjnjzqw2zltfvqw4zbnirbfq): Macros controlling output of file names in DBX format.
- [SDB and DWARF](SDB-and-DWARF.md#apple-knceellbnzsc2rcxifjem): Macros for SDB (COFF) and DWARF formats.
- [VMS Debug](VMS-Debug.md#apple-kzgvglkemvrhkzy): Macros for VMS debug format.
