# The WebObjects Builder Toolbar

At the left of the toolbar are three buttons:
The ! pop-up list allows you to switch editing modes. See ["Editing Modes"](Editing4.md#apple-g42dcmy).

The ! button brings up the Inspector window, which allows you to set various attributes of the currently selected element. ["The Inspector"](The%20Inspector.md#apple-geydkmjr) section describes each type of element in more detail.

The ! button brings up the Palette window. See ["Palettes"](Palettes.md#apple-geytcnjv) for more information on creating and using palettes.
