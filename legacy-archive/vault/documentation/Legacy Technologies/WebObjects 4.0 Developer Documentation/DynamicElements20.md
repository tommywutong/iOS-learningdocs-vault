## WOApplets

The WOApplet dynamic element represents a Java applet or client-side component. There are several ways to create a WOApplet. You can:

- Click ! in the toolbar.

This creates a WOApplet, whose bindings you must set.

!

- Drag a file of type __.class__ into your component.

You are asked whether you want to add the __.class__ file to your project. If you reply Yes, it is added to the Web Server Resources suitcase. A WOApplet appears in your component, with its __code__ attribute set to the name of the file.

- Drag an element from the Client-Side Components palette to your component (see ["Palettes"](Palettes.md#apple-geytcnjv)).
