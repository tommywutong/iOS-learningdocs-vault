# What's New in WebObjects 4.0

---

This document describes changes made to the WebObjects product between release 3.5 and release 4.0. Release 4.0 is compatible with release 3.5, but you must recompile any existing applications. This document tells you how to convert applications to 4.0, describes changes made to existing features, and then describes some new features you may want to start using in your applications. This document is organized as follows:

- [Compatibility With Earlier Releases](Compatibility%20With%20Earlier%20Releases.md#apple-giydsnbr)
- [Converting an Existing WebObjects Application](Converting%20an%20Existing%20WebObjects%20Application.md#apple-giydsnzt)
- [File Location Changes](File%20Location%20Changes.md#apple-giytcmrv)
- [Running an Application on WebObjects 4.0](Running%20an%20Application%20on%20WebObjects%204.0.md#apple-giytemzq)
- [Support for Multithreaded Applications](Support%20for%20Multithreaded%20Applications.md#apple-giytknry)
- [Direct Actions](Direct%20Actions.md#apple-gm3tqmbu)
- [Improved Nested Component Support](Improved%20Nested%20Component%20Support.md#apple-gi2tanjx)
- [Improved Image Loading](Improved%20Image%20Loading.md#apple-gi2tsnjr)
- [New Methods](New%20Methods.md#apple-gmydemrz)
- [WOMailDelivery Class](WOMailDelivery%20Class.md#apple-gm3tmmzy)
- [Cookie API](Cookie%20API.md#apple-gmydamjr)
- [WOExtensions Changes](WOExtensions%20Changes.md#apple-gi3dgnbu)
- [Dynamic Elements Changes](Dynamic%20Elements%20Changes.md#apple-gi4tanjx)
- [Changes to Localization](Changes%20to%20Localization.md#apple-gi4domjv)
- [Tool Changes](Tool%20Changes.md#apple-gm2dimjw)
- [Rapid Turnaround Mode](Rapid%20Turnaround%20Mode.md#apple-gm3dcnbq)
- [Debugging](Debugging.md#apple-gi4tknbz)
- [Other Changes](Other%20Changes.md#apple-gi3tenbt)

WebObjects 4.0 includes Enterprise Objects Framework release 3.0. For a description of the changes to Enterprise Objects Framework, see "[What's New in Enterprise Objects Framework 3.0](What%27s%20New%20in%20Enterprise%20Objects%20Framework%203.0.md)" .

__Note:__  This document describes changes in the Java and Objective-C versions of the WebObjects APIs. Where Java and Objective-C method names are dissimilar, both method names are provided. For methods that take zero arguments, both languages use the same name. For single argument methods, the Java name is the Objective-C name minus the trailing colon (:).
