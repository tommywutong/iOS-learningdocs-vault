## Choosing Assistance

If your application doesn't access a database, choose None for Available Assistance.
If your application accesses a database, you also choose None if you want to develop the entire application yourself. However, you may wish to use one of the levels of assistance that WebObjects provides. Information about Direct to Web option can be found in the ["Direct To Web"](Creating%20a%20Direct%20to%20Web%20Project.md) chapter. Information about the Database Wizard can be found in "[Creating a WebObjects Database Application](Creating%20a%20WebObjects%20Database%20Application.md)" in _Getting Started With WebObjects_.
