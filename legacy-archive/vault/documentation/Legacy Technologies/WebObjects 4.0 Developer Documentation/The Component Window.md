# The Component Window

When you open a component, WebObjects Builder displays it in a _component window_. You create your component's appearance graphically in the upper pane of the component window. The browser at the bottom of the window (known as the _object browser__)_ displays variables and methods your component uses.
The toolbar at the top of the window contains several buttons you use to create the content of your component. WebObjects Builder also has menu commands corresponding to these buttons.

!

__Note:__ Depending on the width of the window, the toolbar may appear as two rows or one.
