# WOExtensions Changes

WebObjects 4.0 includes the source code for the WOExtensions framework, in __/System/Developer/Examples/WebObjects/Source/WOExtensions__ (on NT, __$___NEXT_ROOT___/Developer/Examples/WebObjects/Source/WOExtensions).__

## New Components

A number of components have been added to the WOExtensions framework: WOAppleScript, WOBatchNavigationBar, WOCompletionBar, WOIFrame, and WOMetaRefresh.
