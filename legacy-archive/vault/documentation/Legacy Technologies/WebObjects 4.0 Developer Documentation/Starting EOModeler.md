# Starting EOModeler

To start EOModeler on Windows NT, launch EOModeler from the WebObjects program group in the Start menu. On Rhapsody, locate EOModeler in __/System/Developer/Applications__ and double-click its icon (shown in [Figure 1](#apple-geytomjv)).

!

Figure 1. EOModeler's Application Icon

Alternatively, you can start EOModeler by double-clicking an existing model file-from inside the Project Builder application or from the file system.
Tip: On Windows NT, you open a model's __.eomodeld__ directory and double-clicking the __index.eomodeld__ file to open it in EOModeler.
