# What's New in Enterprise Objects Framework 3.0

---

This document describes changes made to the Enterprise Objects Framework product between release 2.2 and release 3.0. It tells you how to convert applications to 3.0, describes changes made to existing features, and then describes some new features you may want to start using in your application. It is organized into the following sections:

- [Compatibility With Earlier Releases](Compatibility%20With%20Earlier%20Releases-2.md#apple-g4ytqoa)
- [File Location Changes](File%20Location%20Changes-2.md#apple-ge4dqnbr)
- [Changes to Java API](Changes%20to%20Java%20API.md#apple-ge2tkmzx)
- [Deprecated API](Deprecated%20API.md#apple-g44dkny)
- [Support for the OpenBase Lite Database](Support%20for%20the%20OpenBase%20Lite%20Database.md#apple-gezdqmzr)
- [New Convenience API](New%20Convenience%20API.md#apple-ge3deojv)
- [Changes to EOModeler](Changes%20to%20EOModeler.md#apple-geztqmru)
- [Binding to Complex Qualifiers](Binding%20to%20Complex%20Qualifiers.md#apple-ha3deni)
- [Merging Object Changes](Merging%20Object%20Changes.md#apple-heydenq)
- [Raw Row Fetching](Raw%20Row%20Fetching.md#apple-hezdcnq)
- [Support for Multi-Threaded Applications](Support%20for%20Multi-Threaded%20Applications.md#apple-he2tgna)
- [Changes to Key-Value Coding](Changes%20to%20Key-Value%20Coding.md#apple-he3tgma)
- [Changes to Enterprise Object Validation](Changes%20to%20Enterprise%20Object%20Validation.md#apple-ge4dinjw)
- [Changes to the Interface Layer](Changes%20to%20the%20Interface%20Layer.md#apple-ge3tonbt)

For a description of the changes to the WebObjects product, see "[What's New in WebObjects 4.0](What%27s%20New%20in%20WebObjects%204.0.md)."

__Note:__  This document describes changes in both the Java and Objective-C implementations of Enterprise Objects Framework. Where Java and Objective-C method names are dissimilar, both method names are provided. For methods that take zero arguments, both languages use the same name. For single argument methods, the Java name is the Objective-C name minus the trailing colon (:).
