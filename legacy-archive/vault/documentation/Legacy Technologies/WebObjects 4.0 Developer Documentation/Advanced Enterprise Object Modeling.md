# Advanced Enterprise Object Modeling

---

This chapter discusses advanced enterprise object modeling issues not covered in the chapter "Designing Enterprise Objects." It is organized into the following sections:

- ["Modeling Complex Attributes"](Modeling%20Complex%20Attributes.md#apple-gmytc) describes how to work with RTF text, image data, and your own custom data types.
- ["Modeling Relationships"](Modeling%20Relationships.md#apple-gi3tq) describes approaches for modeling optional to-one relationships, handling __null__-valued
  to-one relationships, and modeling many-to-many relationships.
- ["Modeling Inheritance"](Modeling%20Inheritance.md#apple-he4da) describes the three ways to model inheritance and the advantages and disadvantages of each.
- ["Designing Database-Savvy Enterprise Objects"](Designing%20Database-Savvy%20Enterprise%20Objects.md#apple-geydinjy) describes how to implement an enterprise object class that knows how to fetch its instances.
