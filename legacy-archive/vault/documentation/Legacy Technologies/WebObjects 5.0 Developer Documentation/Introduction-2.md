# Introduction

Direct to Java Client dynamically generates
the user-interfaces for applications or for parts of them. The advantage
of this technology is that it's not necessary to write source-code
to generate or manage an application's user interface. This allows
developers to focus on the business logic of an application, instead
of on the user interface.
