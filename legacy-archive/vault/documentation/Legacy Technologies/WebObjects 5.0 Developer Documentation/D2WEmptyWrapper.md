__D2WEmptyWrapper__

__Package__: com.webobjects.directtoweb

__Inherits from__:com.webobjects.appserver.WOComponent

---

__Class Description__

---

This component acts as the page wrapper when a Direct to Web application has no `PageWrapper.wo` component. It is a subclass of WOComponent and defines no additional variables or methods.
