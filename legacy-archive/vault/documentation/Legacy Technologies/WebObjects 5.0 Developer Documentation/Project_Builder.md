## Project Builder

While developing a WebObjects application, you spend most
of your time working with the Project Builder application. It allows
you to organize your project and all the associated files, compile
and run your project, and edit your source code.

Project Builder is installed as part of the developer package.
It is located in the /Developer/Applications directory.
