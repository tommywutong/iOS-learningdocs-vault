# Installing the Software

This chapter provides an overview of WebObjects
Deployment installation issues, including what elements of the software
need to be installed on a computer, taking the computer's purpose
into account. However, it does not give platform-specific instructions. For
detailed installation instructions, see the _Installation
Guide_ included with your package.
