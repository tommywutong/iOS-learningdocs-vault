## Operating Systems Supported

The following are the supported deployment platforms for WebObjects
5:

- __Mac
  OS X Server__ Mac OS X Server 10.0.4.
- __Solaris__ Sun Solaris 2.8.
- __Windows 2000__ Microsoft Windows 2000
  Pro with J2SE 1.3.1.

WebObjects applications can be deployed on other platforms
running J2SE 1.3 or later.
