## Guidelines for Choosing Java Client

Some applications simply require the flexibility and interactivity
of a Java Client user interface-an HTML-only solution just isn't
acceptable. However, Java Client is rarely appropriate for mass
markets and highly visible websites. Typically it's practical
only in intranet environments.

As mentioned in the last section, Java Client applications
have special deployment requirements because part of the application
runs on the user's machine. You either need to install the client-side
application on the user's machine, which requires system administration,
or the user needs to download the client-side application, which
can take a long time if the network is slow. If neither solution
is acceptable, you need to use the WebObjects HTML-based approach
or the Direct to Web approach.
