## Customizing Your Application With the WebAssistant

The WebAssistant allows you to customize each page of your
application. You can specify

- which entities
  of the model the application displays and, of these, which are read-only
- global attributes of pages, such as style, color, and border
  thickness
- which properties are displayed, and in what order

  By
  default, an entity's properties are listed in alphabetical order.
  Often, you'll want to change the order, as well as hiding some
  properties.
- how number and date strings should be represented
- how relationships should be represented
