__Class Description__

---

This component allows you to use a WebObjects reusable component as a property-level component. You can use the Web Assistant to specify the name of the reusable component to embed.

D2WCustomComponent passes two bindings to the reusable component: `object`, which specifies the object containing the property to modify or display, and `key`, which specifies the key for the property to modify or display. See the "Customizing a Direct to Web Application" chapter in _Developing WebObjects Applications With Direct to Web_ for more information about this component.
