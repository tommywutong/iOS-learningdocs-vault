## Configuring Sites

When you click the Site tab in Monitor, the site configuration
page is displayed. It contains three sections:

- __HTTP
  Adaptor URL__ This is where you tell Monitor how to compose
  an application's URL, which used in the application detail page
  to connect you to instances of your application.

  To set the
  URL for your application, enter the URL in the URL to Adaptor field.
- __HTTP Adaptor Settings__ This is where
  you set default HTTP adaptor settings for all your deployed applications.
  They can be overridden by each application. For more information,
  see ["Load Balancing and Adaptor Settings"](Setting_Up_Applications.md#apple-ijbusqsfjjeeg) and ["Load Balancing and Adaptor Settings"](https://developer.apple.com/library/archive/documentation/LegacyTechnologies/WebObjects/WebObjects_5/DeployingWebObjects/Reference/iApplication__Properties.html).
- __Email Notifications__ Here's where
  you specify the SMTP host and the return address that Monitor uses
  for email notifications.
