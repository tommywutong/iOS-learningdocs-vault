# Managing Application Instances

This chapter provides a detailed description
of Monitor and wotaskd, two tools you use to manage the application
instances running on your site, and it explains how instances communicate
with wotaskd:

- ["Configuration Files"](Configuration_Files.md#apple-ijbusskfircum) provides
  an overview of the configuration files that can be used in your
  site.
- ["Lifebeats"](Lifebeats.md#apple-krifqusfiyytani) introduces
  lifebeats, the mechanism used by wotaskd processes to determine
  the status of the application instances that they manage.
- ["wotaskd Processes"](wotaskd_Processes.md#apple-ijbusrcjjjfeu) explains how wotaskd processes ensure that
  the application instances they manage are always running. It also
  describes how to restrict access to wotaskd using Monitor.
- ["Starting WebObjects Services"](Starting_We_ts_Services.md#apple-ijbusr2ei5cum) shows you how to configure a computer
  to start wotaskd and Monitor during system startup.
