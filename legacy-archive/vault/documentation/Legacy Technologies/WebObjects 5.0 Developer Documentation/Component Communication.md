# Component Communication

A single component does not an application
make. One of the aspects of the WebObjects strategy is the ability
to define new components and share data between them.

As was said before, WebObjects is a heavily object-oriented
system. It provides for easy encapsulation of data into components
and custom classes, and facilitates the sharing of data between
components when an application is run.

In this chapter, you

- encapsulate
  data into a custom a class
- learn how WebObjects follows keypaths
- add a new WOComponent to your application
- programmatically create new components and return them to
  the user
- pass information between components
