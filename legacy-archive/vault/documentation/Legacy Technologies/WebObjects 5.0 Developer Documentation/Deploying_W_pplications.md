## Deploying WebObjects 4.5.1 and WebObjects 5 Applications

If you want to deploy WebObjects 4.5.1 and WebObjects 5 applications,
you must use either the WebObjects 4.5.1 or the WebObjects 5 versions
of Monitor and wotaskd. You cannot use the wotaskd in WebObjects
4.5.1 with the Monitor included in WebObjects 5.
