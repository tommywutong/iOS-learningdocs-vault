# Application Administration

After deploying applications, you should monitor
their performance to find out, among other things, if you need to
add instances to an application to improve response times. ["Monitoring Activity"](Monitoring_Activity.md#apple-krifqusfiyytamq) shows
you the kind of performance data you can collect about an application.

There are several steps you can take to improve your site's
performance; most of them have been explained in the preceding chapters.
In the section ["Improving Performance"](Improving_Performance.md#apple-krifqusfiyytcny) you'll find list of recommended measures
that will help optimize your site's operation.
