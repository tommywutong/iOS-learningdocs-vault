# Related Documentation

Other WebObjects documents might be of interest to system administrators:

- _Installation Guide_
  : Includes system requirements, compatibility information, and location of the WebObjects Home Page. (The _Installation Guide_
  is printed and included with the WebObjects CD-ROM or can be downloaded from NeXTanswers; it is not online).
- _Post-Installation Instructions_
  : Describes how to verify the installation and troubleshoot if WebObjects applications do not run.
- Installation instructions for supported HTTP adaptors can be found in __InstallationInstructions.html__
  , which is located in  ___NEXT_ROOT___
  __/Developer/Examples/WebObjects/Source/Adaptors/__
  . Instructions for building HTTP adaptors from provided source code are located in __BuildingInstructions.html__
  in the same directory.
