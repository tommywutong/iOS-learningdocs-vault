#  Cleaning Up After a Failed Installation

If a problem occurred during installation and WebObjects isn't listed under the Start menu, you can remove the partial installation using software provided on the WebObjects CD. Within the Install directory on the WebObjects CD is a WebObjects 4.5 directory; this directory contains the uninstallation software. Follow the instructions in the
readme.txt
file to both remove any installed files and clean up the Windows NT registry. Note that you can safely skip the first step, which tells you to run the uninstaller.
