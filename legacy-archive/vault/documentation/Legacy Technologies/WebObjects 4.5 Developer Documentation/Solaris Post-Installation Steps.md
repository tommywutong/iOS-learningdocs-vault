#   Solaris Post-Installation Steps

After you've finished installing on Solaris, perform the following steps:

- 

  Set NEXT_ROOT
- 

  Set PATH
- 

  (optional) Enable and Start machd and nmserver
- 

  [Setting the LD_LIBRARY_PATH](Setting%20the%20LDLIBRARYPATH.md#apple-gezdomjr)
- 

  [Set the Time Zone](Set%20the%20Time%20Zone.md#apple-ha2tanjq)
- 

  [Install the Java Native Threads Pack](Install%20the%20Java%20Native%20Threads%20Pack.md#apple-g43tgmrz)
- 

  [Rebuild the Executable WODefaultApp](Rebuild%20the%20Executable%20WODefaultApp.md#apple-ha4dmobx)

  [Obtain and Install Database Client Libraries](Obtain%20and%20Install%20Database%20Client%20Libraries-2.md#apple-gi3tambv)
