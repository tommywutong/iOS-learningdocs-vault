# EOTextAssociation.JTextComponentAccess

> **__Package:__**
> : com.apple.client.eointerface

---

## Interface Description

---

EOTextAssociation.JTextComponentAccess is
an interface that specifies the way an EOTextAssociation accesses
its display object's underlying javax.swing.text.JTextComponent.
