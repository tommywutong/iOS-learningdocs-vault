#  Binding Elements

When a user enters information in form elements, your application needs a way of accessing that information. This is done by _binding_ the form elements to variables in your application. When the user submits the form, WebObjects puts the data into the variables you've specified.

Your application typically processes the data and returns a new page (or the same page) displaying information that makes sense based on the user's input. The information displayed is usually represented by other dynamic elements that are bound to variables and methods in your code.

This process of receiving a request (triggered by actions such as submitting a form or clicking a hyperlink) and responding by returning a page is known as the _request-response loop_. This loop is at the heart of WebObjects programming.

In this tutorial, you'll have WebObjects return the same page, with the information you received from the user displayed in a slightly different format at the bottom.
