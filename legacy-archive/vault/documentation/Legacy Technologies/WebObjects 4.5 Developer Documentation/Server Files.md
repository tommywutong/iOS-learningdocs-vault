#  Server Files

The server-side project files are, as usual, accessible from the first column of the project browser (the main project). Most notable of these is the Main component (__Main.wo__) in the WebComponents suitcase. The __Main.html__ file contains this generated HTML code:

<HTML>

<HEAD>

  <TITLE>Main</TITLE>

</HEAD>

<BODY>

  <CENTER><WEBOBJECT NAME=Applet></WEBOBJECT></CENTER>

</BODY>

</HTML>
