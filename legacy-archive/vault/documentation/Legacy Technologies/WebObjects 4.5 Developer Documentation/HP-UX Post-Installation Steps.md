#   HP-UX Post-Installation Steps

After you've finished installing on HP-UX, perform the following steps:

- 

  Set NEXT_ROOT
- 

  Set PATH
- 

  (optional) Enable and Start machd and nmserver
- 

  [Setting the LPATH and SHLIB_PATH Environment Variables](Setting%20the%20LPATH%20and%20SHLIBPATH%20Environment%20Variables.md#apple-g43tcmzt)
- 

  [Set the Time Zone](Set%20the%20Time%20Zone-2.md#apple-heztsmby)
- 

  [Change the UID for User nobody](Change%20the%20UID%20for%20User%20nobody.md#apple-g43dimrr)
- 

  [Rebuild the Executable WODefaultApp](Rebuild%20the%20Executable%20WODefaultApp-2.md#apple-gqztonbz)
- 

  [Obtain and Install Database Client Libraries](Obtain%20and%20Install%20Database%20Client%20Libraries-3.md#apple-gizdcnbr)
