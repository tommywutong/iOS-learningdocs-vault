# Action Methods

An _action method_ is a method you associate with a user action-for instance, clicking a submit button, an active image, or a hyperlink. There are two types of action methods that you can implement: _component actions_ and _direct actions_. Component actions are the default. See ["What Is WebObjects?"](What%20Is%20a%20WebObjects%20Application.md#apple-gezdmmjt) for a general description of the differences between component actions and direct actions and when you might want to use each one.
