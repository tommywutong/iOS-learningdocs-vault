## Debugging WebScript

To debug WebScript code, you rely on log messages and trace statements described in the section, ["Debugging Techniques"](Debugging%20Techniques.md#apple-gu4tcoa).

If you've written an application entirely in WebScript, you typically debug it by running __NeXT_ROOT/Library/WebObjects/Executables/WODefaultApp__ from the Project Builder launch panel, as described in _[WebObjects Tools and Techniques](WebObjects%20Tools%20and%20Techniques.md)_. When you do, the output from the debugging and trace statements is displayed in the launch panel.
