# Fetch Specifications

To perform a query in an Enterprise Objects Framework application, you use an EOFetchSpecification object. Fetch specifications have associated with them an entity, a qualifier, a sort ordering, and several other options. You can create fetch specifications programmatically, or you can use EOModeler to create and store them. For more information on the EOFetchSpecification class, see its specification in the _Enterprise Objects Framework Reference_.
