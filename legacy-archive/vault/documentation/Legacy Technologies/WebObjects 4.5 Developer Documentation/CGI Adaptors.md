# CGI Adaptors

The CGI adaptor is an executable file named __WebObjects__
--__WebObjects.exe__
on Windows NT--which resides in the host HTTP server's __cgi-bin__
or __scripts__
directory. This adaptor is available on all supported platforms. It is generic in that it works with any HTTP server conforming to the Common Gateway Interface (CGI).
