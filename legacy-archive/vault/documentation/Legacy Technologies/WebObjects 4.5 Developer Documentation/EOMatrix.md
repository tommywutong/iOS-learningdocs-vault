## Class Description

---

EOMatrix is a class used to group collections
of mutually exclusive JRadioButtons and to lay them out on a grid.
It is a subclass of EOView that uses a java.awt.GridLayout.

|  |
| --- |
| __Note:__ This class doesn't exist in the com.apple.yellow.eointerface package. |

For more information on the way a matrix of JRadioButtons
behaves, see the Sun class documentation for javax.swing.ButtonGroup.
