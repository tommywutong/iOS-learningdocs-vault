#  Opening an Existing Project

To open an existing project from Project Builder:

1. 

   Choose Project !
   Open.
2. 

   In the Open Project panel, navigate to the project folder and click Open.

To open an existing project from the file system, double-click the __PB.project__
file in the project directory. Project Builder launches (if it is not already running) and opens the project.
