# Introduction to Launch Time Performance Guidelines

This document provides specific tips on how to identify and improve your application’s performance at launch time. The launch of an application provides users with the first impression of your application. If your application launches quickly, it leaves users with a good impression.

This document contains the following articles:

- [Launch Time Tips](Launch%20Time%20Tips.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrha2tklkcineuqqkhiffa) describes some standard techniques for improving the performance of your application at launch time.
- [Gathering Launch Time Metrics](Gathering%20Launch%20Time%20Metrics.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrha2tmlkdjjbeursjirca) describes ways to measure the speed of your application launch.
- [Minimizing File Access At Launch Time](Minimizing%20File%20Access%20At%20Launch%20Time.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrha2tolkdjjbeursjirca) shows you how to measure and reduce your file usage at launch time.
- [Prebinding Your Application](Prebinding%20Your%20Application.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrha2tqlkdjjbeursjirca) explains the prebinding process and shows you how to determine if your application is prebound.
