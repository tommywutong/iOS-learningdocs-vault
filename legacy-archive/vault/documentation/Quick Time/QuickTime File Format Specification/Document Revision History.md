# Document Revision History

This table describes the changes to _QuickTime File Format Specification_.

| __Date__ | __Notes__ |
| 2016-09-13 | Updated the color atom ('colr') to include information on new color standards, including DCI P3, P3 D65, and ITU-R BT.2020. |
| 2015-02-14 | Added facility for timed metadata tracks. |

Introduce `'cdsc'`track reference type, see [Table 2-2](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwtgobugq4q). Added more well-known metadata data types, see [Table 3-5](Metadata.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmjnknltgni). |
| 2014-02-11 | Updated the section on closed caption tracks. |
| 2012-08-14 | Corrected the values for kQTSampleDependency_OtherSamplesDependOnThisSample and kQTSampleDependency_- NoOtherSampleDependsOnThisSample. |
| 2012-08-01 | The following updates are included in this revision: In [User Data Atoms](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwtenjvgm4a), expanded the description of `'tnam'` and added `'tagc'` with related section [Media Characteristic Tags](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwvgvztg4). Added [Track Exclude From Autoselection Atoms](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwvgvzug4). Explained alternate groups in [Track Header Atoms](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwtenjvguya). Added `clcp`, `fall`, `folw`, and `forc` to [Track Reference Atoms](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwtenjwga2a). Corrected structure of gmhd and gmin in [Base Media Information Atoms](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwtenjwgu4a). [General Structure of a Sample Description](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwtmmjrgeza) includes emphasized importance of data size due to occasional terminating zeroes. Added [Text Media Information Atom](Media%20Data%20Atom%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqguwvgvzzga), [Closed Captioning Media](Media%20Data%20Atom%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqguwvgvzyg4), and [Subtitle Media](Media%20Data%20Atom%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqguwvgvzyge). [Timecode Media Information Atom](Media%20Data%20Atom%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqguwtknzuge2q) now documents the reserved integer after the text size. Added [Preparing Sound and Subtitle Alternate Groups for Use with Apple Devices](Some%20Useful%20Examples%20and%20Scenarios.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqg4wvgvzu). “Audio track” changed to “sound track” for consistency. Deprecated ‘rsrc’ data reference. |
| 2011-07-13 | The following updates are included in this revision: The sound sample description v2 format along with the definition of two new sound sample description extensions are incorporated, see [Sound Sample Description (Version 2)](Media%20Data%20Atom%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqguwtcmryheytm). New atoms for the display of track aperture in different modes have been documented, see [Track Aperture Mode Dimension Atoms](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwvgvzrgu). New sample atoms for handling out-of-order movie samples have been added, see [Sample Atoms](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwtgmztga3q). Appendix G, [Audio Priming - Handling Encoder Delay in AAC](Audio%20Priming%20-%20Handling%20Encoder%20Delay%20in%20AAC.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrnknltc), has been added which treats how to handle temporal positioning of AAC audio data explicitly. The Macintosh language codes table has been updated with current language names, see [Table 5-1](Basic%20Data%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgywtgnbtguzq) and the related [Extended Language Tag Atom](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwvgvzrgy) defined. |
| 2010-08-03 | Corrected the order of fields described in the Metadata Handler Atom structure. |
| 2010-05-03 | Added description of clip-based metadata and specific key/value pairs for location metadata. |
| 2007-09-04 | First public release of complete, updated _QuickTime File Format Specification_ with information about atoms and atom types. Added licensing information and disclaimer for developers. Modified introductory sections and atom descriptions; updated artwork and edited for technical accuracy. |
|  | A QuickTime file may now contain a file type compatibility atom. See [The File Type Compatibility Atom](Overview%20of%20QTFF.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgmwtknbrg44q). A movie atom may now contain a movie profile atom. See [The Movie Profile Atom](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwtknbzgq4a). A track atom may now contain a track profile atom. See [Track Profile Atom](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwtkobxgyzq). Video sample descriptions may now contain a pixel aspect ratio atom for non-square pixels. See [Pixel Aspect Ratio ('pasp')](Media%20Data%20Atom%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqguwtcmrugu2ta). Video sample descriptions may now also contain a color parameter atom. See [Color Parameter Atoms ('colr')](Media%20Data%20Atom%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqguwtcmrvguzdm). Video sample descriptions may now a clean aperture atom. See [Clean Aperture ('clap')](Media%20Data%20Atom%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqguwtcmrvha2ta). The sound description record has been expanded to represent variable bit-rate compression more accurately. See [Sound Sample Descriptions](Media%20Data%20Atom%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqguwtknztge3q). The section describing MPEG-4 audio has been modified. See [MPEG-4 Audio](Media%20Data%20Atom%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqguwtcmryg42ts). |
|  | It is now recommended that the file creation and modification times be set using UTC, rather than local time zones. See [Calendar Date and Time Values](Basic%20Data%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgywtcobxgmyq). User data text may now be encoded using either Macintosh text encoding or ISO text encoding (Unicode). See [User Data Text Strings and Language Codes](Movie%20Atoms.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgqwtkobuhe4q). MPEG-4 video and audio sample descriptions may now contain elementary stream descriptor atoms. See [MPEG-4 Elementary Stream Descriptor Atom ('esds')](Media%20Data%20Atom%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqguwtcmrug43ti) and [MPEG-4 Elementary Stream Descriptor Atom ('esds')](Media%20Data%20Atom%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqguwtcmzugq3dg). It is now possible to specify languages using either Macintosh language codes or ISO language codes. See [Language Code Values](Basic%20Data%20Types.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmzzfvbuqmrqgywtenzqga2q). |
