# Introduction to QuickTime Movie Basics

This book introduces you to some of the basic concepts you need to understand when working with QuickTime movies.

You need to read this book if you are going to work with QuickTime movies.

This book consists of the following chapters:

- [Editing Movies](https://developer.apple.com/library/archive/documentation/QuickTime/RM/MovieBasics/MTEditing/B-Chapter/2EditingMovies.html#//apple_ref/doc/uid/TP40000908-EditingMovies-SW1) describes the functions of the movie toolbox that your application will use to edit movies and tracks.
- [Saving Movies](https://developer.apple.com/library/archive/documentation/QuickTime/RM/MovieBasics/MTEditing/C-Chapter/3SavingMovies.html#//apple_ref/doc/uid/TP40000908-SavingMovies-SW1) tells you how to save movies into movie files.
- [Overview of Application-Defined Functions](https://developer.apple.com/library/archive/documentation/QuickTime/RM/MovieBasics/MTEditing/D-Chapter/4OverviewofApplicati.html#//apple_ref/doc/uid/TP40000908-OverviewofApplicationDefinedFunctions-SW1) describes the application-defined functions used with the QuickTime Movie Toolbox.
- [Working With Application-Defined Functions](https://developer.apple.com/library/archive/documentation/QuickTime/RM/MovieBasics/MTEditing/E-Chapter/5WorkingWithApplicat.html#//apple_ref/doc/uid/TP40000908-WorkingWithApplicationDefinedFunctions-SW1) shows how to implement functions that are invoked during specific operations. A sample cover function is provided.
- [Creating Tracks and Media Structures](https://developer.apple.com/library/archive/documentation/QuickTime/RM/MovieBasics/MTEditing/F-Chapter/6CreatingTracksandMe.html#//apple_ref/doc/uid/TP40000908-CreatingTracksandMediaStructures-SW1) describes the functions your application can use to create and dispose of tracks and media structures.
- [Working With Media Samples](https://developer.apple.com/library/archive/documentation/QuickTime/RM/MovieBasics/MTEditing/G-Chapter/7WorkingWithMediaSam.html#//apple_ref/doc/uid/TP40000908-WorkingWithMediaSamples-SW1) describes the functions your application can use to get information about a movie’s sample data.
- [Understanding QuickTime Atoms](https://developer.apple.com/library/archive/documentation/QuickTime/RM/MovieBasics/MTEditing/H-Chapter/8UnderstandingQuickT.html#//apple_ref/doc/uid/TP40000908-UnderstandingQuickTimeAtoms-SW1) discusses QuickTime atoms, a basic structure for storing information in QuickTime, and also describes the functions used to create, dispose of, read from, and store to QuickTime Atom Containers.
- [Timecode Media Handler Functions](https://developer.apple.com/library/archive/documentation/QuickTime/RM/MovieBasics/MTEditing/I-Chapter/9TimecodeMediaHandle.html#//apple_ref/doc/uid/TP40000908-TimecodeMediaHandlerFunctions-SW1) discusses the functions and structures that allow you to use the timecode media handler, and tells you how to create a timecode track.
- [Locating Tracks, Saving Movies, and Modifying Movie Properties](https://developer.apple.com/library/archive/documentation/QuickTime/RM/MovieBasics/MTEditing/J-Chapter/10LocatingTracksSavin.html#//apple_ref/doc/uid/TP40000908-LocatingTracksSavingMoviesandModifyingMovieProperties-SW1) discusses functions you can use to locate a movie’s tracks and media structures, save movies, capture and restore the edit state of a movie, and modify movie properties.
- [Matrix Functions](https://developer.apple.com/library/archive/documentation/QuickTime/RM/MovieBasics/MTEditing/K-Chapter/11MatrixFunctions.html#//apple_ref/doc/uid/TP40000908-MatrixFunctions-SW1) describes the functions that allow you to work with transformation matrices.
- [Movie Toolbox Constants, Data Types, and Functions](https://developer.apple.com/library/archive/documentation/QuickTime/RM/MovieBasics/MTEditing/L-Chapter/12MovieToolboxConstan.html#//apple_ref/doc/uid/TP40000908-MovieToolboxConstantsDataTypesandFunctions-SW1) describes some of the constants, data types, and functions in the Movie Toolbox that you can use in your application development.

The following Apple books cover related aspects of QuickTime programming:

- _[QuickTime Overview](QuickTime%20Overview.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridgmbqgaydsojs)_ gives you the starting information you need to do QuickTime programming.
- _[QuickTime Movie Creation Guide](QuickTime%20Movie%20Creation%20Guide.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmbw)_ describes some of the different ways your application can create a new QuickTime movie.
- _[QuickTime Movie Internals Guide](QuickTime%20Movie%20Internals%20Guide.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaydsmjr)_ covers some of the technology present inside QuickTime movies, including time management, modifier tracks, access keys, posters, and movie and file previews.
- _QuickTime Guide for Windows_ provides information specific to programming for QuickTime on the Windows platform.
- _QuickTime API Reference_ provides encyclopedic details of all the functions, callbacks, data types and structures, atom types, and constants in the QuickTime API.
