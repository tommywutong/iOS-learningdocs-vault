## WOSMILHeadLayout

This element encloses the layout elements of the presentation.
It corresponds to the `<layout>` tag.
Its binding is listed in [Table 4-4](#apple-ijbegr2ii5eui).

__Table
4-4 Basic binding of the WOSMILHeadLayout
element__

| Binding | Description |
| `type` | Determines the layout language used by the element. |
