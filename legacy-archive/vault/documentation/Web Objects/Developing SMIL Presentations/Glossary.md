# Glossary

**__component, WebObjects__**
: An object (of the WOComponent class) that represents
a Web page or a reusable portion of one.

**__curl__**
: Command-line tool used to transfer files using
URL syntax.

**__QuickTime Player__**
: A multimedia player.

**__RealPlayer__**
: A multimedia player.

**__SMIL (Synchronized Multimedia
Integration Language)__**
: Language
specification that facilitates the integration of various media objects
into a single, synchronized presentation.

**__URI (Uniform Resource
Identifier)__**
: The Web naming and
addressing technology. A URI is a string of characters that identify
a resource. Some typical URI schemes are HTTP and FTP.

**__URN (Uniform Resource
Name)__**
: URNs are URIs that identify
a resource regardless of its physical location. URLs are a type
of URN.
