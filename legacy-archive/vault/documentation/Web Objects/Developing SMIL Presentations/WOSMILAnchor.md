## WOSMILAnchor

This element provides the ability to link to a media object;
it corresponds to the `<anchor>` tag. [Table 4-17](#apple-ijbegrcgjbauo) lists
its bindings.

__Table
4-17 Additional members of the WOSMILAnchor
element__

| Binding | Description |
| `begin` | The start time for this element. |
| `coordinates` | Specifies a rectangle within the presentation's window. |
| `end` | The end time of this element. |
| `show` | Value: `"replace"`, `"new"`, or `"pause"`. |
| `skipContent` | Used for future extensibility of SMIL. Value: `"true"` or `"false"`. |
| `title` | Meaningful description for this element. |
