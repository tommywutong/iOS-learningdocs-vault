# Introduction to Buttons

A button is a user interface object that sends an action message to a target when clicked.

You should read this document to learn what are the different types of button provided by Cocoa and how you can use them.

This document describes how to use a button. These articles give you basic information on the different types of button, and how you can customize buttons:

- [How Buttons Work](How%20Buttons%20Work.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4dilkcijbueqskjjea) describes how buttons work.
- [Types of Button](Types%20of%20Button.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4dklkdijeukqkhjfba) describes the types of button, how they act, how it highlights when pressed and whether it shows its state.
- [Using Push Buttons](Using%20Push%20Buttons.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4talkcineuersiifaq) explains how to use push buttons.
- [Using Checkboxes](Using%20Checkboxes.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgi2tclkcineuersiifaq) explains how to use checkboxes in matrix objects.
- [Using Radio Buttons](Using%20Radio%20Buttons.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgi2telkcineuersiifaq) explains how to use radio buttons in matrix objects.
- [Querying Button Matrices](Querying%20Button%20Matrices.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga3tsnrufvjvomi) shows how to handle selections in radio buttons and checkboxes.
- [Setting the Appearance of a Button’s Border](Setting%20the%20Appearance%20of%20a%20Button%E2%80%99s%20Border.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4dmlkciffeerkhijbq) describes how to change the border’s shape and grading.
- [Setting a Button’s Title](Setting%20a%20Button%E2%80%99s%20Title.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4dolkcijbugr2cjfba) describes how to change the content and appearance of the button’s title.
- [Setting a Button’s Image](Setting%20a%20Button%E2%80%99s%20Image.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4dqlkciffeeq2hindq) describes how to change the content and appearance of the button’s image.
- [Hiding a Button](Hiding%20a%20Button.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4dslkcineuersiifaq) describes how to make a button invisible or have it show its border only when the mouse is over it.
- [Setting a Button’s Key Equivalent](Setting%20a%20Button%E2%80%99s%20Key%20Equivalent.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4tclkdjjbegrckifca) describes how to attach a key equivalent to a button.
- [Subclassing NSButton](Subclassing%20NSButton.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg4zdslkcineuersiifaq) describes how to subclass `NSButton`.

The following articles in other documents also contain relevant information:

- [Using a Continuous Control](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/ControlCell/Tasks/UsingContControl.html#//apple_ref/doc/uid/20000250) describes how to set up a button so it sends its action message repeatedly while being pressed.
- [Cell States](https://developer.apple.com/library/archive/documentation/Cocoa/Conceptual/ControlCell/Concepts/CellStates.html#//apple_ref/doc/uid/20000069) describes the three states a button can have: on, off, or mixed.
