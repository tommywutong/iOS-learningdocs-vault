# Introduction to Tab Views

A tab view is a convenient way to provide information in multiple pages. A tab view usually contains a row of tabs that give the visual appearance of folder tabs. When the user clicks on a tab, the tab view displays a view page provided by your application.

This programming topic contains the following articles:

- [How Tab Views Work](How%20Tab%20Views%20Work.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg42dmlkcijbugrsiifbq) describes how tab views work.
- [Managing Tab View Items](Managing%20Tab%20View%20Items.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg42dolkcijbuorsgjbcq) describes how to manage a tab view’s list of tab view items.
- [Setting Tab View Appearance](Setting%20Tab%20View%20Appearance.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg42dqlkcijbuorsgjbcq) describes how to change a tab view’s appearance.
- [Using a Tab View Delegate](Using%20a%20Tab%20View%20Delegate.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg42dslkcijbuorsgjbcq) describes how to use a tab view delegate.
