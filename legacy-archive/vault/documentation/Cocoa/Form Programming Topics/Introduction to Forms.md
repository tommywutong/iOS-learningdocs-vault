# Introduction to Forms

A form is group of related text fields. Unlike individual text fields, the fields in a form work together without any intervention from the developer. For example, you can tab from one field to another without writing any code or doing any work in Interface Builder.

This topic discusses forms. [How Forms Work](How%20Forms%20Work.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgeydalkcijbukq2bjfda) gives basic information on them. [Setting a Form’s Appearance](Setting%20a%20Form%E2%80%99s%20Appearance.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgeydclkciffegssbivda) describes how to modify the form’s appearance. [Managing Form Entries](Managing%20Form%20Entries.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgi2tklkciffegssbivda) describes how to access and modify individual entries in a form.

A form is implemented as a type of matrix. For more information, see _[Matrix Programming Guide](../Matrix%20Programming%20Guide/Introduction%20to%20Matrices.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgeydambqgazde2i)_.
