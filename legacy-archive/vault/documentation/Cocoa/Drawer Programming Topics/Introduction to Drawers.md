# Introduction to Drawers

A drawer is a special type of window that can slide out from one side of a window.

This document describes drawers and how they work.

The UI Element Guidelines: Windows chapter in _Aqua Human Interface Guidelines_ discusses drawers from the point of view of how they relate to other OS X user interface objects.
