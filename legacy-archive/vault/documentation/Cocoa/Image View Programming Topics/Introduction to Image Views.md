# Introduction to Image Views

An image view displays a single image in a frame, and can optionally allow a user to drag an image to it.

Note that an image view performs its action only when a user drags an image to it. To perform an action when a user clicks an image, use a button For more information, see _[Button Programming Topics](../Button%20Programming%20Topics/Introduction%20to%20Buttons.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgeydambqgayts2i)_.

[Setting an Image View’s Appearance](Setting%20an%20Image%20View%E2%80%99s%20Appearance.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg4ztilkciffekqkjivcq) describes how to change the appearance of the image view’s image and frame. [Using an Image View to Specify an Image](Using%20an%20Image%20View%20to%20Specify%20an%20Image.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg4ztglkciffekqkjivcq) describes how to use an image view as an image well.
