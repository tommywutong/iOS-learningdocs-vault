# 简介

Foundation 提供了一套用于传递事件发生信息的编程架构。本文档介绍该架构的各个组成部分，并说明如何使用它们。

阅读本文档可以了解[通知](https://developer.apple.com/library/archive/documentation/General/Conceptual/DevPedia-CocoaCore/Notification.html#//apple_ref/doc/uid/TP40008195-CH35)、通知中心和通知队列。

本文档包含以下文章：

- [通知](Notifications.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgiytklkcineugskii5cq)介绍封装事件信息的对象。
- [通知中心](Notification%20Centers.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgiytmlkciffeorcbizbq)介绍管理通知发送和接收的对象。
- [通知队列](Notification%20Queues.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgiytolkdjjbegrkdjjbq)介绍充当通知中心缓冲区的对象。
- [注册通知](Registering%20for%20a%20Notification.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg4zdglkdivdugq2gjfca)介绍如何注册通知。
- [发布通知](Posting%20a%20Notification.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg4zdilkdivduurseizdq)介绍如何发布通知。
- [向特定线程递送通知](Delivering%20Notifications%20To%20Particular%20Threads.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrgi4dslkdivduurseizdq)通过一个示例展示如何处理需要在特定线程上处理的通知。
