# Introduction to Text Attachments

_Text
Attachments_ explains how to add graphics and other attachments
to text.

You should read this document if you need to understand how
text attachments work in the Cocoa text system.

This document contains the following articles:

- [Text Attachments](Text%20Attachments.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqheztslkdjjbeescfizea) explains
  what text attachments are.
- [Adding Attachments to Text](Adding%20Attachments%20to%20Text.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqhe2dalkdjjbeeskbifda) describes
  how to add text attachments to text.
