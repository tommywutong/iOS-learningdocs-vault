# Introduction to Sound Programming Topics for Cocoa

This document contains articles that describe Cocoa’s audio support.

This document contains the following articles:

- [Overview of the NSSound Class](Overview%20of%20the%20NSSound%20Class.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg44dklkcijbumrchizbq) describes the `NSSound` class.
- [Loading Audio Data](Loading%20Audio%20Data.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg44dmlkciffemqsbifea) explains various ways to load audio data into an `NSSound` instance.
- [Managing Sound Playback](Managing%20Sound%20Playback.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg44dolkciffemqsbifea) explains how to play audio with an `NSSound` instance.

This document also contains a revision history.
