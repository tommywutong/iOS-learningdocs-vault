# Introduction to Outline Views

An outline view is a type of table which lets the user expand or collapse rows that contain hierarchical data.

`NSOutlineView`, the class that implements outline views, is a subclass of `NSTableView`. Before reading about outline views, read _[Table View Programming Guide for Mac](../Table%20View%20Programming%20Guide%20for%20Mac/About%20Table%20Views%20in%20OS%20X%20Applications.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgeydambqgazdm2i)_. In particular, The Parts of a Table describes how all the different classes used by a table fit together.

This programming topic contains the following articles:

- [About Outline Views](About%20Outline%20Views.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgeydolkcijbuessgizdq) gives basic information on outline views.
- [Using an Outline View Delegate](Using%20an%20Outline%20View%20Delegate.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgeydqlkcijbuir2eifdq) describes delegate methods for a outline view.
- [Writing an Outline View Data Source](Writing%20an%20Outline%20View%20Data%20Source.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg4zdklkcijbuir2eifdq) describes data source methods for an outline view.
