# Using the Java Bridge

In the world of Mac OS X and WebObjects programming, there are two languages in common use: Java and Objective-C. This document describes the Java bridge, a technology from Apple that makes communication between these two languages possible.

The first section, [Introduction](Legacy%20Documentclose%20button-2.md#apple-ijdugrccinfeo)
gives a brief overview of the bridge's capabilities.

For a technical overview of the bridge, see [How the Bridge Works](Legacy%20Documentclose%20button-3.md#apple-ijdugrckjbfeu)
.

To learn how to expose your Objective-C code to Java, see [Wrapping Objective-C Frameworks](Legacy%20Documentclose%20button-5.md#apple-ijdugqsfizcui)
.

If you want to write Java code that references Objective-C classes, see [Using Java-Wrapped Objective-C Classes](Legacy%20Documentclose%20button-6.md#apple-ijdugrkdjbdug)
. If you are writing Objective-C code that references Java classes, read [Using Java from Objective-C](Legacy%20Documentclose%20button-4.md#apple-ijdugqsgirfes).
