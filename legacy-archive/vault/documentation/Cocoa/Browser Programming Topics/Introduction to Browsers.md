# Introduction to Browsers

A
browser provides a user interface for displaying and selecting items
from a list of data or from hierarchically organized lists of data
such as directory paths.

This document discusses how to use browsers. [About Browsers](About%20Browsers.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga3tklkcineugr2ci5fa) gives basic
information on browsers and describes what happens when you select
a browser item. [Browser Interface Features](Browser%20Interface%20Features.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga3tmlkcijbuerkginfa) describes
how to control some aspects of a browser’s appearance. [Using a Browser Delegate](Using%20a%20Browser%20Delegate.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga3tolkdjjbeercgivfa) describes
how to use a delegate to fill a browser with data.
