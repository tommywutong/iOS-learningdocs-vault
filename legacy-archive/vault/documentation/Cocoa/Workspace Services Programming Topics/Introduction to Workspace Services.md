# Introduction to Workspace Services

The `NSWorkspace` class provides a variety of services to Cocoa applications, including retrieving information from the file system, launching applications, and miscellaneous other tasks.

This programming topic contains the following articles:

- [About Workspace Services](About%20Workspace%20Services.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrgaydelkcijbuerccjjcq) contains a discussion of the services `NSWorkspace` provides.
- [Use of .app Extension](Use%20of%20.app%20Extension.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrgaydglkciffeorkkifeq) describes how OS X uses the `.app` extension to identify applications.
- [Retrieving Information About Files](Retrieving%20Information%20About%20Files.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrgaydilkdjjbesrcdivda) describes how to find file types, application information, and retrieve icons.
- [Manipulating Files](Manipulating%20Files.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrgaydklkcijbuirkfjbca) describes how to perform Finder-like operations on files.
- [Manipulating Applications](Manipulating%20Applications.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrgaydmlkciffeoqseinba) describes how to manipulate, locate, and hide applications.
- [Manipulating Devices](Manipulating%20Devices.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrgaydolkdjjbeoqsdijbq) describes how to track available storage devices and their associated volumes.
- [Receiving Workspace Notifications](Receiving%20Workspace%20Notifications.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrgaydslkdjjbeqrkgivbq) describes how to use the notification center provided by `NSWorkspace` to receive
  workspace notifications.
