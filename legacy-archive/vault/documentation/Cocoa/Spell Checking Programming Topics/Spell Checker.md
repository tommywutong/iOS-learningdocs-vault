# Spell Checker

The NSSpellChecker class gives any application
an interface to the Cocoa spell-checking service. To handle all
its spell checking, an application needs only one instance of NSSpellChecker.
It provides a panel in which the user can specify decisions about
words that are suspect.

The spell checker facility also provides lists of potential
word completions culled from its spelling dictionary for the text-completion system in OS X
version 10.3 and later.
