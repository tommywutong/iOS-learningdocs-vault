# Introduction to Spell Checking

_Spell
Checking_ describes Cocoa’s spell-checking facilities.

You should read this document if you need to implement spell
checking in your application or if you wish to make your spelling
checker available as a service to other applications.

This document contains the following articles:

- [Spell Checker](Spell%20Checker.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg4zdalkcijbumrchizbq) describes the
  basic features of the spell check facility.
- [Checking Text Spelling](Checking%20Text%20Spelling.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg4zdclkciffemqsbifea) explains
  how to use the spell check facilities from an application.
- [Creating a Spell Server](Creating%20a%20Spell%20Server.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg43talkciffemqsbifea) explains
  how to make your particular spelling checker a service that’s
  available to any application
