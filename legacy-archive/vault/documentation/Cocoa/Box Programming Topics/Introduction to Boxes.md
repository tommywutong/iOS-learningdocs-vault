# Introduction to Boxes

A box is a simple view that can draw a border around itself and title itself. It visually groups together other views, including controls.

This topic discusses how to use the NSBox class.

- [Setting a Box’s Subviews](Setting%20a%20Box%E2%80%99s%20Subviews.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4delkcijbuiqsbirbq) describes how to add subviews to a box.
- [Setting a Box’s Title](Setting%20a%20Box%E2%80%99s%20Title.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4dalkdjjbeiqkcivda) describes how to change the content and appearance of the box’s title.
- [Setting a Box’s Border Appearance](Setting%20a%20Box%E2%80%99s%20Border%20Appearance.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4dclkciffekqkjivcq) describes how to change the appearance of the box’s border.
- [Using a Box to Create a Separator](Using%20a%20Box%20to%20Create%20a%20Separator.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqha3dalkciffekqkjivcq) describes how to create visual separators similar to Carbon’s theme separator.

If you want to group several elements of the same class together, see _[Matrix Programming Guide](../Matrix%20Programming%20Guide/Introduction%20to%20Matrices.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgeydambqgazde2i)_.
