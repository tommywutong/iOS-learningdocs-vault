# 二进制数据编程指南简介

二进制数据可以被封装在 Foundation 和 Core Foundation 的数据对象内部，从而获得操作该数据所需的面向对象行为。由于数据对象是桥接对象，你可以互换使用 Foundation 和 Core Foundation 的数据对象。数据对象能够自动管理字节缓冲区的分配和释放。除此之外，数据对象还可以存储在集合中、写入属性列表、保存到文件，以及通过通信端口传输。

下面这篇文章说明了数据对象的工作原理：

- [数据对象](Data%20Objects.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqge3tclkdjjbeiqsiinba) 介绍了数据对象作为字节缓冲区封装的使用方式。

下面这些文章涵盖了常见任务：

- [使用二进制数据](Working%20With%20Binary%20Data.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg4ytolkdjjbeiqsiinba) 说明了如何创建和使用二进制数据对象。
- [使用可变二进制数据](Working%20With%20Mutable%20Binary%20Data.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambsge2talkdjjbeiqsiinba) 说明了如何修改可变二进制数据对象中的字节。
