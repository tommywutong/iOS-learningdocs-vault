# Introduction to Application Menus and Pop-up Lists

This document describes how menus and popup lists work and how you can use them.

This programming topic contains the following articles:

- [How Menus Work](How%20Menus%20Work.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgi2tslkdjjbeorsdifaq) describes classes for managing menus.
- [Enabling Menu Items](Enabling%20Menu%20Items.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgi3dclkciffeershivca) describes how to enable and disable menu items.
- [Using Menu Item States](Using%20Menu%20Item%20States.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgi3dalkcineugssfiraq) describes how to check and uncheck a menu item by changing its state.
- [Removing a Menu](Removing%20a%20Menu.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga2dsnrvfvjvomi) describes how to programmatically remove a menu from the menu bar.
- [Setting a Menu Item’s Key Equivalent](Setting%20a%20Menu%20Item%E2%80%99s%20Key%20Equivalent.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgi3dilkcijbuiq2bjfdq) describes how to assign a key equivalent to a menu item.
- [Managing Pop-Up Buttons and Pull-Down Lists](Managing%20Pop-Up%20Buttons%20and%20Pull-Down%20Lists.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgi3tilkciffeirkfjjaq) describes how to work with pop-up buttons and pull-down lists.
- [Displaying a Contextual Menu](Displaying%20a%20Contextual%20Menu.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga2dsnryfvjvomi) describes how to display a contextual menu associated with a view.
- [Views in Menu Items](Views%20in%20Menu%20Items.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga2tcnrwfvjvomi) describes how you can provide a menu item with a custom view.
