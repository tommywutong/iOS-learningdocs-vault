# Introduction to Matrices

NSMatrix is a class used for creating groups of NSCells that work together in various ways.

This programming topic contains the following articles:

- [About Matrices](About%20Matrices.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgeydilkcineugscbifdq) provides basic information about matrices
- [Matrix Selection Modes](Matrix%20Selection%20Modes.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgeydklkdjjbegskjifdq) describes how the cells in a matrix behave when the matrix is tracking the mouse.
- [Managing the Matrix’s Cells](Managing%20the%20Matrix%E2%80%99s%20Cells.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgi2tglkdjjbegskjifdq) discusses how to add and remove cells programatically.
- [Setting a Matrix’s Appearance](Setting%20a%20Matrix%E2%80%99s%20Appearance.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgi2tilkdjjbegskjifdq) discusses how to change the appearance of a matrix and its cells.

If you want to group several elements visually, see the _[Box Programming Topics](../Box%20Programming%20Topics/Introduction%20to%20Boxes.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgeydambqgayto2i)_ programming topic.
