# Introduction to Sliders

A slider is a user interface element that displays a range of values and has an indicator, or knob, which indicates the current setting.

[About Sliders](About%20Sliders.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgezdglkcijbugrsjijfa) gives basic information on sliders.

[Using Slider Tick Marks](Using%20Slider%20Tick%20Marks.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgezdilkcineuescgirfa) describes how to set and control the appearance of the tick marks on a slider.

[Setting the Shape Of a Slider](Setting%20the%20Shape%20Of%20a%20Slider.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambsgeytolkdjbceqrkbirba) describes how to specify whether your slider is a horizontal bar, vertical bar, or circular dial.
