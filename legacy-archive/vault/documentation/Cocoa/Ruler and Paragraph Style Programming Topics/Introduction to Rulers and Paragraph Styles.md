# Introduction to Rulers and Paragraph Styles

_Rulers and Paragraph Styles_ describes paragraph styles and the ruler views and markers that enable users to view and change the paragraph style attributes used in text.

You should read this document if you need to work directly with paragraph style objects and their associated ruler views.

This document contains the following articles:

- [About Paragraph Styles](About%20Paragraph%20Styles.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqha3tslkdjjbeerkijjaq) describes paragraph styles and the attributes in them you can change.
- [Breaking Lines by Truncation](Breaking%20Lines%20by%20Truncation.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrhaytclkcijbuossdirfa) describes the line break mode attribute of paragraph styles and illustrates how the truncation settings work in the context of table cells.
- [About Ruler Views](About%20Ruler%20Views.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqha3telkdjjbeerkijjaq) describes what’s in a ruler view and how it works.
- [About Ruler Markers](About%20Ruler%20Markers.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqha3tglkdjjbeerkijjaq) describes what a ruler marker is and how it works.
- [Setting Up a Ruler View](Setting%20Up%20a%20Ruler%20View.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqha3tilkcijbuossdirfa) describes how to add and set up a ruler view for a particular view.
- [Changing a Ruler’s Measurement Units](Changing%20a%20Ruler%E2%80%99s%20Measurement%20Units.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqha3tklkcijbuossdirfa) describes how to set a ruler’s measurement units and how to define your own measurement units.
- [Using a Ruler View’s Client](Using%20a%20Ruler%20View%E2%80%99s%20Client.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqha3tmlkcijbuossdirfa) describes how to set a ruler view’s client and adjust the ruler view’s markers and layout to match the client.
- [Letting Users Manipulate Markers](Letting%20Users%20Manipulate%20Markers.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqha3tqlkciffeqskbifdq) describes how to react when the user adds, removes, and moves markers, or when the user clicks in the ruler view.
- [Updating the Ruler View](Updating%20the%20Ruler%20View.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqha3tolkcifbemrsdjjda) describes how to change the ruler view to reflect the current selection or changes the user makes in the view.

For more information, refer to the following documents:

- _[Text Attribute Programming Topics](../Text%20Attribute%20Programming%20Topics/Introduction%20to%20Text%20Attributes.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgeydambqga4dq2i)_ describes the text-related attributes maintained by the Cocoa text system, including paragraph style attributes.
- _[Attributed String Programming Guide](../Attributed%20String%20Programming%20Guide/Introduction%20to%20Attributed%20String%20Programming%20Guide.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgeydambqgaztm2i)_ provides more details about how the text system stores attributes with strings.
