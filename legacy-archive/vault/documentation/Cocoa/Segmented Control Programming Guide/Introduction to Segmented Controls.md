# Introduction to Segmented Controls

This programming topic describes the use of [NSSegmentedControl](https://developer.apple.com/documentation/appkit/nssegmentedcontrol) and [NSSegmentedCell](https://developer.apple.com/documentation/appkit/nssegmentedcell) to implement a horizontal control made of multiple segments.

This document contains the following articles:

- [Segmented Controls Overview](Segmented%20Controls%20Overview.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambsgi2dslkcijbugrsjijfa) provides basic information on segmented controls.
- [Using Segmented Controls](Using%20Segmented%20Controls.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambsgi2talkcijbugrsjijfa) shows how to configure and interact with segmented controls programatically.
