# Introduction to Cocoa-Java Integration Guide

This document discusses issues that arise when writing Java applications with Cocoa, which is implemented in Objective-C.

Here are the concepts covered:

- [Method Selectors](Method%20Selectors.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqha3dqlkcineukrcgi5aq) discusses how Java can make use of Cocoa’s target-action paradigm using the NSSelector class.
- [Java Memory Management](Java%20Memory%20Management.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrgaydclkcineussckjfda) discusses how Java sometimes has to take Objective-C’s memory management into account when using Cocoa.

Here are the tasks covered:

- [Using NSSelector](Using%20NSSelector.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqha3dslkciffeessdirdq) describes how you use the Java-only class NSSelector to implement target-action behavior.
