# Introduction to Value Transformers

_Value Transformers_ describes the `NSValueTransformer` class, the built-in value transformers and how to write your own subclasses. Value transformers are primarily used by Controller Layer bindings.

You should read this document to gain an understanding of the use of value transformers in applications that use Cocoa bindings. You are expected to be familiar with the basics of Cocoa development, including the Objective-C language and memory management.

This programming topic includes the following articles:

- [Role of Value Transformers](Role%20of%20Value%20Transformers.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambsge3dilkciffekqkjivcq) provides an overview of value transformers.
- [Available Value Transformers](Available%20Value%20Transformers.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambsge3dklkciffekqkjivcq) describes the value transformers provided by the Foundation framework.
- [Writing a Custom Value Transformer](Writing%20a%20Custom%20Value%20Transformer.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambsge3dolkciffekqkjivcq) describes how to implement a value transformer subclass.
- [Registering a Value Transformer](Registering%20a%20Value%20Transformer.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambsge3dmlkciffekqkjivcq) describes how to register your own value transformers.
