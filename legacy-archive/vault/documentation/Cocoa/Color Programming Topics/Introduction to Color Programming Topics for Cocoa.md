# Introduction to Color Programming Topics for Cocoa

The color classes let you specify colors and let users choose colors.

This topic contains the following articles:

- [About Color Spaces](About%20Color%20Spaces.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg42tqlkcijbuqqkdjbaq) describes what color spaces are and which ones are available in the Application Kit.
- [About Color Lists](About%20Color%20Lists.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg42tolkciffeqssfireq) describes what color lists are and how they’re used.
- [Working With Color Spaces](Working%20With%20Color%20Spaces.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaytqmbxfvbegskhjfcucsi) discusses how you can create and convert colors using color-space objects and names and how you can create custom color spaces.
- [Accessing a Color’s Components](Accessing%20a%20Color%E2%80%99s%20Components.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg42tslkciffeershivca) describes how to retrieve a color’s individual components.
- [Accessing System Colors](Accessing%20System%20Colors.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg44talkciffeershivca) describes how to access colors that are controlled by user preferences.
- [Using the System Control Tint](Using%20the%20System%20Control%20Tint.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambsge4dalkcineuersbjbea) describes how to use the system-wide control tint in your custom views and control cells.
- [Choosing Colors With Color Wells and Color Panels](Choosing%20Colors%20With%20Color%20Wells%20and%20Color%20Panels.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg44tclkciffeershivca) describes how to let users select colors using color wells and the color panel.
- [Choosing the Color Pickers in a Color Panel](Choosing%20the%20Color%20Pickers%20in%20a%20Color%20Panel.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg44telkciffeershivca) describes how to choose which color pickers are available in the color panel and which one is selected.
- [Adding Custom Color Pickers to a Color Panel](Adding%20Custom%20Color%20Pickers%20to%20a%20Color%20Panel.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg44tglkciffeershivca) describes how to add color pickers to the color panel.
- [Subclassing NSColor](Subclassing%20NSColor.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg44tilkciffeershivca) describes how to create custom subclasses of NSColor.
- [Storing NSColor in User Defaults](Storing%20NSColor%20in%20User%20Defaults.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambrgy4tglkciffeershivca) describes how to store colors in an application’s user defaults.
