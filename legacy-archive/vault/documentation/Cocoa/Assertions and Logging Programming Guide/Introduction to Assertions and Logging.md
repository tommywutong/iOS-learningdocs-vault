# 断言与日志简介

断言是一种在代码中给定条件为假时打印错误消息并引发异常的机制。日志则用于打印错误或提示性消息，通常输出到标准错误设备。

本编程主题涉及的异常处理，仅限于与给定条件的求值以及消息日志记录相关的部分。若要了解更完整的异常处理技术，即涉及异常对象的引发（或抛出）与处理的技术，请参阅 _[异常编程主题](../Exception%20Programming%20Topics/Introduction%20to%20Exception%20Programming%20Topics%20for%20Cocoa.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgeydambqgayte2i)_。
