# NSDrawer Bindings

|  |  |
| --- | --- |
| __Related class__ | [NSDrawer](https://developer.apple.com/documentation/appkit/nsdrawer) |
| __Availability__ | Available in OS X v10.3 and later. |

A Boolean value that specifies if the `NSDrawer` is visible.

If `visible` evaluates to `YES`, the `NSDrawer` is visible.

__Availability:__Available in OS X v10.3 and later.
