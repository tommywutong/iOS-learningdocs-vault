# Introduction to Combo Boxes

A Combo box is a control that gives the user two ways to enter a value: entering it directly in a text field, or choosing it from a pop-up list of pre-selected values.

Developers who want to incorporate a combo box into their user interface should read this document.

This topic describes how to use a combo box; [How Combo Boxes Work](How%20Combo%20Boxes%20Work.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4tilkcineugrchivda) gives basic information on combo boxes. [Providing Data for a Combo Box](Providing%20Data%20for%20a%20Combo%20Box.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4tklkcineuir2givea) describes how to provide data for the combo box’s pop-up list. [Setting the Combo Box’s Value](Setting%20the%20Combo%20Box%E2%80%99s%20Value.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgi2tmlkdjjbeeq2kijea) describes how to set and retrieve the combo box’s value. [Managing the Combo Box’s List](Managing%20the%20Combo%20Box%E2%80%99s%20List.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqga4tmlkcineugrchivda) describes how to use the combo box’s pop-up list. [Using Automatic Completion in Combo Boxes](Using%20Automatic%20Completion%20in%20Combo%20Boxes.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgi2tolkcineugrchivda) describes how the combo box can try to complete what the user enters into the text field.

Because NSComboBox is a subclass of NSTextField, see _Text Fields_ for more information.
