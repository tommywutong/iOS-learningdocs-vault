# Introduction to Cursor Management

Instances of the `NSCursor` class manage the appearance of the cursor.

The following articles provide an introduction to cursors and their usage:

- [About Cursors](About%20Cursors.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg44tklkdjjbeorsdifaq) describes how cursors work.
- [Setting the Current Cursor](Setting%20the%20Current%20Cursor.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg44tmlkciffeershivca) describes how to change the current cursor being displayed.
