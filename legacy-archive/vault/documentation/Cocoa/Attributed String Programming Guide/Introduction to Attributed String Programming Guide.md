# 属性字符串编程指南简介

_属性字符串编程指南_ 介绍了属性字符串对象——由 `NSAttributedString` 类或 CFAttributedString 这一 Core Foundation 不透明类型实例化而来，用于管理与字符字符串或单个字符相关联的一组文本属性（例如字体和字距）。

如果你需要直接使用属性字符串对象，应阅读本文档。

本编程主题包含以下文章：

- [Attributed Strings](Attributed%20Strings.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqge3dalkciffeur2difeq) 介绍了由 `NSAttributedString`、`NSMutableAttributedString`、CFAttributedString 和 CFMutableAttributedString 实例化的属性字符串对象。
- [Creating Attributed Strings in Cocoa](Creating%20Attributed%20Strings%20in%20Cocoa.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqg4ytilkcijbugr2hinbq) 介绍了如何使用你提供的数据创建属性字符串。
- [Accessing Attributes](Accessing%20Attributes.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqge3dclkciffeeqsdijeq) 介绍了如何访问文本属性。
- [Changing an Attributed String](Changing%20an%20Attributed%20String.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqge3delkcijbuer2dirdq) 介绍了如何更改属性字符串中的字符和属性。
- [Drawing Attributed Strings](Drawing%20Attributed%20Strings.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqge3dglkdjjbeoqsjijfa) 介绍了如何在视图中绘制属性字符串。
- [RTF Files and Attributed Strings](RTF%20Files%20and%20Attributed%20Strings.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqge3dilkcijbuessjijbq) 说明了如何在属性字符串与 RTF 数据文件之间进行读写，并介绍了 Apple 对 RTF 语言的扩展。
- [Word and Line Calculations in Attributed Strings](Word%20and%20Line%20Calculations%20in%20Attributed%20Strings.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqge3dklkcijbumrkii5da) 介绍了如何在编辑器中处理属性字符串。
- [Standard Attributes](Standard%20Attributes.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga2dsmbtfvjvomq) 介绍了包含属性名称的全局 `NSString` 常量。

如需更多信息，请参阅以下文档：

- _[String Programming Guide](../String%20Programming%20Guide/Introduction%20to%20String%20Programming%20Guide.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgeydambqgaztk2i)_ 介绍了在属性字符串中承载 Unicode 字符信息的字符串对象。
- _[Text Attribute Programming Topics](../Text%20Attribute%20Programming%20Topics/Introduction%20to%20Text%20Attributes.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgeydambqga4dq2i)_ 说明了文本系统如何处理应用于文本字符串的各类属性。
