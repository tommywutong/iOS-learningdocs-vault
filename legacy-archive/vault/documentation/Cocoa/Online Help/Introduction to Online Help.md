# Introduction to Online Help

This programming topic describes the various types of on-line help found in OS X. Your application rarely needs to contain code to display on-line help. Instead, you use Interface Builder and Xcode to set up on-line help for your application.

This programming topic contains the following articles:

- [Comprehensive Help](Comprehensive%20Help.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgaytolkcijbugrsiifbq) describes the comprehensive help you can provide.
- [Tooltips](Tooltips.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgq3dslkcijbuqqkejbea) describes the short bits of text that can describe a user interface element.
- [Specifying the Comprehensive Help File](Specifying%20the%20Comprehensive%20Help%20File.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgiydambqgazdalkcijbuorsgjbcq) describes how to specify the location for your comprehensive help.
