# About System Messaging

iOS lets you present a standard email or SMS composition interface from within your app. In both cases, you can programmatically preconfigure the message with recipients and content, which the user can then edit before sending. Outgoing mail and SMS messages are automatically handled by the system’s Mail and Messages queues.

This document includes the following articles:

- [Sending a Mail Message](Sending%20a%20Mail%20Message.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgeydimjvfvjvomi) explains how to use the standard mail composition interface as well as how to write a delegate method for dismissing it when the user is finished.
- [Sending an SMS Message](Sending%20an%20SMS%20Message.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgeydimjwfvjvomi) explains how to configure and present a standard SMS message composition interface, as well as how to dismiss it with a delegate object.
