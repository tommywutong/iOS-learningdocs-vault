# Introduction

The purpose of this document is to help you create compelling and effective advertising for Radio on Apple Music and the App Network. In it you will find best practices for designing and building expanded ad units. You’ll also learn more about the features and functionality that are available to you, and you’ll get specifications for your assets.

In addition to reading this document, you should also familiarize yourself with the guidelines governing any content appearing within a banner or an expanded ad unit by reading the _iAd Content Guidelines_ as well as the guidelines for using Apple products and Apple trademarks on the iAd Network, as outlined in _iAd Guidelines for Advertisers_.

To learn how to design and implement your ad using Apple’s graphical ad-creation environment, read [iAd Producer User Guide](http://help.apple.com/iadproducer/).

To learn how to develop and code your ad using iAd JS, read _iAd Developer's Starter Guide_ and _iAd JS Programming Guide_.

To learn about specific iAd JS APIs, see _iAd JS Library Reference_.
