# Introduction

You can further simplify your iAd JS development by representing iAd JS classes declaratively with a CSS class applied to an HTML element (usually a `div` element). You can set the JavaScript properties of these classes with a combination of CSS classes, CSS properties, and HTML attributes.

[iAd JS Declarative Classes](iAd%20JS%20Declarative%20Classes.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgaytkmzzfvbecssfifeukri) describes the CSS classes that correspond to iAd JS JavaScript classes.

[View Processors](View%20Processors.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgeydcobsfvjvomi) describes powerful HTML attributes you can add to any HTML element in your ad to dramatically simplify interactions between your HTML content and your ad’s view controllers.

[View Controller States](View%20Controller%20States.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqgeydimzyfvjvomi) lists CSS classes that you can use to respond to state changes in your ad’s view controllers.

_iAd JS Programming Guide_ contains a more thorough discussion and several examples of using iAd JS declarative classes.

_iAd JS Library Reference_ describes the iAd JS JavaScript classes that iAd JS declarative classes correspond to.
