# View Controller States

View controller states are CSS classes that are applied to a view controller’s view automatically (or manually with the `enterState` method of the `iAd.ViewController` class). You can respond to changes in a view controller’s state declaratively by creating CSS rules for these classes.

The `ad-view-will-appear` CSS class corresponds to the `VIEW_WILL_APPEAR_STATE` JavaScript state.

Available in iAd JS 1.1 and later.

The `ad-view-did-appear` CSS class corresponds to the `VIEW_DID_APPEAR_STATE` JavaScript state.

Available in iAd JS 1.1 and later.

The `ad-view-will-disappear` CSS class corresponds to the `VIEW_WILL_DISAPPEAR_STATE` JavaScript state.

Available in iAd JS 1.1 and later.

The `ad-view-did-disappear` CSS class corresponds to the `VIEW_DID_DISAPPEAR_STATE` JavaScript state.

Available in iAd JS 1.1 and later.

The `ad-view-builds-in` CSS class corresponds to the `VIEW_BUILDS_IN_STATE` JavaScript state.

Available in iAd JS 1.2 and later.

The `ad-view-builds-out` CSS class corresponds to the `VIEW_BUILDS_OUT_STATE` JavaScript state.

Available in iAd JS 1.2 and later.

The `ad-view-is-idle` CSS class corresponds to the `VIEW_IDLE_STATE` JavaScript state.

Available in iAd JS 1.2 and later.

The `ad-transition-controller-visible` CSS class corresponds to the `VIEW_IS_VISIBLE_STATE` JavaScript state.

Available in iAd JS 1.2 and later.

The `ad-transition-controller-hidden` CSS class corresponds to the `VIEW_IS_HIDDEN_STATE` JavaScript state.

Available in iAd JS 1.2 and later.
