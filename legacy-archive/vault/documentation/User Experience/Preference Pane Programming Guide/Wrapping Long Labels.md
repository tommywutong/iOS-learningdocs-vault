# Wrapping Long Labels

Labels are not automatically wrapped by the system, so very long labels must be manually tagged so that they wrap as desired.

Insert the necessary tags to split a long label into two lines into your preference pane’s `.plist` file, as described in _[Information Property List Key Reference](../../General/Information%20Property%20List%20Key%20Reference/About%20Info.plist%20Keys%20and%20Values.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4tenbx)_. If you need additional guidance, see _[Property List Programming Guide](../../Cocoa/Property%20List%20Programming%20Guide/Introduction%20to%20Property%20Lists.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpgeydambqga2dq2i)_.
