# Introduction

Time Machine is a technology for backing up computers to local and network volumes. The Time Machine Network Interface Specification (TMNIS) describes requirements to which Apple Filing Protocol servers must conform before they can be used to provide Time Machine backup volumes.

You should read this document if you are implementing an Apple Filing Protocol server and wish for that server to be used as a destination volume for Time Machine backups.

This document contains a single chapter, [Time Machine Server Requirements](Time%20Machine%20Server%20Requirements.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqga4dsnjrfvbuqmjqgawvgvzr). This chapter lists the requirements to which a server must conform before it can be used as a Time Machine backup volume.
