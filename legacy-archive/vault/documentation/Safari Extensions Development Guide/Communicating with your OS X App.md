# Communicating with your OS X App

Currently, the best option to communicate with a native OS X app is to use a __Safari App Extension__. Safari app extensions are available starting in Safari 10 on OS X 10.11.5 and later. For more information on writing Safari app extensions, see the [Safari App Extensions](https://developer.apple.com/documentation/safariservices#2191080).
