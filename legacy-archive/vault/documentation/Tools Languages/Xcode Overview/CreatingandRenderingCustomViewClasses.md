## Creating and Rendering Custom View Classes

You can render custom view classes in Interface Builder at design time. You can also add properties from your custom view class to the Attributes inspector.

（原归档配图获取待重试：`IB_OM_H_modified_inspected_values_2x.png`）

For example, you can add a view class that draws a frame with properties for the color and width of the frame. By following the steps in Creating a Custom View That Renders in Interface Builder, the view will draw in Interface Builder and update as the attributes change.
