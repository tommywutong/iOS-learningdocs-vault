## Adding Watch Complications

Use the asset catalog to add the required watch complication placeholders.

（原归档配图获取待重试：`Watch_Complications_2x.png`）

### Adding Complications

Add a new complication by clicking the Add button (+) in an asset catalog and choosing New Watch Complication. Name the complication, then drag images into the appropriate image wells. Each image well is for a different complication template and watch size. For example, the figure above the Modular complication has two image wells, one for a 38mm watch and one for a 42mm watch.

For more information on watch complications, see [Complication Essentials](https://developer.apple.com/library/archive/documentation/General/Conceptual/WatchKitProgrammingGuide/ComplicationEssentials.html#//apple_ref/doc/uid/TP40014969-CH27) in _[App Programming Guide for watchOS](../../General/App%20Programming%20Guide%20for%20watchOS/index.md#apple-f4xwc4dqnrsv64tfmyxwi33df52wszbpkridimbqge2dsnrz)_.
