## Learning from Detailed User Guides

Apple provides detailed teaching guides for developer tool topics, including iOS Simulator, Instruments, app distribution, and continuous integration. To locate user guides for features in Xcode, use the search bar in the Xcode documentation viewer and look for results under Tools Guides.

（原归档配图获取待重试：`ToolsDocSearch_2x.png`）

The _Instruments User Guide_, for example, explains how to use the Instruments app to examine program behavior. Like many developer tool guides, it begins with a quick start tutorial.

### Using Tabs

Use the tab bar in the doc viewer to keep multiple related documents open at once. To create a tab, choose File > New > Tab (or click the Add button (+) in the tab bar).

（原归档配图获取待重试：`TabbedDocViewer_2x.png`）

### Showing the Table of Contents

To hide or show a list of the chapter and section titles for the document, click the “Table of Contents” button (（原归档配图获取待重试：`TOCIcon_2x.png`）) to the left of the search bar .

（原归档配图获取待重试：`InstrumentsUserGuide_2x.png`）

### Browsing the Documentation

Click the Documentation Navigator button (（原归档配图获取待重试：`DocSetNavigator_2x.png`）) to the left of the “Table of Contents” button to display a navigation sidebar. To browse the list of Apple developer documentation installed in Xcode, click the Documentation Library button (（原归档配图获取待重试：`DocLibraryIcon_2x.png`）).

（原归档配图获取待重试：`DocNavigator_2x.png`）

### Searching Documentation

Use the search bar in the Xcode documentation viewer to locate help for a task. In Xcode, choose Help > Documentation and API Reference to display the documentation viewer. As you type in the search field, a menu appears of top search results. Choose a document directly from this menu, or click Show All Results at the bottom to see a comprehensive list of search results.

（原归档配图获取待重试：`DocSearch_2x.png`）

Xcode obtains these results by searching through all of the documentation relevant to your project’s SDK. You’ll find results for API symbols listed under API Reference, programming guide results under SDK Guides, and Xcode documentation results under Tools Guides.

### Bookmarking Documents

For quicker access to documents that you’ll return to, click the Bookmark icon (（原归档配图获取待重试：`BookmarkIcon_2x.png`）) next to a chapter or section title. To display all of your bookmarks, click the Documentation Navigator button (（原归档配图获取待重试：`DocSetNavigator_2x.png`）) to display the navigation sidebar, then click the Bookmark button (（原归档配图获取待重试：`BookmarkButton_2x.png`）) at the top of the sidebar.
