# Apple 旧版归档

这里存放从 [XiyouMobile3G-iOS/apple-developer-archive-vault](https://github.com/XiyouMobile3G-iOS/apple-developer-archive-vault) 迁入的旧版 Apple 文档。

- [完整旧仓库快照](vault/README.md)：来自组织仓库 `main` 的 `c0fc987fe`，包含 5,183 份文档、全部分类索引和本地附件。
- [英文基线](en/README.md) / [中文译文](zh/README.md)：高价值资料的成对翻译工作区，供现行校验工具使用。

旧版资料与现行 DocC 文档的数据模型不同，因此完整快照保持原目录结构；后续新译文继续写入 `en/zh` 配对目录。
