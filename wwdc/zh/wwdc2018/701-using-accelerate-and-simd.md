第二步，我们必须准备 vImage 输入和输出缓冲区。

我们已经在 CV image buffer 中有了这个图像。我们所要做的就是获取信息，如高度和宽度，然后我们可以把它打包成一个 vImage buffer 对象，以便被 vImage 库消费。我们对亮度和色度通道都这样做。

现在我们需要准备一个输出缓冲区。记住，我们还没有为输出图像分配一块内存，所以需要这样做，vImage 有一个便捷函数 vImage buffer in it 来做这个。给定高度、宽度和每像素位数，vImage buffer in it 将分配一块足够大的内存来容纳这个图像，然后还创建一个 vImage buffer 对象，以便被 vImage 库消费。最后一步是把这个处理后的图像放到屏幕上。像我之前说的，RGB 真的是显示的最佳格式，所以让我们使用转换函数把 YCbCr 图像转换成 RGB 图像。然后因为 UI 期望 cgImage 对象，我们必须创建一个。vImage 中有一个便捷函数 vImageCreatesCGImage FromBuffer，它帮助你基于 vImage 中已有的缓冲区创建 cgImage。

需要注意的一点是，我们实际上并没有把图像中的大数据缓冲区从一个地方复制到另一个地方。我们只是创建一个 cgImage 对象，给这个图像缓冲区添加一个容器。所以我们只是填写 cgImage 需要的信息，创建 cgImage 对象，而不是在各处复制数据。一旦有了它，我们就可以把 cgImage 对象发送给 image view，它将被显示在屏幕上。就这么简单。四个步骤，你就可以创建自己的效果，我们向你展示了饱和度效果。现在，vImage 还可以做其他效果。我们可以做旋转，像我之前说的，旋转图像顺时针、逆时针。我们可以做模糊，或者把某物淡入背景。而且你觉得，如果你想要给图像添加一些复古感，你可以对黑白图像做抖动，对彩色图像做颜色量化。让我向你展示它们在 App 中的样子。

对于旋转效果，你可以调用 vImageRotate，并给定旋转角度，它会逆时针或顺时针旋转，以更好地对齐你的图像。

那就是我想要向你展示的四个额外效果，我认为现在是进入下一个主题的好时机。LINPACK 基准测试。我们谈到了 Accelerate 的功能。我们谈到了在你的 App 中使用 Accelerate 有多容易。我们还没有谈 Accelerate 真正有多快。LINPACK 基准测试是做这件事的完美工具。什么是 LINPACK 基准测试？基本上，它试图测量你在机器上求解线性系统有多快。

实际上有三种不同的 LINPACK 基准测试。第一种是求解 100x100 的线性系统。第二种是求解 1000x1000 的。最后一种，也是最有趣的一种，我们今天要用的那种，是无限制的。你可以求解任意大的系统，以充分利用机器上的所有计算能力。让我们看看 iPhone X 使用 Accelerate 的性能。
