但弹簧动画并不只意味着弹跳动画。弹簧确实可以有弹跳，这可能是个好工具，但这不是我们使用弹簧的主要原因。稍后我们再讨论何时使用带弹跳的弹簧，但无弹跳的弹簧也很好！这类非弹跳弹簧被用于 iOS 各处的动画。所以如果不是为了弹跳，弹簧运动好在哪里？再看简单的弹簧动画，注意动画如何结束。它非常缓慢、逐渐地停下来。没有某个瞬间对象突然完成。这比我们预期的对象移动并停止时看到的情况更自然。之所以这个版本感觉更自然，是因为弹簧动画基于物理世界中附在弹簧上的物体的行为，所以我们的双眼看到它运动时感觉更自然、更可信。你可能听过不同属性用弹簧动画时会在不同时间完成，这是真的。如果你习惯计时曲线动画，这可能感觉奇怪。我们不希望所有动画同时开始和停止吗？答案是否定的！我们希望动画感觉像物理世界中我们熟悉的对象运动。通常这些对象会随摩擦力各自开始和停止，所以时间通常不会完全对齐。事实上，对于多属性动画，有时甚至值得更进一步。这是 iOS 上 App 启动的动画。乍看似乎是一个统一的动画，但放慢后，你可以看到不同弹簧、不同开始时间和不同结束时间如何共同组成一个令人惊叹且自然的动画。

现在我们知道了为什么弹簧是如此优秀的动画工具，让我们更仔细地检视弹簧，理解它们如何工作以及如何最好地使用它们。使用弹簧动画时，我们用附在弹簧上的物体的运动来建模。回到物理学，这种运动由 3 个属性定义：物体的质量、弹簧的刚度，以及系统的阻尼——衡量周围环境对物体施加多少摩擦。然后我们用动画的初始位置作为物体的初始位置，用动画的目标位置定义弹簧的静止位置，也就是物体被拉向的位置。然后释放物体开始动画。定义弹簧系统的属性决定了发生的运动类型，改变它们会改变最终动画。

因此创建弹簧动画时，你可以用 mass、stiffness 和 damping 这些相同属性来配置使用哪种弹簧。但虽然它们是建模物理系统的自然方式，对于定义弹簧动画来说并不直观。这里没有真正的质量物体或刚度弹簧，编造这些值来改变曲线并不容易。因此我们一直在完善一种新的弹簧配置方式，更易于理解和使用。它只用 2 个参数：duration 和 bounce。它们的作用符合预期：增加 duration 使动画耗时更长；增加 bounce 为动画添加弹跳。我们正在 Apple 的设计与工程工作中普遍采用它们。因此所有支持弹簧的框架都会使用它们。

当你调整这些弹簧参数时，可以看到曲线上不同的形状类型。当 bounce 大于 0 时，得到过冲目标的弹跳弹簧。当 bounce 为 0 时，得到这条平滑曲线，长尾逐渐趋向目标。还有第三种弹簧。这种不常见，但用负的 bounce 值，你可以得到一条同样长尾逐渐逼近目标、但比 bounce 为 0 时更平缓的曲线。在弹簧物理学中，这些被称为欠阻尼、临界阻尼和过阻尼弹簧。但我更喜欢把它们想成弹跳、平滑和平缓。而且你可能已经注意到，这些弹跳值是百分比，所以弹跳弹簧的弹跳值最高 100%，平缓弹簧的弹跳值在 0 到 -100% 之间。现在我想更深入地探讨这些弹簧。弹簧有时看起来有点吓人，运动也似乎难以理解。但如果我们拆解正在发生的事，它其实是几个简单事物的组合。对我来说，能够理解这些曲线背后的数学，让弹簧感觉更平易近人，所以我想与你分享。但如果你的脑袋被数学搞晕，别担心，完全可选。我们为你实现了所有这些数学。

让我们从弹跳曲线开始。你可能注意到这个弹簧的过冲像更复杂的正弦或余弦波那样振荡。如果我们把弹跳提到最大值 100%，可以看到它现在恰好是余弦波的行为，只是来回振荡。

其物理解释是：这是没有摩擦作用的弹簧，因此它永远振荡而不减速，永远达不到目标位置。如你所料，数学相当简单：就是余弦曲线，时间除以 duration。因此对于这个弹跳值，duration 恰好对应曲线的周期。随着我们降低弹跳，物理上等同于给弹簧添加摩擦或阻尼，使它运动时减速。我们仍然有振荡。事实上，之前的余弦曲线仍然存在，如果叠加绘制会更清楚。这是与之前相同的方程，只是常数不同并水平偏移一点。这解释了曲线中的弹跳，但显然我们还需要别的东西。

在原始曲线中，振荡的幅度随时间变小，或衰减。这就是缺失的部分。这个额外曲线是指数衰减曲线。它是运动的最后一部分，带来逐渐停下来的感觉。

看似复杂的曲线，其实是这两个组件的乘积，称为阻尼余弦或正弦波。这相当令人满足，但如果你仔细看图表，有一件事可能看起来有点奇怪：为什么我们的余弦曲线现在开头有这个下凹？这与我们之前讨论的内容有关：保持速度。记住，对于这个基本情形，我们需要在开始时保持 0 速度。因此我们两个组件曲线乘积的速度在 0 附近应是平的。但注意我们的衰减曲线以向上的斜率开始。如果我们让余弦曲线从平坦开始，初始速度也会向上。因此我们的余弦曲线必须从向下开始，以抵消衰减，得到平的开始。这就是弹簧如何通过在余弦曲线中使用不同的偏移和缩放来匹配任意初始速度。

这个初始速度可以来自手势结束时的速度，然后交接到动画，如我们之前讨论的。还有另一个地方可以提供这个初始速度。让我们在 iPad 上检视。在这里，我们可以点按移动旋钮，并在目标位置显示旋钮的更浅图像。我们也会用更慢的弹簧，以便更容易跟踪发生的事。有时，在动画尚未完成时，会开始一个改变到新目标值的新动画。发生这种情况时，弹簧动画使用它被重新定向时的速度作为朝向新目的地的初始速度，这种速度保持让这类中断感觉平滑、自然。

这就是速度保持与弹跳弹簧的工作方式。现在如果我们降低弹跳，振荡越来越远，直到弹跳完全降到 0，振荡完全消失，我们只剩一条向下延伸并被衰减相乘的直线。因此这些方程更简单。我们只需要直线的基本方程，然后乘以相同的指数，得到最终曲线。

平缓曲线（负弹跳的弹簧）工作方式非常相似，但用两个相加的指数函数而非直线。这种弹簧不太常见，但仅由指数衰减表示的特性使它适合建模衰减速度，如滚动视图中发生的情况。

使用弹簧做动画时你可能想知道的一件事是：弹簧动画到底需要多久才完成？如我们所见，这个问题有点微妙。弹簧的指数衰减意味着技术上它永远移动，只是移动越来越小。当然，我们不希望弹簧动画永远继续，因此需要选择一个移除的时间，当它不再对 UI 产生明显变化时。

弹簧动画完成到足以移除所需的这段时间称为稳定时长。这个稳定时长不同于配置弹簧的 duration 参数。稳定时长取决于许多不同因素，因此可能有点不可预测，但 duration 参数是一个感知时长，被选择为可预测，即使弹簧的其他参数变化也不会移动。因为其不可预测性，你不应等待稳定时长来做面向用户的更改。如果你想在弹簧基本完成时改变 UI，可以使用 SwiftUI 中新的完成处理程序支持，它使用感知时长而非稳定时长。现在我们了解了弹簧如何工作，讨论如何在代码中使用它们。因为弹簧是如此优秀的动画工具，我们如今在 SwiftUI 中把它们作为默认动画，因此你只需调用 withAnimation 就能以弹簧开始。我们还让显式使用弹簧做动画更容易。我们基于 iOS 中使用的弹簧值内置了几个弹簧预设。如果你不确定使用哪些弹簧参数，这些是获得感觉良好的效果的好方法。

你可以在代码中直接使用预设，当你需要动画时。但使用弹簧动画的重要部分是为确切上下文调优，因此这些预设也可以用作可调的起点。你可以取一个预设并指定其 duration 应该不同，或者通过指定要添加的额外弹跳相对量给它多一点或少一点弹跳。这些预设是把弹簧引入 App 的好起点。但如果你想更进一步，也可以用 .spring 动画创建完全自定义的弹簧。这让你可以完全指定弹簧的 duration 和 bounce。这些弹跳值范围从 -1.0 到 1.0。你也可以用相同参数在 UIKit 和 Core Animation 中创建弹簧动画。

还有另一个新弹簧工具，如果你想更进一步。我们给 SwiftUI 添加了 Spring 模型类型，让你可以创建弹簧的表示，包括其参数。这让你可以编程地在指定参数的不同方式之间转换。你也可以用一组参数（如 mass、stiffness 和 damping）创建弹簧模型，然后直接用作弹簧动画。但如果你真的想自己做转换，这里有三个方程，把弹跳和 duration 值转换为 mass、stiffness 和 damping。除了转换参数，你还可以用弹簧模型构建自己的高级弹簧行为。你可以调用弹簧上的方法来获取内置的弹簧求值数学。例如，你可以调用 value 获取弹簧的位置。你只需传入弹簧朝向的目标和你想求值的时间。你也可以在 velocity 方法上使用相同输入来求值弹簧随时间的速度。这让你可以在自己的代码中轻松使用弹簧，对模拟或获取图表值（如本场次的图表）很有用。你甚至可以用它构建自己的自定义动画。只需调用弹簧模型，就可以修改输入或输出来对弹簧动画应用自定义。查看"探索 SwiftUI 动画"了解制作自定义动画的细节。最后我想讨论如何为你的弹簧选择参数。要选择对动画效果很好的值，通常最好先找到一个给你喜欢的节奏的 duration 值。一旦决定，就可以开始调整弹跳量，选择你想要的动画性格和感觉。你会发现不同的弹跳值感觉上有质的不同。弹跳为 0 感觉像平滑、渐进的变化。小弹跳……
