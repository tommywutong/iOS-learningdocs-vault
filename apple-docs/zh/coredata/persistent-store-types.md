# 持久化存储类型

<sub>API 集合</sub>

通过可用的存储类型来持久化数据。

## 主题

### 常量

- [NSSQLiteStoreType](nssqlitestoretype.md) — SQLite 数据库存储类型。
- [NSXMLStoreType](nsxmlstoretype.md) — XML 存储类型。
- [NSBinaryStoreType](nsbinarystoretype.md) — 二进制存储类型。
- [NSInMemoryStoreType](nsinmemorystoretype.md) — 内存存储类型。
