# 流式布局附属视图

<sub>API 集合</sub>

用于指定可通过流式布局呈现的附属视图类型的常量。

## 主题

### 常量

- [UICollectionElementKindSectionHeader](uicollectionview/elementkindsectionheader.md) — 一个附属视图，标识给定分区的页眉。
- [UICollectionElementKindSectionFooter](uicollectionview/elementkindsectionfooter.md) — 一个附属视图，标识给定分区的页脚。

## 另请参阅

### 配置页眉和页脚

- [headerReferenceSize](uicollectionviewflowlayout/headerreferencesize.md) — 用于分区页眉的默认尺寸。
- [footerReferenceSize](uicollectionviewflowlayout/footerreferencesize.md) — 用于分区页脚的默认尺寸。
