# 状态恢复键

<sub>API 集合</sub>

恢复归档中可用的键。

## 主题

### 键

- [UIStateRestorationViewControllerStoryboardKey](uiapplication/staterestorationviewcontrollerstoryboardkey.md) — 引用包含视图控制器的 storyboard。
- [UIApplicationStateRestorationBundleVersionKey](uiapplication/staterestorationbundleversionkey.md) — 负责创建恢复归档的 App 版本。
- [UIApplicationStateRestorationUserInterfaceIdiomKey](uiapplication/staterestorationuserinterfaceidiomkey.md) — App 创建恢复归档时生效的用户界面 idiom。
- [UIApplicationStateRestorationTimestampKey](uiapplication/staterestorationtimestampkey.md) — App 创建恢复归档的时间。
- [UIApplicationStateRestorationSystemVersionKey](uiapplication/staterestorationsystemversionkey.md) — App 创建恢复归档时所在系统的版本。
