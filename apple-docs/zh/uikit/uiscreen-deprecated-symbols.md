# 已废弃符号

<sub>API 集合</sub>

查看不再支持的符号及其替代方案。

## 主题

### 已废弃属性

- [mainScreen](uiscreen/main.md) — 返回代表设备屏幕的屏幕对象。 _(已废弃)_
- [screens](uiscreen/screens.md) — 返回一个数组，其中包含连接到设备的所有屏幕。 _(已废弃)_
- [applicationFrame](uiscreen/applicationframe.md) — App 窗口的 frame 矩形（frame rectangle），以点为单位测量。 _(已废弃)_
- [focusedItem](uiscreen/focuseditem.md) — 当前获得焦点的项目。 _(已废弃)_
- [focusedView](uiscreen/focusedview.md) — 当前获得焦点的视图。 _(已废弃)_
- [supportsFocus](uiscreen/supportsfocus.md) — 一个布尔值，表示屏幕是否支持基于焦点的输入。 _(已废弃)_

### 已废弃通知

- [UIScreenDidConnectNotification](uiscreen/didconnectnotification.md) — 系统在新屏幕连接到设备时发布的通知。 _(已废弃)_
- [UIScreenDidDisconnectNotification](uiscreen/diddisconnectnotification.md) — 系统在屏幕从设备断开连接时发布的通知。 _(已废弃)_
