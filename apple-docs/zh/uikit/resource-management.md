# 资源管理

<sub>API 集合</sub>

管理你用来实现 App 界面的图像、字符串、Storyboard 和 nib 文件。

## 主题

### Storyboard

- [Customizing the behavior of segue-based presentations](customizing-the-behavior-of-segue-based-presentations.md) — 在转场过程中在视图控制器之间传递数据，并以编程方式控制转场何时发生。
- [Dismissing a view controller with an unwind segue](dismissing-a-view-controller-with-an-unwind-segue.md) — 在 Storyboard 文件中配置一个返回转场，动态选择接下来最合适的视图控制器进行显示。
- [UIStoryboard](uistoryboard.md) — 对 Interface Builder Storyboard 资源文件中表示的设计时视图控制器图的封装。
- [UIStoryboardSegue](uistoryboardsegue.md) — 一个为两个视图控制器之间的视觉转场做准备并执行该转场的对象。
- [UIStoryboardUnwindSegueSource](uistoryboardunwindseguesource.md) — 对返回转场相关信息的封装。

### 资源

- [UIImageAsset](uiimageasset.md) — 一个容器，包含以多种方式描述同一件美术作品的一组图像。
- [NSDataAsset](nsdataasset.md) — 来自资源目录中存储的数据集类型的对象。

### nib 文件

- [UINib](uinib.md) — 一个包含 Interface Builder nib 文件的对象。
