# 已废弃符号

<sub>API 集合</sub>

按钮不再支持的符号。

## 主题

### 标题效果

- [reversesTitleShadowWhenHighlighted](uibutton/reversestitleshadowwhenhighlighted.md) — 一个布尔值，决定按钮高亮时标题阴影是否发生变化。 _(已废弃)_

### 按钮呈现方式

- [adjustsImageWhenHighlighted](uibutton/adjustsimagewhenhighlighted.md) — 一个布尔值，决定按钮高亮时图像是否发生变化。 _(已废弃)_
- [adjustsImageWhenDisabled](uibutton/adjustsimagewhendisabled.md) — 一个布尔值，决定按钮禁用时图像是否发生变化。 _(已废弃)_
- [showsTouchWhenHighlighted](uibutton/showstouchwhenhighlighted.md) — 一个布尔值，决定点按按钮是否会使其发光。 _(已废弃)_

### 边缘内边距

- [contentEdgeInsets](uibutton/contentedgeinsets.md) — 环绕按钮全部内容的矩形的内缩或外扩边距。 _(已废弃)_
- [titleEdgeInsets](uibutton/titleedgeinsets.md) — 环绕按钮标题文本的矩形的内缩或外扩边距。 _(已废弃)_
- [imageEdgeInsets](uibutton/imageedgeinsets.md) — 环绕按钮图像的矩形的内缩或外扩边距。 _(已废弃)_

### 尺寸

- [- backgroundRectForBounds:](<uibutton/backgroundrect(forbounds_).md>) — 返回接收者绘制其背景所使用的矩形。 _(已废弃)_
- [- contentRectForBounds:](<uibutton/contentrect(forbounds_).md>) — 返回接收者绘制其全部内容所使用的矩形。 _(已废弃)_
- [- titleRectForContentRect:](<uibutton/titlerect(forcontentrect_).md>) — 返回接收者绘制其标题所使用的矩形。 _(已废弃)_
- [- imageRectForContentRect:](<uibutton/imagerect(forcontentrect_).md>) — 返回接收者绘制其图像所使用的矩形。 _(已废弃)_
