# 已废弃符号

<sub>API 集合</sub>

查看不再支持的符号及其替代方案。

## 主题

### 已废弃

- [persistent](uipasteboard/ispersistent.md) — 一个布尔值，表示粘贴板是否为持久性粘贴板。 _(已废弃)_
- [- setPersistent:](<uipasteboard/setpersistent(__).md>) — 一个布尔值，表示粘贴板是否为持久性粘贴板。 _(已废弃)_
- [detectPatterns(for:completionHandler:)](<uipasteboard/detectpatterns(for_completionhandler_)-5zlnd.md>) — 在不通知用户的情况下，判断第一个粘贴板条目是否匹配指定的模式。 _(已废弃)_
- [detectPatterns(for:inItemSet:completionHandler:)](<uipasteboard/detectpatterns(for_initemset_completionhandler_)-29iwn.md>) — 在不通知用户的情况下，判断粘贴板条目是否匹配指定的模式。 _(已废弃)_
- [detectValues(for:completionHandler:)](<uipasteboard/detectvalues(for_completionhandler_)-9p2ff.md>) — 判断第一个粘贴板条目是否匹配指定的模式，如果找到匹配项则读取其内容。 _(已废弃)_
- [detectValues(for:inItemSet:completionHandler:)](<uipasteboard/detectvalues(for_initemset_completionhandler_)-8y0iw.md>) — 判断粘贴板条目是否匹配指定的模式，如果找到匹配项则读取其内容。 _(已废弃)_
