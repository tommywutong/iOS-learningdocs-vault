# UIKit 数据类型

<sub>API 集合</sub>

UIKit 框架定义了在整个框架多处使用的数据类型。

## 主题

### 数据类型

- [ComponentKey](uitextformattingviewcontroller/componentkey.md) — 预定义的文本格式化视图控制器组件。
- [Highlight](uitextformattingviewcontroller/highlight.md) — 文本格式化高亮状态。
- [TextAlignment](uitextformattingviewcontroller/textalignment.md) — 文本格式化水平对齐状态。
- [TextList](uitextformattingviewcontroller/textlist.md) — 文本格式化文本列表状态。
