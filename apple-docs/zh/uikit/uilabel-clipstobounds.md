# clipsToBounds

<sub>文章</sub>

一个布尔值，用于确定子视图是否被限制在该视图的边界内。

## 概述

`UILabel` 从父类 `UIView` 继承此属性。此类将该属性的默认值改为 [true](../swift/true.md)。
