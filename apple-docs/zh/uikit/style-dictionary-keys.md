# 样式字典键

<sub>API 集合</sub>

包含定义文本样式特征的属性的字典。

## 概述

样式 [NSDictionary](../foundation/nsdictionary.md) 对象用于为标记文本提供样式信息（[markedTextStyle](uitextinput/markedtextstyle.md) 属性），以及在某个位置提供文本样式信息（[- textStylingAtPosition:inDirection:](<uitextinput/textstyling(at_in_).md>) 方法）。

## 主题

### 常量

- [UITextInputTextBackgroundColorKey](uitextinputtextbackgroundcolorkey.md) — 文本的背景颜色。_(已废弃)_
- [UITextInputTextColorKey](uitextinputtextcolorkey.md) — 文本的颜色。_(已废弃)_
- [UITextInputTextFontKey](uitextinputtextfontkey.md) — 文本的字体。_(已废弃)_
