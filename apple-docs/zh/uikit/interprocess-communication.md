# 进程间通信

<sub>API 集合</sub>

向人们显示基于活动的服务。

## 主题

### 用户活动

- [NSUserActivity](../foundation/nsuseractivity.md) — App 在某一时刻状态的表示。
- [UIUserActivityRestoring](uiuseractivityrestoring.md) — 采用以从用户活动恢复对象状态的协议。

### 服务

- [UIActivity](uiactivity.md) — 你为其子类以实现 App 特定服务的抽象类。
- [UIActivityViewController](uiactivityviewcontroller.md) — 用于向人们提供 App 标准服务的视图控制器。
- [UIActivityItemSource](uiactivityitemsource.md) — 活动视图控制器用于检索要操作的数据项的一组方法。
- [UIActivityItemProvider](uiactivityitemprovider.md) — 传递给活动视图控制器的数据的代理。
