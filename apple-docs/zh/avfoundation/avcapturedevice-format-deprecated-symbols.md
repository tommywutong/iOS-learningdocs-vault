# 已废弃符号

<sub>API 集合</sub>

查阅不再支持的符号及其替代方案。

## 主题

### 确定视频防抖动支持

- [videoStabilizationSupported](avcapturedevice/format/isvideostabilizationsupported.md) — 一个布尔值，指示该格式是否支持视频防抖动。 _(已废弃)_

### 确定照片质量

- [highResolutionStillImageDimensions](avcapturedevice/format/highresolutionstillimagedimensions.md) — 系统能为该格式生成的最高分辨率静态图像。 _(已废弃)_

### 确定变焦能力

- [supportedVideoZoomFactorsForDepthDataDelivery](avcapturedevice/format/supportedvideozoomfactorsfordepthdatadelivery.md) — 该格式为深度数据送达所支持的变焦系数。 _(已废弃)_
- [videoMinZoomFactorForDepthDataDelivery](avcapturedevice/format/videominzoomfactorfordepthdatadelivery.md) — 设备在配置为深度数据送达时所支持的最小变焦系数。 _(已废弃)_
- [videoMaxZoomFactorForDepthDataDelivery](avcapturedevice/format/videomaxzoomfactorfordepthdatadelivery.md) — 设备在配置为深度数据送达时所支持的最大变焦系数。 _(已废弃)_
