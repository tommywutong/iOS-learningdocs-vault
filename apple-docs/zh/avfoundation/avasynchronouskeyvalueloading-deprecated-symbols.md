# 已废弃符号

<sub>API 集合</sub>

查阅不再支持的符号及其替代方案。

## 概述

有关基于 Swift 并发特性的替代 API 的信息，请参阅[异步加载媒体数据](loading-media-data-asynchronously.md)。

## 主题

### 加载属性值

- [- loadValuesAsynchronouslyForKeys:completionHandler:](<avasynchronouskeyvalueloading/loadvaluesasynchronously(forkeys_completionhandler_).md>) — 让媒体资源加载所有尚未加载的指定键的值。 _(已废弃)_
- [- statusOfValueForKey:error:](<avasynchronouskeyvalueloading/statusofvalue(forkey_error_).md>) — 返回一个状态，指示属性值是否无需阻塞调用线程即可立即获得。 _(已废弃)_
- [AVKeyValueStatus](avkeyvaluestatus.md) — 指示属性加载状态的值。 _(已废弃)_
