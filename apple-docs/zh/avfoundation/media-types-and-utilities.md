# 媒体类型与实用工具

<sub>API 集合</sub>

识别 AVFoundation 支持的内容类型和文件格式。

## 主题

### 媒体类型

- [AVMediaType](avmediatype.md) — 各种媒体类型的标识符。
- [AVMediaCharacteristic](avmediacharacteristic.md) — 一个定义媒体数据特性的结构。

### 文件类型

- [AVFileType](avfiletype.md) — 各种文件格式的统一类型标识符。
- [AVFileTypeProfile](avfiletypeprofile.md) — 流式格式的文件类型描述文件。

### 实用工具

- [AVMakeRectWithAspectRatioInsideRect](<avmakerect(aspectratio_insiderect_).md>) — 返回一个在边界矩形内保持指定宽高比的缩放后矩形。
