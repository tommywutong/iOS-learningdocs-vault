# 编码器比特率策略值

表示可能的比特率策略取值的常量。

## 概述

这些值与 [AVEncoderBitRateStrategyKey](../avfaudio/avencoderbitratestrategykey.md) 配合使用。

## 主题

### 策略

- [AVAudioBitRateStrategy_Constant](../avfaudio/avaudiobitratestrategy_constant.md) — 表示恒定比特率策略的值。
- [AVAudioBitRateStrategy_LongTermAverage](../avfaudio/avaudiobitratestrategy_longtermaverage.md) — 表示平均比特率策略的值。
- [AVAudioBitRateStrategy_VariableConstrained](../avfaudio/avaudiobitratestrategy_variableconstrained.md) — 表示受约束的可变比特率策略的值。
- [AVAudioBitRateStrategy_Variable](../avfaudio/avaudiobitratestrategy_variable.md) — 表示可变比特率策略的值。
