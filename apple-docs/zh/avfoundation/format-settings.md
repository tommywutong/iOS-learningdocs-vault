# 格式设置

适用于音频播放器和录制器类所支持的所有音频格式的音频设置。

## 主题

### 设置

- [AVFormatIDKey](../avfaudio/avformatidkey.md) — 一个表示音频数据格式的整数值。
- [AVSampleRateKey](../avfaudio/avsampleratekey.md) — 一个表示采样率的浮点值（以赫兹为单位）。
- [AVNumberOfChannelsKey](../avfaudio/avnumberofchannelskey.md) — 一个表示通道数的整数值。

## 另请参阅

### 格式

- [AVAudioFormat](../avfaudio/avaudioformat.md) — 一个描述音频格式表示方式的对象。
- [AVAudioChannelLayout](../avfaudio/avaudiochannellayout.md) — 一个描述一组音频通道各自角色的对象。
- [AVChannelLayoutKey](../avfaudio/avchannellayoutkey.md)
- [线性 PCM 格式设置](linear-pcm-format-settings.md) — 适用于线性 PCM 音频格式的音频设置。
