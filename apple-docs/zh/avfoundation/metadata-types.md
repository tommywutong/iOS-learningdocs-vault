# 元数据类型

<sub>API 集合</sub>

查看该框架支持的元数据对象类型。

## 主题

### 2D 和 3D 码

- [AVMetadataMachineReadableCodeObject](avmetadatamachinereadablecodeobject.md) — 由元数据捕获输出检测到的条形码信息。

### 人脸

- [AVMetadataFaceObject](avmetadatafaceobject.md) — 由元数据捕获输出检测到的人脸信息。

### 头部

- [AVMetadataCatHeadObject](avmetadatacatheadobject.md) — 一个表示猫头部的具体元数据对象子类。
- [AVMetadataDogHeadObject](avmetadatadogheadobject.md) — 一个表示狗头部的具体元数据对象子类。

### 身体

- [AVMetadataBodyObject](avmetadatabodyobject.md) — 一个为元数据身体对象定义接口的抽象类。
- [AVMetadataCatBodyObject](avmetadatacatbodyobject.md) — 一个表示图片中检测到的单个猫身体的对象。
- [AVMetadataDogBodyObject](avmetadatadogbodyobject.md) — 一个表示图片中检测到的单个狗身体的对象。
- [AVMetadataHumanBodyObject](avmetadatahumanbodyobject.md) — 一个表示图片中检测到的单个人体的对象。
- [AVMetadataHumanFullBodyObject](avmetadatahumanfullbodyobject.md) — 一个表示图片中检测到的完整人体的对象。

### 显著区域

- [AVMetadataSalientObject](avmetadatasalientobject.md) — 一个表示图片中单个显著区域的对象。

## 另请参阅

### 元数据捕获

- [AVCaptureMetadataInput](avcapturemetadatainput.md) — 一种用于向捕获会话提供定时元数据的捕获输入。
- [AVCaptureMetadataOutput](avcapturemetadataoutput.md) — 一种用于处理由捕获会话产生的定时元数据的捕获输出。
- [AVMetadataObject](avmetadataobject.md) — 由元数据捕获输出提供的对象的抽象超类。
