# Comparable 实现

<sub>API 集合</sub>

## 主题

### 运算符

- [...(_:)](<'...(__)-1sif9.md>) — 返回从下界向上延伸的部分范围。
- [...(_:)](<'...(__)-6i99j.md>) — 返回到上界并包含上界的部分范围。
- [...(_:_:)](<'...(____).md>) — 返回包含两个边界的闭区间。
- [..<(_:)](<'.._(__).md>) — 返回到上界但不包含上界的部分范围。
- [..<(_:_:)](<'.._(____).md>) — 返回包含下界但不包含上界的半开区间。
- [<(_:_:)](<_(____).md>) — 返回一个布尔值，指示第一个参数的值是否小于第二个参数的值。
- [>(_:_:)](<_(____)-6spv6.md>) — 返回一个布尔值，指示第一个参数的值是否大于第二个参数的值。
- [<=(_:_:)](<_=(____)-3twpp.md>) — 返回一个布尔值，指示第一个参数的值是否小于或等于第二个参数的值。
- [>=(_:_:)](<_=(____)-5a3de.md>) — 返回一个布尔值，指示第一个参数的值是否大于或等于第二个参数的值。
