# 全局数值函数

<sub>API 集合</sub>

将这些函数用于数值以及其他可比较的类型。

## 主题

### 选出最小值和最大值

- [min(_:_:)](<min(____).md>) — 返回两个可比较值中较小的一个。
- [min(_:_:_:_:)](<min(________).md>) — 返回传入参数中最小的一个。
- [max(_:_:)](<max(____).md>) — 返回两个可比较值中较大的一个。
- [max(_:_:_:_:)](<max(________).md>) — 返回传入参数中最大的一个。

### 求绝对值

- [abs(_:)](<abs(__).md>) — 返回给定数值的绝对值。
