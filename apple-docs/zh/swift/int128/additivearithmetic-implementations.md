# AdditiveArithmetic 实现

<sub>API 集合</sub>

## 主题

### 运算符

- [+(_:)](<+(__).md>) — 返回未更改的给定数字。
- [+(_:_:)](<+(____).md>) — 将两个值相加并产生它们的和。
- [+=(_:_:)](<+=(____).md>) — 将两个值相加，并将结果存储在左侧变量中。
- [-(_:_:)](<-(____).md>) — 用一个值减去另一个值并产生它们的差。
- [-=(_:_:)](<-=(____).md>) — 从第一个值中减去第二个值，并将差值存储在左侧变量中。
