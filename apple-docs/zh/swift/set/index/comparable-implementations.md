# Comparable 实现

<sub>API 集合</sub>

## 主题

### 运算符

- [...(_:)](<'...(__)-30fi7.md>) — 返回一个到（且包含）上界的部分区间。
- [...(_:)](<'...(__)-61uj4.md>) — 返回一个从下界向上延伸的部分区间。
- [...(_:_:)](<'...(____).md>) — 返回一个同时包含其两个边界的闭合区间。
- [..\<(_:)](<'.._(__).md>) — 返回一个到（但不包含）上界的部分区间。
- [..\<(_:_:)](<'.._(____).md>) — 返回一个包含下界但不包含上界的半开区间。
- [\<(_:_:)](<_(____).md>) — 返回一个布尔值，指示第一个参数的值是否小于第二个参数的值。
- [\>(_:_:)](<_(____)-46ohg.md>) — 返回一个布尔值，指示第一个参数的值是否大于第二个参数的值。
- [\>=(_:_:)](<_=(____)-85ahe.md>) — 返回一个布尔值，指示第一个参数的值是否大于或等于第二个参数的值。
- [\<=(_:_:)](<_=(____)-9skvc.md>) — 返回一个布尔值，指示第一个参数的值是否小于或等于第二个参数的值。
