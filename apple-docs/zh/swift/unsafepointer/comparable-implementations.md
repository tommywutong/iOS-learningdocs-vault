# Comparable 实现

<sub>API 集合</sub>

## 主题

### 运算符

- [...(_:)](<'...(__)-4mm4r.md>) — 返回一个包含其上界在内的部分范围。
- [...(_:)](<'...(__)-6ct5j.md>) — 返回一个从下界向上扩展的部分范围。
- [...(_:_:)](<'...(____).md>) — 返回一个包含其两个边界的闭区间（closed range）。
- [..\<(_:)](<'.._(__).md>) — 返回一个上界不包含在内的部分范围。
- [..\<(_:_:)](<'.._(____).md>) — 返回一个包含下界但不包含上界的半开区间（half-open range）。
- [\>(_:_:)](<_(____)-3izr0.md>) — 返回一个布尔值，指示第一个参数的值是否大于第二个参数的值。
- [\<(_:_:)](<_(____)-fe61.md>) — 返回一个布尔值，指示第一个参数的值是否小于第二个参数的值。
- [\<=(_:_:)](<_=(____)-5i1qx.md>) — 返回一个布尔值，指示第一个参数的值是否小于或等于第二个参数的值。
- [\>=(_:_:)](<_=(____)-5nvy9.md>) — 返回一个布尔值，指示第一个参数的值是否大于或等于第二个参数的值。
