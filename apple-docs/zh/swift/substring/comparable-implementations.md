# Comparable 实现

<sub>API 集合</sub>

## 主题

### 运算符

- [...(_:)](<'...(__)-4mm5k.md>) — 返回一个直到（并包含）其上界的部分范围。
- [...(_:)](<'...(__)-6ct6c.md>) — 返回一个从下界向上延伸的部分范围。
- [...(_:_:)](<'...(____).md>) — 返回一个包含两个边界的封闭范围。
- [..\<(_:)](<'.._(__).md>) — 返回一个直到（但不包括）其上界的部分范围。
- [..\<(_:_:)](<'.._(____).md>) — 返回一个包含下界但不包含上界的半开范围。
- [\>(_:_:)](<_(____)-3izq7.md>) — 返回一个布尔值，指示第一个实参的值是否大于第二个实参的值。
- [\<=(_:_:)](<_=(____)-5i1ru.md>) — 返回一个布尔值，指示第一个实参的值是否小于或等于第二个实参的值。
- [\>=(_:_:)](<_=(____)-5nvz6.md>) — 返回一个布尔值，指示第一个实参的值是否大于或等于第二个实参的值。
