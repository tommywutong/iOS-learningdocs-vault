# 数字与基本值

<sub>API 集合</sub>

使用数字、布尔值和其他基础类型对数据建模。

## 主题

### 逻辑值

- [Bool](bool.md) — 一种值类型，其实例要么是 `true`，要么是 `false`。

### 数值

- [Int](int.md) — 一种有符号整数值类型。
- [Double](double.md) — 一种双精度（64 位）浮点值类型。
- [Float](float.md) — 一种单精度（32 位）浮点值类型。

### 范围

- [Range](range.md) — 从下界到上界（不含上界）的一个半开区间。
- [ClosedRange](closedrange.md) — 从下界到上界（含上界）的一个区间。

### 错误

- [Error](error.md) — 表示可被抛出的错误值的一种类型。
- [Result](result.md) — 一种表示成功或失败的值，两种情况下都包含一个相关联的值。

### 可选值

- [Optional](optional.md) — 表示一个被包装的值或值的缺失的一种类型。

### 高级数值运算

- [Numeric Protocols](numeric-protocols.md) — 编写适用于任意数值类型的泛型代码。
- [Special-Use Numeric Types](special-use-numeric-types.md) — 使用不同大小的固定宽度数值类型。
- [SIMD Vector Types](simd-vector-types.md) — 使用不同大小的固定宽度数值类型构成的固定宽度向量。
- [Global Numeric Functions](global-numeric-functions.md) — 将这些函数用于数值和其他可比较的类型。

### 随机数生成器

- [SystemRandomNumberGenerator](systemrandomnumbergenerator.md) — 系统默认的随机数据来源。
- [RandomNumberGenerator](randomnumbergenerator.md) — 提供均匀分布随机数据的一种类型。
