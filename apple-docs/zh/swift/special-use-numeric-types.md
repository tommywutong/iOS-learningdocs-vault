# 特殊用途数值类型

<sub>API 集合</sub>

使用不同大小的固定宽度数值类型。

## 主题

### 无符号整数

- [UInt](uint.md) — 一个无符号整数值类型。
- [UInt8](uint8.md) — 一个 8 位无符号整数值类型。
- [UInt16](uint16.md) — 一个 16 位无符号整数值类型。
- [UInt32](uint32.md) — 一个 32 位无符号整数值类型。
- [UInt64](uint64.md) — 一个 64 位无符号整数值类型。
- [UInt128](uint128.md) — 一个 128 位无符号整数值类型。

### 有符号整数

- [Int8](int8.md) — 一个 8 位有符号整数值类型。
- [Int16](int16.md) — 一个 16 位有符号整数值类型。
- [Int32](int32.md) — 一个 32 位有符号整数值类型。
- [Int64](int64.md) — 一个 64 位有符号整数值类型。
- [Int128](int128.md) — 一个 128 位有符号整数值类型。

### 整数类型之间的转换

- [numericCast(_:)](<numericcast(__).md>) — 返回给定整数在另一种整数类型中的等价值。

### 浮点值

- [Float16](float16.md) — 一个半精度（16 位）浮点值类型。
- [Float80](float80.md) — 一个扩展精度浮点值类型。

### 浮点类型别名

- [Float32](float32.md) — 一个 32 位浮点类型。
- [Float64](float64.md) — 一个 64 位浮点类型。
