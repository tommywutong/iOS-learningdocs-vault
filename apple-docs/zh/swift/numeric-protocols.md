# 数值协议

<sub>API 集合</sub>

编写适用于任意数值类型的泛型代码。

## 主题

### 基本算术运算

- [AdditiveArithmetic](additivearithmetic.md) — 其值支持加法和减法运算的一种类型。
- [Numeric](numeric.md) — 其值支持乘法运算的一种类型。
- [SignedNumeric](signednumeric.md) — 具有取负运算的一种数值类型。
- [Strideable](strideable.md) — 表示可以被偏移和测量的连续一维值的一种类型。

### 整数

- [BinaryInteger](binaryinteger.md) — 具有二进制表示的一种整数类型。
- [FixedWidthInteger](fixedwidthinteger.md) — 每个实例都使用固定大小的一种整数类型。
- [SignedInteger](signedinteger.md) — 既能表示正值也能表示负值的一种整数类型。
- [UnsignedInteger](unsignedinteger.md) — 只能表示非负值的一种整数类型。

### 浮点数

- [FloatingPoint](floatingpoint.md) — 一种浮点数值类型。
- [BinaryFloatingPoint](binaryfloatingpoint.md) — 一种基数为 2（二进制）的浮点类型。

### 浮点数特性

- [FloatingPointClassification](floatingpointclassification.md) — IEEE 754 浮点数的分类。
- [FloatingPointRoundingRule](floatingpointroundingrule.md) — 浮点数的一种舍入规则。
- [FloatingPointSign](floatingpointsign.md) — 浮点值的符号。
