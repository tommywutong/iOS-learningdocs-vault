# 字符串与文本

<sub>API 集合</sub>

使用 Unicode 安全的字符串处理文本。

## 主题

### 字符串与字符

- [String](string.md) — 一个 Unicode 字符串值，是字符的集合。
- [Character](character.md) — 一个单独的扩展字素簇（extended grapheme cluster），近似表示一个用户可感知的字符。

### 正则表达式

- [Regex](regex.md) — 一个正则表达式。
- [RegexRepetitionBehavior](regexrepetitionbehavior.md) — 指定使用量词（quantifier）时尝试匹配的程度。
- [RegexSemanticLevel](regexsemanticlevel.md) — 正则表达式匹配期间使用的语义级别。
- [RegexWordBoundaryKind](regexwordboundarykind.md) — 正则表达式匹配期间使用的单词边界算法。
- [AnyRegexOutput](anyregexoutput.md) — 正则表达式匹配的类型擦除的动态输出。
- [RegexComponent](regexcomponent.md) — 一种表示正则表达式的类型。
- [CustomConsumingRegexComponent](customconsumingregexcomponent.md)

### 编码与存储

- [Unicode](unicode.md) — 一个用于 Unicode 实用工具的命名空间。

### 编译期字符串

- [StaticString](staticstring.md) — 一种设计用来表示编译时已知的文本的字符串类型。
