# 键路径表达式

<sub>API 集合</sub>

使用键路径表达式动态访问属性。

## 主题

### 键路径

- [KeyPath](keypath.md) — 从特定根类型到特定结果值类型的键路径。
- [PartialKeyPath](partialkeypath.md) — 一个部分类型擦除的键路径，从具体根类型到任意结果值类型。
- [AnyKeyPath](anykeypath.md) — 一个类型擦除的键路径，从任意根类型到任意结果值类型。

### 可写键路径

- [WritableKeyPath](writablekeypath.md) — 支持读取和写入结果值的键路径。
- [ReferenceWritableKeyPath](referencewritablekeypath.md) — 支持以引用语义读取和写入结果值的键路径。
