# OSLogBoolFormat.truth

<sub>枚举 case</sub>

将布尔值格式化为 true 或 false 字符串的选项。

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case truth
```

## 讨论

此选项会把布尔值 true 格式化为 `true`，把布尔值 false 格式化为 `false`。
