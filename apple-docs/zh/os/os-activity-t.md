# os_activity_t

<sub>API 集合</sub>

一个表示由用户触发的活动的对象。

## 概述

Activity Tracing API 提供了一种机制，用于对响应用户交互或其他事件所完成的工作进行分组和标记，这样你就能看到与触发该操作相关的所有日志消息。
