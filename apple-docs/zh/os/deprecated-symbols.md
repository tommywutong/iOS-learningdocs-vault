# 已废弃的符号

<sub>API 集合</sub>

查看不再受支持的符号及其替代方案。

## 主题

### 已废弃的函数

- [os_trace_debug_enabled](<os_trace_debug_enabled().md>) — 返回是否已启用 debug 级别的 trace 信息。 _(已废弃)_
- [os_trace_info_enabled](<os_trace_info_enabled().md>) — 返回是否已启用 info 级别的 trace 信息。 _(已废弃)_
- [os_trace_type_enabled](<os_trace_type_enabled(__).md>) — 返回是否已启用指定的 info 级别 trace 信息。 _(已废弃)_

### 已废弃的宏

- [OS_TRACE_TYPE_DEBUG](os_trace_type_debug.md) — 附加调试器时出现的 trace 消息。 _(已废弃)_
- [OS_TRACE_TYPE_INFO](os_trace_type_info.md) — 附加调试器且请求了额外信息时出现的 trace 消息。 _(已废弃)_
- [OS_TRACE_TYPE_RELEASE](os_trace_type_release.md) — 安装到用户设备上的 App 需要捕获的 trace 消息。 _(已废弃)_

### 已废弃的类型别名

- [os_trace_payload_object_t](os_trace_payload_object_t.md) — 指向 trace 负载对象的指针。 _(已废弃)_
