# disabled

<sub>类型属性</sub>

一个已禁用的 Logger，运行时不会发出日志消息。可用于关闭通过某个特定 logger 变量发出的所有日志记录。

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static var disabled: Logger { get }
```
