# 遗留的日志记录符号

<sub>API 集合</sub>

把你的代码从这些遗留符号迁移出来。

## 主题

### 日志消息

- [os_log(_:)](<os_log(__).md>) — 向默认子系统添加一条新的日志消息。 _(已废弃)_
- [os_log(_:log:_:)](<os_log(__log___).md>) — 使用可选的日志对象和日志级别添加一条新的日志消息。 _(已废弃)_
- [os_log(_:dso:log:_:_:)](<os_log(__dso_log_____).md>) — 向日志系统发送一条消息，可以选择指定自定义日志对象、日志级别以及任意消息格式参数。 _(已废弃)_
- [os_log(_:dso:log:type:_:)](<os_log(__dso_log_type___).md>) — 向日志系统发送一条消息，可以选择指定自定义日志对象、日志级别以及任意消息格式参数。 _(已废弃)_
