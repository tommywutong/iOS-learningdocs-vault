# 架构类型

<sub>API 集合</sub>

用于标识可执行文件架构类型的常量。

## 主题

### 常量

- [kCFBundleExecutableArchitectureI386](kcfbundleexecutablearchitecturei386.md) — 指定 32 位 Intel 架构。
- [kCFBundleExecutableArchitecturePPC](kcfbundleexecutablearchitectureppc.md) — 指定 32 位 PowerPC 架构。
- [kCFBundleExecutableArchitectureARM64](kcfbundleexecutablearchitecturearm64.md)
- [kCFBundleExecutableArchitectureX86_64](kcfbundleexecutablearchitecturex86_64.md) — 指定 64 位 Intel 架构。
- [kCFBundleExecutableArchitecturePPC64](kcfbundleexecutablearchitectureppc64.md) — 指定 64 位 PowerPC 架构。
