# 提醒级别

<sub>API 集合</sub>

标识用户通知严重程度的标志。

## 概述

如果你指定了要在对话框中显示的图标，该图标会覆盖每个提醒级别所用的默认图标。

## 主题

### 常量

- [kCFUserNotificationStopAlertLevel](kcfusernotificationstopalertlevel.md) — 通知非常严重。
- [kCFUserNotificationNoteAlertLevel](kcfusernotificationnotealertlevel.md) — 通知不太严重。
- [kCFUserNotificationCautionAlertLevel](kcfusernotificationcautionalertlevel.md) — 通知有一定严重性。
- [kCFUserNotificationPlainAlertLevel](kcfusernotificationplainalertlevel.md) — 通知不严重。
