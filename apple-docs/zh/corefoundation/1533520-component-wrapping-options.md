# 组件回绕选项

<sub>API 集合</sub>

回绕选项指定日历计算中日历组件的溢出行为

## 概述

回绕选项指定日历计算中日历组件的溢出行为——参见 [CFCalendarAddComponents](cfcalendaraddcomponents.md) 和 [CFCalendarGetComponentDifference](cfcalendargetcomponentdifference.md)。

## 主题

### 常量

- [kCFCalendarComponentsWrap](kcfcalendarcomponentswrap.md) — 指定为日历组件指定的那些组件应递增，并在溢出时回绕到零/一，但不应导致更高单位递增。

## 另请参阅

### 常量

- [CFCalendarUnit](cfcalendarunit.md) — CFCalendarUnit 常量用于在各种日历计算中指定历法单位，例如日或月。
