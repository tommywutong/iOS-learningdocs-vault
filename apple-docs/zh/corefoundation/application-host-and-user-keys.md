# 应用程序、主机与用户键

<sub>API 集合</sub>

用于指定常用偏好域的键。

## 概述

并非所有应用程序、主机与用户的组合都是受支持的偏好域。具体而言，`kCFPreferencesAnyHost` 不支持与其他选项的任何组合。

## 主题

### 常量

- [kCFPreferencesAnyApplication](kcfpreferencesanyapplication.md) — 指示适用于任何应用程序的偏好设置。
- [kCFPreferencesAnyHost](kcfpreferencesanyhost.md) — 指示适用于任何主机的偏好设置。
- [kCFPreferencesAnyUser](kcfpreferencesanyuser.md) — 指示适用于任何用户的偏好设置。
- [kCFPreferencesCurrentApplication](kcfpreferencescurrentapplication.md) — 指示仅适用于当前应用程序的偏好设置。
- [kCFPreferencesCurrentHost](kcfpreferencescurrenthost.md) — 指示仅适用于当前主机的偏好设置。
- [kCFPreferencesCurrentUser](kcfpreferencescurrentuser.md) — 指示仅适用于当前用户的偏好设置。
