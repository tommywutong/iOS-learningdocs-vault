# 通知投递选项

<sub>API 集合</sub>

投递通知时可用的选项。

## 概述

调用 [CFNotificationCenterPostNotificationWithOptions](<cfnotificationcenterpostnotificationwithoptions(__________).md>) 函数时使用这些常量。

## 主题

### 常量

- [kCFNotificationDeliverImmediately](kcfnotificationdeliverimmediately.md) — 立即投递通知。
- [kCFNotificationPostToAllSessions](kcfnotificationposttoallsessions.md) — 向所有会话投递通知。

## 另请参阅

### 常量

- [CFNotificationSuspensionBehavior](cfnotificationsuspensionbehavior.md) — 挂起标志，指示当接收应用程序位于后台时，应如何处理分布式通知。
