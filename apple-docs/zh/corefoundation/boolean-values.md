# 布尔值

<sub>API 集合</sub>

CFBoolean 求值为 true 或 false；其中 `kCFBooleanTrue` 为 true 值，`kCFBooleanFalse` 为 false 值。

## 主题

### 常量

- [kCFBooleanTrue](kcfbooleantrue.md) — 布尔 true 值。
- [kCFBooleanFalse](kcfbooleanfalse.md) — 布尔 false 值。
