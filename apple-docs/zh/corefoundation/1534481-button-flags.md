# 按钮标志

<sub>API 集合</sub>

用于更改用户通知对话框中按钮显示方式的标志。

## 概述

在使用 [CFUserNotificationCreate](<cfusernotificationcreate(__________).md>) 创建用户通知时指定这些标志。

## 主题

### 常量

- [kCFUserNotificationNoDefaultButtonFlag](kcfusernotificationnodefaultbuttonflag.md) — 显示不带默认、备选或其他按钮的对话框。
- [kCFUserNotificationUseRadioButtonsFlag](kcfusernotificationuseradiobuttonsflag.md) — 为用户通知描述字典中 [kCFUserNotificationCheckBoxTitlesKey](kcfusernotificationcheckboxtitleskey.md) 数组的元素创建一组单选按钮，而不是复选框。
