# Safari 发行说明

了解 iOS、iPadOS、macOS 以及 visionOS 上 Safari 与 Safari View Controller 的变更；iOS、iPadOS、macOS、watchOS 以及 visionOS 上 WKWebView 的变更；以及 macOS 上 Web Inspector 的变更。

## 概述

Safari 是一款可在 iOS 和 macOS 上使用的 Web 浏览器 App 及 Web 技术平台。它基于 WebKit 构建，WebKit 是一个实现了 Web 标准的快速开源 Web 渲染引擎。Safari 包含诸多 Apple Web 创新功能，例如智能防跟踪、阅读器模式、Safari App 扩展和 Web Inspector。
