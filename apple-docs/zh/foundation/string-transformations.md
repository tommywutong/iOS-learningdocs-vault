# 字符串变换

<sub>API 集合</sub>

这些常量指定 [- applyTransform:reverse:range:updatedRange:](<nsmutablestring/applytransform(__reverse_range_updatedrange_).md>) 方法所使用的变换。

## 主题

### 常量

- [NSStringTransformLatinToKatakana](stringtransform/latintokatakana.md) — 一个常量，包含把字符串从拉丁字母转写为片假名的操作。
- [NSStringTransformLatinToHiragana](stringtransform/latintohiragana.md) — 一个常量，包含把字符串从拉丁字母转写为平假名的操作。
- [NSStringTransformLatinToHangul](stringtransform/latintohangul.md) — 一个常量，包含把字符串从拉丁字母转写为谚文的操作。
- [NSStringTransformLatinToArabic](stringtransform/latintoarabic.md) — 一个常量，包含把字符串从拉丁字母转写为阿拉伯文字的操作。
- [NSStringTransformLatinToHebrew](stringtransform/latintohebrew.md) — 一个常量，包含把字符串从拉丁字母转写为希伯来文字的操作。
- [NSStringTransformLatinToThai](stringtransform/latintothai.md) — 一个常量，包含把字符串从拉丁字母转写为泰文的操作。
- [NSStringTransformLatinToCyrillic](stringtransform/latintocyrillic.md) — 一个常量，包含把字符串从拉丁字母转写为西里尔字母的操作。
- [NSStringTransformToLatin](stringtransform/tolatin.md) — 一个常量，包含把字符串从任意文字转写为拉丁字母的操作。
- [NSStringTransformMandarinToLatin](stringtransform/mandarintolatin.md) — 一个常量，包含把字符串从汉字音译为拉丁字母的操作。
- [NSStringTransformHiraganaToKatakana](stringtransform/hiraganatokatakana.md) — 一个常量，包含把字符串从平假名转写为片假名的操作。
- [NSStringTransformFullwidthToHalfwidth](stringtransform/fullwidthtohalfwidth.md) — 一个常量，包含把字符串从中日韩全角字符变换为半角形式的操作。
- [NSStringTransformToXMLHex](stringtransform/toxmlhex.md) — 一个常量，包含把字符串从字符变换为 XML 十六进制转义码的操作。
- [NSStringTransformToUnicodeName](stringtransform/tounicodename.md) — 一种把字符转换为 Unicode 名称的变换的标识符。
- [NSStringTransformStripCombiningMarks](stringtransform/stripcombiningmarks.md) — 一个常量，包含通过移除组合标记来变换字符串的操作。
- [NSStringTransformStripDiacritics](stringtransform/stripdiacritics.md) — 一个常量，包含通过移除变音符号来变换字符串的操作。
