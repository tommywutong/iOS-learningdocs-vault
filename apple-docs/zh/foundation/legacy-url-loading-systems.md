# 旧版 URL 加载系统

<sub>API 集合</sub>

将你的代码迁移出这些旧版对象。

## 主题

### URL 连接

- [NSURLConnection](nsurlconnection.md) — 一个使你能够启动和停止 URL 请求的对象。
- [NSURLConnectionDelegate](nsurlconnectiondelegate.md) — 一个由 URL 连接的委托实现的协议，用于接收连接对象的状态并向其提供反馈。
- [NSURLConnectionDataDelegate](nsurlconnectiondatadelegate.md) — 一个由 URL 连接的大多数委托实现的协议，用于接收与该连接关联的数据。
- [NSURLConnectionDownloadDelegate](nsurlconnectiondownloaddelegate.md) — 一个由使用 Newsstand Kit 创建的 URL 连接的委托实现的协议，用于接收与下载关联的数据。

### URL 下载

- [NSURLDownload](nsurldownload.md) — 一个异步下载资源并将数据保存到文件的对象。
- [NSURLDownloadDelegate](nsurldownloaddelegate.md) — 一个由 URL 下载委托实现的协议，用于与 URL 下载请求进行交互。

### URL 句柄

- [NSURLHandle](nsurlhandle.md) — 一个访问并管理由 URL 指示的资源数据的对象。

### URL 认证挑战发送方

- [URLAuthenticationChallengeSender](urlauthenticationchallengesender.md) — `URLAuthenticationChallengeSender` 协议表示认证挑战的发送方必须实现的接口。
