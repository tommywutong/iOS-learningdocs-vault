# AttributedStringProtocol 实现

<sub>API 集合</sub>

## 主题

### 实例属性

- [characters](characters.md) — 带属性字符串的字符，作为对底层字符串的一个视图。
- [endIndex](endindex.md) — 该字符串末尾之后的位置——比最后一个有效下标参数大 1 的位置。
- [runs](runs-swift.property.md) — 带属性字符串的属性串，作为对底层字符串的一个视图。
- [startIndex](startindex.md) — 某个非空属性化字符串中第一个字符的位置。
- [unicodeScalars](unicodescalars.md) — 带属性字符串的 Unicode 标量，作为对底层字符串的一个视图。
- [utf16](utf16.md) — 将带属性字符串的内容视为 UTF-16 码元集合的一个视图。
- [utf8](utf8.md) — 将带属性字符串的内容视为 UTF-8 码元集合的一个视图。

### 下标

- [subscript(_:)](<subscript(__)-2vqsz.md>) — 使用范围指示子字符串边界，返回带属性字符串的一个子字符串。
- [subscript(dynamicMember:)](<subscript(dynamicmember_)-34zdf.md>) — 返回键路径所指示的属性值。
- [subscript(dynamicMember:)](<subscript(dynamicmember_)-9modq.md>) — 返回键路径所指示的范围化属性容器。
