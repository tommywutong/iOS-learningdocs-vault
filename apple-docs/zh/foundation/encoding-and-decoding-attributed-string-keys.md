# 编码和解码属性字符串键

<sub>API 集合</sub>

属性键（attribute key）采用这些协议，以对数据进行编码和解码。

## 主题

### 编码和解码键

- [DecodableAttributedStringKey](decodableattributedstringkey.md) — 一个协议，用于定义属性键如何解码其值。
- [EncodableAttributedStringKey](encodableattributedstringkey.md) — 一个协议，用于定义属性键如何编码其值。
- [CodableAttributedStringKey](codableattributedstringkey.md) — 同时可编码和可解码的属性键所使用的类型别名。

### Markdown 键

- [MarkdownDecodableAttributedStringKey](markdowndecodableattributedstringkey.md) — 一个协议，用于定义属性键如何解码与 Markdown 语法对应的值。
