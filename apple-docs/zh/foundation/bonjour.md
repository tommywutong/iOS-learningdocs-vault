# Bonjour

<sub>API 集合</sub>

发布服务以便在本地网络上轻松发现，或发现其他设备发布的服务。

## 主题

### 本地网络服务

- [NetService](netservice.md) — 使用多播 DNS 广播自身可用性的网络服务。_(已废弃)_
- [NetServiceDelegate](netservicedelegate.md) — 网络服务用来向其委托（delegate）告知所提供服务状态的接口。
- [NSBonjourServices](../bundleresources/information-property-list/nsbonjourservices.md) — App 浏览的 Bonjour 服务类型。
- [NSLocalNetworkUsageDescription](../bundleresources/information-property-list/nslocalnetworkusagedescription.md) — 告知用户 App 请求访问本地网络原因的信息。

### 服务发现

- [NetServiceBrowser](netservicebrowser.md) — 使用多播 DNS 查找网络上已发布服务的网络服务浏览器。_(已废弃)_
- [NetServiceBrowserDelegate](netservicebrowserdelegate.md) — 网络服务浏览器用来向委托告知服务发现状态的接口。
