# AttributedStringProtocol 实现

<sub>API 集合</sub>

## 主题

### 实例属性

- [characters](characters.md) — 带属性字符串的字符，作为对底层字符串的一个视图。
- [endIndex](endindex.md) — 某个子字符串末尾之后的位置——比最后一个有效下标参数大 1 的位置。
- [runs](runs.md) — 带属性字符串的属性串，作为对底层字符串的一个视图。
- [startIndex](startindex.md) — 某个非空属性化子字符串中第一个字符的位置。
- [unicodeScalars](unicodescalars.md) — 带属性字符串的 Unicode 标量，作为对底层字符串的一个视图。
- [utf16](utf16.md) — 将带属性子字符串的内容视为 UTF-16 码元集合的一个视图。
- [utf8](utf8.md) — 将带属性子字符串的内容视为 UTF-8 码元集合的一个视图。

### 下标

- [subscript(_:)](<subscript(__)-2hp64.md>) — 返回与带属性字符串键对应的属性值。
- [subscript(_:)](<subscript(__)-96fey.md>) — 返回范围所指示的带属性子字符串的一个子字符串。
- [subscript(dynamicMember:)](<subscript(dynamicmember_)-3o8o1.md>) — 返回键路径所指示的属性值。
- [subscript(dynamicMember:)](<subscript(dynamicmember_)-548k0.md>) — 返回键路径所指示的范围化属性容器。
