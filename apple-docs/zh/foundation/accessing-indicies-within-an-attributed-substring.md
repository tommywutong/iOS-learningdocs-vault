# 访问属性化子字符串内的索引

<sub>API 集合</sub>

## 主题

### Accessing Terminal Indices

- [startIndex](attributedsubstring/startindex.md) — 某个非空属性化子字符串中第一个字符的位置。
- [endIndex](attributedsubstring/endindex.md) — 某个子字符串末尾之后的位置——比最后一个有效下标参数大 1 的位置。

### Supporting Types

- [Index](attributedstring/index.md) — 一种类型，表示某个字符或代码单元在属性化字符串内的位置。
