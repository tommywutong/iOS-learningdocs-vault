# 匿名

<sub>API 集合</sub>

以下常量由 `NSProcessInfo` 类提供，作为 [- operatingSystem](<processinfo/operatingsystem().md>) 的返回值。

## 主题

### 常量

- [NSHPUXOperatingSystem](nshpuxoperatingsystem.md) — 表示 HP UX 操作系统。
- [NSMACHOperatingSystem](nsmachoperatingsystem.md) — 表示 macOS 操作系统。
- [NSOSF1OperatingSystem](nsosf1operatingsystem.md) — 表示 OSF/1 操作系统。
- [NSSolarisOperatingSystem](nssolarisoperatingsystem.md) — 表示 Solaris 操作系统。
- [NSSunOSOperatingSystem](nssunosoperatingsystem.md) — 表示 Sun OS 操作系统。
- [NSWindows95OperatingSystem](nswindows95operatingsystem.md) — 表示 Windows 95 操作系统。
- [NSWindowsNTOperatingSystem](nswindowsntoperatingsystem.md) — 表示 Windows NT 操作系统。

## 另请参阅

### Getting host information

- [hostName](processinfo/hostname.md) — 进程正在其上执行的主机计算机的名称。
- [operatingSystemVersionString](processinfo/operatingsystemversionstring.md) — 一个字符串，包含进程正在其上执行的操作系统的版本。
- [operatingSystemVersion](processinfo/operatingsystemversion.md) — 进程正在其上执行的操作系统的版本。
- [- isOperatingSystemAtLeastVersion:](<processinfo/isoperatingsystematleast(__).md>) — 返回一个布尔值，指示进程正在其上执行的操作系统版本是否与给定版本相同或更新。
- [OperatingSystemVersion](operatingsystemversion.md) — 一个结构体，包含当前正在执行的操作系统的版本信息，包括主版本号、次版本号和补丁版本号。
- [- operatingSystem](<processinfo/operatingsystem().md>) — 返回一个常量，表示进程正在其上执行的操作系统。_(已废弃)_
- [- operatingSystemName](<processinfo/operatingsystemname().md>) — 返回一个字符串，包含进程正在其上执行的操作系统的名称。_(已废弃)_
