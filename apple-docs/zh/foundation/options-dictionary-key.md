# 选项字典键

<sub>API 集合</sub>

指示生成项目提供程序数据时所用选项的键。

## 概述

这些键用于传递给 [LoadHandler](nsitemprovider/loadhandler.md) block 的 `options` 参数所对应的字典。

## 主题

### 常量

- [NSItemProviderPreferredImageSizeKey](nsitemproviderpreferredimagesizekey.md) — 提供给选项字典的一个键，用于指示首选图像尺寸。
