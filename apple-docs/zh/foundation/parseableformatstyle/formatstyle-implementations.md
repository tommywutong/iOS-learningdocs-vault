# FormatStyle 实现

<sub>API 集合</sub>

## 主题

### 类型属性

- [dateTime](datetime.md) — 用于格式化日期和时间的样式。
- [number](number.md) — 用于格式化十进制值的样式。
- [percent](percent.md) — 用于将十进制值格式化为百分比表示的样式。
- [url](url.md) — 用于格式化 URL 的样式。

### 类型方法

- [name(style:)](<name(style_).md>) — 返回一个格式样式，使用给定的人名样式根据各组成部分格式化人名。
