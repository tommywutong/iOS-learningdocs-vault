# NSAppleEvent 超时

<sub>API 集合</sub>

不应使用以下常量，它们最终可能会被移除。

## 主题

### 常量

- [NSAppleEventTimeOutDefault](nsappleeventtimeoutdefault.md) — 指定事件处理操作应继续执行，直到根据 Apple Event Manager 确定的值发生超时（约 1 分钟）。App 当前不使用此常量。
- [NSAppleEventTimeOutNone](nsappleeventtimeoutnone.md) — 指定 App 愿意无限期等待当前操作完成。App 当前不使用此常量。
