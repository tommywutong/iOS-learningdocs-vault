# 属性键

<sub>API 集合</sub>

这些键对应扩展项目的属性（property），并在扩展的 `Info.plist` 中指定。

## 主题

### 常量

- [NSExtensionItemAttributedTitleKey](nsextensionitemattributedtitlekey.md) — 扩展项目的可选标题。
- [NSExtensionItemAttributedContentTextKey](nsextensionitemattributedcontenttextkey.md) — 描述扩展项目内容的可选字符串。
- [NSExtensionItemAttachmentsKey](nsextensionitemattachmentskey.md) — 与扩展项目关联的可选媒体数据数组。
