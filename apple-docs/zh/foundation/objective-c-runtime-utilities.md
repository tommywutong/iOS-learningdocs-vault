# Objective-C 运行时实用工具

<sub>API 集合</sub>

与 Objective-C 运行时交互。

## 主题

### 类型查找

- [NSClassFromString](<nsclassfromstring(__).md>) — 通过名称获取类。
- [NSStringFromClass](<nsstringfromclass(__).md>) — 以字符串形式返回类的名称。
- [NSSelectorFromString](<nsselectorfromstring(__).md>) — 返回具有给定名称的选择器（selector）。
- [NSStringFromSelector](<nsstringfromselector(__).md>) — 返回给定选择器的字符串表示。
- [NSStringFromProtocol](<nsstringfromprotocol(__).md>) — 以字符串形式返回协议的名称。
- [NSProtocolFromString](<nsprotocolfromstring(__).md>) — 返回具有给定名称的协议。

### 序列化

- [NSGetSizeAndAlignment](<nsgetsizeandalignment(______).md>) — 获取已编码类型的实际大小和对齐大小。
