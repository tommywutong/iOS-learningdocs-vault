# 字节序

<sub>API 集合</sub>

用于指定字节序格式的常量。

## 概述

这些常量由 [NSHostByteOrder](<nshostbyteorder().md>) 返回。

## 主题

### 常量

- [NS_BigEndian](ns_bigendian.md) — 字节序为大端序。
- [NS_LittleEndian](ns_littleendian.md) — 字节序为小端序。
- [NS_UnknownByteOrder](ns_unknownbyteorder.md) — 字节序未知。

## 另请参阅

### 常量

- [NSSwappedDouble](nsswappeddouble.md) — 包含与字节序无关的 `double` 值的不透明结构体。
- [NSSwappedFloat](nsswappedfloat.md) — 包含与字节序无关的 `float` 值的不透明类型。
