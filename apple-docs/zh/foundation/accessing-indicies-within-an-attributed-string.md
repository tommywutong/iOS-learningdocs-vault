# 访问属性化字符串内的索引

<sub>API 集合</sub>

访问属性化字符串内的某个位置，可以是从起始处偏移得到的位置，也可以是相对于另一个已知位置之前或之后的位置。

## 主题

### Accessing Terminal Indices

- [startIndex](attributedstring/startindex.md) — 某个非空属性化字符串中第一个字符的位置。
- [endIndex](attributedstring/endindex.md) — 该字符串末尾之后的位置——比最后一个有效下标参数大 1 的位置。

### Supporting Types

- [Index](attributedstring/index.md) — 一种类型，表示某个字符或代码单元在属性化字符串内的位置。
