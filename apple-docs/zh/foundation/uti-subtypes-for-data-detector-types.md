# 数据检测器类型的 UTI 子类型

这些常量表示 `com.apple.structured-text` 的统一类型标识符子类型。

## 概述

这些常量表示 `com.apple.structured-text` 的[统一类型标识符](https://developer.apple.com/library/archive/documentation/General/Conceptual/DevPedia-CocoaCore/UniformTypeIdentifier.html#//apple_ref/doc/uid/TP40008195-CH60)子类型，后者符合 `public.plain-text`。使用这些常量来指定你的扩展处理的数据类型。

## 主题

### 常量

- [NSTypeIdentifierDateText](../appkit/nstypeidentifierdatetext.md)
- [NSTypeIdentifierAddressText](../appkit/nstypeidentifieraddresstext.md)
- [NSTypeIdentifierPhoneNumberText](../appkit/nstypeidentifierphonenumbertext.md)
- [NSTypeIdentifierTransitInformationText](../appkit/nstypeidentifiertransitinformationtext.md)
