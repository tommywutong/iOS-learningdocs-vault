# 键控归档器根对象键

<sub>API 集合</sub>

归档器在已编码对象层级结构中使用的键。

## 主题

### 常量

- [NSKeyedArchiveRootObjectKey](nskeyedarchiverootobjectkey.md) — 使用类方法 [+ archivedDataWithRootObject:](<nskeyedarchiver/archiveddata(withrootobject_).md>) 创建的归档，会将此键用于已编码对象层级结构中的根对象。[NSKeyedUnarchiver](nskeyedunarchiver.md) 类方法 [+ unarchiveObjectWithData:](<nskeyedunarchiver/unarchiveobject(with_).md>) 也会查找此根键。
