# 分布式对象支持

<sub>API 集合</sub>

支持不同进程中的对象相互通信，无论这些进程位于本地还是远程系统上。

## 主题

### 旧版

- [NSMachPortDelegate](nsmachportdelegate.md) — 用于处理传入 Mach 消息的接口。
- [NSMachPort](nsmachport.md) — 可用作分布式对象连接（或原始消息传递）端点的端口。
- [MessagePort](messageport.md) — 可用作分布式对象连接（或原始消息传递）端点的端口。
- [PortDelegate](portdelegate.md) — 用于处理传入消息的接口。
- [PortMessage](portmessage.md) — 用于 App 间（以及线程间）消息的底层、独立于操作系统的类型。
- [NSProtocolChecker](nsprotocolchecker.md) — 限制可发送给另一个对象（称为检查器的委托（delegate））的消息的对象。
