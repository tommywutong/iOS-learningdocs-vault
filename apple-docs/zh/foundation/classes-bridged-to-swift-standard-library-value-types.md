# 桥接到 Swift 标准库值类型的类

<sub>API 集合</sub>

当你需要引用语义或 Foundation 特有的行为时，请使用桥接的引用类型。

## 主题

### 字符串

- [NSString](nsstring.md) — 一个静态的纯文本 Unicode 字符串对象。
- [NSMutableString](nsmutablestring.md) — 一个动态的纯文本 Unicode 字符串对象。

### 数组

- [NSArray](nsarray.md) — 一个对象的静态有序集合。
- [NSMutableArray](nsmutablearray.md) — 一个对象的动态有序集合。

### 字典

- [NSDictionary](nsdictionary.md) — 一个与唯一键关联的对象的静态集合。
- [NSMutableDictionary](nsmutabledictionary.md) — 一个与唯一键关联的对象的动态集合。

### 集合

- [NSSet](nsset.md) — 一个静态的、无序的唯一对象集合。
- [NSMutableSet](nsmutableset.md) — 一个动态的无序唯一对象集合。

## 另请参阅

### Swift 支持

- [ReferenceConvertible](referenceconvertible.md) — 应用于由 Foundation 引用类型支撑的类型的一种修饰。
