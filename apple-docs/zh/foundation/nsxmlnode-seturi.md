# setURI:

<sub>文章</sub>

设置接收者的 URI。

## 概述

接收者必须是 [XMLElement](xmlelement.md) 或 [XMLDocument](xmldocument.md) 文稿，或者是一个特性（attribute，即类型为 [NSXMLAttributeKind](xmlnode/kind-swift.enum/attribute.md) 的 `NSXMLNode` 对象）。对于文稿，该 URI 是文稿来源的 URI。
