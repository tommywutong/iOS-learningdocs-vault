# isEqual:

<sub>文章</sub>

返回一个布尔值，指示接收者与给定对象是否具有相同的 URL 字符串和基础 URL。

## 概述

该方法定义了实例相等意味着什么。当且仅当两个 NSURL 对 [baseURL](nsurl/baseurl.md) 和 [relativeString](nsurl/relativestring.md) 都返回相同的值时，才认为它们相等。
