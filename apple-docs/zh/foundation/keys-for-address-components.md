# 地址组成部分的键

<sub>API 集合</sub>

以下常量标识了 [addressComponents](nstextcheckingresult/addresscomponents.md) 字典中可能返回的键。

## 主题

### 常量

- [NSTextCheckingNameKey](nstextcheckingkey/name.md) — 对应于地址中姓名组成部分的键。
- [NSTextCheckingJobTitleKey](nstextcheckingkey/jobtitle.md) — 对应于地址中职务组成部分的键。
- [NSTextCheckingOrganizationKey](nstextcheckingkey/organization.md) — 对应于地址中组织组成部分的键。
- [NSTextCheckingStreetKey](nstextcheckingkey/street.md) — 对应于地址中街道地址组成部分的键。
- [NSTextCheckingCityKey](nstextcheckingkey/city.md) — 对应于地址中城市组成部分的键。
- [NSTextCheckingStateKey](nstextcheckingkey/state.md) — 对应于地址中州或省组成部分的键。
- [NSTextCheckingZIPKey](nstextcheckingkey/zip.md) — 对应于地址中邮政编码组成部分的键。
- [NSTextCheckingCountryKey](nstextcheckingkey/country.md) — 对应于地址中国家或地区组成部分的键。
- [NSTextCheckingPhoneKey](nstextcheckingkey/phone.md) — 对应于地址中电话号码组成部分的键。

- [NSTextCheckingTypes](nstextcheckingtypes.md) — 定义了可用的检查类型。这些值可以使用 C 语言的按位或运算符进行组合。系统支持其自身的内部类型，用户也可以通过继承 `NSTextCheckingResult` 并添加自己的自定义类型来扩展这些类型。
