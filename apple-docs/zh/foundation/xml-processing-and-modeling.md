# XML 处理与建模

<sub>API 集合</sub>

解析 XML 文稿。

## 主题

### 基于树的处理

- [XMLDTD](xmldtd.md) — 文档类型定义（DTD）的一种表示。
- [XMLDTDNode](xmldtdnode.md) — 文档类型定义中元素、属性列表、实体和记法声明的一种表示。
- [XMLDocument](xmldocument.md) — 内部化为逻辑树结构的 XML 文档。
- [XMLElement](xmlelement.md) — XML 树结构中的元素节点。
- [XMLNode](xmlnode.md) — 表示 XML 文档的抽象逻辑树结构中的节点。

### 基于事件的处理

- [XMLParser](xmlparser.md) — 一个事件驱动的 XML 文档解析器（包括 DTD 声明）。
- [XMLParserDelegate](xmlparserdelegate.md) — XML 解析器用于告知其委托所解析文档内容的接口。
