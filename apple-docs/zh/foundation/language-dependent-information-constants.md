# 与语言相关的信息常量

<sub>API 集合</sub>

这些常量已废弃，不应使用。

## 另请参阅

### 已废弃

- [- initWithUser:](<userdefaults/init(user_).md>) — 创建一个以指定用户账户的默认值进行初始化的用户默认值对象。_(已废弃)_
- [- synchronize](<userdefaults/synchronize().md>) — 等待对默认值数据库的任何待处理异步更新完成后返回；这个方法没有必要，不应使用。
- [+ resetStandardUserDefaults](<userdefaults/resetstandarduserdefaults().md>) — 这个方法没有任何效果，不应使用。
- [- persistentDomainNames](<userdefaults/persistentdomainnames().md>) — 返回当前持久化域名称组成的数组。_(已废弃)_
- [NSUbiquitousUserDefaultsCompletedInitialSyncNotification](userdefaults/completedinitialcloudsyncnotification.md) — 当无处不在的默认值完成数据下载时发出，无论是设备首次连接到 iCloud 账户，还是用户切换其主要 iCloud 账户时。_(已废弃)_
- [NSUbiquitousUserDefaultsDidChangeAccountsNotification](userdefaults/didchangecloudaccountsnotification.md) — 当用户更改主要 iCloud 账户时发出。_(已废弃)_
- [NSUbiquitousUserDefaultsNoCloudAccountNotification](userdefaults/nocloudaccountnotification.md) — 当设置了云默认值，但没有 iCloud 用户登录时发出。_(已废弃)_
