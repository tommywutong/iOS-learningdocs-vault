# 命令行工具

在“终端”中开发和自定义你的项目。

## 概述

你可以使用命令行工具在“终端”中执行某些操作，而无需运行 Xcode。例如，你可以开发开源或跨平台项目、公证 macOS 软件、自动化构建、实现持续集成，以及为项目应用特定设置。

> [!note] 注意
> 有关访问命令行工具文档的更多信息，请参阅[阅读 UNIX 手册页面](../os/reading-unix-manual-pages.md)。

## 主题

### 基础

- [安装命令行工具](installing-the-command-line-tools.md) — 使用安装器包或“终端” App 安装 Xcode 的命令行工具。
- [配置命令行工具设置](configuring-command-line-tools-settings.md) — 在 Xcode 设置或“终端”中，选择要用于命令行工具的 Xcode 版本。
- [Xcode 命令行工具参考](xcode-command-line-tool-reference.md) — 使用需要你安装 Xcode 并将该 App 设置为活跃开发者目录的命令行工具。
