# 在 Xcode 项目中管理文件和文件夹

<sub>文章</sub>

向项目中添加新文件或现有文件，并使用群组来组织项目导航器中的文件和文件夹。

## 概述

项目导航器显示项目的文件，并允许你打开、添加、删除和重新排列这些文件。要打开项目导航器，请在项目窗口导航区域顶部点击类似于文件夹的图标。

![使用项目导航器选择文件并在 Xcode 项目中查找项。](../../../attachments/4dd86a2ee0fbde094f156c00ea1a4f0c/project-navigator-overview@2x.png)

当你在导航器中选择文件时，检查器面板会显示该文件的信息，而编辑器区域会显示文件的内容。编辑器区域的外观会根据所选文件的类型而变化。例如，源代码文件会显示源代码编辑器，而属性列表文件会显示属性列表编辑器。

要根据关键字或其他条件定位文件，请使用导航区域底部的过滤栏：

- 要搜索文件，在过滤栏的文本字段中输入关键字。
- 要仅显示最近修改的文件，点击“最近文件”图标。
- 要仅显示源代码管理状态已更改的文件，点击“源代码管理”图标。

### 向项目中添加新文件

Xcode 为可能添加到项目中的常见文件类型提供了模板，例如 Swift 文件或 Playground。在项目导航器中，选择要添加文件的文件夹或群组，然后执行以下任一操作：

1. 点击过滤栏中的添加按钮（+），并从弹出菜单中选择“文件”。
2. 选择“文件”>“新建”>“文件”。
3. 按住 Control 键点击并选择“新建文件”。

在新建文件表单（sheet）中，为新文件选择一个模板。Xcode 按类型组织模板，以便于查找。你还可以使用过滤控制（control）按名称搜索模板。选择模板后，点击“下一步”。

![用于选择要添加到项目中的文件类型的表单（sheet）。](../../../attachments/bc8fbff0c30d0e54a3f4fc866f122b73/files-new-file-template@2x.png)

某些模板要求你为新文件指定额外信息。例如，Cocoa Touch 模板要求你指定所创建类的信息，包括父类名称。Xcode 使用这些信息用一些初始内容填充文件。

最后一步是将文件保存到文件系统。当 Xcode 提示你选择文件位置时，它还会要求你指定群组和目标信息。群组指示文件在项目中的放置位置，Xcode 会根据上下文信息选择一个默认群组。Xcode 还会选择一个默认目标。对目标和群组值进行任何相关更改，然后点击“创建”以创建文件。

![一个表单（sheet）显示了复制文件、创建群组以及将文件添加到现有目标的选项。](../../../attachments/f315024f296172b99a155b1547233776/files-add-existing@2x.png)

### 向项目中添加现有文件和文件夹

Xcode 提供了多种将现有文件和文件夹添加到项目中的方式。你可以：

- 从访达中将文件拖到项目导航器中。
- 点击项目导航器过滤栏中的添加按钮，然后选择“将文件添加到“_项目名称_””。
- 选择“文件”>“将文件添加到“_项目名称_””。

Xcode 会提示你选择要添加的文件和文件夹，并配置如何将它们添加到项目中。如果你添加的文件要求目标，请至少选择一个目标。然后，从操作选择器（picker）中选择以下选项之一：

- **复制文件到目标位置** — 在将文件和文件夹添加到项目导航器之前，将所有文件和文件夹复制到项目文件夹。使用此选项可以处理文件的副本，而不是原始版本。
- **移动文件到目标位置** — 将所有文件和文件夹从原始源移动到项目文件夹。使用此选项可以处理原始文件并同时从磁盘上的原始位置移除它们。
- **原地引用文件** — 将文件保留在磁盘上的原始位置，并从项目中添加对它们的引用。当你希望在 Xcode 项目之外单独存储文件，但仍然能够在项目中使用它们时，选择此选项。

接下来，从群组选择器（picker）中，选择你希望如何群组文件夹：

- **创建群组** — 在项目中创建一个与磁盘上所选文件和文件夹结构匹配的群组结构。Xcode 为你添加的每个文件夹在项目导航器中创建一个群组，并将该文件夹的内容添加到该群组中。当你希望 Xcode 中的群组结构与磁盘上的目录结构不同，或者想要引用项目外部的文件时，选择此选项。
- **创建文件夹** — 在项目导航器中显示文件夹，并根据你在操作选择器（picker）中的选择来复制、移动或引用文件。在项目导航器中，每个添加的文件夹都指向文件系统中的一个文件夹。当你希望项目导航器文件夹与磁盘上的文件和目录结构匹配，并希望最小化添加或删除文件时对项目文件的更改时，选择此选项。

将本地 Swift 包文件夹添加到项目时，请执行以下额外步骤：

- 将包放在 Packages 群组中以便于追踪。要在项目导航器中创建新群组，请选择“文件”>“新建”>“群组”。将包从访达拖入该群组。
- 将包添加到项目设置中的链接库构建阶段。在项目编辑器中，选择“Build Phases”并展开“Link Binary With Libraries”。点击加号（+）按钮并从工作区中选择包。

有关管理 Swift 包的更多信息，请参阅 [Swift 包](swift-packages.md)。

> [!note] 注意
> 要使用你通过 Reality Composer Pro 创建的 RealityKit 内容，你可以将其文件夹添加到 Xcode 项目中，并与其中包含的 Swift 包链接。有关 Reality Composer Pro 的更多信息，请参阅[使用 RealityKit 和 Reality Composer Pro 创作交互式 3D 内容](../realitykit/composing-interactive-3d-content-with-realitykit-and-reality-composer-pro.md)。

### 在导航器中组织项目文件

大多数新项目都包含一些结构来组织项目内容——例如，将源文件与生成的产品分开。你可以创建额外的群组和文件夹来组织内容，并使大型项目更易于导航。

- 文件夹是你从项目引用的文件系统目录。Xcode 将文件夹的内容包含在项目中。
- 群组是项目中资源的集合。默认情况下，Xcode 将每个群组映射到项目目录中的一个文件夹，但你也可以创建没有底层文件系统文件夹的群组。如果你希望在项目中管理文件而不改变磁盘上文件的底层组织，你可能会使用不带文件夹的群组。

在项目导航器中，使用直接交互或菜单命令创建和修改群组：

- **创建一个由文件夹支持的新群组** — 选择一个项，然后选择“文件”>“新建”>“群组”，或者按住 Control 键点击项并从上下文菜单中选择“新建群组”。
- **创建一个群组并将项移入其中** — 选择项，然后选择“文件”>“新建”>“来自所选群组”，或者按住 Control 键点击所选项并选择“来自所选的新建群组”。
- **创建一个新文件夹** — 选择项，然后选择“文件”>“新建”>“文件夹”，或者按住 Control 键点击所选项并选择“新建文件夹”。
- **创建一个新文件夹并将项移入其中** — 选择项，然后选择“文件”>“新建”>“来自所选文件夹”，或者按住 Control 键点击所选项并选择“来自所选的新建文件夹”。
- **重命名文件或群组** — 双击文件或群组，然后输入新名称。
- **更改群组的关联文件夹** — 选择群组，然后选择“显示”>“检查器”>“显示文件检查器”。将新文件夹从访达拖到文件检查器中“位置”下方的旧文件夹名称上。
- **创建一个没有文件夹的新群组** — 按住 Control 键点击项，然后按住 Option 键并从上下文菜单中选择“无文件夹的新建群组”。
- **创建一个没有文件夹的群组并将项移入其中** — 按住 Control 键点击项，然后按住 Option 键并从上下文菜单中选择“来自所选的无文件夹的新建群组”。

> [!important] 重要
> 如果群组与文件夹关联，Xcode 会对文件系统中的文件夹执行所有重命名、删除、移动和复制操作。对于在源代码管理下的项目，Xcode 使用源代码管理系统来执行操作并追踪更改。如果你在同一个 Git 仓库中的群组之间移动文件，Xcode 会在文件系统中移动这些文件。如果文件位于不同的仓库中，Xcode 会将文件复制到新仓库的文件夹中。

### 删除文件和文件夹

要从项目中删除文件或文件夹，请选择它并按 Delete 键，或选择“编辑”>“删除”。Xcode 会提示你选择删除所选项的方式。

- **移到废纸篓** — 此选项从项目和文件系统中移除文件和文件夹。当你不再需要文件中的信息时选择此选项。
- **移除引用** — 此选项仅从项目中移除文件和文件夹。Xcode 不会从文件系统中移除它们。

### 将群组转换为文件夹

在组织 Xcode 项目文件时，使用文件夹而非群组有几个好处。文件夹在项目文件中占用的表示空间要小得多，这可能会导致更少的合并冲突，因为当你添加或删除文件到项目时，你不会修改项目文件。此外，当你对文件系统进行更改时，Xcode 项目文件会自动更新。

要使用项目导航器中的“转换为文件夹”选项将群组转换为文件夹：

1. 在项目导航器中选择一个或多个群组。
2. 按住 Control 键点击所选群组，然后选择“转换为文件夹”。

Xcode 会检查 Xcode 项目中的群组是否与磁盘上底层的文件和目录匹配。如果匹配，Xcode 会将每个群组转换为文件夹。如果群组和底层目录结构不匹配，Xcode 会显示一个带有“显示详细信息”按钮的对话框。点击“显示详细信息”按钮以查看 Xcode 无法转换的文件和目录列表。

要转换 Xcode 在“显示详细信息”中列出的文件，请使 Xcode 中的文件和目录结构与访达在磁盘上显示的结构匹配。要么修改 Xcode 中的文件和群组结构以匹配访达中的文件和目录结构，要么修改访达中的文件和目录结构以匹配 Xcode 中群组的内容。然后再次选择这些群组，按住 Control 键点击，并选择“转换为文件夹”。
