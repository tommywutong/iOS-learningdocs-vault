# SlothCreator：在 Xcode 中构建 DocC 文档

<sub>示例代码</sub>

为一个包含 DocC Catalog 的 Swift package 构建 DocC 文档。

## 概述

> [!note] 注意
> 该示例代码项目与 WWDC23 场次 [10244: Create rich documentation with Swift-DocC](https://developer.apple.com/wwdc23/10244)、WWDC22 场次 [110368: What's new in Swift-DocC](https://developer.apple.com/wwdc22/110368) 和 [110369: Improve the discoverability of your Swift-DocC content](https://developer.apple.com/wwdc22/110369) 相关联。它还与 WWDC21 场次 [10166: Meet DocC documentation in Xcode](https://developer.apple.com/wwdc21/10166)、[10167: Elevate your DocC documentation in Xcode](https://developer.apple.com/wwdc21/10167)、[10236: Host and automate your DocC Documentation](https://developer.apple.com/wwdc21/10236) 以及 [10235: Build interactive tutorials in DocC](https://developer.apple.com/wwdc21/10235) 相关联。

### 配置示例代码项目

要为这个 package 构建文档，请使用 Xcode 13，打开 `Package.swift` 文件，并选择 Product \> Build Documentation。
