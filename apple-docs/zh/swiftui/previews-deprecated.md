# 已废弃

<sub>API 集合</sub>

查阅已废弃的预览符号及其替代方案。

## 主题

### 定义预览

- [PreviewProvider](previewprovider.md) — 一种在 Xcode 中生成视图预览的类型。 _(已废弃)_
- [PreviewPlatform](previewplatform.md) — 可以运行预览的平台。 _(已废弃)_
- [previewDisplayName(_:)](<view/previewdisplayname(__).md>) — 为预览设置一个在画布中显示的用户可见名称。 _(已废弃)_

### 自定预览

- [previewDevice(_:)](<view/previewdevice(__).md>) — 覆盖预览的设备。 _(已废弃)_
- [PreviewDevice](previewdevice.md) — 运行预览的模拟器设备。 _(已废弃)_
- [previewLayout(_:)](<view/previewlayout(__).md>) — 覆盖预览容器的尺寸。 _(已废弃)_
- [previewInterfaceOrientation(_:)](<view/previewinterfaceorientation(__).md>) — 覆盖预览的方向。 _(已废弃)_
- [InterfaceOrientation](interfaceorientation.md) — 从用户视角看的界面方向。

### 设置上下文

- [previewContext(_:)](<view/previewcontext(__).md>) — 为预览声明一个上下文。 _(已废弃)_
- [PreviewContext](previewcontext.md) — 用于预览的上下文类型。 _(已废弃)_
- [PreviewContextKey](previewcontextkey.md) — 预览上下文的键类型。 _(已废弃)_
