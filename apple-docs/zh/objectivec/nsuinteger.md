# NSUInteger

<sub>类型别名</sub>

Describes an unsigned integer.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```objc
typedef unsigned long NSUInteger;
```

## 讨论

在构建 32 位应用程序时，NSUInteger 是 32 位无符号整数。64 位应用程序将 NSUInteger 视为 64 位无符号整数
