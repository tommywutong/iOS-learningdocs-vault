# webPlugInSetIsSelected(_:)

<sub>实例方法</sub>

根据选中状态控制插件行为。

<sub>macOS</sub>

```swift
func webPlugInSetIsSelected(_ isSelected: Bool)
```

## 参数

- `isSelected` — 如果为 [YES](../yes.md)，则插件当前被选中；否则未被选中。

## 讨论

例如，可用于在用户选中插件时更改其外观。
