# YES

<sub>宏</sub>

将 `YES` 定义为 `1`。

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```objc
#define YES
```

## 讨论

Objective-C 的 `YES` 宏桥接到 Swift 为值为 `true` 的 [ObjCBool](objcbool.md)。
