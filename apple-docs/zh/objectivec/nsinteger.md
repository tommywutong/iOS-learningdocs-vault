# NSInteger

<sub>类型别名</sub>

描述一个整数。

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
typealias NSInteger = Int
```

## 讨论

在构建 32 位应用程序时，NSInteger 是 32 位整数。64 位应用程序将 NSInteger 视为 64 位整数。
