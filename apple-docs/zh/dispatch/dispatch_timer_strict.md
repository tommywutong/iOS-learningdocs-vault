# DISPATCH_TIMER_STRICT

<sub>全局变量</sub>

系统尽最大努力遵守定时器指定的容差（leeway）值，即使该值小于默认容差。

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
var DISPATCH_TIMER_STRICT: Int32 { get }
```
