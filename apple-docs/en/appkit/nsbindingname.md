# NSBindingName

<sub>Structure</sub>

Values that specify a binding for certain methods.

<sub>macOS</sub>

```swift
struct NSBindingName
```

## Discussion

The following values are used to specify a binding to [bind(_:to:withKeyPath:options:)](<../objectivec/nsobject-swift.class/bind(__to_withkeypath_options_).md>), [infoForBinding(_:)](<../objectivec/nsobject-swift.class/infoforbinding(__).md>), [unbind(_:)](<../objectivec/nsobject-swift.class/unbind(__).md>) and [valueClassForBinding(_:)](<../objectivec/nsobject-swift.class/valueclassforbinding(__).md>). See [Cocoa Bindings Reference](https://developer.apple.com/library/archive/documentation/Cocoa/Reference/CocoaBindingsRef/CocoaBindingsRef.html#//apple_ref/doc/uid/10000189i) for more information.
