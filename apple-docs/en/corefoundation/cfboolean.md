# CFBoolean

<sub>Class</sub>

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
class CFBoolean
```

## Overview

CFBoolean objects are used to wrap boolean values for use in Core Foundation property lists and collection types.

## Relationships

- **Conforms To**: [Equatable](../swift/equatable.md), [Hashable](../swift/hashable.md)

## Topics

### CFBoolean Miscellaneous Functions

- [CFBooleanGetTypeID](<cfbooleangettypeid().md>) — Returns the Core Foundation type identifier for the CFBoolean opaque type.
- [CFBooleanGetValue](<cfbooleangetvalue(__).md>) — Returns the value of a CFBoolean object as a standard C type `Boolean`.

### Constants

- [Boolean Values](boolean-values.md) — CFBoolean evaluates to either true or false values where `kCFBooleanTrue` is the true, and `kCFBooleanFalse` is the false value.
