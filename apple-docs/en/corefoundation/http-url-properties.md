# HTTP URL Properties

<sub>API Collection</sub>

Properties for HTTP URL resources.

## Overview

In addition to the above properties, each field within an HTTP request or response header is itself a property. You can specify a header field by using the field name as the property name.

## Topics

### Constants

- [kCFURLHTTPStatusCode](kcfurlhttpstatuscode.md) — A `CFNumber` object holding the status code of an HTTP request. _(deprecated)_
- [kCFURLHTTPStatusLine](kcfurlhttpstatusline.md) — A `CFString` object holding the status line of an HTTP request. _(deprecated)_
