# Predefined Callback Structures

<sub>API Collection</sub>

`CFBinaryHeap` provides some predefined callbacks for your convenience.

## Topics

### Constants

- [kCFStringBinaryHeapCallBacks](kcfstringbinaryheapcallbacks.md) — Predefined [CFBinaryHeapCallBacks](cfbinaryheapcallbacks.md) structure containing a set of callbacks appropriate for use when the values in a binary heap are all `CFString` objects.
