# Padding Positions

<sub>API Collection</sub>

These constants are used to specify how numbers should be padded.

## Topics

### Constants

- [kCFNumberFormatterPadBeforePrefix](cfnumberformatterpadposition/beforeprefix.md) — Specifies the number of padding characters before the prefix.
- [kCFNumberFormatterPadAfterPrefix](cfnumberformatterpadposition/afterprefix.md) — Specifies the number of padding characters after the prefix.
- [kCFNumberFormatterPadBeforeSuffix](cfnumberformatterpadposition/beforesuffix.md) — Specifies the number of padding characters before the suffix.
- [kCFNumberFormatterPadAfterSuffix](cfnumberformatterpadposition/aftersuffix.md) — Specifies the number of padding characters after the suffix.
