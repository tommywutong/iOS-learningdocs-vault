# CFDateFormatterStyle.mediumStyle

<sub>Case</sub>

Specifies a medium style, typically with abbreviated text, such as “Nov 23, 1937”.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case mediumStyle
```
