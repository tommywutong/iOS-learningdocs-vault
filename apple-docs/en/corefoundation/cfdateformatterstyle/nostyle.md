# CFDateFormatterStyle.noStyle

<sub>Case</sub>

Specifies no output.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case noStyle
```

## Discussion

You use this constant to suppress output for the date or time (see [CFDateFormatterCreate](<../cfdateformattercreate(________).md>) for more details).
