# version

<sub>Instance Property</sub>

An integer of type `CFIndex`. Assign the version number of the allocator. Currently the only valid value is 0.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
var version: CFIndex
```
