# CFTimeZoneNameStyle.shortDaylightSaving

<sub>Case</sub>

Specifies the short daylight saving name style; for example, “CDT” for the Central time zone.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case shortDaylightSaving
```

### Enumeration Cases

- [kCFTimeZoneNameStyleDaylightSaving](daylightsaving.md) — Specifies the daylight saving name style; for example, “Central Daylight Time” for the Central time zone.
- [kCFTimeZoneNameStyleGeneric](generic.md) — Specifies the generic name style, which does not distinguish between daylight saving and standard time; for example, “Central Time” for the Central time zone.
- [kCFTimeZoneNameStyleShortGeneric](shortgeneric.md) — Specifies the short generic name style, which does not distinguish between daylight saving and standard time; for example, “CT” for the Central time zone.
- [kCFTimeZoneNameStyleShortStandard](shortstandard.md) — Specifies the short standard name style; for example, “CST” for the Central time zone.
- [kCFTimeZoneNameStyleStandard](standard.md) — Specifies the standard name style; for example, “Central Standard Time” for the Central time zone.
