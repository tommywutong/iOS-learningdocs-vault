# Application, Host, and User Keys

<sub>API Collection</sub>

Keys used to specify the common preference domains.

## Overview

Not all combinations of application, host, and user are supported preference domains. Specifically, `kCFPreferencesAnyHost` is not supported in any combination with other options.

## Topics

### Constants

- [kCFPreferencesAnyApplication](kcfpreferencesanyapplication.md) — Indicates a preference that applies to any application.
- [kCFPreferencesAnyHost](kcfpreferencesanyhost.md) — Indicates a preference that applies to any host.
- [kCFPreferencesAnyUser](kcfpreferencesanyuser.md) — Indicates a preference that applies to any user.
- [kCFPreferencesCurrentApplication](kcfpreferencescurrentapplication.md) — Indicates a preference that applies only to the current application.
- [kCFPreferencesCurrentHost](kcfpreferencescurrenthost.md) — Indicates a preference that applies only to the current host.
- [kCFPreferencesCurrentUser](kcfpreferencescurrentuser.md) — Indicates a preference that applies only to the current user.
