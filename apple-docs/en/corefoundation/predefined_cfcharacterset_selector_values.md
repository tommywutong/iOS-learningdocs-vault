# Predefined CFCharacterSet Selector Values

<sub>API Collection</sub>

Identifiers for the available predefined CFCharacterSet objects.

## Overview

Use these constants with the [CFCharacterSetGetPredefined](<cfcharactersetgetpredefined(__).md>) function to get one of the predefined character sets.

## Topics

### Constants

- [kCFCharacterSetControl](cfcharactersetpredefinedset/control.md) — Control character set (Unicode General Category Cc and Cf).
- [kCFCharacterSetWhitespace](cfcharactersetpredefinedset/whitespace.md) — Whitespace character set (Unicode General Category Zs and U0009 CHARACTER TABULATION).
- [kCFCharacterSetWhitespaceAndNewline](cfcharactersetpredefinedset/whitespaceandnewline.md) — Whitespace and Newline character set (Unicode General Category Z*, `U000A ~ U000D`, and `U0085`).
- [kCFCharacterSetDecimalDigit](cfcharactersetpredefinedset/decimaldigit.md) — Decimal digit character set.
- [kCFCharacterSetLetter](cfcharactersetpredefinedset/letter.md) — Letter character set (Unicode General Category L* & M*).
- [kCFCharacterSetLowercaseLetter](cfcharactersetpredefinedset/lowercaseletter.md) — Lowercase character set (Unicode General Category Ll).
- [kCFCharacterSetUppercaseLetter](cfcharactersetpredefinedset/uppercaseletter.md) — Uppercase character set (Unicode General Category Lu and Lt).
- [kCFCharacterSetNonBase](cfcharactersetpredefinedset/nonbase.md) — Non-base character set (Unicode General Category M*).
- [kCFCharacterSetDecomposable](cfcharactersetpredefinedset/decomposable.md) — Canonically decomposable character set.
- [kCFCharacterSetAlphaNumeric](cfcharactersetpredefinedset/alphanumeric.md) — Alpha Numeric character set (Unicode General Category L*, M*, & N*).
- [kCFCharacterSetPunctuation](cfcharactersetpredefinedset/punctuation.md) — Punctuation character set (Unicode General Category P*).
- [kCFCharacterSetCapitalizedLetter](cfcharactersetpredefinedset/capitalizedletter.md) — Titlecase character set (Unicode General Category Lt).
- [kCFCharacterSetSymbol](cfcharactersetpredefinedset/symbol.md) — Symbol character set (Unicode General Category S*).
- [kCFCharacterSetNewline](cfcharactersetpredefinedset/newline.md) — Newline character set (`U000A ~ U000D`, `U0085`, `U2028`, and `U2029`).
- [kCFCharacterSetIllegal](cfcharactersetpredefinedset/illegal.md) — Illegal character set.
