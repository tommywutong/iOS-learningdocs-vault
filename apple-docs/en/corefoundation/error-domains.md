# Error domains

<sub>API Collection</sub>

These constants define domains for CFError objects.

## Overview

The value of “code” will correspond to preexisting values in these domains.

## Topics

### Constants

- [kCFErrorDomainPOSIX](kcferrordomainposix.md) — A constant that specified the POSIX domain.
- [kCFErrorDomainOSStatus](kcferrordomainosstatus.md) — A constant that specified the OS domain.
- [kCFErrorDomainMach](kcferrordomainmach.md) — A constant that specified the Mach domain.
- [kCFErrorDomainCocoa](kcferrordomaincocoa.md) — A constant that specified the Cocoa domain.
