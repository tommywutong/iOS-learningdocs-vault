# Reading and Writing Error Codes

<sub>API Collection</sub>

Error codes for property list reading and writing functions such as [CFPropertyListCreateWithData](<cfpropertylistcreatewithdata(__________).md>).

## Topics

### Constants

- [kCFPropertyListReadCorruptError](kcfpropertylistreadcorrupterror.md) — Signifies an error parsing a property list.
- [kCFPropertyListReadUnknownVersionError](kcfpropertylistreadunknownversionerror.md) — Signifies the version number in the property list is unknown.
- [kCFPropertyListReadStreamError](kcfpropertylistreadstreamerror.md) — Signifies a stream error reading a property list.
- [kCFPropertyListWriteStreamError](kcfpropertylistwritestreamerror.md) — Signifies a stream error writing a property list.
