# Architecture Types

<sub>API Collection</sub>

- [kCFBundleExecutableArchitecturePPC](kcfbundleexecutablearchitectureppc.md) — Specifies the 32-bit PowerPC architecture.
- [kCFBundleExecutableArchitectureARM64](kcfbundleexecutablearchitecturearm64.md)
- [kCFBundleExecutableArchitectureX86_64](kcfbundleexecutablearchitecturex86_64.md) — Specifies the 64-bit Intel architecture.
