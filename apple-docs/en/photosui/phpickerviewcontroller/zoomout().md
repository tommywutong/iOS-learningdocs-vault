# zoomOut()

<sub>Instance Method</sub>

Changes the picker’s content scale by making the photo thumbnails smaller in the view.

<sub>iOS, iPadOS, Mac Catalyst, macOS, visionOS</sub>

```swift
func zoomOut()
```
