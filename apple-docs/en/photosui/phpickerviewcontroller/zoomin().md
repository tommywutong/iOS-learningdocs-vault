# zoomIn()

<sub>Instance Method</sub>

Changes the picker’s content scale by making the photo thumbnails larger in the view.

<sub>iOS, iPadOS, Mac Catalyst, macOS, visionOS</sub>

```swift
func zoomIn()
```
