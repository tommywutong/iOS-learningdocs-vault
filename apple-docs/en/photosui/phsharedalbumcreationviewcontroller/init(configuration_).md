# init(configuration:)

<sub>Initializer</sub>

Returns a view controller that allows the user to create a new shared album.

<sub>iOS, iPadOS, Mac Catalyst, macOS, visionOS</sub>

```swift
@MainActor @preconcurrency convenience init(configuration: PHSharedAlbumCreationConfiguration)
```

## Parameters

- `configuration` — The configuration for creating a new shared album.
