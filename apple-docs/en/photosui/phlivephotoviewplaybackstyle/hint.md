# PHLivePhotoViewPlaybackStyle.hint

<sub>Case</sub>

Plays back only a brief section of the motion content of the Live Photo, without sound.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
case hint
```

## Discussion

This style matches the effect seen in various iOS interface elements for hinting to the user when an asset contains Live Photo content.

### Constants

- [PHLivePhotoViewPlaybackStyleUndefined](undefined.md) — This value is invalid for use.
- [PHLivePhotoViewPlaybackStyleFull](full.md) — Plays back the entire motion and sound content of the Live Photo, including transition effects at the start and end.
