# NetworkBrowser.State.cancelled

<sub>Case</sub>

The browser has been cancelled. Do not call `start()` on the browser to restart it. Instead, create a new browser.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case cancelled
```
