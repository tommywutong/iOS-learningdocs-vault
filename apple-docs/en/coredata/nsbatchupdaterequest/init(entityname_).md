# init(entityName:)

<sub>Initializer</sub>

Creates a batch-update request for a named managed entity.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(entityName: String)
```

## Parameters

- `entityName` — The name of the managed entity to update data for.
