# enumerateResults(_:)

<sub>Instance Method</sub>

Enumerates the current set of results using the given block.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
func enumerateResults(_ block: (Any, Int, UnsafeMutablePointer<ObjCBool>) -> Void)
```

## Parameters

- `block` — The block to execute for each current result.

## Discussion

This method disables the query at the start of the iteration and reenables it upon completion. Use [- enumerateResultsWithOptions:usingBlock:](<enumerateresults(options_using_).md>) if you want to use concurrent or reverse iteration.
