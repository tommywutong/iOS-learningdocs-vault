# enableUpdates()

<sub>Instance Method</sub>

Enables updates to the query results.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
func enableUpdates()
```

## Discussion

Unless you use [- enumerateResultsUsingBlock:](<enumerateresults(__).md>) or [- enumerateResultsWithOptions:usingBlock:](<enumerateresults(options_using_).md>), you should invoke this method after you’re done iterating over the query results.
