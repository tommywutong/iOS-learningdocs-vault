# iso8601

<sub>Type Property</sub>

A style for formatting a date in accordance with the ISO-8601 standard.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static var iso8601: Date.ISO8601FormatStyle { get }
```

## Discussion

Use the dot-notation form of this type property when the call point allows the use of [ISO8601FormatStyle](../date/iso8601formatstyle.md); in other words, when the value type is `Date`. Typically, you use this with the [formatted(_:)](<../date/formatted(__).md>) method of `Date`.
