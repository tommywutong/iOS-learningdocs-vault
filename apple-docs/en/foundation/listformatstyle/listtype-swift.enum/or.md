# ListFormatStyle.ListType.or

<sub>Case</sub>

Specifies an _or_ list type.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case or
```

## Discussion

This width creates a list like `One, Two, or Three` in U.S. English.

The rawValue of `or` is 1.
