# SortOrder.reverse

<sub>Case</sub>

The ordering that places the first item after the second when comparing two items using an ascending order.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case reverse
```

## Discussion

The ordering places the first item after the second when a [ComparisonResult](../comparisonresult.md) of two items is [NSOrderedAscending](../comparisonresult/orderedascending.md).
