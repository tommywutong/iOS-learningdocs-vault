# NSPropertyListImmutable

<sub>Enumeration Case</sub>

Causes the returned property list to contain immutable objects.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```objc
NSPropertyListImmutable
```
