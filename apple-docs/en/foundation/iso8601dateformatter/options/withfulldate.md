<sub>Type Property</sub>

```swift
static var withFullDate: ISO8601DateFormatter.Options { get }
```

## Discussion

The date representation includes the year, month, and day. Equivalent to specifying [NSISO8601DateFormatWithYear](withyear.md), [NSISO8601DateFormatWithMonth](withmonth.md), and [NSISO8601DateFormatWithDay](withday.md)
