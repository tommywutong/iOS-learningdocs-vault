# AttributeScopes.CoreTextAttributes.LineHeightAttribute

<sub>Enumeration</sub>

An attribute for defining the height of lines in a text.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
@frozen enum LineHeightAttribute
```

## Overview

> [!important] Important
> Note that this attribute is not for usage with CoreText APIs directly, but exposed to give other frameworks common vocabulary to express the line height concept as defined by CoreText in Swift. For more details, see [CoreTextAttributes](../coretextattributes.md).
