# init(listDescriptor:)

<sub>Initializer</sub>

Initializes a newly allocated instance as an empty list descriptor.

<sub>Mac Catalyst, macOS</sub>

```swift
convenience init(listDescriptor: ())
```

## Return Value

An empty list descriptor, or `nil` if an error occurs.

## Discussion

You can add items to the empty list descriptor with [- insertDescriptor:atIndex:](<insert(__at_).md>). The list indices are one-based.
