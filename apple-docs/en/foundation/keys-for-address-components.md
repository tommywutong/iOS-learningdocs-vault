# Keys for Address Components

<sub>API Collection</sub>

The following constants identify the possible keys returned in the [addressComponents](nstextcheckingresult/addresscomponents.md) dictionary.

## Topics

### Constants

- [NSTextCheckingNameKey](nstextcheckingkey/name.md) — A key that corresponds to the name component of the address.
- [NSTextCheckingJobTitleKey](nstextcheckingkey/jobtitle.md) — A key that corresponds to the job component of the address.
- [NSTextCheckingOrganizationKey](nstextcheckingkey/organization.md) — A key that corresponds to the organization component of the address.
- [NSTextCheckingStreetKey](nstextcheckingkey/street.md) — A key that corresponds to the street address component of the address.
- [NSTextCheckingCityKey](nstextcheckingkey/city.md) — A key that corresponds to the city component of the address.
- [NSTextCheckingStateKey](nstextcheckingkey/state.md) — A key that corresponds to the state or province component of the address.
- [NSTextCheckingZIPKey](nstextcheckingkey/zip.md) — A key that corresponds to the zip code or postal code component of the address.
- [NSTextCheckingCountryKey](nstextcheckingkey/country.md) — A key that corresponds to the country or region component of the address.
- [NSTextCheckingPhoneKey](nstextcheckingkey/phone.md) — A key that corresponds to the phone number component of the address.
