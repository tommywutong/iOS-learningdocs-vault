# NSMidY(_:)

<sub>Function</sub>

Returns the y coordinate of a given rectangle’s midpoint.

<sub>Mac Catalyst, macOS</sub>

```swift
func NSMidY(_ aRect: NSRect) -> Double
```

## Return Value

The y coordinate of `aRect`’s center point.
