# init(identifier:)

<sub>Initializer</sub>

Creates a language from an identifier.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(identifier: String)
```

## Parameters

- `identifier` — A Unicode language identifier, like `en-US`, `es-419`, or `zh-Hant-TW`.
