# init(stringLiteral:)

<sub>Initializer</sub>

Creates a language code from an identifier as a string literal.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(stringLiteral value: String)
```

## Parameters

- `value` — A two-letter ISO 639-1 or three-letter ISO 639-2 code, such as `en` for English. You can also use a code of your own choice for a custom language.
