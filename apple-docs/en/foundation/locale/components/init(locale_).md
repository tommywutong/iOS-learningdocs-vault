# init(locale:)

<sub>Initializer</sub>

Creates a language components instance from an existing locale.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(locale: Locale)
```

## Parameters

- `locale` — A locale from which to copy component values.
