# string(withCString:)

<sub>Type Method</sub>

Creates a new string using a given C-string.

> [!warning] Deprecated
> Use `NSString/init(CString:encoding:)-7auq8` instead.

<sub>tvOS, visionOS, watchOS</sub>

```swift
class func string(withCString bytes: UnsafePointer<CChar>) -> Any?
```

## Discussion

`cString` should contain data in the default C string encoding. If the argument passed to [+ stringWithCString:](<string(withcstring_).md>) is not a zero-terminated C-string, the results are undefined.
