# init(_:)

<sub>Initializer</sub>

Creates a new kind of progress using the specified string.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift

```

## Parameters

- `rawValue` — A string that represents the kind of progress.
