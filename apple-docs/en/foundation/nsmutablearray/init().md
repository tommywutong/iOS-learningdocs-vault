# init()

<sub>Initializer</sub>

Initializes a newly allocated array.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init()
```

## Return Value

An array.

## Discussion

This method is a designated initializer.
