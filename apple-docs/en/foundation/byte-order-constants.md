# Byte Order

<sub>API Collection</sub>

Recognize constants that specify a byte-order format.

## Overview

These constants are returned by [NSHostByteOrder](<nshostbyteorder().md>).

## Topics

### Constants

- [NS_BigEndian](ns_bigendian.md) — The byte order is big endian.
- [NS_LittleEndian](ns_littleendian.md) — The byte order is little endian.
- [NS_UnknownByteOrder](ns_unknownbyteorder.md) — The byte order is unknown.
