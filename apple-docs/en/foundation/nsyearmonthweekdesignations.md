# NSYearMonthWeekDesignations

<sub>Global Variable</sub>

Key for an array of strings that specify the words for year, month, and week in the current locale.

> [!warning] Deprecated
> There is no direct replacement. If you need to localize words such as “year,” you should use a strings file as you would for any other localizable text—see Localizing String Resources.

<sub>macOS</sub>

```objc
extern NSString * const NSYearMonthWeekDesignations;
```

## Discussion

The defaults are “year,” “month,” and “week.”
