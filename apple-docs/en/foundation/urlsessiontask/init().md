# init()

<sub>Initializer</sub>

Initializes an empty URL sesson task.

> [!warning] Deprecated
> Not supported

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init()
```

## Discussion

Don’t use this initializer directly. Instead, create tasks from a [URLSession](../urlsession.md).
