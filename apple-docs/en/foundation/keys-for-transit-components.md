# Keys for Transit Components

<sub>API Collection</sub>

The following constants identify the possible keys returned in the components dictionary.

## Topics

### Constants

- [NSTextCheckingAirlineKey](nstextcheckingkey/airline.md) — A key that corresponds to the airline of a transit result.
- [NSTextCheckingFlightKey](nstextcheckingkey/flight.md) — A key that corresponds to the flight component of a transit result.
