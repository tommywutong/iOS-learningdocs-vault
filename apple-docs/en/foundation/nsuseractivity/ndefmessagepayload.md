# ndefMessagePayload

<sub>Instance Property</sub>

The NDEF message read by the system in the background.

<sub>iOS, iPadOS, Mac Catalyst</sub>

```swift
var ndefMessagePayload: NFCNDEFMessage { get }
```

## Discussion

For user activities not generated by background tag reading, [ndefMessagePayload](ndefmessagepayload.md) returns a message that contains only one [NFCNDEFPayload](../../corenfc/nfcndefpayload.md) record. That record has a [typeNameFormat](../../corenfc/nfcndefpayload/typenameformat.md) of [NFCTypeNameFormat.empty](../../corenfc/nfctypenameformat/empty.md). For more information, see [Adding Support for Background Tag Reading](../../corenfc/adding-support-for-background-tag-reading.md).
