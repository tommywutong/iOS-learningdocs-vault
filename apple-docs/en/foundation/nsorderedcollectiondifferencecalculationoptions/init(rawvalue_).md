# init(rawValue:)

<sub>Initializer</sub>

Creates a set of difference calculation options.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(rawValue: UInt)
```

## Parameters

- `rawValue` — An unsigned integer that represents a combined set of difference calculation options.
