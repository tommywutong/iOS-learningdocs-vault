# init()

<sub>Initializer</sub>

Initializes a new UUID with RFC 4122 version 4 random bytes.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init()
```

## Return Value

A new UUID object.
