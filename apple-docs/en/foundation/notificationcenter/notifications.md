# NotificationCenter.Notifications

<sub>Class</sub>

An asynchronous sequence of notifications generated by a notification center.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
final class Notifications
```

## Overview

Use the [notifications(named:object:)](<notifications(named_object_).md>) method to create an instance of this type, then iterate over its elements with the `for`-`await`-`in` syntax.

> [!tip] Tip
> The [Notification](../notification.md) type doesn’t conform to [Sendable](../../swift/sendable.md), so iterating over this asynchronous sequence produces a compiler warning. You can use a [map(_:)](<../../swift/asyncsequence/map(__)-1q1k3.md>) or [compactMap(_:)](<../../swift/asyncsequence/compactmap(__)-gfdq.md>) operator on the sequence to extract sendable properties of the notification and iterate over those instead. See [notifications(named:object:)](<notifications(named_object_).md>) for an example of this approach.
