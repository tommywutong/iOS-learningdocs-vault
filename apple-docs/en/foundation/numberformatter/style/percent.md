# NumberFormatter.Style.percent

<sub>Case</sub>

A percent style format.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case percent
```

## Discussion

For example, in the en_US locale, the number 0.123 is represented as 12%.
