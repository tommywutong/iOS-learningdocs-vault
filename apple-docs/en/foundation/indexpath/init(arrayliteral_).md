# init(arrayLiteral:)

<sub>Initializer</sub>

Creates an index path from an array literal.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(arrayLiteral indexes: IndexPath.Element...)
```
