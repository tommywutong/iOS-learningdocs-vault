# init(indexes:)

<sub>Initializer</sub>

Creates an index path from an array of elements.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(indexes: Array<IndexPath.Element>)
```
