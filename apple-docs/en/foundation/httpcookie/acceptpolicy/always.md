# HTTPCookie.AcceptPolicy.always

<sub>Case</sub>

Accept all cookies.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case always
```

## Discussion

This is the default cookie accept policy.
