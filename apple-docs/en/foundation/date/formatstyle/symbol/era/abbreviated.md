# abbreviated

<sub>Type Property</sub>

An abbreviated representation of an era.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static var abbreviated: Date.FormatStyle.Symbol.Era { get }
```

## Discussion

A custom format style conveying an abbreviated representation of an era. For example, `BC` (_before Christ_) and `AD` (_anno Domini_).
