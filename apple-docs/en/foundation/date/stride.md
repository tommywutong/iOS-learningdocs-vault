# Date.Stride

<sub>Type Alias</sub>

A type alias to define the stride of a date.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
typealias Stride = TimeInterval
```

## Discussion

The stride of a Date is a [TimeInterval](../timeinterval.md).
