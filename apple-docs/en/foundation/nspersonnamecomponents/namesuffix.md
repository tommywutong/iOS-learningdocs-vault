# nameSuffix

<sub>Instance Property</sub>

The portion of a name’s full form of address that follows the name itself _(for example, “Esq.,” “Jr.,” “Ph.D.”)_.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
var nameSuffix: String? { get set }
```
