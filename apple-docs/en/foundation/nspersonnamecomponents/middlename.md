# middleName

<sub>Instance Property</sub>

Secondary name bestowed upon an individual to differentiate them from others that have the same given name _(for example, “Maple”)_.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>
