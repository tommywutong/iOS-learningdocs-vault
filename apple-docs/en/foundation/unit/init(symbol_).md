# init(symbol:)

<sub>Initializer</sub>

Initializes a new unit with the specified symbol.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(symbol: String)
```

## Parameters

- `symbol` — The symbol used to represent the unit.

## Return Value

A new unit with the specified symbol.
