# Keyed Archiver Root Object Key

<sub>API Collection</sub>

Keys that the archiver uses in the hierarchy of encoded objects.

## Topics

### Constants

- [NSKeyedArchiveRootObjectKey](nskeyedarchiverootobjectkey.md) — Archives created using the class method [+ archivedDataWithRootObject:](<nskeyedarchiver/archiveddata(withrootobject_).md>) use this key for the root object in the hierarchy of encoded objects. The [NSKeyedUnarchiver](nskeyedunarchiver.md) class method [+ unarchiveObjectWithData:](<nskeyedunarchiver/unarchiveobject(with_).md>) looks for this root key as well.
