# Property Keys

<sub>API Collection</sub>

These keys correspond to the extension item properties and are specified in the extension’s `Info.plist`.

## Topics

### Constants

- [NSExtensionItemAttributedTitleKey](nsextensionitemattributedtitlekey.md) — An optional title of the extension item.
- [NSExtensionItemAttributedContentTextKey](nsextensionitemattributedcontenttextkey.md) — An optional string describing the extension item content.
- [NSExtensionItemAttachmentsKey](nsextensionitemattachmentskey.md) — An optional array of media data associated with the extension item.
