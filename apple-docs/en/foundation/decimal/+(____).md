# +(_:_:)

<sub>Operator</sub>

Adds two decimal numbers.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static func + (lhs: Decimal, rhs: Decimal) -> Decimal
```

## Parameters

- `lhs` — A value to add.

- `rhs` — Another value to add.

## Return Value

The result of adding `lhs` and `rhs`.

## Discussion

If the result of this operation requires more precision than the `Decimal` type can provide, the result is rounded using the [NSRoundPlain](../nsdecimalnumber/roundingmode/plain.md) rounding mode. To specify a different rounding mode, use the [NSDecimalAdd](<../nsdecimaladd(________).md>) function instead.
