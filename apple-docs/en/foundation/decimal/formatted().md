# formatted()

<sub>Instance Method</sub>

Formats the decimal using a default localized format style.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
func formatted() -> String
```

## Return Value
