# -=(_:_:)

<sub>Operator</sub>

Subtracts one decimal number from another, storing the result in the first number.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static func -= (lhs: inout Decimal, rhs: Decimal)
```

## Parameters

- `lhs` — The value to subtract from.

- `rhs` — The value to subtract.

## Discussion

If the result of this operation requires more precision than the `Decimal` type can provide, the result is rounded using the [NSRoundPlain](../nsdecimalnumber/roundingmode/plain.md) rounding mode. To specify a different rounding mode, use the [NSDecimalSubtract](<../nsdecimalsubtract(________).md>) function instead.
