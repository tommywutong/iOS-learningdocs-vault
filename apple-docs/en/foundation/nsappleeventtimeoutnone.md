# NSAppleEventTimeOutNone

<sub>Global Variable</sub>

Specifies that the application is willing to wait indefinitely for the current operation to complete. Not currently used by applications.

<sub>Mac Catalyst, macOS</sub>

```swift
let NSAppleEventTimeOutNone: Double
```

## See Also

### Constants

- [NSAppleEventTimeOutDefault](nsappleeventtimeoutdefault.md) — Specifies that an event-processing operation should continue until a timeout occurs based on a value determined by the Apple Event Manager (about 1 minute). Not currently used by applications.
