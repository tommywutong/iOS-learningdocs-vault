# init()

<sub>Initializer</sub>

Initializes a newly allocated set.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init()
```

## Return Value

A set.

## Discussion

This method is a designated initializer of `NSSet`.
