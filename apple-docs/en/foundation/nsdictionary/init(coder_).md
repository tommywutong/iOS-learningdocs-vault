# init(coder:)

<sub>Initializer</sub>

Creates a dictionary initialized from data in the provided unarchiver.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init?(coder: NSCoder)
```

## Parameters

- `coder` — An unarchiver object.
