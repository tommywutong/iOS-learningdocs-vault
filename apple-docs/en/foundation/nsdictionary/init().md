# init()

<sub>Initializer</sub>

Initializes a newly allocated dictionary.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init()
```

## Return Value

A dictionary.

## Discussion

This method is a designated initializer of [NSDictionary](../nsdictionary.md).
