# NSOpenStepUnicodeReservedBase

<sub>API Collection</sub>

Specifies lower bound for a Unicode character range reserved for Apple’s corporate use.

## Topics

### Constants

- [NSOpenStepUnicodeReservedBase](nsopenstepunicodereservedbase.md) — Specifies lower bound for a Unicode character range reserved for Apple’s corporate use (the range is `0xF400–0xF8FF`).
