# Accessing Indicies Within an Attributed String

<sub>API Collection</sub>

Access a position within an attributed string, offset from the beginning, or before or after another known position.

## Topics

### Accessing Terminal Indices

- [startIndex](attributedstring/startindex.md) — The position of the first character in a nonempty attributed string.
- [endIndex](attributedstring/endindex.md) — The string’s past-the-end position — the position one greater than the last valid subscript argument.

### Supporting Types

- [Index](attributedstring/index.md) — A type that represents the position of a character or code unit within an attributed string.
