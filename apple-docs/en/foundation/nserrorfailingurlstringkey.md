# NSErrorFailingURLStringKey

<sub>Global Variable</sub>

The URL that caused the error.

> [!warning] Deprecated
> This constant is deprecated starting in macOS 10.6 and is superseded by [NSURLErrorFailingURLStringErrorKey](nsurlerrorfailingurlstringerrorkey.md). Both constants refer to the same value for backward-compatibility, but the new symbol name has a better prefix.

let NSErrorFailingURLStringKey: String
