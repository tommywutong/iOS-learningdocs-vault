# setURI:

<sub>Article</sub>

Sets the URI of the receiver.

## Overview

The receiver must be an [XMLElement](xmlelement.md) or [XMLDocument](xmldocument.md) document, or an attribute (that is, an`NSXMLNode` object of type [NSXMLAttributeKind](xmlnode/kind-swift.enum/attribute.md)). For documents it is the URI of document origin.
