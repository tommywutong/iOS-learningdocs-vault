# NSByteCountFormatterUseDefault

<sub>Enumeration Case</sub>

This causes default units appropriate for the platform to be used. This is the default.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```objc
NSByteCountFormatterUseDefault
```
