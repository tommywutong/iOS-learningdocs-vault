# init(coder:)

<sub>Initializer</sub>

Creates a predicate by decoding from the coder you specify.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init?(coder: NSCoder)
```

## Parameters

- `coder` — The coder to read data from.
