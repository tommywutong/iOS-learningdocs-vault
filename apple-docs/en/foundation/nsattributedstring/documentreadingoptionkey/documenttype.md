# documentType

<sub>Type Property</sub>

The document type.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static let documentType: NSAttributedString.DocumentReadingOptionKey
```

## Discussion

One of the document types described in [DocumentType](../documenttype.md), indicating a document type to be forced when loading the document. The previous string constant was `@"DocumentType"`.
