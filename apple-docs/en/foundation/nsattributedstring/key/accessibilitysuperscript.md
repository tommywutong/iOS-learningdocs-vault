# accessibilitySuperscript

<sub>Type Property</sub>

Text superscript style (`NSNumber`). Values \> 0 are superscript; values \< 0 are subscript.

<sub>macOS</sub>

```swift
static let accessibilitySuperscript: NSAttributedString.Key
```
