# superscript

<sub>Type Property</sub>

The superscript of the text.

<sub>macOS</sub>

```swift
static let superscript: NSAttributedString.Key
```

## Discussion

The value of this attribute is an [NSNumber](../../nsnumber.md) object containing an integer. The default value is `0`.
