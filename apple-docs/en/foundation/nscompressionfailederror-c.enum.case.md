# NSCompressionFailedError

<sub>Enumeration Case</sub>

An error code value that indicates a failure to compress data using the provided algorithm.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

