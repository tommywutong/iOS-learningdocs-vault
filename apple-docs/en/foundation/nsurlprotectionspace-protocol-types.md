# NSURLProtectionSpace protocol types

<sub>API Collection</sub>

These constants describe the supported protocols for a protection space, as returned by [protocol](urlprotectionspace/protocol.md).

## Topics

### Protocol types

- [NSURLProtectionSpaceHTTP](nsurlprotectionspacehttp.md) — The protocol type for HTTP.
- [NSURLProtectionSpaceHTTPS](nsurlprotectionspacehttps.md) — The protocol type for HTTPS.
- [NSURLProtectionSpaceFTP](nsurlprotectionspaceftp.md) — The protocol type for FTP. _(deprecated)_
