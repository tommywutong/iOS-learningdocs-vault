# init()

<sub>Initializer</sub>

Initializes a newly allocated ordered set.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init()
```

## Return Value

An ordered set.

## Discussion

This method is a designated initializer of `NSOrderedSet`.
