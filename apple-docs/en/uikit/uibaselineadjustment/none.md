# UIBaselineAdjustment.none

<sub>Case</sub>

Adjust text relative to the top-left corner of the bounding box.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case none
```

## Discussion

This is the default adjustment.
