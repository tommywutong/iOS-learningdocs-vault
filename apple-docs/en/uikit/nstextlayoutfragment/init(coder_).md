# init(coder:)

<sub>Initializer</sub>

Creates a new layout fragment with the coder you provide.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
init?(coder: NSCoder)
```

## Parameters

- `coder` — A coder that conforms to [NSCoder](../../foundation/nscoder.md).
