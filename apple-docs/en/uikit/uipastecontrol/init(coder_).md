# init(coder:)

<sub>Initializer</sub>

Creates a paste button by deserializing the specified coder.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
init?(coder: NSCoder)
```

## Parameters

- `coder` — An object that contains a serialized paste button.

## See Also

### Creating a paste button

- [- initWithConfiguration:](<init(configuration_).md>) — Creates a paste button that conforms to the specified configuration.
- [- initWithFrame:](<init(frame_).md>) — Creates a paste button with the specified size and position.
