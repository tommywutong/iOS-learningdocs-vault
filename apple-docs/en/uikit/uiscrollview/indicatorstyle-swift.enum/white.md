# UIScrollView.IndicatorStyle.white

<sub>Case</sub>

A style of indicator is white and smaller than the default style.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case white
```

## Discussion

This style is good against a black content background.
