# init(horizontalSizeClass:)

<sub>Initializer</sub>

Creates a trait collection that contains only a specified horizontal size class.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
init(horizontalSizeClass: UIUserInterfaceSizeClass)
```

## Parameters

- `horizontalSizeClass` — A [UIUserInterfaceSizeClass](../uiuserinterfacesizeclass.md) value specifying the horizontal size class for the new trait collection.

## Return Value

A new trait collection containing only a specified horizontal size class trait.
