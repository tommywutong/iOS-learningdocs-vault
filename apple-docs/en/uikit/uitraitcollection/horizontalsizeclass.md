# horizontalSizeClass

<sub>Instance Property</sub>

The horizontal size class of the trait collection.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
var horizontalSizeClass: UIUserInterfaceSizeClass { get }
```

## Discussion
