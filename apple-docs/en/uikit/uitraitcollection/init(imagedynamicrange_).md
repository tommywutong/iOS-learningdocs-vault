# init(imageDynamicRange:)

<sub>Initializer</sub>

Construct a new trait collection with the given image content dynamic range.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
init(imageDynamicRange: UIImage.DynamicRange)
```
