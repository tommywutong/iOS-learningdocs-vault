# font

<sub>Instance Property</sub>

The font for the label.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
var font: UIFont
```

## Discussion

The default value of this property is the preferred font for [UIFontTextStyleBody](../../uifont/textstyle/body.md).
