## Topics

### Deprecated properties

- [mainScreen](uiscreen/main.md) — Returns the screen object representing the device’s screen. _(deprecated)_
- [screens](uiscreen/screens.md) — Returns an array containing all of the screens attached to the device. _(deprecated)_
- [applicationFrame](uiscreen/applicationframe.md) — The frame rectangle for the app window, measured in points. _(deprecated)_
- [focusedItem](uiscreen/focuseditem.md) — The item that is currently focused. _(deprecated)_
- [focusedView](uiscreen/focusedview.md) — The view that is currently focused. _(deprecated)_
- [supportsFocus](uiscreen/supportsfocus.md) — A Boolean value that indicates whether the screen supports focus-based inputs. _(deprecated)_

### Deprecated notifications

- [UIScreenDidConnectNotification](uiscreen/didconnectnotification.md) — A notification the system posts when a new screen connects to the device. _(deprecated)_
- [UIScreenDidDisconnectNotification](uiscreen/diddisconnectnotification.md) — A notification the system posts when a screen disconnects from the device. _(deprecated)_
