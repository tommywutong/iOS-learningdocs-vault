# UISegmentedControlStylePlain

<sub>Enumeration Case</sub>

The large plain style for segmented controls.

> [!warning] Deprecated
> Use `tintColor` instead.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
UISegmentedControlStylePlain
```

## Discussion

This style is the default.
