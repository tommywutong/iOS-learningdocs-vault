# UIAlertController.Style.actionSheet

<sub>Case</sub>

An action sheet displayed by the view controller that presented it.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case actionSheet
```

## Discussion

Use an action sheet to present the user with a set of alternatives for how to proceed with a given task. You can also use this style to prompt the user to confirm a potentially dangerous action. This alert style isn’t supported by tvOS; use [UIAlertControllerStyleAlert](alert.md) instead.
