# UIKeyboardType.webSearch

<sub>Case</sub>

Specifies a keyboard for web search terms and URL entry.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case webSearch
```

## Discussion

This keyboard type prominently features the space and period (”`.`”) characters.
