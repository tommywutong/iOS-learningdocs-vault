# grayButtonConfiguration

<sub>Type Method</sub>

Creates a configuration for a button with a gray background.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
+ (instancetype) grayButtonConfiguration;
```

## Return Value

A new configuration object.
