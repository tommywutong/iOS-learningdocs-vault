# addInteraction(_:)

<sub>Instance Method</sub>

Adds an interaction to the view.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift

```

## Parameters

- `interaction` — The interaction object to add to the view.
