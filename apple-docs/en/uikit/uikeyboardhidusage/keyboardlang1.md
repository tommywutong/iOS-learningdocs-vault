# UIKeyboardHIDUsage.keyboardLANG1

<sub>Case</sub>

The raw usage code 144 (decimal)/90 (hexadecimal).

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case keyboardLANG1
```

## Discussion

On Japanese language keyboards from Apple, the [UIKeyboardHIDUsageKeyboardLANG1](keyboardlang1.md) key is the Kana switch (かな) key. On Korean language keyboards, it’s the Hangul/English toggle key.
