# UITextDropEditability.no

<sub>Case</sub>

A text-drop editability specifier indicating that a noneditable text view does not accept drops.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
case no
```

## See Also

### Editability styles

- [UITextDropEditabilityTemporary](temporary.md) — A text-drop editability specifier indicating that a noneditable text view does accept drops but reverts to its noneditable status immediately afterward.
- [UITextDropEditabilityYes](yes.md) — A text-drop editability specifier indicating that a noneditable text view does accept drops, and that the dropped text remains editable after the drop is finished.
