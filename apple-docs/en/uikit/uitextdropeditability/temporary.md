# UITextDropEditability.temporary

<sub>Case</sub>

A text-drop editability specifier indicating that a noneditable text view does accept drops but reverts to its noneditable status immediately afterward.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
case temporary
```

## See Also

### Editability styles

- [UITextDropEditabilityNo](no.md) — A text-drop editability specifier indicating that a noneditable text view does not accept drops.
- [UITextDropEditabilityYes](yes.md) — A text-drop editability specifier indicating that a noneditable text view does accept drops, and that the dropped text remains editable after the drop is finished.
