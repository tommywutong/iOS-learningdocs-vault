# UIStackView.Alignment.leading

<sub>Case</sub>

A layout for vertical stacks where the stack view aligns the leading edge of its arranged views along its leading edge.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case leading
```

## Discussion

This value is equivalent to the [UIStackViewAlignmentTop](top.md) alignment for horizontal stacks.

The following image shows an example of a vertical stack view that uses the [UIStackViewAlignmentLeading](leading.md) alignment.

![A vertical stack view with four arranged subviews. The stack view aligns the subviews to its leading edge.](../../../../../attachments/139d69d392b2ec2d73b8956be18f4c7a/media-2557458@2x.png)
