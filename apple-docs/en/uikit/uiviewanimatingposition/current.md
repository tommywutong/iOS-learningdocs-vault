# UIViewAnimatingPosition.current

<sub>Case</sub>

The current position. Use this constant when you want the most recent value set by an animator object.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case current
```

- [UIViewAnimatingPositionStart](start.md) — The beginning of the animation. Use this constant when you want the starting values for any animatable properties—that is, the values of the properties before you applied any animations.
