# UIViewAnimatingPosition.start

<sub>Case</sub>

The beginning of the animation. Use this constant when you want the starting values for any animatable properties—that is, the values of the properties before you applied any animations.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case start
```

### Constants

- [UIViewAnimatingPositionEnd](end.md) — The end point of the animation. Use this constant when you want the final values for any animatable properties—that is, you want to refer to the values you specified in your animation blocks.
- [UIViewAnimatingPositionCurrent](current.md) — The current position. Use this constant when you want the most recent value set by an animator object.
