# UIMenuElement.State.mixed

<sub>Case</sub>

A constant indicating the menu element is in the “mixed” state.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case mixed
```

## Discussion

A [UIMenuElementStateMixed](mixed.md) state is one that’s neither “on” or “off”. The menu system displays a mixed-mark, such as a checkmark or hyphen, next to the menu element.
