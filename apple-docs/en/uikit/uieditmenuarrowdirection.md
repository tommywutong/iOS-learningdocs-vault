## Topics

### Constants

- [UIEditMenuArrowDirectionAutomatic](uieditmenuarrowdirection/automatic.md) — The arrow is pointing up or down at the object of focus, based on its location in the screen, which is the default.
- [UIEditMenuArrowDirectionUp](uieditmenuarrowdirection/up.md) — The arrow is pointing up at the object of focus.
- [UIEditMenuArrowDirectionDown](uieditmenuarrowdirection/down.md) — The arrow is pointing down at the object of focus.
- [UIEditMenuArrowDirectionLeft](uieditmenuarrowdirection/left.md) — The arrow is pointing left at the object of focus.
- [UIEditMenuArrowDirectionRight](uieditmenuarrowdirection/right.md) — The arrow is pointing right at the object of focus.
