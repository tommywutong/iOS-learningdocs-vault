# UIEvent.EventSubtype.remoteControlPreviousTrack

<sub>Case</sub>

A remote-control event for skipping to the previous audio or video track.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case remoteControlPreviousTrack
```

## Discussion

This is a subtype of the [UIEventTypeRemoteControl](../eventtype/remotecontrol.md) general event type.
