# init(location:)

<sub>Initializer</sub>

Creates a new text range at the location you specify.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```swift
convenience init(location: any NSTextLocation)
```

## Parameters

- `location` — An [NSTextLocation](../nstextlocation.md).
