# init(coder:)

<sub>Initializer</sub>

Initializes and returns a newly allocated text list item.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```swift
init?(coder: NSCoder)
```

## Parameters

- `coder` — An instance of [NSCoder](../../foundation/nscoder.md).
