# UITableViewCell.SelectionStyle.blue

<sub>Case</sub>

The cell has a default background color when it’s selected.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case blue
```

## Discussion

In iOS 7, the selection color is no longer blue. Use [UITableViewCellSelectionStyleDefault](default.md) instead.
