# UIPreferredPresentationStyle

<sub>Enumeration</sub>

The presentation styles that determine how a view shows an item provider’s data.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
enum UIPreferredPresentationStyle : NSInteger;
```

## Topics

### Presentation styles

- [UIPreferredPresentationStyleUnspecified](uipreferredpresentationstyle/uipreferredpresentationstyleunspecified.md) — A presentation style indicating that no preferred style is specified.
- [UIPreferredPresentationStyleInline](uipreferredpresentationstyle/uipreferredpresentationstyleinline.md) — A presentation style indicating that the item provider data should be presented inline.
- [UIPreferredPresentationStyleAttachment](uipreferredpresentationstyle/uipreferredpresentationstyleattachment.md) — A presentation style indicating that the item provider data should be presented as an attachment.
