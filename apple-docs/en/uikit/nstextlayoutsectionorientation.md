# NSTextLayoutSectionOrientation

<sub>Global Variable</sub>

The orientation of the text.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
extern NSTextLayoutSectionKey const NSTextLayoutSectionOrientation;
```

## Discussion

An [NSNumber](../foundation/nsnumber.md) object containing an [TextLayoutOrientation](nslayoutmanager/textlayoutorientation.md) value. The default value is [NSTextLayoutOrientationHorizontal](nslayoutmanager/textlayoutorientation/horizontal.md).
