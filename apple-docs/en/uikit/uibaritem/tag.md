# tag

<sub>Instance Property</sub>

The bar item’s tag, an app-supplied integer that you can use to identify bar item objects in your app.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
var tag: Int { get set }
```

## Discussion

The default value is `0`.
