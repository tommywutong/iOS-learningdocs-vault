# UITouch.TouchType.pencil

<sub>Case</sub>

A touch from Apple Pencil.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case pencil
```

## Discussion

A pencil touch occurs when Apple Pencil interacts with the device’s screen.

## See Also

### Touch types

- [UITouchTypeDirect](direct.md) — A touch resulting from direct contact with the screen.
- [UITouchTypeIndirect](indirect.md) — A touch that doesn’t result from contact with the screen.
- [UITouchTypeIndirectPointer](indirectpointer.md) — A touch resulting from a button-based, indirect input device that describes the input sequence from button press to button release.
