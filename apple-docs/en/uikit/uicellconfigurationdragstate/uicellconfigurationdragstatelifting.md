# UICellConfigurationDragStateLifting

<sub>Enumeration Case</sub>

A user interaction is lifting the cell, but it isn’t yet part of an active drag session.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
UICellConfigurationDragStateLifting
```
