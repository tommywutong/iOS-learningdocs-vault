# UICellConfigurationDragStateNone

<sub>Enumeration Case</sub>

The system hasn’t associated the cell with a drag session.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
UICellConfigurationDragStateNone
```
