# Deprecated symbols

<sub>API Collection</sub>

Symbols that buttons no longer support.

## Topics

### Title effects

- [reversesTitleShadowWhenHighlighted](uibutton/reversestitleshadowwhenhighlighted.md) — A Boolean value that determines whether the title shadow changes when the button is highlighted. _(deprecated)_

### Button presentation

- [adjustsImageWhenHighlighted](uibutton/adjustsimagewhenhighlighted.md) — A Boolean value that determines whether the image changes when the button is highlighted. _(deprecated)_
- [adjustsImageWhenDisabled](uibutton/adjustsimagewhendisabled.md) — A Boolean value that determines whether the image changes when the button is disabled. _(deprecated)_
- [showsTouchWhenHighlighted](uibutton/showstouchwhenhighlighted.md) — A Boolean value that determines whether tapping the button causes it to glow. _(deprecated)_

### Edge insets

- [contentEdgeInsets](uibutton/contentedgeinsets.md) — The inset or outset margins for the rectangle surrounding all of the button’s content. _(deprecated)_
- [titleEdgeInsets](uibutton/titleedgeinsets.md) — The inset or outset margins for the rectangle around the button’s title text. _(deprecated)_
- [imageEdgeInsets](uibutton/imageedgeinsets.md) — The inset or outset margins for the rectangle around the button’s image. _(deprecated)_

### Dimensions

- [- backgroundRectForBounds:](<uibutton/backgroundrect(forbounds_).md>) — Returns the rectangle in which the receiver draws its background. _(deprecated)_
- [- contentRectForBounds:](<uibutton/contentrect(forbounds_).md>) — Returns the rectangle in which the receiver draws its entire content. _(deprecated)_
- [- titleRectForContentRect:](<uibutton/titlerect(forcontentrect_).md>) — Returns the rectangle in which the receiver draws its title. _(deprecated)_
- [- imageRectForContentRect:](<uibutton/imagerect(forcontentrect_).md>) — Returns the rectangle in which the receiver draws its image. _(deprecated)_
