# frame

<sub>Instance Property</sub>

The frame rectangle, which describes the item’s location and size in its section’s coordinate system.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
var frame: CGRect { get }
```
