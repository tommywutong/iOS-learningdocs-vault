# bounds

<sub>Instance Property</sub>

The bounds rectangle, which describes the item’s location and size in its own coordinate system.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
var bounds: CGRect { get }
```
