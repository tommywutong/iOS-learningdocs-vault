# UIWritingToolsBehavior.limited

<sub>Case</sub>

An option to provide a limited, overlay-panel experience for the text view.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
case limited
```

## See Also

### Getting the writing tools behaviors

- [UIWritingToolsBehaviorNone](none.md) — An option to prevent the writing tools from modifying the text in the view.
- [UIWritingToolsBehaviorDefault](default.md) — An option to let the system determine the best way to enable writing tools for the view.
- [UIWritingToolsBehaviorComplete](complete.md) — An option to provide the complete writing tools experience for the text view.
