# UIUserNotificationActionResponseTypedTextKey

<sub>Global Variable</sub>

The response text selected by the user.

> [!warning] Deprecated
> Use [userText](../usernotifications/untextinputnotificationresponse/usertext.md) instead.

<sub>iOS, iPadOS, Mac Catalyst</sub>

```swift
let UIUserNotificationActionResponseTypedTextKey: String
```

## Discussion

The value of this key is an [NSString](../foundation/nsstring.md) containing the user’s text response.
