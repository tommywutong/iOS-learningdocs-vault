# offset

<sub>Instance Property</sub>

The offset, in points, of the layer’s shadow. Defaults to `CGSizeZero`.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
@property (nonatomic, assign) CGSize offset;
```
