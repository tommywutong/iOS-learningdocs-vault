# radius

<sub>Instance Property</sub>

The blur radius, in points, used to render the shadow. Defaults to `0.0`.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
@property (nonatomic, assign) CGFloat radius;
```
