# UITextInputTextColorKey

<sub>Global Variable</sub>

The color of the text.

> [!warning] Deprecated
> In Swift, use [foregroundColor](../foundation/nsattributedstring/key/foregroundcolor.md) instead. In Objective-C, use [NSForegroundColorAttributeName](nsforegroundcolorattributename.md) instead.

<sub>iOS, iPadOS, Mac Catalyst</sub>

```swift
let UITextInputTextColorKey: String
```

## Discussion

The value of this key is a [UIColor](uicolor.md) object.
