# init(coder:)

<sub>Initializer</sub>

Creates a search bar from data in a given unarchiver.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
init?(coder: NSCoder)
```

## Parameters

- `coder` — An unarchiver object.
