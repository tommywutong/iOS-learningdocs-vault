# UISearchBar.Style.default

<sub>Case</sub>

The search bar has the default style.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case `default`
```

## Discussion

Defaults to [UISearchBarStyleProminent](prominent.md).

## See Also

### Constants

- [UISearchBarStyleProminent](prominent.md) — The search bar has a translucent background, and the search field is opaque.
- [UISearchBarStyleMinimal](minimal.md) — The search bar has no background, and the search field is translucent.
