# placeholder

<sub>Instance Property</sub>

The string to display when there’s no other text in the text field.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
var placeholder: String? { get set }
```

## Discussion

The default value is `nil`.
