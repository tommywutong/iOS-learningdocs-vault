# UIPageViewController.SpineLocation.none

<sub>Case</sub>

No spine.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case none
```

## Discussion

This spine location is not valid if the transition style is [UIPageViewControllerTransitionStylePageCurl](../transitionstyle-swift.enum/pagecurl.md).
