# infinite

<sub>Type Property</sub>

Returns the region that encloses all points.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
class var infinite: UIRegion { get }
```

## Return Value

A shared region object that encompasses an infinite area.
