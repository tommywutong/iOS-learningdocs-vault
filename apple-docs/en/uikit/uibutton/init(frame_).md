# init(frame:)

<sub>Initializer</sub>

Creates a new button with the specified frame.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
init(frame: CGRect)
```

## Parameters

- `frame` — The frame rectangle for the view, measured in points.

## See Also

### Creating buttons

- [- initWithFrame:primaryAction:](<init(frame_primaryaction_).md>) — Creates a new button with the specified frame, registers the primary action event, and sets the title and image to the action’s title and image.
- [- initWithCoder:](<init(coder_).md>) — Creates a new button with data in an unarchiver.
