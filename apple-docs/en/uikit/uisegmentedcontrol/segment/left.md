# UISegmentedControl.Segment.left

<sub>Case</sub>

The capped, leftmost segment.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift

```

## Discussion

Applies only when [numberOfSegments](../numberofsegments.md) is greater than 1.
