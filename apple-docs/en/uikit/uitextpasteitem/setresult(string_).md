# setResult(string:)

<sub>Instance Method</sub>

Sets a text paste item’s textual value to a specified plaintext string from the item provider.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
func setResult(string: String)
```
