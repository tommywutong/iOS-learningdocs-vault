# left

<sub>Type Property</sub>

Scroll so that the item is positioned at the left edge of the collection view’s bounds.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
static var left: UICollectionView.ScrollPosition { get }
```

## Discussion

This option is mutually exclusive with the [UICollectionViewScrollPositionCenteredHorizontally](centeredhorizontally.md) and [UICollectionViewScrollPositionRight](right.md) options.
