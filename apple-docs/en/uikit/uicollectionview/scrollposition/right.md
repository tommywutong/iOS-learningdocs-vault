# right

<sub>Type Property</sub>

Scroll so that the item is positioned at the right edge of the collection view’s bounds.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
static var right: UICollectionView.ScrollPosition { get }
```

## Discussion

This option is mutually exclusive with the [UICollectionViewScrollPositionLeft](left.md) and [UICollectionViewScrollPositionCenteredHorizontally](centeredhorizontally.md) options.
