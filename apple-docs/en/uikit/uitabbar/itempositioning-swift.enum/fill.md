# UITabBar.ItemPositioning.fill

<sub>Case</sub>

Distribute items across the entire width of the tab bar.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

## Discussion

When the [UITabBarItemPositioningAutomatic](automatic.md) option is selected, the tab bar uses this behavior in horizontally compact environments.
