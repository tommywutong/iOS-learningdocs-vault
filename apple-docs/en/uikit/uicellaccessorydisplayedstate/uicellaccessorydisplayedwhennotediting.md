# UICellAccessoryDisplayedWhenNotEditing

<sub>Enumeration Case</sub>

The accessory displays only when the cell isn’t in editing mode.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
UICellAccessoryDisplayedWhenNotEditing
```

## See Also

### States

- [UICellAccessoryDisplayedAlways](uicellaccessorydisplayedalways.md) — The accessory always displays.
- [UICellAccessoryDisplayedWhenEditing](uicellaccessorydisplayedwhenediting.md) — The accessory displays only when the cell is in editing mode.
