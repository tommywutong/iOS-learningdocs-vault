# UICellAccessoryDisplayedWhenEditing

<sub>Enumeration Case</sub>

The accessory displays only when the cell is in editing mode.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
UICellAccessoryDisplayedWhenEditing
```

## See Also

### States

- [UICellAccessoryDisplayedAlways](uicellaccessorydisplayedalways.md) — The accessory always displays.
- [UICellAccessoryDisplayedWhenNotEditing](uicellaccessorydisplayedwhennotediting.md) — The accessory displays only when the cell isn’t in editing mode.
