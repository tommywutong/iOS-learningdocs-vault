# UITextAttributeTextColor

<sub>Global Variable</sub>

The key to the text color in a text attributes dictionary.

> [!warning] Deprecated
> Use [NSForegroundColorAttributeName](nsforegroundcolorattributename.md) instead.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
extern NSString * const UITextAttributeTextColor;
```

## Discussion

The corresponding value is an instance of [UIColor](uicolor.md).
