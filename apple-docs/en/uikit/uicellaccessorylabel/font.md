# font

<sub>Instance Property</sub>

The font for the label.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
@property (nonatomic, strong) UIFont * font;
```

## Discussion

The default value of this property is the preferred font for [UIFontTextStyleBody](../uifont/textstyle/body.md).

### Accessing configuration options

- [text](text.md) — The text for the label to display.
