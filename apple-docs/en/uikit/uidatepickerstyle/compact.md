# UIDatePickerStyle.compact

<sub>Case</sub>

A style indicating that the date picker displays as a label that when tapped displays a calendar-style editor.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
case compact
```

## Discussion

You can’t use this style with the [UIDatePickerModeCountDownTimer](../uidatepicker/mode/countdowntimer.md) mode.
