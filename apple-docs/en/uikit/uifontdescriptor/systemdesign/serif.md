# serif

<sub>Type Property</sub>

The serif variant of the default typeface.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```swift
static let serif: UIFontDescriptor.SystemDesign
```

## Discussion

Using this constant with [- fontDescriptorWithDesign:](<../withdesign(__).md>) returns [New York](https://developer.apple.com/fonts/).
