# init(coder:)

<sub>Initializer</sub>

Creates a new content manager object from data in an unarchiver.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
init?(coder: NSCoder)
```

## Parameters

- `coder` — An unachiver that conforms to the [NSCoder](../../foundation/nscoder.md) class.
