# init(configuration:)

<sub>Initializer</sub>

Creates a new content-unavailable view with the specified configuration.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
@MainActor @preconcurrency convenience init(configuration: UIContentUnavailableConfiguration)
```

## Parameters

- `configuration` — The configuration describing the view’s appearance and behavior.
