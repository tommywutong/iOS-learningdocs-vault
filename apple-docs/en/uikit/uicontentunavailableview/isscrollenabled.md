# isScrollEnabled

<sub>Instance Property</sub>

A Boolean value that determines whether the view content can scroll.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
var isScrollEnabled: Bool { get set }
```

## Discussion

The default is `NO`.
