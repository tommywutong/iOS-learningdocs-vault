# NSLineBreakStrategyNone

<sub>Enumeration Case</sub>

The text system doesn’t use any line-break strategies.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
NSLineBreakStrategyNone
```

## See Also

### Getting the line-break styles

- [NSLineBreakStrategyPushOut](../nsparagraphstyle/linebreakstrategy-swift.struct/pushout.md) — The text system pushes out individual lines to avoid an orphan word on the last line of the paragraph.
- [NSLineBreakStrategyHangulWordPriority](../nsparagraphstyle/linebreakstrategy-swift.struct/hangulwordpriority.md) — The text system prohibits breaking between Hangul characters.
- [NSLineBreakStrategyStandard](../nsparagraphstyle/linebreakstrategy-swift.struct/standard.md) — The text system uses the same configuration of line-break strategies that it uses for standard UI labels.
