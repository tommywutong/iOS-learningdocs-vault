# Style dictionary keys

<sub>API Collection</sub>

A dictionary that contains properties that define text style characteristics.

## Overview

The style [NSDictionary](../foundation/nsdictionary.md) object is used for providing styling information for marked text ([markedTextStyle](uitextinput/markedtextstyle.md) property) and for providing text-styling information at a certain position ([- textStylingAtPosition:inDirection:](<uitextinput/textstyling(at_in_).md>) method).
