# position

<sub>Instance Property</sub>

The position of the halo effect relative to its shape.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
var position: UIFocusHaloEffect.Position { get set }
```

## Discussion

The default value of this property is [UIFocusHaloEffectPositionAutomatic](position-swift.enum/automatic.md).
