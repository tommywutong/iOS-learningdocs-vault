# UISplitViewController.Column.inspector

<sub>Case</sub>

The column for the inspector, or trailing, view controller.

<sub>iOS, iPadOS, Mac Catalyst</sub>

```swift
case inspector
```

## Overview

By default, the split view controller hides the `inspector` column. To show the `inspector` column, call [- showColumn:](<../show(__).md>).
