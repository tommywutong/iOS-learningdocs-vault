# UISplitViewController.Column.compact

<sub>Case</sub>

The column for the view controller that’s shown when the split view controller is collapsed.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case compact
```

## Discussion

If a view controller is set for this column, that view controller is shown when [collapsed](../iscollapsed.md) is [true](../../../swift/true.md).
