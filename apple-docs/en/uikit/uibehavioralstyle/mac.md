# UIBehavioralStyle.mac

<sub>Case</sub>

A style that indicates that a control appears and behaves as it does in macOS.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
case mac
```

## Discussion

This style effects a control’s behavior only when the app’s user interface idiom is [UIUserInterfaceIdiomMac](../uiuserinterfaceidiom/mac.md).
