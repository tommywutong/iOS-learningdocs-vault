# offset

<sub>Instance Property</sub>

The floating-point value of the anchor’s offset from the item it’s attached to.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
var offset: CGPoint { get }
```

### Getting the offset

- [isAbsoluteOffset](isabsoluteoffset.md) — A Boolean value that indicates whether the anchor’s offset is expressed as an absolute value.
- [isFractionalOffset](isfractionaloffset.md) — A Boolean value that indicates whether the anchor’s offset is expressed as a fraction of its supplementary item’s dimension.
