# isAbsoluteOffset

<sub>Instance Property</sub>

A Boolean value that indicates whether the anchor’s offset is expressed as an absolute value.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
var isAbsoluteOffset: Bool { get }
```

### Getting the offset

- [offset](offset.md) — The floating-point value of the anchor’s offset from the item it’s attached to.
- [isFractionalOffset](isfractionaloffset.md) — A Boolean value that indicates whether the anchor’s offset is expressed as a fraction of its supplementary item’s dimension.
