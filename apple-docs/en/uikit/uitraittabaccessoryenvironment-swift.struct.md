# UITraitTabAccessoryEnvironment

<sub>Structure</sub>

A struct that represents tab accessory environment trait.

<sub>iOS, iPadOS, Mac Catalyst</sub>

```swift
struct UITraitTabAccessoryEnvironment
```

## Overview

The trait specifies the [Environment](uitabaccessory/environment.md), if any, that a view is in. It is set on views inside [bottomAccessory](uitabbarcontroller/bottomaccessory.md). Defaults to [UITabAccessoryEnvironmentUnspecified](uitabaccessory/environment/unspecified.md).
