# init(components:)

<sub>Initializer</sub>

Creates a group of components.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
init(components: [UITextFormattingViewController.Component])
```

## Parameters

- `components` — Components to be included in the group.
