# isAnimating

<sub>Instance Property</sub>

A Boolean value indicating whether the activity indicator is currently running its animation.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
var isAnimating: Bool { get }
```
