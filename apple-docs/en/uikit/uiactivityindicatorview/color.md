# color

<sub>Instance Property</sub>

The color of the activity indicator.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
var color: UIColor! { get set }
```

## Discussion

If you set a color for an activity indicator, it overrides the color provided by the [activityIndicatorViewStyle](style-swift.property.md) property.
