# init(coder:)

<sub>Initializer</sub>

Creates an activity indicator from data in an unarchiver.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
init(coder: NSCoder)
```

## Parameters

- `coder` — An unarchiver object.
