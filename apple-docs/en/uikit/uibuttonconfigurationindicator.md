# UIButtonConfigurationIndicator

<sub>Enumeration</sub>

Constants that determine the style of the indicator that appears on a button.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
enum UIButtonConfigurationIndicator : NSInteger;
```

## Overview

Use these constants to set the value of the [indicator](uibuttonconfiguration/indicator.md) property.

## Topics

### Indicator styles

- [UIButtonConfigurationIndicatorAutomatic](uibuttonconfigurationindicator/uibuttonconfigurationindicatorautomatic.md) — A constant that automatically determines an indicator style according to the button’s properties.
- [UIButtonConfigurationIndicatorNone](uibuttonconfigurationindicator/uibuttonconfigurationindicatornone.md) — A constant that doesn’t show an indicator.
- [UIButtonConfigurationIndicatorPopup](uibuttonconfigurationindicator/uibuttonconfigurationindicatorpopup.md) — A constant that shows a popup-style indicator.
