# UINavigationBar.NSToolbarSection.none

<sub>Case</sub>

A constant that disables hosting the navigation bar in the toolbar.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
case none
```

## Discussion

Use this value to disable [NSToolbar](../../../appkit/nstoolbar.md) hosting. This value is equivalent to setting the [preferredBehavioralStyle](../preferredbehavioralstyle.md) of the navigation bar to [UIBehavioralStylePad](../../uibehavioralstyle/pad.md).
