# NSTextAlignment.natural

<sub>Case</sub>

Text uses the default alignment for the current localization of the app.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```swift
case natural
```

## Discussion

The default alignment for left-to-right scripts is [NSTextAlignmentLeft](left.md), and the default alignment for right-to-left scripts is [NSTextAlignmentRight](right.md).
