# UITab.Placement.default

case `default`

## See Also

### Placement values

- [UITabPlacementAutomatic](automatic.md) — The system adds only top-level items to the tab bar, but people can add, remove, or move this item.
- [UITabPlacementFixed](fixed.md) — The item appears in the tab bar’s leading edge, and people can’t move or remove it.
- [UITabPlacementMovable](movable.md) — The item appears in the tab bar, people can move it but can’t remove it.
- [UITabPlacementOptional](optional.md) — The item doesn’t appear in the tab bar, but people can add it and move it.
- [UITabPlacementPinned](pinned.md) — The item appears as a pinned tab, on the trailing edge of the tab bar.
- [UITabPlacementSidebarOnly](sidebaronly.md) — The item only appears in the sidebar.
