# systemGray5

<sub>Type Property</sub>

A fifth-level shade of gray that adapts to the environment.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
class var systemGray5: UIColor { get }
```

## Discussion

This color adapts to the current environment. In light environments, this gray is slightly lighter than [systemGray4Color](systemgray4.md). In dark environments, this gray is slightly darker than [systemGray4Color](systemgray4.md).
