# systemGray2

<sub>Type Property</sub>

A second-level shade of gray that adapts to the environment.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
class var systemGray2: UIColor { get }
```

## Discussion

This color adapts to the current environment. In light environments, this gray is slightly lighter than [systemGrayColor](systemgray.md). In dark environments, this gray is slightly darker than [systemGrayColor](systemgray.md).
