# lightText

<sub>Type Property</sub>

The nonadaptable system color for text on a dark background.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
class var lightText: UIColor { get }
```

## Return Value

The `UIColor` object.

## Discussion
