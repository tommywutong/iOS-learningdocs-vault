# systemGray3

<sub>Type Property</sub>

A third-level shade of gray that adapts to the environment.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
class var systemGray3: UIColor { get }
```

## Discussion

This color adapts to the current environment. In light environments, this gray is slightly lighter than [systemGray2Color](systemgray2.md). In dark environments, this gray is slightly darker than [systemGray2Color](systemgray2.md).
