# systemGray6

<sub>Type Property</sub>

A sixth-level shade of gray that adapts to the environment.

<sub>iOS, iPadOS, Mac Catalyst, visionOS</sub>

```swift
class var systemGray6: UIColor { get }
```

## Discussion

This color adapts to the current environment, and is close in color to [systemBackgroundColor](systembackground.md). In light environments, this gray is slightly lighter than [systemGray5Color](systemgray5.md). In dark environments, this gray is slightly darker than [systemGray5Color](systemgray5.md).
