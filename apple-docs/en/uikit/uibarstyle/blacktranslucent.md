# UIBarStyle.blackTranslucent

<sub>Case</sub>

A deprecated translucent style.

> [!warning] Deprecated
> Use [UIBarStyleBlack](black.md) and set the [translucent](../uinavigationbar/istranslucent.md) property to [true](../../swift/true.md) instead.

<sub>iOS, iPadOS, Mac Catalyst</sub>

```swift
case blackTranslucent
```
