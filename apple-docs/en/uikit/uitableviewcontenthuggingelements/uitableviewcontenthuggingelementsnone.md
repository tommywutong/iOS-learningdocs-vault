# UITableViewContentHuggingElementsNone

<sub>Enumeration Case</sub>

A mode where none of the items in the table view tightly hug their content.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
UITableViewContentHuggingElementsNone
```
