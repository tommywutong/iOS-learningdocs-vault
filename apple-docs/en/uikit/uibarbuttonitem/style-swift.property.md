# style

<sub>Instance Property</sub>

The style of the item.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
var style: UIBarButtonItem.Style { get set }
```

## Discussion

One of the constants defined in [Style](style-swift.enum.md). The default value is [UIBarButtonItemStylePlain](style-swift.enum/plain.md).
