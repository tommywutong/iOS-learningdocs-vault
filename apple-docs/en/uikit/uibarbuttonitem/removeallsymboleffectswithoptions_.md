# removeAllSymbolEffectsWithOptions:

<sub>Instance Method</sub>

Removes all symbol effects from the bar button item, using the specified options.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```objc
- (void) removeAllSymbolEffectsWithOptions:(NSSymbolEffectOptions *) options;
```

## Parameters

- `options` — The options to use when removing the symbol effects.
