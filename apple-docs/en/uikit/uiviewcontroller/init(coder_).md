# init(coder:)

<sub>Initializer</sub>

Creates a view controller with data in an unarchiver.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
init?(coder: NSCoder)
```

## Parameters

- `coder` — An unarchiver object.
