# MTLAccelerationStructureInstanceOptionNone

<sub>Enumeration Case</sub>

Specifies the default behavior for resulting acceleration structure.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```objc
MTLAccelerationStructureInstanceOptionNone
```
