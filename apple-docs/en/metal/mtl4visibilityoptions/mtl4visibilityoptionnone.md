# MTL4VisibilityOptionNone

<sub>Enumeration Case</sub>

Don’t flush caches. When you use this option on a barrier, it turns it into an execution barrier.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```objc
MTL4VisibilityOptionNone
```
