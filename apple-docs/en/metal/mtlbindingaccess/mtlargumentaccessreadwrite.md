# MTLArgumentAccessReadWrite

<sub>Enumeration Case</sub>

The function can either read or write its argument data.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```objc
MTLArgumentAccessReadWrite
```
