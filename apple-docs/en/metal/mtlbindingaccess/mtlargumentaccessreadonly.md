# MTLArgumentAccessReadOnly

<sub>Enumeration Case</sub>

The function can only read its argument data.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```objc
MTLArgumentAccessReadOnly
```

### Specifying access options

- [MTLArgumentAccessReadWrite](mtlargumentaccessreadwrite.md) — The function can either read or write its argument data. _(deprecated)_
