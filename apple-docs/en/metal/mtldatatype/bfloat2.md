# MTLDataType.bfloat2

<sub>Case</sub>

A two-component vector with 16-bit, brain floating-point values.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
case bfloat2
```

## Discussion

Each 16-bit value stores one sign bit, eight exponent bits, and seven mantissa bits.
