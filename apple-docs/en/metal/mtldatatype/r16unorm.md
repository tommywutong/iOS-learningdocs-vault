# MTLDataType.r16Unorm

<sub>Case</sub>

An ordinary pixel with one component that’s a 16-bit, normalized, unsigned integer value.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
case r16Unorm
```

## Discussion

The single color component is for red.
