# MTLDataType.r16Snorm

<sub>Case</sub>

An ordinary pixel with one component that’s a 16-bit, normalized, signed integer value.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
case r16Snorm
```

## Discussion

The single color component is for red.
