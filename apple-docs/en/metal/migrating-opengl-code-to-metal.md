## Overview

> [!note] Note
> This sample code project is associated with WWDC 2019 session [611: Bringing OpenGL Apps to Metal](https://developer.apple.com/videos/play/wwdc2019/611/).

### Configure the sample code project

To run the app:

- Build the project with Xcode 11 or later.
- Target an iOS device or simulator with iOS 11 or later.
