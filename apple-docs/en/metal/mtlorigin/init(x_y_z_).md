# init(x:y:z:)

<sub>Initializer</sub>

Initializes a new origin with the specified coordinates.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
init(x: Int, y: Int, z: Int)
```

## Parameters

- `x` — The x coordinate.

- `y` — The y coordinate.

- `z` — The z coordinate.
