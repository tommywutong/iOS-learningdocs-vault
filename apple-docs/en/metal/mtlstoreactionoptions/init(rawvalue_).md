# init(rawValue:)

<sub>Initializer</sub>

Creates a store action option from a raw integer value.

> [!warning] Deprecated
> Store action options have no effect on Apple Silicon

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
init(rawValue: UInt)
```

## Parameters

- `rawValue` — The raw value to use.
