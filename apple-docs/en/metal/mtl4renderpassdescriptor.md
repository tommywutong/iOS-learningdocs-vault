# MTL4RenderPassDescriptor

<sub>Class</sub>

Describes a render pass.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
class MTL4RenderPassDescriptor
```

## Overview

You use render pass descriptors to create instances of [MTL4RenderCommandEncoder](mtl4rendercommandencoder.md) and encode draw commands into instances of [MTL4CommandBuffer](mtl4commandbuffer.md).

To create render command encoders, you typically call [renderCommandEncoderWithDescriptor:](mtl4commandbuffer/rendercommandencoderwithdescriptor_.md). The [- renderCommandEncoderWithDescriptor:options:](<mtl4commandbuffer/makerendercommandencoder(descriptor_options_).md>) variant of this method allows you to specify additional options to encode a render pass in parallel from multiple CPU cores by creating _suspending_ and _resuming_ render passes.
