# init(rawValue:)

<sub>Initializer</sub>

Creates a set of resource options from a raw value.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
init(rawValue: UInt)
```

## Parameters

- `rawValue` — The raw value to convert into a set of resource options.
