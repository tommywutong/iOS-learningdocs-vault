# Accelerating ray tracing and motion blur using Metal

<sub>Sample Code</sub>

Generate ray-traced images with motion blur using GPU-based parallel processing.

## Overview

> [!note] Note
> This sample code project is associated with WWDC22 session [10105: Maximize your Metal ray tracing performance](https://developer.apple.com/wwdc22/10105/) and WWDC21 session [10149: Enhance your app with Metal ray tracing](https://developer.apple.com/wwdc21/10149/).

### Configure the sample code project

This sample requires the following system and software configuration:

- macOS 12 or later
- iOS 15 or later
- Xcode 13 or later
