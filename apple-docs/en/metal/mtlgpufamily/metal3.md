# MTLGPUFamily.metal3

<sub>Case</sub>

Represents the Metal 3 features.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
case metal3
```

## Discussion

The following platform and GPU combinations support Metal 3:

|  | GPUs |
|---|---|
| iOS | A14 and later |
| iPadOS | A14 and later ![](../../../../attachments/67dc4b07a8d84366d4cc0e812eb40b4a/spacer.png) M1 and later |
| macOS | M1 and later ![](../../../../attachments/67dc4b07a8d84366d4cc0e812eb40b4a/spacer.png) AMD Vega ![](../../../../attachments/67dc4b07a8d84366d4cc0e812eb40b4a/spacer.png) AMD 5000-series ![](../../../../attachments/67dc4b07a8d84366d4cc0e812eb40b4a/spacer.png) AMD 6000-series ![](../../../../attachments/67dc4b07a8d84366d4cc0e812eb40b4a/spacer.png) Intel Iris Pro Graphics  ![](../../../../attachments/67dc4b07a8d84366d4cc0e812eb40b4a/spacer.png) Intel UHD Graphics 630 |
