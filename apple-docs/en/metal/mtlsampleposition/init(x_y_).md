# init(x:y:)

<sub>Initializer</sub>

Returns a new sample position on a subpixel grid at specified coordinates.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
init(x: Float, y: Float)
```

## Parameters

- `x` — The x coordinate.

- `y` — The y coordinate.
