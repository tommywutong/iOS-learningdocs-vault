# init(for:)

<sub>Initializer</sub>

Creates a request for modifying the specified upload job.

<sub>iOS, iPadOS, Mac Catalyst, macOS</sub>

```swift
convenience init?(for job: PHAssetResourceUploadJob)
```

## Parameters

- `job` — A job to be modified.
