# Gradient Types

<sub>API Collection</sub>

The style of gradient drawn by the layer.

## Topics

### Constants

- [kCAGradientLayerAxial](cagradientlayertype/axial.md) — An axial gradient (also called a linear gradient) varies along an axis between two defined end points. All points that lie on a line perpendicular to the axis have the same color value.
