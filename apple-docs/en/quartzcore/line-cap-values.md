# Line Cap Values

<sub>API Collection</sub>

These constants specify the shape of endpoints for an open path when stroked.

## Overview

Used by [lineCap](cashapelayer/linecap.md). The following figure shows the appearance of the available line cap styles.

![](../../../attachments/5639a2a1fdd14a26edcf53a53ca3d86a/media-1965770.gif)

## Topics

### Constants

- [kCALineCapButt](cashapelayerlinecap/butt.md) — Specifies a butt line cap style for endpoints for an open path when stroked.
- [kCALineCapRound](cashapelayerlinecap/round.md) — Specifies a round line cap style for endpoints for an open path when stroked.
- [kCALineCapSquare](cashapelayerlinecap/square.md) — Specifies a square line cap style for endpoints for an open path when stroked.
