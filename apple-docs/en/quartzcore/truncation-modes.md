# Truncation modes

<sub>API Collection</sub>

These constants are used by the [truncationMode](catextlayer/truncationmode.md) property.

## Topics

### Constants

- [kCATruncationNone](catextlayertruncationmode/none.md) — Each line is displayed so that the text is either wrapped or clipped.
- [kCATruncationStart](catextlayertruncationmode/start.md) — Each line is displayed so that the end fits in the container and the missing text is indicated by some kind of ellipsis glyph.
- [kCATruncationEnd](catextlayertruncationmode/end.md) — Each line is displayed so that the beginning fits in the container and the missing text is indicated by some kind of ellipsis glyph.
- [kCATruncationMiddle](catextlayertruncationmode/middle.md) — Each line is displayed so that the beginning and end fit in the container and the missing text is indicated by some kind of ellipsis glyph in the middle.
