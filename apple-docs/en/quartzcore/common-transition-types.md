# Common Transition Types

<sub>API Collection</sub>

These constants specify the transition types that can be used with the [type](catransition/type.md) property.

## Topics

### Constants

- [kCATransitionFade](catransitiontype/fade.md) — The layer’s content fades as it becomes visible or hidden.
- [kCATransitionMoveIn](catransitiontype/movein.md) — The layer’s content slides into place over any existing content.
- [kCATransitionPush](catransitiontype/push.md) — The layer’s content pushes any existing content as it slides into place.
- [kCATransitionReveal](catransitiontype/reveal.md) — The layer’s content is revealed gradually in the direction specified by the transition subtype.
