# Scroll Modes

<sub>API Collection</sub>

These constants describe the supported scroll modes used by the [scrollMode](cascrolllayer/scrollmode.md) property.

## Topics

### Constants

- [kCAScrollNone](cascrolllayerscrollmode/none.md) — The receiver is unable to scroll.
- [kCAScrollVertically](cascrolllayerscrollmode/vertically.md) — The receiver is able to scroll vertically.
- [kCAScrollHorizontally](cascrolllayerscrollmode/horizontally.md) — The receiver is able to scroll horizontally.
- [kCAScrollBoth](cascrolllayerscrollmode/both.md) — The receiver is able to scroll both horizontally and vertically.
