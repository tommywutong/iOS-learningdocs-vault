# tileSize

<sub>Instance Property</sub>

The maximum size of each tile used to create the layer’s content.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
var tileSize: CGSize { get set }
```

## Discussion

Defaults to (256.0, 256.0).
