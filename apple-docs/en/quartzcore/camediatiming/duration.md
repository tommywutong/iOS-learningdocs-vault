# duration

<sub>Instance Property</sub>

Specifies the basic duration of the animation, in seconds.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
var duration: CFTimeInterval { get set }
```

## Discussion

Defaults to 0.
