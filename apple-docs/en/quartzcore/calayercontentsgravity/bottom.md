# bottom

<sub>Type Property</sub>

The content is horizontally centered at the bottom-edge of the bounds rectangle.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
static let bottom: CALayerContentsGravity
```
