# P521

<sub>Enumeration</sub>

An elliptic curve that enables NIST P-521 signatures and key agreement.

## Topics

### Performing operations

- [KeyAgreement](p521/keyagreement.md) — A mechanism used to create a shared secret between two users by performing NIST P-521 elliptic curve Diffie Hellman (ECDH) key exchange.
- [Signing](p521/signing.md) — A mechanism used to create or verify a cryptographic signature using the NIST P-521 elliptic curve digital signature algorithm (ECDSA).
