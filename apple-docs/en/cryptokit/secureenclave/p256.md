# SecureEnclave.P256

<sub>Enumeration</sub>

An elliptic curve that enables NIST P-256 signatures and key agreement within the Secure Enclave.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
enum P256
```

## Relationships

- **Conforms To**: [Sendable](../../swift/sendable.md), [SendableMetatype](../../swift/sendablemetatype.md)

## Topics

### Performing operations

- [KeyAgreement](p256/keyagreement.md) — A mechanism used to create a shared secret between two users by performing NIST P-256 elliptic curve Diffie Hellman (ECDH) key exchange within the Secure Enclave.
- [Signing](p256/signing.md) — A mechanism used to create or verify a cryptographic signature using the NIST P-256 elliptic curve digital signature algorithm (ECDSA) within the Secure Enclave.
