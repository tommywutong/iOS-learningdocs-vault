# ControlWidgetButtonDefaultActionLabel

<sub>Structure</sub>

A view representing the default action label for a `ControlWidgetButton` if none is specified.

<sub>iOS, iPadOS, Mac Catalyst, macOS, watchOS</sub>

```swift
@MainActor @preconcurrency struct ControlWidgetButtonDefaultActionLabel
```

## Overview

You don’t initialize this type yourself. Instead WidgetKit will create this type when using a `ControlWidgetButton` initializer that doesn’t provide a label.
