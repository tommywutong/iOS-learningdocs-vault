# removeFontWeight(in:)

<sub>Instance Method</sub>

Removes a font weight from a range of text.

<sub>iOS, iPadOS, Mac Catalyst, macOS</sub>

```swift

```

## Parameters

- `range` — The range from which to remove the style.
