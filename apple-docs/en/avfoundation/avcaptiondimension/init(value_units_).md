# init(value:units:)

<sub>Initializer</sub>

Creates a caption dimension with a value and unit type.

<sub>iOS, iPadOS, Mac Catalyst, macOS</sub>

```swift
init(value: CGFloat, units: AVCaptionUnitsType)
```

## Parameters

- `value` — A floating-point value.

- `units` — The value’s unit type.
