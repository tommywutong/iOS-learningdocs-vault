# AVCaptureDevice.CinematicVideoFocusMode.weak

<sub>Case</sub>

Indicates that the Cinematic Video algorithm should automatically adjust focus according to the prominence of the subjects in the scene.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS</sub>

```swift
case weak
```

## See Also

### Focus modes

- [AVCaptureCinematicVideoFocusModeNone](none.md) — Indicates that no focus mode is specified, in which case weak focus is used as default.
- [AVCaptureCinematicVideoFocusModeStrong](strong.md) — Indicates that the subject should remain in focus until it exits the scene.
