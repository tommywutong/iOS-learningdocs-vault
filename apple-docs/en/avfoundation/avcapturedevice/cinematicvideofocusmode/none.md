# AVCaptureDevice.CinematicVideoFocusMode.none

<sub>Case</sub>

Indicates that no focus mode is specified, in which case weak focus is used as default.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS</sub>

```swift
case none
```

## See Also

### Focus modes

- [AVCaptureCinematicVideoFocusModeStrong](strong.md) — Indicates that the subject should remain in focus until it exits the scene.
- [AVCaptureCinematicVideoFocusModeWeak](weak.md) — Indicates that the Cinematic Video algorithm should automatically adjust focus according to the prominence of the subjects in the scene.
