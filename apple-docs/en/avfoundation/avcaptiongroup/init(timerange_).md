# init(timeRange:)

<sub>Initializer</sub>

Creates a caption group with a time range.

<sub>iOS, iPadOS, Mac Catalyst, macOS</sub>

```swift
init(timeRange: CMTimeRange)
```

## Parameters

- `timeRange` — The time range of the caption group.
