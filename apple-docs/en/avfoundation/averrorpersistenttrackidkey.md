# AVErrorPersistentTrackIDKey

<sub>Global Variable</sub>

The user information key to retrieve the track’s persistent identifier.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
let AVErrorPersistentTrackIDKey: String
```

## Discussion

The associated value is of type [CMPersistentTrackID](../coremedia/cmpersistenttrackid.md).
