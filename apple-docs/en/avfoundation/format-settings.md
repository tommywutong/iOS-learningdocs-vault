# Format settings

The audio settings that apply to all audio formats that the audio player and recorder classes support.

## Topics

### Settings

- [AVFormatIDKey](../avfaudio/avformatidkey.md) — An integer value that represents the format of the audio data.
- [AVSampleRateKey](../avfaudio/avsampleratekey.md) — A floating point value that represents the sample rate, in hertz.
- [AVNumberOfChannelsKey](../avfaudio/avnumberofchannelskey.md) — An integer value that represents the number of channels.
