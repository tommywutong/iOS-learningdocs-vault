# AVCaptureCameraLensSmudgeDetectionStatus.smudged

<sub>Case</sub>

Indicates that the most recent detection found the camera lens to be smudged.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS</sub>

```swift
case smudged
```

### Status values

- [AVCaptureCameraLensSmudgeDetectionStatusDisabled](disabled.md) — Indicates that the detection is not enabled.
- [AVCaptureCameraLensSmudgeDetectionStatusSmudgeNotDetected](smudgenotdetected.md) — Indicates that the most recent detection found no smudge on the camera lens.
