# AVPlayerInterstitialEventAssetListResponseStatus.unavailable

<sub>Case</sub>

Indicates that the asset list response is unavailable.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case unavailable
```

## Discussion

The system is unable to read the `X-ASSET-LIST` response from the stream.

## See Also

### Status values

- [AVPlayerInterstitialEventAssetListResponseStatusAvailable](available.md) — Indicates that a valid asset list response is available.
- [AVPlayerInterstitialEventAssetListResponseStatusCleared](cleared.md) — Indicates that the system cleared the asset list response.
