# AVAssetExportPresetPassthrough

<sub>Global Variable</sub>

A preset to export the asset in its current format, unless otherwise prohibited.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
let AVAssetExportPresetPassthrough: String
```

## Discussion

This option doesn’t show up in the [+ allExportPresets](<avassetexportsession/allexportpresets().md>) and [+ exportPresetsCompatibleWithAsset:](<avassetexportsession/exportpresets(compatiblewith_).md>) methods.
