# init

<sub>Article</sub>

Creates an initialized legible output object.

## Overview

This method will create a properly configured legible output instance.

> [!note] Note
> Using this method is preferred over using the [- initWithMediaSubtypesForNativeRepresentation:](<avplayeritemlegibleoutput/init(mediasubtypesfornativerepresentation_).md>) method.
