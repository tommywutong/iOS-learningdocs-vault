# init(rawValue:)

<sub>Initializer</sub>

Initializes a format with a string value.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(rawValue: UInt)
```

## Parameters

- `rawValue` — A string matching one of the supported Spatialization Formats.
