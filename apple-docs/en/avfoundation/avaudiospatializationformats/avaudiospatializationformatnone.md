# AVAudioSpatializationFormatNone

<sub>Enumeration Case</sub>

A value that indicates the player item doesn’t support audio spatialization.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```objc
AVAudioSpatializationFormatNone
```
