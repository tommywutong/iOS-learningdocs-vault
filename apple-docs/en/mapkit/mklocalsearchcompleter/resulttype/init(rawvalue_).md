# init(rawValue:)

<sub>Initializer</sub>

Creates a direction transport type using a raw unsigned integer value.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(rawValue: UInt)
```

## Parameters

- `rawValue` — The unsigned integer value of the direction transport type.
