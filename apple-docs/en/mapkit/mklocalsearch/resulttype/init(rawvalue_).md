# init(rawValue:)

<sub>Initializer</sub>

Creates a search result type from the provided value.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(rawValue: UInt)
```

## Parameters

- `rawValue` — An unsigned integer that represents the type of the requested search result.
