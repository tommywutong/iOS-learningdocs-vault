# MapItemDetailSelectionAccessoryStyle.CalloutStyle

<sub>Structure</sub>

The style to use for callout content.

<sub>iOS, iPadOS, Mac Catalyst, macOS, visionOS</sub>

```swift
struct CalloutStyle
```

## Overview

Use the [full](calloutstyle/full.md) style works for map views on iPadOS and macOS. Use sheet presentation to display full detail place information on iOS.

## Topics

### Type Properties

- [automatic](calloutstyle/automatic.md) — A value that allows the framework to choose an appropriate callout style automatically.
- [compact](calloutstyle/compact.md) — A compact, space-saving callout style.
- [full](calloutstyle/full.md) — A rich, detailed callout style that is suitable for large map views.
