# PointOfInterestCategories

<sub>Structure</sub>

A structure you use to define points of interest to include or exclude on a map.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
struct PointOfInterestCategories
```

## Relationships

- **Conforms To**: [Copyable](../swift/copyable.md), [Escapable](../swift/escapable.md), [ExpressibleByArrayLiteral](../swift/expressiblebyarrayliteral.md)

## Topics

### Categories to include or exclude

- [all](pointofinterestcategories/all.md) — A list of all points of interest categories, both included and excluded.
- [excludingAll](pointofinterestcategories/excludingall.md) — A list of point of interest categories to exclude from display on the map.

### Modifying the categories to include or exclude

- [excluding(_:)](<pointofinterestcategories/excluding(__)-16bp0.md>) — Show all points of interest except those belonging to certain categories using the array you provide.
- [excluding(_:)](<pointofinterestcategories/excluding(__)-4jo9h.md>) — Show all points of interest except those belonging to certain categories using the list you provide.
- [including(_:)](<pointofinterestcategories/including(__)-22f7x.md>) — Show only points of interest belonging to certain categories from the provided array.
- [including(_:)](<pointofinterestcategories/including(__)-6flda.md>) — Show only points of interest belonging to certain categories from the provided list.
