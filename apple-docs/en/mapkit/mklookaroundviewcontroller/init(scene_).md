# init(scene:)

<sub>Initializer</sub>

Creates a new LookAround view controller with the specified scene.

<sub>iOS, iPadOS, Mac Catalyst, macOS, visionOS</sub>

```swift
init(scene: MKLookAroundScene)
```

## Parameters

- `scene` — A [MKLookAroundScene](../mklookaroundscene.md).
