# init(coder:)

<sub>Initializer</sub>

Creates a new LookAround view controller object from a coder object provided by a storyboard or nib file.

<sub>iOS, iPadOS, Mac Catalyst, macOS, visionOS</sub>

```swift
init?(coder: NSCoder)
```

## Parameters

- `coder` — The [NSCoder](../../foundation/nscoder.md) object
