# init(elevationStyle:)

<sub>Initializer</sub>

Creates a new hybrid map configuration with the specified elevation style.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
convenience init(elevationStyle: MKMapConfiguration.ElevationStyle)
```

## Parameters

- `elevationStyle` — One of the [ElevationStyle](../mkmapconfiguration/elevationstyle-swift.enum.md) elevation styles.

### Creating a hybrid map configuration

- [- init](<init().md>) — Creates a new hybrid map configuration.
