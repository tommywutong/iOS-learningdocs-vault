# init(_:)

<sub>Initializer</sub>

Creates a polygon from the polygon you provide.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(_ polygon: MKPolygon)
```

## Parameters

- `polygon` — An [MKPolygon](../mkpolygon.md) that defines the polygon.

## See Also

### Creating a map polygon

- [init(coordinates:)](<init(coordinates_).md>) — Creates a polygon from a list of coordinates you provide.
- [init(points:)](<init(points_).md>) — Creates a polygon from a list of map points.
