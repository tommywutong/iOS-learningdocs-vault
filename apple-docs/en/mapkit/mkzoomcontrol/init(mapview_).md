# init(mapView:)

<sub>Initializer</sub>

Creates a zoom control and associates it with the specified map view.

<sub>Mac Catalyst, macOS</sub>

```swift
convenience init(mapView: MKMapView?)
```

## Parameters

- `mapView` — The map to associate with the zoom control.
