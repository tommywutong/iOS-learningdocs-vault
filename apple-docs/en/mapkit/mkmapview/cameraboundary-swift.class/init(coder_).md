# init(coder:)

<sub>Initializer</sub>

Creates a camera boundary using the provided coder.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
init?(coder: NSCoder)
```

## Parameters

- `coder` — The decoder to use during initialization.
