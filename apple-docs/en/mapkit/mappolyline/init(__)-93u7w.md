# init(_:)

<sub>Initializer</sub>

Creates a polyline from polyline you provide.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(_ polyline: MKPolyline)
```

## Parameters

- `polyline` — The [MKPolyline](../mkpolyline.md) to convert.
