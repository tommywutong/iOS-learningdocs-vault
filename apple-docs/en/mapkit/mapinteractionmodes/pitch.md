# pitch

<sub>Type Property</sub>

The map allows people to set the map’s pitch to view the map from different angles.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static let pitch: MapInteractionModes
```
