# YES

<sub>Macro</sub>

Defines `YES` as `1`.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```objc
#define YES
```

## Discussion

The `YES` macro from Objective-C is bridged to Swift as an [ObjCBool](objcbool.md) value of `true`.
