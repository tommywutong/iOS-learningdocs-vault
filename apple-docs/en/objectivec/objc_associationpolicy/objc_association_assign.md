# objc_AssociationPolicy.OBJC_ASSOCIATION_ASSIGN

<sub>Case</sub>

Specifies an unsafe unretained reference to the associated object.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case OBJC_ASSOCIATION_ASSIGN
```
