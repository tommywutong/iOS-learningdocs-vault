# Dispatch Function Prototypes

<sub>API Collection</sub>

This macro indicates whether dispatch functions must be cast to an appropriate function pointer type.

## Topics

### Constants

- [OBJC_OLD_DISPATCH_PROTOTYPES](objc_old_dispatch_prototypes.md) — `OBJC_OLD_DISPATCH_PROTOTYPES == 0` enforces the rule that the dispatch functions must be cast to an appropriate function pointer type.
