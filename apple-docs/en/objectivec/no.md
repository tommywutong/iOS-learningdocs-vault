# NO

<sub>Macro</sub>

Defines `NO` as `0`.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```objc
#define NO
```

## Discussion

The `NO` macro from Objective-C is bridged to Swift as an [ObjCBool](objcbool.md) value of `false`.
