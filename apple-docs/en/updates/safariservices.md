### Safari settings export browsing data UI

- Web browsers can present the Export Browsing Data sheet from Safari’s settings using [SFSafariSettings](../safariservices/sfsafarisettings.md) and its [openExportBrowsingDataSettings(completionHandler:)](<../safariservices/sfsafarisettings/openexportbrowsingdatasettings(completionhandler_).md>) method.
