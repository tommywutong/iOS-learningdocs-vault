# FinanceKit updates

<sub>Article</sub>

Learn more about changes to FinanceKit.

## Overview

Browse notable changes in [FinanceKit](../financekit.md).

## June 2024

- Use the FinanceKit API to get access to on device financial data.
- Call `TransactionPicker()` with [FinanceKitUI](../financekitui.md) to display an interface with searchable user transactions.
- Query individual account balances and transactions with [AccountQuery](../financekit/accountquery.md) or track them overtime with `accountHistory()`.
