# Core ML updates

<sub>Article</sub>

Learn about important changes to Core ML.

## Overview

Browse notable changes in [Core ML](../coreml.md).

## June 2024

- Stitch machine learning models and manipulate model inputs and outputs using the [MLTensor](../coreml/mltensor.md) type.
- Add efficient reshaping and transposing to [MLShapedArray](../coreml/mlshapedarray.md).
- Add [Sendable](../swift/sendable.md) conformance to [MLShapedArray](../coreml/mlshapedarray.md) and [MLShapedArraySlice](../coreml/mlshapedarrayslice.md).
- Improve performance with stateful predictions. Store and load state using the [MLState](../coreml/mlstate.md) class.
- Support efficient model adaptation with multifunction ML programs.
- Reduce model size while maintaining accuracy with new compression techniques added to [Core ML Tools 8](https://apple.github.io/coremltools/docs-guides/source/new-features.html).
