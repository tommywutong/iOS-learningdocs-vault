# App Clips updates

<sub>Article</sub>

Learn about important changes in App Clips.

## Overview

Browse notable changes in [App Clips](../appclip.md).

## June 2025

- Make a demo version of your app or game available as an App Clip.
- Use the autogenerated demo URL to offer an App Clip that’s up to 100 MB in size and supports physical invocations.
- Download additional assets for your App Clip with [Background Assets](../backgroundassets.md).
