# container

<sub>Instance Property</sub>

The context’s model container.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
var container: ModelContainer { get }
```

## Discussion

The property provides a reference to the model container you specify when calling the context’s initializer. For more information, see [init(_:)](<init(__).md>).
