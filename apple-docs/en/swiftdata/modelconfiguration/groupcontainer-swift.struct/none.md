# none

<sub>Type Property</sub>

Prevents SwiftData from using a group container as the root location for the app’s persistent storage.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static var none: ModelConfiguration.GroupContainer { get }
```

## See Also

### Getting discovery options

- [automatic](automatic.md) — Tells SwiftData to use the app’s primary group container as the root location for the persistent storage.
- [identifier(_:)](<identifier(__).md>) — Tells SwiftData to use the specified group container as the root location for the app’s persistent storage.
