# CLLocationSpeed

<sub>Type Alias</sub>

The velocity (measured in meters per second) at which the device is moving.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
typealias CLLocationSpeed = Double
```
