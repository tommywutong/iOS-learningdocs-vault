# CLDeviceOrientation.faceUp

<sub>Case</sub>

The device is held parallel to the ground with the screen facing upwards.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case faceUp
```

### Device Orientations

- [CLDeviceOrientationUnknown](unknown.md) — The orientation is currently not known.
- [CLDeviceOrientationPortrait](portrait.md) — The device is in portrait mode, with the device held upright and the home button at the bottom.
- [CLDeviceOrientationPortraitUpsideDown](portraitupsidedown.md) — The device is in portrait mode but upside down, with the device held upright and the home button at the top.
