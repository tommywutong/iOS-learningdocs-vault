# CIParallelogramTile

<sub>Protocol</sub>

The properties you use to configure a parallelogram tile filter.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
protocol CIParallelogramTile : CIFilterProtocol
```

## Topics

### Instance Properties

- [acuteAngle](ciparallelogramtile/acuteangle.md) — The primary angle for the repeating parallelogram tile.
- [angle](ciparallelogramtile/angle.md) — The angle, in radians, of the tiled pattern.
- [center](ciparallelogramtile/center.md) — The x and y position to use as the center of the effect.
- [inputImage](ciparallelogramtile/inputimage.md) — The image to use as an input image.
- [width](ciparallelogramtile/width.md) — The width of a tile.
