# Vector Quantity Attributes

<sub>API Collection</sub>

Vector data types.

## Topics

### Constants

- [kCIAttributeTypePosition](kciattributetypeposition.md) — A two-dimensional location in the working coordinate space. (A 2-element vector type.)
- [kCIAttributeTypeOffset](kciattributetypeoffset.md) — An offset. (A 2-element vector type.)
- [kCIAttributeTypePosition3](kciattributetypeposition3.md) — A three-dimensional location in the working coordinate space. (A 3-element vector type.)
- [kCIAttributeTypeRectangle](kciattributetyperectangle.md) — A Core Image vector that specifies the _x_ and _y_ values of the rectangle origin, and the width (_w_) and height (_h_) of the rectangle. The vector takes the form [_x_, _y_, _w_, _h_]. (A 4-element vector type.)
