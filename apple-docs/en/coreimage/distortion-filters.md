# Distortion Filters

<sub>API Collection</sub>

Apply distortion to images.

## Topics

### Filters

- [+ bumpDistortionFilter](<cifilter-swift.class/bumpdistortion().md>) — Distorts an image with a concave or convex bump.
- [+ bumpDistortionLinearFilter](<cifilter-swift.class/bumpdistortionlinear().md>) — Linearly distorts an image with a concave or convex bump.
- [+ circleSplashDistortionFilter](<cifilter-swift.class/circlesplashdistortion().md>) — Distorts an image with radiating circles to the periphery of the image.
- [+ circularWrapFilter](<cifilter-swift.class/circularwrap().md>) — Distorts an image by increasing the distance of the center of the image.
- [+ displacementDistortionFilter](<cifilter-swift.class/displacementdistortion().md>) — Applies the grayscale values of the second image to the first image.
- [+ drosteFilter](<cifilter-swift.class/droste().md>) — Stylizes an image with the Droste effect.
- [+ glassDistortionFilter](<cifilter-swift.class/glassdistortion().md>) — Distorts an image by applying a glass-like texture.
- [+ glassLozengeFilter](<cifilter-swift.class/glasslozenge().md>) — Creates a lozenge-shaped lens and distorts the image.
- [+ holeDistortionFilter](<cifilter-swift.class/holedistortion().md>) — Distorts an image with a circular area that pushes the image outward.
- [+ lightTunnelFilter](<cifilter-swift.class/lighttunnel().md>) — Distorts an image by generating a light tunnel.
- [+ ninePartStretchedFilter](<cifilter-swift.class/ninepartstretched().md>) — Distorts an image by stretching it between two breakpoints.
- [+ ninePartTiledFilter](<cifilter-swift.class/nineparttiled().md>) — Distorts an image by tiling portions of it.
- [+ pinchDistortionFilter](<cifilter-swift.class/pinchdistortion().md>) — Distorts an image by creating a pinch effect with stronger distortion in the center.
- [+ stretchCropFilter](<cifilter-swift.class/stretchcrop().md>) — Distorts an image by stretching or cropping to fit a specified size.
- [+ torusLensDistortionFilter](<cifilter-swift.class/toruslensdistortion().md>) — Creates a torus-shaped lens to distort the image.
- [+ twirlDistortionFilter](<cifilter-swift.class/twirldistortion().md>) — Distorts an image by rotating pixels around a center point.
- [+ vortexDistortionFilter](<cifilter-swift.class/vortexdistortion().md>) — Distorts an image by using a vortex effect created by rotating pixels around a point.
