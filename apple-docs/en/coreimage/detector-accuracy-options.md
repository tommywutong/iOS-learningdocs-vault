# Detector Accuracy Options

<sub>API Collection</sub>

Value options used to specify the desired accuracy of the detector.

## Topics

### Constants

- [CIDetectorAccuracyLow](cidetectoraccuracylow.md) — Indicates that the detector should choose techniques that are lower in accuracy, but can be processed more quickly.
- [CIDetectorAccuracyHigh](cidetectoraccuracyhigh.md) — Indicates that the detector should choose techniques that are higher in accuracy, even if it requires more processing time.
