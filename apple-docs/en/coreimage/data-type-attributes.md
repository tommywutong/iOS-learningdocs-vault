<sub>API Collection</sub>

## Topics

### Constants

- [kCIAttributeTypeTime](kciattributetypetime.md) — A parametric time for transitions, specified as a floating-point value in the range of `0.0` to `1.0`.
- [kCIAttributeTypeScalar](kciattributetypescalar.md) — A scalar value.
- [kCIAttributeTypeDistance](kciattributetypedistance.md) — A distance.
- [kCIAttributeTypeAngle](kciattributetypeangle.md) — An angle.
- [kCIAttributeTypeBoolean](kciattributetypeboolean.md) — A Boolean value.
- [kCIAttributeTypeInteger](kciattributetypeinteger.md) — An integer value.
- [kCIAttributeTypeCount](kciattributetypecount.md) — A positive integer value.
