# CICheckerboardGenerator

<sub>Protocol</sub>

The properties you use to configure a checkerboard generator filter.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
protocol CICheckerboardGenerator : CIFilterProtocol
```

## Relationships

- **Inherits From**: [CIFilterProtocol](cifilterprotocol.md)

## Topics

### Instance Properties

- [center](cicheckerboardgenerator/center.md) — The center of the effect as x and y coordinates.
- [color0](cicheckerboardgenerator/color0.md) — A color to use for the first set of squares.
- [color1](cicheckerboardgenerator/color1.md) — A color to use for the second set of squares.
- [sharpness](cicheckerboardgenerator/sharpness.md) — The sharpness of the edges in the pattern.
- [width](cicheckerboardgenerator/width.md) — The width of the squares in the pattern.
