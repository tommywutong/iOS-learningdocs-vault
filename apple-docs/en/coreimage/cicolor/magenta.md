# magenta

<sub>Type Property</sub>

Returns a singleton Core Image color instance in the sRGB color space with RGB values `1,0,1` and alpha value `1`.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>
