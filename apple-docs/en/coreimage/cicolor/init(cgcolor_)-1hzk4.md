# init(cgColor:)

<sub>Initializer</sub>

Create a Core Image color object with a Core Graphics color object.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
init(cgColor color: CGColor)
```

## Return Value

An initialized [CIColor](../cicolor.md) instance.
