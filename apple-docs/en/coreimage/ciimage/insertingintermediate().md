# insertingIntermediate()

<sub>Instance Method</sub>

Create an image that inserts a intermediate that is cacheable

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
func insertingIntermediate() -> CIImage
```

## Return Value

An autoreleased [CIImage](../ciimage.md).

## Discussion

This intermediate will be not be cached if [kCIContextCacheIntermediates](../cicontextoption/cacheintermediates.md) is false.
