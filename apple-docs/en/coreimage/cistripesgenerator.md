# CIStripesGenerator

<sub>Protocol</sub>

The properties you use to configure a stripes generator filter.

```swift
protocol CIStripesGenerator : CIFilterProtocol
```

## Topics

### Instance Properties

- [center](cistripesgenerator/center.md) — The x and y position to use as the center of the stripe pattern.
- [color0](cistripesgenerator/color0.md) — A color to use for the odd stripes.
- [color1](cistripesgenerator/color1.md) — A color to use for the even stripes.
- [sharpness](cistripesgenerator/sharpness.md) — The sharpness of the stripe pattern.
- [width](cistripesgenerator/width.md) — The width of a stripe.
