# Generator Filters

<sub>API Collection</sub>

Generate barcode, geometric, and special-effect images.

## Topics

### Filters

- [+ attributedTextImageGeneratorFilter](<cifilter-swift.class/attributedtextimagegenerator().md>) — Generates an attributed-text image.

- [+ QRCodeGenerator](<cifilter-swift.class/qrcodegenerator().md>) — Generates a quick response (QR) code image.

- [+ stripesGeneratorFilter](<cifilter-swift.class/stripesgenerator().md>) — Generates a line of stripes as an image
- [+ sunbeamsGeneratorFilter](<cifilter-swift.class/sunbeamsgenerator().md>) — Generates an image resembling the sun.
- [+ textImageGeneratorFilter](<cifilter-swift.class/textimagegenerator().md>) — Generates a text image.
