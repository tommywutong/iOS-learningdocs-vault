# concentration

<sub>Instance Property</sub>

The size of the spotlight.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
var concentration: Float { get set }
```

## Discussion

The smaller the value, the more tightly focused the light beam.
