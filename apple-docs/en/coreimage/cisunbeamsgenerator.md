# CISunbeamsGenerator

<sub>Protocol</sub>

The properties you use to configure a sunbeams generator filter.

### Instance Properties

- [color](cisunbeamsgenerator/color.md) — The color of the sun.
- [maxStriationRadius](cisunbeamsgenerator/maxstriationradius.md) — The radius of the sunbeams.
