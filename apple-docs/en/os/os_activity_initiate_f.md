# os_activity_initiate_f

<sub>Macro</sub>

Synchronously executes a new activity using the provided function.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```objc
#define os_activity_initiate_f(description, flags, context, function)
```

## Parameters

- `description` — A C string that describes the activity. The description must be a constant string within the calling executable or library.

- `flags` — Flags that define how the activity should be created. See [os_activity_flag_t](os_activity_flag_t.md).

- `context` — A context to pass to the function. This may be `NULL`.

- `function` — A function to call within the context of the given activity. This function must match the signature defined by [os_function_t](os_function_t.md).

## Discussion

This function creates a new activity object implicitly as a child of the current activity object on the current thread. The object persists for the duration of the activity block’s execution.
