# Font Variation Axis Keys

<sub>API Collection</sub>

Keys used for a font variation axis dictionary.

## Topics

### Constants

- [kCGFontVariationAxisName](cgfont/variationaxisname.md) — The key used to obtain the variation axis name from a variation axis dictionary.
- [kCGFontVariationAxisMinValue](cgfont/variationaxisminvalue.md) — The key used to obtain the minimum variation axis value from a variation axis dictionary.
- [kCGFontVariationAxisMaxValue](cgfont/variationaxismaxvalue.md) — The key used to obtain the maximum variation axis value from a variation axis dictionary.
- [kCGFontVariationAxisDefaultValue](cgfont/variationaxisdefaultvalue.md) — The key used to obtain the default variation axis value from a variation axis dictionary.
