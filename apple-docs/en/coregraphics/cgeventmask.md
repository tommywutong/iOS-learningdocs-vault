# CGEventMask

<sub>Type Alias</sub>

Defines a mask that identifies the set of Quartz events to be observed in an event tap.

<sub>Mac Catalyst, macOS</sub>

```swift
typealias CGEventMask = UInt64
```

## Discussion

When you call either [CGEventTapCreate](<cgevent/tapcreate(tap_place_options_eventsofinterest_callback_userinfo_).md>) or [CGEventTapCreateForPSN](<cgevent/tapcreateforpsn(processserialnumber_place_options_eventsofinterest_callback_userinfo_).md>) to register an event tap, you supply a bit mask that identifies the set of events to be observed. You specify each event using one of the event type constants listed in [CGEventType](cgeventtype.md). To form the bit mask, use the `CGEventMaskBit` macro to convert each constant into an event mask and then OR the individual masks together. For example:

```objc
CGEventMask mask = CGEventMaskBit(kCGEventLeftMouseDown) |
                   CGEventMaskBit(kCGEventLeftMouseUp);
```

You can also supply a mask to observe all events:

```objc
CGEventMask mask = kCGEventMaskForAllEvents;
```
