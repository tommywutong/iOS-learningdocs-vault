# CGEventSourceKeyboardType

<sub>Type Alias</sub>

Defines a code that represents the type of keyboard used with a specified event source.

<sub>Mac Catalyst, macOS</sub>

```swift
typealias CGEventSourceKeyboardType = UInt32
```

## Discussion

This code is the same keyboard type identifier used with the [UCKeyTranslate(_:_:_:_:_:_:_:_:_:_:)](../coreservices/1390584-uckeytranslate.md) function to drive keyboard translation.
