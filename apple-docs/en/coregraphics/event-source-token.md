# Event Source Token

<sub>API Collection</sub>

Specifies any input event type.

## Overview

This constant is typically used with the function [CGEventSourceSecondsSinceLastEventType](<cgeventsource/secondssincelasteventtype(__eventtype_).md>) to specify that you want the elapsed time since the last input event of any type.
