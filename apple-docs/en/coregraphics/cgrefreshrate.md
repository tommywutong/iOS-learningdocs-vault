# CGRefreshRate

<sub>Type Alias</sub>

A display’s refresh rate in frames per second.

<sub>Mac Catalyst, macOS</sub>

```swift
typealias CGRefreshRate = Double
```

## Discussion

When requesting a new display mode, you can specify a desired refresh rate as a hint to Quartz. For example, see the function [CGDisplayBestModeForParametersAndRefreshRate](<cgdisplaybestmodeforparametersandrefreshrate(____________).md>).

### Special Considerations

Most applications should never need this data type. Starting in OS X v10.6, the `CGDisplayBestMode` functions are deprecated and the new display mode API does not use this type.
