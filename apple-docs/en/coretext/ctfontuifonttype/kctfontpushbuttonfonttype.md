# kCTFontPushButtonFontType

<sub>Type Property</sub>

The font used for a push button, a rounded rectangular button with a text label on it.

> [!warning] Deprecated
> Use [kCTFontUIFontPushButton](pushbutton.md) instead.

<sub>iOS, iPadOS, Mac Catalyst, macOS, visionOS</sub>

```swift
static var kCTFontPushButtonFontType: CTFontUIFontType { get }
```
