# kCTFontManagerBundleIdentifier

<sub>Global Variable</sub>

<sub>macOS</sub>

```swift
let kCTFontManagerBundleIdentifier: CFString
```

## Discussion

The Font Manager bundle identifier to be used when getting or setting global auto-activation using [CTFontManagerGetAutoActivationSetting](<ctfontmanagergetautoactivationsetting(__).md>) or [CTFontManagerSetAutoActivationSetting](<ctfontmanagersetautoactivationsetting(____).md>).
