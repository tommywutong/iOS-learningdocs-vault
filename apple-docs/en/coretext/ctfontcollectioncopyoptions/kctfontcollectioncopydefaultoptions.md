# kCTFontCollectionCopyDefaultOptions

<sub>Enumeration Case</sub>

Passing this option indicates that defaults are to be used.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```objc
kCTFontCollectionCopyDefaultOptions
```

### Constants

- [kCTFontCollectionCopyUnique](unique.md) — Passing this option indicates that duplicate values should be removed from the results.
