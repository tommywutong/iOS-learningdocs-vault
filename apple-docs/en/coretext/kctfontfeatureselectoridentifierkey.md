# kCTFontFeatureSelectorIdentifierKey

<sub>Global Variable</sub>

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
let kCTFontFeatureSelectorIdentifierKey: CFString
```

## Discussion
