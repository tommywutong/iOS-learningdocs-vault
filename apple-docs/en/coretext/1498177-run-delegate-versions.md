# Run Delegate Versions

<sub>API Collection</sub>

The version of the run delegate.

## Overview

Set the version field of the [CTRunDelegateCallbacks](ctrundelegatecallbacks.md) structure to `kCTRunDelegateCurrentVersion` when creating a CTRunDelegate object with a call to [CTRunDelegateCreate](<ctrundelegatecreate(____).md>).

## Topics

### Constants

- [kCTRunDelegateVersion1](kctrundelegateversion1.md) — Version 1 of the run delegate.
- [kCTRunDelegateCurrentVersion](kctrundelegatecurrentversion.md) — The current version of the run delegate.
