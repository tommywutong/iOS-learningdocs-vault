# mpeg4Audio

<sub>Type Property</sub>

A type that represents an MPEG-4 audio layer file.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static var mpeg4Audio: UTType { get }
```

## Discussion

The identifier for this type is `public.mpeg-4-audio`.

This type conforms to [UTTypeMPEG](../uttypempeg.md) and [UTTypeAudio](../uttypeaudio.md).
