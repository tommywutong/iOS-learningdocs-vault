# version

<sub>Instance Property</sub>

The type’s version, if available.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
var version: Int? { get }
```

## Discussion

Most types don’t have a version.
