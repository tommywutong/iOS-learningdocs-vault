# UTTypeXMLPropertyList

<sub>Global Variable</sub>

## Discussion

The identifier for this type is `com.apple.xml-property-list`.

This type conforms to [UTTypeXML](uttypexml.md) and [UTTypePropertyList](uttypepropertylist.md).
