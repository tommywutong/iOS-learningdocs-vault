# UTTypeMPEG2TransportStream

<sub>Global Variable</sub>

A type that represents data in MPEG-2 transport stream movie format.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```objc
extern UTType * const UTTypeMPEG2TransportStream;
```

## Discussion

The identifier for this type is `public.mpeg-2-transport-stream`.

This type conforms to [UTTypeMovie](uttypemovie.md).
