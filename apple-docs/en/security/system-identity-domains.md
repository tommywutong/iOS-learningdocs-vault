# System Identity Domains

<sub>API Collection</sub>

Set or obtain a system identity for domains.

## Overview

These constants can be used with the [SecIdentitySetSystemIdentity](<secidentitysetsystemidentity(____).md>) and [SecIdentityCopySystemIdentity](<secidentitycopysystemidentity(______).md>) functions.

## Topics

### Constants

- [kSecIdentityDomainDefault](ksecidentitydomaindefault.md) — The system-wide default identity.
- [kSecIdentityDomainKerberosKDC](ksecidentitydomainkerberoskdc.md) — Kerberos Key Distribution Center (KDC) identity.
