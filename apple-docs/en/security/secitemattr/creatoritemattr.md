# SecItemAttr.creatorItemAttr

<sub>Case</sub>

Identifies the creator attribute.

<sub>Mac Catalyst, macOS</sub>

```swift
case creatorItemAttr
```

## Discussion

You use this tag to set or get a value of type `FourCharCode` that represents the item’s creator.
