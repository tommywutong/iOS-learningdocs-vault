# Certificate Item Attribute Constants

<sub>API Collection</sub>

Use these four character values to indicate certificate item attributes.

## Topics

### Constants

- [kSecSubjectItemAttr](ksecsubjectitemattr.md) — DER-encoded subject distinguished name.
- [kSecIssuerItemAttr](ksecissueritemattr.md) — DER-encoded issuer distinguished name.
- [kSecSerialNumberItemAttr](ksecserialnumberitemattr.md) — DER-encoded certificate serial number (without the tag and length).
- [kSecPublicKeyHashItemAttr](ksecpublickeyhashitemattr.md) — Public key hash.
- [kSecSubjectKeyIdentifierItemAttr](ksecsubjectkeyidentifieritemattr.md) — Subject key identifier.
- [kSecCertTypeItemAttr](kseccerttypeitemattr.md) — Certificate type.
- [kSecCertEncodingItemAttr](kseccertencodingitemattr.md) — Certificate encoding.
