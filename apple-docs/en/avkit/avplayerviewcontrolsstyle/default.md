# default

<sub>Type Property</sub>

The view’s default controls style.

<sub>macOS</sub>

```swift
static var `default`: AVPlayerViewControlsStyle { get }
```

## Discussion

The default controls style is [AVPlayerViewControlsStyleInline](inline.md).

## See Also

### Controls Styles

- [AVPlayerViewControlsStyleNone](none.md) — The view displays no playback controls.
- [AVPlayerViewControlsStyleInline](inline.md) — The view displays playback controls in a bar along the view’s bottom edge.
- [AVPlayerViewControlsStyleFloating](floating.md) — The view displays playback controls in a floating window over the video content.
- [AVPlayerViewControlsStyleMinimal](minimal.md) — The view presents basic controls to play and pause playback.
