# AVPlayerViewControlsStyle.floating

<sub>Case</sub>

The view displays playback controls in a floating window over the video content.

<sub>macOS</sub>

```swift
case floating
```

## Discussion

This style matches the look of QuickTime Player’s playback controls.

## See Also

### Controls Styles

- [AVPlayerViewControlsStyleNone](none.md) — The view displays no playback controls.
- [AVPlayerViewControlsStyleInline](inline.md) — The view displays playback controls in a bar along the view’s bottom edge.
- [AVPlayerViewControlsStyleMinimal](minimal.md) — The view presents basic controls to play and pause playback.
- [AVPlayerViewControlsStyleDefault](default.md) — The view’s default controls style.
