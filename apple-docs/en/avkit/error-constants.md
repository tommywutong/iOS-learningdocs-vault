# Error Constants

<sub>API Collection</sub>

Error code constants for framework operations.

## Topics

### Error Code Constants

- [unknown](avkiterror-swift.struct/unknown.md) — An unknown error.
- [contentRatingUnknown](avkiterror-swift.struct/contentratingunknown.md) — The media content rating is missing or unrecognized.
- [contentDisallowedByPasscode](avkiterror-swift.struct/contentdisallowedbypasscode.md) — A restriction disallows access to this content, but the user can override the restriction by entering the device passcode.
- [contentDisallowedByProfile](avkiterror-swift.struct/contentdisallowedbyprofile.md) — An installed profile restricts access to this content.
- [pictureInPictureStartFailed](avkiterror-swift.struct/pictureinpicturestartfailed.md) — The system failed to start Picture in Picture.
