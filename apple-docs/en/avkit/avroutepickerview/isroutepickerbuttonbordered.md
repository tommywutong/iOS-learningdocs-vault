# isRoutePickerButtonBordered

<sub>Instance Property</sub>

A Boolean value that indicates whether the route picker button has a border.

<sub>macOS</sub>

```swift
var isRoutePickerButtonBordered: Bool { get set }
```

## Discussion

The default value is `true`.
