# default

<sub>Type Property</sub>

The view’s default controls style.

<sub>macOS</sub>

```swift
static var `default`: AVCaptureViewControlsStyle { get }
```

## Discussion

The default controls style is [AVCaptureViewControlsStyleInline](inline.md).
