# init(integerLiteral:)

<sub>Initializer</sub>

Creates a constant width or height from an integer.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
nonisolated init(integerLiteral value: Int)
```

## Parameters

- `value` — The width or height.
