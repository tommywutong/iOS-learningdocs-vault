# value(_:_:)

<sub>Type Method</sub>

```swift
static func value(_ labelKey: LocalizedStringKey, _ value: Value) -> PlottableValue<Value>
```

## Parameters

- `labelKey` — The localized string key for label.

- `value` — The parameter’s value.
