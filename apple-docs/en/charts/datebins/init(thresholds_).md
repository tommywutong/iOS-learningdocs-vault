# init(thresholds:)

<sub>Initializer</sub>

Creates N-1 bins with the given N `thresholds`.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
nonisolated init(thresholds: [Date])
```

## Parameters

- `thresholds` — The threshold values that surround the bins.

## Return Value

The bins.
