# Numbers and Basic Values

<sub>API Collection</sub>

Model data with numbers, Boolean values, and other fundamental types.

## Topics

### Logical Values

- [Bool](bool.md) — A value type whose instances are either `true` or `false`.

### Numeric Values

- [Int](int.md) — A signed integer value type.
- [Double](double.md) — A double-precision (64-bit), floating-point value type.
- [Float](float.md) — A single-precision (32-bit), floating-point value type.

### Ranges

- [Range](range.md) — A half-open interval from a lower bound up to, but not including, an upper bound.
- [ClosedRange](closedrange.md) — An interval from a lower bound up to, and including, an upper bound.

### Errors

- [Error](error.md) — A type representing an error value that can be thrown.
- [Result](result.md) — A value that represents either a success or a failure, including an associated value in each case.

### Optionals

- [Optional](optional.md) — A type that represents either a wrapped value or the absence of a value.

### Advanced Numerics

- [Numeric Protocols](numeric-protocols.md) — Write generic code that works with any numeric type.
- [Special-Use Numeric Types](special-use-numeric-types.md) — Work with fixed-width numeric types of different sizes.
- [SIMD Vector Types](simd-vector-types.md) — Work with fixed-width vectors of fixed-width numeric types of different sizes.
- [Global Numeric Functions](global-numeric-functions.md) — Use these functions with numeric values and other comparable types.

### Random Number Generators

- [SystemRandomNumberGenerator](systemrandomnumbergenerator.md) — The system’s default source of random data.
- [RandomNumberGenerator](randomnumbergenerator.md) — A type that provides uniformly distributed random data.
