# init(_:)

<sub>Initializer</sub>

Creates an instance equal to the given Boolean value.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(_ value: Bool)
```

## Parameters

- `value` — The Boolean value to copy.
