# .\>(_:_:)

<sub>Operator</sub>

Pointwise compare greater than.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static func .> (a: Scalar, b: SIMD64<Scalar>) -> SIMDMask<SIMD64<Scalar>.MaskStorage>
```

## Discussion

Each lane of the result is true if a is greater than the corresponding lane of b, and false otherwise.

Equivalent to:

```swift
var result = SIMDMask<MaskStorage>()
for i in 0..<64 {
  result[i] = (a > b[i])
}
```
