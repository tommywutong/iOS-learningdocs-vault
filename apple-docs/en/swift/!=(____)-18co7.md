# !=(_:_:)

<sub>Operator</sub>

Returns a Boolean value indicating whether any corresponding components of the two tuples are not equal.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
func != (lhs: (), rhs: ()) -> Bool
```

## Parameters

- `lhs` — An empty tuple.

- `rhs` — An empty tuple.

## Discussion

All arity zero tuples are equal.
