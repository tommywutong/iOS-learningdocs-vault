# name

<sub>Instance Property</sub>

The name of this capture, if the capture is named.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
var name: String? { get }
```

## Discussion

If the capture is unnamed, `name` is `nil`.
