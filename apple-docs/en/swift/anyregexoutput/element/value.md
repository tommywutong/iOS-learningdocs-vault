# value

<sub>Instance Property</sub>

The captured value, if there was a capture.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
var value: Any? { get }
```

## Discussion

If nothing was captured, `value` is `nil`.
