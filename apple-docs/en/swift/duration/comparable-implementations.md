### Operators

- [...(_:)](<'...(__)-1a3h.md>) — Returns a partial range up to, and including, its upper bound.
- [...(_:)](<'...(__)-9h7ny.md>) — Returns a partial range extending upward from a lower bound.
- [...(_:_:)](<'...(____).md>) — Returns a closed range that contains both of its bounds.
- [..\<(_:)](<'.._(__).md>) — Returns a partial range up to, but not including, its upper bound.
- [..\<(_:_:)](<'.._(____).md>) — Returns a half-open range that contains its lower bound but not its upper bound.
- [\>(_:_:)](<_(____)-17kzb.md>) — Returns a Boolean value indicating whether the value of the first argument is greater than that of the second argument.

- [\<=(_:_:)](<_=(____)-xlnf.md>) — Returns a Boolean value indicating whether the value of the first argument is less than or equal to that of the second argument.
