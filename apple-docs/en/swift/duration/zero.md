# zero

<sub>Type Property</sub>

The zero value.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static var zero: Duration { get }
```

## Discussion

Zero is the identity element for addition. For any value, `x + .zero == x` and `.zero + x == x`.
