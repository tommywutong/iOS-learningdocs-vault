# ...(_:)

<sub>Operator</sub>

Creates an unbounded range expression.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static func ... (_: UnboundedRange_)
```

## Discussion

The unbounded range operator (`...`) is valid only within a collection’s subscript.
