# init(_:)

<sub>Initializer</sub>

Creates an instance containing just the given element.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(_ element: Element)
```

## Parameters

- `element` — The element to store in the collection.
