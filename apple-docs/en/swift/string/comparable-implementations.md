### Operators

- [...(_:)](<'...(__)-4mm4o.md>) — Returns a partial range up to, and including, its upper bound.
- [...(_:)](<'...(__)-6ct5g.md>) — Returns a partial range extending upward from a lower bound.
- [...(_:_:)](<'...(____).md>) — Returns a closed range that contains both of its bounds.
- [..\<(_:)](<'.._(__).md>) — Returns a partial range up to, but not including, its upper bound.
- [..\<(_:_:)](<'.._(____).md>) — Returns a half-open range that contains its lower bound but not its upper bound.
- [\<(_:_:)](<_(____).md>) — Returns a Boolean value indicating whether the value of the first argument is less than that of the second argument.
- [\>(_:_:)](<_(____)-3izr3.md>) — Returns a Boolean value indicating whether the value of the first argument is greater than that of the second argument.
- [\<=(_:_:)](<_=(____)-5i1qy.md>) — Returns a Boolean value indicating whether the value of the first argument is less than or equal to that of the second argument.
- [\>=(_:_:)](<_=(____)-5nvya.md>) — Returns a Boolean value indicating whether the value of the first argument is greater than or equal to that of the second argument.
