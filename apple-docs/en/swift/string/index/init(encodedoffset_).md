# init(encodedOffset:)

<sub>Initializer</sub>

Creates a new index at the specified code unit offset.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(encodedOffset offset: Int)
```

## Parameters

- `offset` — An offset in code units.
