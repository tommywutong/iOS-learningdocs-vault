# .|(_:_:)

<sub>Operator</sub>

A vector mask that is the pointwise logical disjunction of the inputs.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static func .| (a: SIMDMask<Storage>, b: SIMDMask<Storage>) -> SIMDMask<Storage>
```

## Discussion

Equivalent to:

```swift
var result = SIMDMask<SIMD64<Int32>>()
for i in result.indices {
  result[i] = a[i] || b[i]
}
```

Note that unlike the scalar `||` operator, the SIMD `.|` operator always fully evaluates both arguments.
