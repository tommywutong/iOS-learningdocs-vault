# .&=(_:_:)

<sub>Operator</sub>

Replaces `a` with the pointwise logical conjunction of `a` and `b`.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static func .&= (a: inout SIMDMask<Storage>, b: Bool)
```

## Discussion

Equivalent to:

```swift
if !b { a = SIMDMask(repeating: false) }
```
