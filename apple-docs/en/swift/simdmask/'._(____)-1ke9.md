# .^(_:_:)

<sub>Operator</sub>

A vector mask that is the pointwise exclusive or of the inputs.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static func .^ (a: Bool, b: SIMDMask<Storage>) -> SIMDMask<Storage>
```

## Discussion

Equivalent to `a ? .!b : b`.
