# .|=(_:_:)

<sub>Operator</sub>

Replaces `a` with the pointwise logical disjunction of `a` and `b`.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static func .|= (a: inout SIMDMask<Storage>, b: SIMDMask<Storage>)
```

## Discussion

Equivalent to:

```swift
for i in a.indices {
  a[i] = a[i] || b[i]
}
```
