# init()

<sub>Initializer</sub>

Creates an empty option set.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init()
```

## Discussion

This initializer creates an option set with a raw value of zero.
