# Binary Integer Operators

<sub>API Collection</sub>

Perform arithmetic and bitwise operations or compare values.

## Topics

### Arithmetic

- [+(_:_:)](<binaryinteger/+(____).md>) — Adds two values and produces their sum.
- [-(_:_:)](<binaryinteger/-(____).md>) — Subtracts one value from another and produces their difference.
- [*(_:_:)](<binaryinteger/_(____).md>) — Multiplies two values and produces their product.
- [/(_:_:)](<binaryinteger/_(____)-8zc6l.md>) — Returns the quotient of dividing the first value by the second.

### Arithmetic with Assignment

- [+=(_:_:)](<binaryinteger/+=(____).md>) — Adds two values and stores the result in the left-hand-side variable.
- [-=(_:_:)](<binaryinteger/-=(____).md>) — Subtracts the second value from the first and stores the difference in the left-hand-side variable.
- [*=(_:_:)](<binaryinteger/_=(____).md>) — Multiplies two values and stores the result in the left-hand-side variable.
- [/=(_:_:)](<binaryinteger/_=(____)-20xv1.md>) — Divides the first value by the second and stores the quotient in the left-hand-side variable.

### Bitwise Operations

- [&(_:_:)](<binaryinteger/&(____).md>) — Returns the result of performing a bitwise AND operation on the two given values.
- [&=(_:_:)](<binaryinteger/&=(____).md>) — Stores the result of performing a bitwise AND operation on the two given values in the left-hand-side variable.
- [~(_:)](<binaryinteger/~(__).md>) — Returns the inverse of the bits set in the argument.

### Comparison

- [!=(_:_:)](<binaryinteger/!=(____)-9ooa7.md>) — Returns a Boolean value indicating whether the two given values are not equal.
- [!=(_:_:)](<binaryinteger/!=(____)-4ljme.md>) — Returns a Boolean value indicating whether two values are not equal.
