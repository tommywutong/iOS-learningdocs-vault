# .\<(_:_:)

<sub>Operator</sub>

Pointwise compare less than.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static func .< (a: SIMD32<Scalar>, b: SIMD32<Scalar>) -> SIMDMask<SIMD32<Scalar>.MaskStorage>
```

## Discussion

Each lane of the result is true if that lane of a is less than the corresponding lane of b, and false otherwise.

Equivalent to:

```swift
var result = SIMDMask<MaskStorage>()
for i in 0..<32 {
  result[i] = (a[i] < b[i])
}
```
