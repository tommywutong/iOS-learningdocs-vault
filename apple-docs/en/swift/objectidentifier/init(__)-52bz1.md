# init(_:)

<sub>Initializer</sub>

Creates an instance that uniquely identifies the given metatype.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(_ x: any (~Copyable & ~Escapable).Type)
```

## Parameters

- `x` — A metatype.
