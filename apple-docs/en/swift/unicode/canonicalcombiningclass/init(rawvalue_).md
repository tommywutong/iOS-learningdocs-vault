# init(rawValue:)

<sub>Initializer</sub>

Creates a new canonical combining class with the given raw integer value.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(rawValue: UInt8)
```

## Parameters

- `rawValue` — The raw integer value of the canonical combining class.
