# Unicode.GeneralCategory.letterNumber

<sub>Case</sub>

## Discussion

This value corresponds to the category `Letter_Number` (abbreviated `Nl`) in the [Unicode Standard](https://unicode.org/reports/tr44/#General_Category_Values).
