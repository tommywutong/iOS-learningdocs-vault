# lowerBound

<sub>Instance Property</sub>

The range’s lower bound.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
let lowerBound: Bound
```

## Discussion

In an empty range, `lowerBound` is equal to `upperBound`.
