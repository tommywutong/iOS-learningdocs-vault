# .\>(_:_:)

<sub>Operator</sub>

Pointwise compare greater than.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static func .> (a: SIMD2<Scalar>, b: SIMD2<Scalar>) -> SIMDMask<SIMD2<Scalar>.MaskStorage>
```

## Discussion

Each lane of the result is true if that lane of a is greater than the corresponding lane of b, and false otherwise.

Equivalent to:

```swift
var result = SIMDMask<MaskStorage>()
for i in 0..<2 {
  result[i] = (a[i] > b[i])
}
```
