# init(range:)

<sub>Initializer</sub>

Create a single selection with a given range.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(range: Range<String.Index>)
```

## Parameters

- `range` — A range of `String.Index` representing the selection.
