# Body

<sub>Associated Type</sub>

The type of effect representing the body of this effect. When you create a custom effect, Swift infers this type from your implementation of the required [body(content:)](<body(content_).md>) method.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
associatedtype Body : CustomHoverEffect
```
