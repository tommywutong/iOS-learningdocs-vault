# automatic

<sub>Type Property</sub>

An effect  that attempts to determine the effect automatically. This is the default effect.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
static var automatic: HoverEffect { get }
```
