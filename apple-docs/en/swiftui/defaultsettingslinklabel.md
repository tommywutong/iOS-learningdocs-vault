# DefaultSettingsLinkLabel

<sub>Structure</sub>

The default label to use for a settings link.

<sub>macOS</sub>

```swift
nonisolated struct DefaultSettingsLinkLabel
```

## Overview

You don’t use this type directly. Instead, the system creates it automatically when you construct a [SettingsLink](settingslink.md) with the default label.
