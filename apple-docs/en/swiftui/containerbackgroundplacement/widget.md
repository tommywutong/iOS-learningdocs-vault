# widget

<sub>Type Property</sub>

The container background placement for a widget.

<sub>iOS, iPadOS, Mac Catalyst, macOS, visionOS, watchOS</sub>

```swift
static let widget: ContainerBackgroundPlacement
```

## Discussion

Pass the container background placement to the [containerBackground(_:for:)](<../view/containerbackground(__for_).md>) function to configure the background of your widgets.
