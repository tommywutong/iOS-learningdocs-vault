# BorderedTableStyle

<sub>Structure</sub>

The table style that describes the behavior and appearance of a table with standard border.

<sub>macOS</sub>

```swift
nonisolated struct BorderedTableStyle
```

## Overview

You can also use [bordered](tablestyle/bordered.md) to construct this style.
