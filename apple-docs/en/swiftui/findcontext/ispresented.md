# isPresented

<sub>Instance Property</sub>

A binding controlling if the find navigator is presented, or nil if no binding has been provided via the [findNavigator(isPresented:)](<../view/findnavigator(ispresented_).md>) modifier.

<sub>iOS, iPadOS, Mac Catalyst, macOS, visionOS</sub>

```swift
var isPresented: Binding<Bool>?
```
