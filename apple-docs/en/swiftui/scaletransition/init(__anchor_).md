# init(_:anchor:)

<sub>Initializer</sub>

Creates a transition that scales the view by the specified amount.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
nonisolated init(_ scale: Double, anchor: UnitPoint = .center)
```
