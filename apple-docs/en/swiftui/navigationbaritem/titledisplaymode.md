# NavigationBarItem.TitleDisplayMode

<sub>Enumeration</sub>

A style for displaying the title of a navigation bar.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```swift
enum TitleDisplayMode
```

## Overview

Use one of these values with the [navigationBarTitleDisplayMode(_:)](<../view/navigationbartitledisplaymode(__).md>) view modifier to configure the title of a navigation bar.
