# NavigationBarItem

<sub>Structure</sub>

A configuration for a navigation bar that represents a view at the top of a navigation stack.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```swift
struct NavigationBarItem
```

## Overview

Use one of the [TitleDisplayMode](navigationbaritem/titledisplaymode.md) values to configure a navigation bar title’s display mode with the [navigationBarTitleDisplayMode(_:)](<view/navigationbartitledisplaymode(__).md>) view modifier.
