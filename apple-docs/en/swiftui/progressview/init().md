# init()

<sub>Initializer</sub>

Creates a progress view for showing indeterminate progress, without a label.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
nonisolated init() where Label == EmptyView
```
