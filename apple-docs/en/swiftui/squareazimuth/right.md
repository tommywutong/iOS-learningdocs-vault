# SquareAzimuth.right

<sub>Case</sub>

Has an orientation with an horizontal angle equal to `90°`.

<sub>visionOS</sub>

```swift
case right
```

## Discussion

The continuous input azimuth is `≥ 45°` and `< 135°`.
