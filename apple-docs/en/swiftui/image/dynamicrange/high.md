# high

<sub>Type Property</sub>

Allow image content to use an unrestricted extended range.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS</sub>

```swift
static let high: Image.DynamicRange
```

## See Also

### Getting dynamic range values

- [standard](standard.md) — Restrict the image content dynamic range to the standard range.
- [constrainedHigh](constrainedhigh.md) — Allow image content to use some extended range. This is appropriate for placing HDR content next to SDR content.
