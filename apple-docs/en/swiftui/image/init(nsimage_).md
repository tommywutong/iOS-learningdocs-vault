# init(nsImage:)

<sub>Initializer</sub>

Creates a SwiftUI image from an AppKit image instance.

<sub>macOS</sub>

```swift
nonisolated init(nsImage: NSImage)
```

## Parameters

- `nsImage` — The AppKit image to wrap with a SwiftUI [Image](../image.md). instance.
