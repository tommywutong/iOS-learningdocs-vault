# Image.Interpolation.medium

<sub>Case</sub>

A value that indicates a medium level of interpolation quality, between the low- and high-quality values.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case medium
```

## See Also

### Getting interpolation options

- [Image.Interpolation.high](high.md) — A value that indicates a high level of interpolation quality, which may slow down image rendering.
- [Image.Interpolation.low](low.md) — A value that indicates a low level of interpolation quality, which may speed up image rendering.
- [Image.Interpolation.none](none.md) — A value that indicates SwiftUI doesn’t interpolate image data.
