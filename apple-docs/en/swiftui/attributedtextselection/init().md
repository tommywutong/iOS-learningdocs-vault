# init()

<sub>Initializer</sub>

Initialize the default selection for a new text editor.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init()
```

## Discussion

The default selection is an insertion point at the end of the text.
