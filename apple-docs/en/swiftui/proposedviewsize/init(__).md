# init(_:)

<sub>Initializer</sub>

Creates a new proposed size from a specified size.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(_ size: CGSize)
```

## Parameters

- `size` — A proposed size with dimensions measured in points.
