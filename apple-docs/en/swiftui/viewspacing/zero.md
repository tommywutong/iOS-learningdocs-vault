# zero

<sub>Type Property</sub>

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static let zero: ViewSpacing
```

## Discussion

You typically only use this value for an empty view.
