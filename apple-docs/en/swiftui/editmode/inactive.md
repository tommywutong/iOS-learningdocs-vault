# EditMode.inactive

<sub>Case</sub>

The user can’t edit the view content.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case inactive
```

## Discussion

The [isEditing](isediting.md) property is `false` in this state.

## See Also

### Getting edit modes

- [EditMode.active](active.md) — The user can edit the view content.
