# EditMode.active

<sub>Case</sub>

The user can edit the view content.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
case active
```

## Discussion

The [isEditing](isediting.md) property is `true` in this state.
