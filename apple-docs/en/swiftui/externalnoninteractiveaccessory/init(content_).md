# init(content:)

<sub>Initializer</sub>

Creates a scene accessory that presents non-interactive content on an external display.

<sub>iOS, iPadOS, Mac Catalyst</sub>

```swift
nonisolated init(@ContentBuilder content: @escaping () -> Content)
```

## Parameters

- `content` — The scene’s content.
