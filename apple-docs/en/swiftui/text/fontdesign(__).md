# fontDesign(_:)

<sub>Instance Method</sub>

Sets the font design of the text.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
nonisolated func fontDesign(_ design: Font.Design?) -> Text
```

## Parameters

- `design` — One of the available font designs.

## Return Value

Text that uses the font design you specify.

### Choosing a font

- [font(_:)](<font(__).md>) — Sets the default font for text in the view.
- [fontWeight(_:)](<fontweight(__).md>) — Sets the font weight of the text.
- [fontWidth(_:)](<fontwidth(__).md>) — Sets the font width of the text.
