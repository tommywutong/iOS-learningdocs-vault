# Text.Case.lowercase

<sub>Case</sub>

Displays text in all lowercase characters.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case lowercase
```

## Discussion

For example, “Hello” would be displayed as “hello”.

> `StringProtocol.lowercased(with:)`
