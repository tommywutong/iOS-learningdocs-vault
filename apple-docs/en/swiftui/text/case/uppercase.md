# Text.Case.uppercase

<sub>Case</sub>

Displays text in all uppercase characters.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case uppercase
```

## Discussion

For example, “Hello” would be displayed as “HELLO”.

> [!info] See Also
> `StringProtocol.uppercased(with:)`
