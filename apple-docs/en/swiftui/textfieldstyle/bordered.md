# bordered

<sub>Type Property</sub>

A text field style with a system-defined border whose shape is determined by the [textInputBorderShape(_:)](<../view/textinputbordershape(__).md>) modifier.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
@export(implementation) static var bordered: BorderedTextFieldStyle { get }
```
