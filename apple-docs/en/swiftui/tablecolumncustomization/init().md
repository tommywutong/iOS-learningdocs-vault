# init()

<sub>Initializer</sub>

Creates an empty table column customization.

<sub>iOS, iPadOS, Mac Catalyst, macOS, visionOS</sub>

```swift
init()
```

## Discussion

With an empty customization, columns will be ordered as described by the table’s column builder.
