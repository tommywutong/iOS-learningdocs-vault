# automatic

<sub>Type Property</sub>

A shape that defers to the system to determine an appropriate shape for the given context and platform.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static let automatic: ButtonBorderShape
```

## Discussion

Use the [buttonBorderShape(_:)](<../view/buttonbordershape(__).md>) view modifier to apply the shape to bordered buttons within a view hierarchy.
