# init(edge:)

<sub>Initializer</sub>

Creates a transition that moves the view away, towards the specified edge of the view.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
nonisolated init(edge: Edge)
```
