# UnifiedCompactWindowToolbarStyle

<sub>Structure</sub>

A window toolbar style similar to [unified](windowtoolbarstyle/unified.md), but with a more compact vertical sizing.

## Overview

You can also use [unifiedCompact](windowtoolbarstyle/unifiedcompact.md) or [unifiedCompact(showsTitle:)](<windowtoolbarstyle/unifiedcompact(showstitle_).md>) to construct this style.
