# init(initialValue:repeating:content:keyframes:)

<sub>Initializer</sub>

Loops the given keyframes continuously, updating the view using the modifiers you apply in `body`.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
nonisolated init(initialValue: Value, repeating: Bool = true, @ContentBuilder content: @escaping (Value) -> Content, @KeyframesBuilder<Value> keyframes: @escaping (Value) -> KeyframePath)
```

## Parameters

- `initialValue` — The initial value that the keyframes will animate from.

- `repeating` — Whether the keyframes are currently repeating. If false, the value at the beginning of the keyframe timeline will be provided to the content closure.

- `content` — A content builder closure that takes the interpolated value generated by the keyframes as its single argument.

- `keyframes` — Keyframes defining how the value changes over time. The current value of the animator is the single argument, which is equal to `initialValue` when the view first appears, then is equal to the end value of the previous keyframe animation on subsequent calls.

## Discussion

Note that the `content` closure will be updated on every frame while animating, so avoid performing any expensive operations directly within `content`.
