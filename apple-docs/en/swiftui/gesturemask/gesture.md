# gesture

<sub>Type Property</sub>

Enable the added gesture but disable all gestures in the subview hierarchy.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
static let gesture: GestureMask
```

## See Also

### Getting gesture options

- [all](all.md) — Enable both the added gesture as well as all other gestures on the view and its subviews.
- [subviews](subviews.md) — Enable all gestures in the subview hierarchy but disable the added gesture.
- [none](none.md) — Disable all gestures in the subview hierarchy, including the added gesture.
