# ControlSize.extraLarge

<sub>Case</sub>

A control version that is substantially sized. The largest control size. Resolves to [ControlSize.large](large.md) on platforms other than visionOS.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case extraLarge
```

## See Also

### Getting control sizes

- [ControlSize.mini](mini.md) — A control version that is minimally sized.
- [ControlSize.small](small.md) — A control version that is proportionally smaller size for space-constrained views.
- [ControlSize.regular](regular.md) — A control version that is the default size.
- [ControlSize.large](large.md) — A control version that is prominently sized.
