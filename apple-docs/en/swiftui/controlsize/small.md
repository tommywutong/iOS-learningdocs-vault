# ControlSize.small

<sub>Case</sub>

A control version that is proportionally smaller size for space-constrained views.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
case small
```

## See Also

### Getting control sizes

- [ControlSize.mini](mini.md) — A control version that is minimally sized.
- [ControlSize.regular](regular.md) — A control version that is the default size.
- [ControlSize.large](large.md) — A control version that is prominently sized.
- [ControlSize.extraLarge](extralarge.md) — A control version that is substantially sized. The largest control size. Resolves to [ControlSize.large](large.md) on platforms other than visionOS.
