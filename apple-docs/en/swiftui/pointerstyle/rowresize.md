# rowResize

<sub>Type Property</sub>

The pointer style for resizing a row, or horizontal division, in either direction.

<sub>macOS</sub>

```swift
static let rowResize: PointerStyle
```

## Discussion

You may apply this pointer style to a single view or a view hierarchy using the [pointerStyle(_:)](<../view/pointerstyle(__).md>) modifier.
