# init(all:)

<sub>Initializer</sub>

Create corner styles with all corner having the same style.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(all: Edge.Corner.Style)
```

## Parameters

- `all` — Corner style for all corners.
