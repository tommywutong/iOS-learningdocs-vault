# init(_:)

<sub>Initializer</sub>

Creates a localized string key from the given string value.

<sub>iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS, watchOS</sub>

```swift
init(_ value: String)
```

## Parameters

- `value` — The string to use as a localization key.
