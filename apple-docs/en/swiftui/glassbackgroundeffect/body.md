# Body

<sub>Associated Type</sub>

The type of effect representing the body of this effect. When you create a custom effect, Swift infers this type from your implementation of the required [makeBody(configuration:)](<makebody(configuration_).md>) method.

```swift
associatedtype Body : GlassBackgroundEffect
```
