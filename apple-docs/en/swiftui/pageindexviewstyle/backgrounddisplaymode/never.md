# never

<sub>Type Property</sub>

Background is never displayed behind the page index view.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS, watchOS</sub>

```swift
static let never: PageIndexViewStyle.BackgroundDisplayMode
```

### Getting the display modes

- [automatic](automatic.md) — Background will use the default for the platform.
- [always](always.md) — Background is always displayed behind the page index view.
- [interactive](interactive.md) — Background is only shown while the index view is interacted with.
