# always

<sub>Type Property</sub>

Background is always displayed behind the page index view.

<sub>iOS, iPadOS, Mac Catalyst, tvOS, visionOS</sub>

```swift
static let always: PageIndexViewStyle.BackgroundDisplayMode
```

## See Also

### Getting the display modes

- [automatic](automatic.md) — Background will use the default for the platform.
- [interactive](interactive.md) — Background is only shown while the index view is interacted with.
- [never](never.md) — Background is never displayed behind the page index view.
